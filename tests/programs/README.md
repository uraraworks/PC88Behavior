# tests/programs — ゴールAの代表プログラム集（下書き）

ここに置く8本は、いずれも自分で書いたN88-BASICのプログラムであり、
マニュアルの例題・雑誌掲載プログラム等を写したものではない（禁止事項2・
著作物の複製の回避）。**使っている機能は、仕様書
`docs/spec/l4-basic.md`（第3.7版）・`docs/spec/l4-program.md`（第5版、
`198d023`）で観測済みのものだけに限定している。** 英字はすべて小文字で
書いている（打鍵注入は小文字で届く、[l4-basic.md](../../docs/spec/l4-basic.md)
「器具の確認」節）。

これらは後の適合テストの場面（`l4-c5`想定、事前登録→公式ROMで期待値
〔非空白セルの件数とSHA-256のみ〕→自作と照合）で使う候補であり、本コミット
では下書きの位置づけ（実際に公式ROM・自作ROMで走らせて確認する作業は、
この下書きの担当範囲外とする）。

## 画面の命令（CLS・LOCATE・COLOR・WIDTH）を使う版について

**8本のいずれも画面の命令を使っていない。** `CLS`・`LOCATE`・`COLOR`・
`WIDTH`は本版時点で未測定（[l4-program.md](../../docs/spec/l4-program.md)
第6節・23番）であり、「使ってよい機能は観測済みのものだけ」という制約
から今回は除外した。画面の命令を使う版は、測定が済んでから別ディレクトリ
（例: `tests/programs/screen/`）に分け、ファイル名にも分かる印
（例: `s01_..._screen.bas`）を付けて追加する方針とする。

## 出力の収まり方（各プログラム共通）

- いずれも出力は画面1枚（20行）に収まり、80桁の折り返しを超える行は
  無い（数値の幅は最大でも十数桁、`p04`・`p05`のように多数の値を
  `;`で並べる場合も自動折り返しで数行に収まる）。
- いずれも有限回のループで終了し、無限ループは無い。実行の最後には
  `RUN`後の並び（[l4-program.md](../../docs/spec/l4-program.md) 4.1節、
  出力→`Ok`）どおり`Ok`が出る。
- 打鍵1行はいずれも70文字以内（実際には最大でも30文字程度）、行数も
  最大`p03`の20行にとどまる。

## 使わなかった機能・避けた理由

- **`RND`**: 未測定のため使わない。乱数を使う代わりに、`p08`の
  `INPUT`は打つ値をあらかじめ決めて固定した（依頼文の方針どおり）。
- **`READ`/`DATA`**: 観測済みの一覧に無いため使わず、`p03`の配列の
  初期値は代入文（`a(1)=5`等、観測済み）で設定した。
- **`IF`の`THEN`に代入文を直接書く形**（例: `IF x THEN y=0`）: 観測
  されているのは`THEN`の後が`PRINT`文か行番号の場合だけ
  （[l4-program.md](../../docs/spec/l4-program.md) 4.7節）なので、
  `p02`・`p03`では`THEN`の後を必ず行番号にし、代入はその行番号の
  行で別途行うようにした。
- **`CLS`・`LOCATE`・`COLOR`・`WIDTH`**: 未測定のため使わない（上記
  「画面の命令を使う版について」参照）。
- **`PRINT USING`**: 未測定のため使わない。すべて素の`PRINT`。
- **`CHR$`・`INKEY$`・`STRING$`・`SPACE$`**: 未測定のため使わない。
  文字列関数は`MID$`・`LEN`・`LEFT$`・`RIGHT$`・`STR$`・`VAL`・`+`結合
  （いずれも[l4-program.md](../../docs/spec/l4-program.md) 4.14節で
  観測済み）にとどめた。
- **整数変数（`%`）への範囲外代入**: 整数変数への小数の丸め（4.4b節）
  は観測済みだが、整数の範囲を超える値を`%`変数へ代入したときの挙動は
  未測定のため、`p04`・`p05`の桁あふれの実演には`%`を使わず、無印
  （単精度）変数と`#`（倍精度）変数だけを使った。
- **`FOR`の境界に式を書く形**（例: `FOR j=1 TO 6-i`のような可変上限）:
  観測されている`FOR`の範囲は定数・単純な変数のみで、式を境界に使う形
  は明示的には確認されていないため、`p03`の内側ループは`FOR j=1 TO 5`
  固定にした（範囲を絞らない分、比較回数は増えるが、バブルソートの
  正しさそのものには影響しない）。
- **配列の添字の下限確認**: `p03`は宣言・使用とも添字`1`〜`6`のみを
  使い、添字`0`の動作確認が必要な形は避けた（添字の下限は未確定、
  [l4-program.md](../../docs/spec/l4-program.md) 第6節・12番）。
