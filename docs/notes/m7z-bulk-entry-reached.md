# m7z: 高速バルク入口到達とデータ列分岐

測定日: 2026-08-13

第一実装診断に従い、交換#14累積12件目の通常RECV完遂直後へ入口5フェーズを
移した第二実装を、公式環境と公式main＋自作subで各1800フレーム再測定した。
値比較は`tools/cmp_io.py --location-only`の内部だけで行い、値を表示せず、比較後の
両ログは`tools/redact_iolog.py`でデータポート値を伏せた。

## 4指標

- main `IN $FC`値一致プレフィックス: 779件（変化なし）
- main構造一致プレフィックス: 258件（変化なし）
- sub構造一致プレフィックス: 752件（変化なし）
- 混成main `IN $FD`: 0件から3601件へ前進

高速バルク入口は成立し、混成mainが`IN $FD`を開始した。公式期待5635件との値比較は
先頭から0件一致で、混成側は3601件でバルクから離脱した。現在流しているのは既存の
1セクタFDCバッファの反復であり、交換#14が累積7/11件境界で行う5回のREAD DATAを
まだ実装していないためである。

次に必要なのは、その5回のREAD DATAの座標生成規則と、読み取ったデータを連結する
規則である。仕様第43版の測定では要求内の同値候補が複数残り生成式は未確定であり、
これ以上の決定にはデータポートの要求値そのものが必要になる。停止条件に従い、
ブラックボックス値探索や推測座標による実装は行わない。
