GWの手順を散文で整理する。DEF FNは関数名の項目を探し、直接モードを拒否し、
定義の仮引数列と式の位置を登録する。DEFを実行した時点で登録され、後の同名DEFで更新する。
古い小容量版についての冒頭コメントではなく、今回読んだ実際の処理は複数引数と文字列を扱う。
FN呼出しは未登録を拒否し、実引数を評価して仮引数の型に変換する。引数列の区切りと
終わりを定義側と照合し、引数の値を別の領域へ束縛する。式を評価して以前の束縛を戻し、
結果を関数名の型に変換する。大域変数の探索へ戻る経路があり、入れ子と再帰を許す。
関数名にも通常の変数名探索を使い、2文字目以降も探索対象にする。

SWAPは第1変数の値と型を保存し、第2変数を探索して型の一致を要求する。
第2変数探索で配列領域の開始位置が変わった場合は誤りにし、その後に同じ型の値を交換する。
このため未設定変数は単に一律0交換とは予測しない。第1だけ未設定なら新設後の位置を基準に
第2を探せるが、第2を新設する腕では誤りと予測する（文字列の初期値は長さ0）。

ERASEは通常の単純変数ではなく配列表を探し、見つからなければ誤りにする。
見つかればその配列だけを取り除き、後続領域を詰め、コンマがあれば続ける。
その後のDIMは新設でき、未宣言の要素参照は既定の上限10で配列を作る。
消していない配列と単純変数は残る。既存配列へのDIMは重複定義を拒否する。

## 候補と値の予測

主候補 **G_GW** は上の手順を採る。誤り番号はGWの機種から転記せず、
別の小候補 **E_table**（PC88の7.1表に対応する下記番号）を組み合わせる。
**E_unassigned** は同じ誤り経路で番号を予測しない候補であり、照合の合格にはしない。
G_GWの誤り番号が違った場合、観測後にE_tableを修正しない。

## 打鍵・採取と関門

手本と同じく、腕ごとに起動しNEWで自分のプログラムを入れ、準備・操作・結果の3枚を採る。
直接DEFと直接誤りの対照以外はRUNする。小文字ASCII、1行80文字未満、@なし。
直接行を数字で始めない。正のPRINT数値の先頭空白を取り出しで許す。
準備の打鍵・写しが後の時刻を動かすことを計算する。RUNには15000フレームを足す。
複数写しの `.f<6桁フレーム>` を解決し、一枚なら元の名前を使う。生写しはfinallyで削除する。
公式ROMの指定は環境変数 `PC88_REF_ROM_DIR` のみ。作業置き場の既定は `../tmp/l4s9k-work`。

**ERR 2対策は本登録から組み込む**。全program腕で790行の正常終了と800行の
ON ERROR処理の両方に終端印を置き、END後の直接打鍵には依存しない。
直接DEFの主予測はERR 12なので直接終端印を使う。終端印欠落を後から合格扱いしない。

採取するのは短い自作PRINT印と整数だけ。文字列はlen/ascのみ。
その他の行、誤り経路の印の間の中身、フロントエンドのstdout/stderrは出さず行数のみ。
誤りは手本のprobe-entryと同じ番号の包含で採り、exactは真偽値として保存するだけで
期待値照合・関門・2走一致から外す。行全体との完全一致を要求しない。

関門は2走とも採取成功、3段階の形式、準備・操作の既知印、結果先頭・終端の一意性と順序、
印の整数個数・型・16行以下、exactを除いた2走一致、対照11腕一式の既知予測一致。
予測と違う値・捕捉番号・pでも形式が正しければ関門を通してdifferにする。
関門通過は採取の妥当性であって、予測なしの合格ではない。
再帰で期限までに終端が出なければ採取関門失敗とし、「永久に止まらない」と結論しない。

`check`は既知期待値と一致した腕だけを合格にし、SKIP・観測のみ・予測なしを拒否する。
`--predicted-only`は期待値TSVのnull予測を除き、期待値がある腕だけ照合する。
測定TSVの余分な腕は合格に数えず、期待値の腕が測定に欠ければ不合格。
対照11腕はこの選択肢でも必要。予測なし腕へ観測を期待値として与えても拒否する。
`rejudge`は保存TSVの走・打鍵・失敗フラグ・観測・行数から共通emitで再構成し、
旧判定列を信用しない。入力と出力は別ファイルとする。

## 器具の検証と決めないこと

実行する検証は `bash tools/l4_deffn_selftest.sh < /dev/null` のみ。
合成画面の取り出し陽性陰性、固定値、番号包含、exact除外、本文非出力、打鍵時刻、
複数写し名、2走、破損拒否、SKIP拒否、予測なし拒否、subset照合と期待腕欠落拒否を検査する。
値・ERR・pの改変が形式関門を通ってdifferに届くことも検査し、陰性が手前で落ちるだけにしない。
自作ROMを一時ビルドし、対照11腕×2走を既知値と照合し、期待値改変を拒否する。
run_allは登録のみで実行しない。src/・tests/は変更しない。git add・コミットはしない。

DEF USR・DEF SEG・DEFINT等の型宣言、FNの正確な深さ上限、行編集とDEFの相互作用は決めない。
本測定の予測なし腕や有限時間内の未完了から仕様を確定しない。
