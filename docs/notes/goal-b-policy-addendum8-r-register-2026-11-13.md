# ゴール B 方針 追補8 — G5 の実走で R レジスタへ自作の値を入れて道の変わり方を見る

記録日: 2026-11-13
位置づけ: [追補7](goal-b-policy-addendum7-intervene-in-game-run-2026-11-13.md) の後続。これまでのノートは書き換えない。

## 何が起きたか
自作 main の 7071 を公式とそろえた版（entry11）で、7071 から戻った時点の A・F・BC・DE・HL・IX・IY・SP・裏レジスタ・I・IM・IFF・EF86・EF87 は公式と一致した。
それでもゲームの出来事は戻ってから 62 件目で分かれる。その区間はメモリ・I/O・ROM 呼び出しが無く、入力として違い得るのは R レジスタだけだった。
ゲームが R を乱数として読んでいると推定される。R は実行した命令の数で進むので、自作 ROM の命令数が公式と違えば値が変わる。

## 2026-11-13 に利用者と決めた線
**G5 の公式 ROM での実走の中で、R レジスタを自作の値に書き換え、公式でも道が変わるか、変わった道でも止まらずに進むかを見てよい。**
（利用者がこのスレッドで直接「R の介入 OK」と返答、2026-11-13 03:45）

- 介入する値はこちらが選んだ値。記録するのは、ゲームの出来事の並びが基準と同じか違うか（何件目で分かれるか）、止まらずに進むか（指定フレームまで I/O が続くか）、の真偽と件数だけ。
- 基準の走の値、画面の中身、ゲームのデータは従来どおり出さない。
- 自作 ROM の命令数を公式に合わせること（R をそろえること）はしない。G5 は今後、画面ハッシュの一致ではなく「止まらずに進むか」で評価する。
