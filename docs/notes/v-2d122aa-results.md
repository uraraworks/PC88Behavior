# 2d122aa の実走確認（2026-11-17、クラウド）

B95・B98・B99 を受けた実装（ee09a40・dd4b730・2d122aa）を、push 前に bundle でクラウドへ渡して確かめた。公開するのは件数・一致数・真偽だけ。

## V1 処理時間合わせ（G5、公式・自作とも漢字 ROM なし、600F ごと60点）

画面ハッシュの一致は N 37（前回38）、SP 43（前回4）、RT 52（前回33）。キー入力のある腕は大きく改善した。N は変わらない。6F6B・7071 は合わせていない（計時器が作れず保留）。

## V2 キー（B95 の12腕の再走）

- K-A・K-1・K-SA・K-S1・K-KANA・K-TEN8：積んだ文字列・ECDF 回数・35CE 回数とも公式と一致。修飾キーの修正は効いた。
- K-SF1：積む文字は公式・自作とも0件だが、ECDF は公式1回・自作0回。
- K-F1・K-UP・K-ESC：自作は積まない。公式は 1・3・3 件積む（自作表に無い文字）。
- K-AB：件数 4/4・ECDF 2/2 で一致するが、並びが1番目から違い、リピートが公式と別のキーに付く。
- K-FULL：10/11 で3番目から違う（1文字のリピートが1回多い）。ECDF は 10/10 で一致。

## V3 リセット

- R-G・R-T・R-COLD：R+300 で自作もグラフィック VRAM が0になり、直った。
- R-G5-OUT・R-G2-OUT・R-G3-OUT（ゲームを動かした後のリセット）：自作は0にならない（公式は0）。ゲームが自作の「起動済み」の印（F22C–F22D）を書き換えたためとみられる。
- G5 を F3600 でリセットし R+5／R+60 で媒体を抜く腕：公式も SENSE DRIVE STATUS を約120万回出すが R+960／R+1057 で止まる。自作は約36万回を R+1800 まで出し続ける。R+60 では READ DATA が公式4件・自作0件。
- G2・G3 で媒体を抜いてからリセットした腕は、公式・自作とも FDC コマンド0件。

## V4 回帰（旧 main ead352f と新 main の比較）

G1 の9本はすべて 60/60。G2 N は 52/60（F7800〜12000 で違い、その後戻る。37C9・37D2 の待ちの影響とみられる）。G3 RT は 59/60（F9600 の1点）、他は 60/60。旧と新の比較なので、公式とどちらが近いかは別に見る。

## 判定と次

1. 起動済みの判定を、ゲームに書き換えられても「起動済み」と判断できる形に変える（l1-ipl 第5版）。
2. 同時押しの処理順は、走査順（行・ビットの昇順）ではなく逆と読める（1番目から違い、リピートが別のキーに付く）。降順に変える（main-rom-entry 第15版）。K-FULL・K-SF1 の ECDF は未確定のまま。
3. 媒体が抜けたときの起動の再試行を公式は R+1000 前後で打ち切る。打ち切りの条件を測ってから自作に入れる（B100）。
4. G2・G3 は新 ROM と公式の比較を取り直す。
