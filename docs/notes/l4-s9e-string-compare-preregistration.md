## 読んだ範囲と資料の規則

CLAUDE.md全文、第8節項目16、docs/notes/l4-s9a-string-functions-preregistration.md、
tools/l4_strfunc_measure.py・l4_strfunc_selftest.sh を読んだ。
公式ROMのバイト列・逆アセンブルは読んでいない。
GW-BASIC MIT公開ソース ../refs/GW-BASIC/ を `rg -a` で探索した
（CP932・NEL混在のため、0件を不存在の根拠にしない）。
読んだ範囲（sed によるLF行番号）は BISTRS.ASM 55–125・570–580、
GWEVAL.ASM 360–380・395–475・500–530・1015–1030、MATH1.ASM 2728–2745。
以下はコードの転載でなく、処理の散文要約である。

- 文字列どうしの比較は STRCMP が行う。左辺・右辺の文字列の先頭から1バイトずつ
  **符号なしバイト**として比べ、最初に違う位置の大小で結果が決まる（128以上のコードは
  0〜127より大きい）。
- 全バイトが等しいまま片方が先に終わったら、**短い方が小さい**（接頭辞は小さい）。
  両方同時に終わったら等しい。空文字列は任意の非空より小さく、空どうしは等しい。
  文字コードそのものの比較なので大文字と小文字は別（"a"=97 > "A"=65）。chr$(0) も
  通常のバイトとして比べ、長さで終端を判定する（途中の0で打ち切らない）。
- 演算子は関係ビット（>=1, ==2, <=4）の和で表し、`<>`=5、`<=`=6、`>=`=3。
  比較結果は真なら-1、偽なら0の整数。AND/OR/NOT/算術へはその整数が渡る。
  関係演算子の優先順位は AND/OR より上、`+`（連結）より下。
- 型混在: 左が文字列・右が数値は STRCMP 内の文字列検査、左が数値・右が文字列は
  適用時の右辺文字列検査で、どちらも Type mismatch（ERR=13）。

## 取り出しと打鍵

1標本=1腕、腕内番号n=1。小文字の行だけを打ち、全行80文字未満、`@`は使わない。
大文字・chr$(0)・128以上は chr$ で作る。手本と同じ8フレーム/文字、行間240、
公式起動改行300・入力開始700、自作入力開始100、RUN後15000フレーム、
採取前200フレームを固定する。

プログラム形: `950 print "s9e";n;err:f=1:resume next`、`10 n=1:f=0`、
`15 on error goto 950`、必要なら `16〜` で変数 a$,b$ を設定、`20 v=<比較式>`、
`30 if f=0 then print "s9f";n;v`、`40 print "s9d";n;1`。
（`print "s9f";n;(式)` と同じ値だが、誤りが出たとき印が行の途中で切れないよう
代入を先に行う。）IF形は `20 if <条件> then print "s9f";n;1 else print "s9f";n;0`。
正の数は先頭空白、負数は `-` で印行は整数のみの完全一致。他の画面行は件数だけ。
エラーメッセージの文言は採らない。

## 腕（本体209腕＋定数対照4腕＝213腕、各2走）

候補は **C_GW** のみ。全腕の整数列を `predict` が出す。
`[s9f,1,V]`（V=-1/0）または `[s9e,1,N]` のあとに `[s9d,1,1]`。

| 群 | 腕数 | 内容 |
|---|---|---|
| lit-* | 132 | 6演算子（= <> < > <= >=）×22対のリテラル比較。等しい／接頭辞（短-長・長-短）／空どうし／空-非空・非空-空／最後の1文字違い（前・後）／最初の1文字違い（前・後）／大小文字（"a"とchr$(65)、逆順）／128以上（chr$(200)と"a"、chr$(127)とchr$(128)、逆順）／chr$(0)を含む（"a"+chr$(0)と"a"、逆順、chr$(0)と空、chr$(0)どうし、chr$(0)とchr$(1)、途中の0の後で違う） |
| var-* | 18 | 変数どうし（a$op b$）。("ab","abc")、(chr$(200),"a")、("","")×6演算子 |
| func-* | 17 | left$/mid$/right$/str$/chr$/連結の結果との比較、数値関数との混在（asc、val） |
| logic-* | 16 | AND/OR/NOT/加算/単項マイナス/比較結果どうしの比較との組み合わせ（括弧あり・なし） |
| if-* | 16 | IFの中の比較。`a$=""`・`a$<>""`（未設定・"x"・chr$(0)）、リテラル、AND/OR/NOT併用、関数結果、chr$(200) |
| type-* | 10 | `"a"=1`・`1="a"`・`"a"<1`・`1<"a"`・`"a"<>1`・`1<>"a"`・`""=0`・`"1"=1`・`1="1"`・`a$=1`、すべて ERR=13 と予測 |
| control-* | 4 | 定数対照（下記） |

C_GWの予測値は、上の規則をそのまま機械的に当てはめた値。
例: `"ab"<"abc"` -1、`chr$(200)>"a"` -1（符号なし）、`"a">chr$(65)` -1、
`"a"+chr$(0)>"a"` -1、`chr$(0)=""` 0、`"ab"<>"ab"` 0。
`("a"="a")+1` は 0、`-("a"="a")` は 1、`not ("a"="b")` は -1。

予測できない点・小候補に割る点: **なし**（ソース手順に未決点がない）。
ただし次は規則の読み違いを疑う「外れたとき」の候補として記録する（測定前の予測は変えない）:
(a) 符号付きバイト比較（chr$(200) < "a" となる）、(b) chr$(0) で文字列が打ち切られる、
(c) 長さを先に比べる（"b"<"ab" となる）、(d) 型混在が誤りにならず0・-1を返す。

## 定数対照（関門）

`(1=1)`→`[s9f,1,-1]`、`(1=2)`→`[s9f,1,0]`、`asc(mid$("hello",2,3))`→`[s9f,1,101]`、
`error 5`→`[s9e,1,5]`。いずれも後ろに `[s9d,1,1]`。
全対照が2走とも既知の値と一致したときだけ関門通過。SKIPは合格にしない。
一致しなければ全腕 gate_failed。ON ERROR/ERRORが使えない場合も全体関門は失敗のまま残し、
画面のエラー本文から番号を推測しない（代替は追補で事前登録し、対照を検証してから測り直す）。

## 判定・器具検証

`tools/l4_strcmp_measure.py`: `predict --out FILE`（ROM不要）、
`measure --rom-dir DIR --out FILE [--official] [--work-dir D]`（既定作業場 ../tmp/l4s9e-work）、
`check --expected FILE --measured FILE`、`selftest`。

全腕の予測列の取り出し陽性、印の破壊・桁欠け・値改変・ERR番号改変の陰性、
全腕の2走再生、片走改変、定数ERR改変による全体関門失敗、打鍵失敗、
自作ROMの一時ビルドと数値定数3腕（control-error・文字列比較は自作ROMでは測らない。
