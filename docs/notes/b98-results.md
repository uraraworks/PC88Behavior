# B98 結果：G5 の打鍵なしのずれは ROM 入口の処理時間から来る

実施: 2026-11-17、クラウド（G5 無入力、36000 フレーム、全走正常）。手順は [事前登録](b98_preregistration.md) のとおりで、待ちの介入と所要 T ステートの記録はリポジトリ外のプローブで足した。値・画面本文は出さない。

## 公式に待ちを足した腕

基準 T-OFF-0a・0b は完全一致した。

| 腕 | 境界の最初の違い | main I/O の最初の違い | 画面ハッシュ一致（60点中） |
|---|---|---|---|
| 3080 の戻りに +4T（22967回） | 21802 件目（F8300） | F7403 | 58 |
| +8T | 21764 件目（F8284） | F7403 | 56 |
| +40T | 20518 件目（F7847） | F7187 | 49 |
| 7071 の帰還だけ +40T（1回） | 最後まで一致 | F7725 | 53 |

sub の I/O はどの腕も分かれなかった。T-SELF（自作）は画面一致6だったが、自作側に漢字 ROM が無かったため、漢字 ROM なしの公式を1走足して比べ直すと38（B94 の無入力と同じ）。

## 入口ごとの所要 T ステートの最頻値（公式/自作）

入口の命令 fetch から呼び元へ戻った最初の fetch まで。所要時間は振る舞いの測定値である。

| 入口 | 公式 | 自作 |
|---|---:|---:|
| 3080 | 3016 | 1751 |
| 37D2 | 567 | 391 |
| 3847 | 588 | 624 |
| 37C9 | 966 | 756 |
| 369A | 95830 | 81811 |
| 6F6B | 460709 | 79357 |
| 7071 | 378058 | 1779 |
| 3391 | 3043（公式のみ83件） | — |

35CE は無入力なので0件。

## 判定

公式自身が 3080 の戻りに 4T 足しただけで分かれるので、**処理時間説を支持する**。G5 の打鍵なしの散発ずれは、自作 ROM の入口の所要時間が公式と違い、割り込みの受理位置がずれることで説明できる。ただし公式に +40T を足しても不一致は11点で、自作の22点には届かないので、差の大きい入口（3080 の呼び出しの多さ、6F6B・7071 の大きな差）を合わせて足す必要がある。
