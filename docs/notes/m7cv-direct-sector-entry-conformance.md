# m7cv: 直接セクタ入出力需要入口の事前登録

実施日: 2026-08-27

本稿の到達条件は実測前に固定した。公式ROM・公式ディスクの内容は読まず、
生ログ、画面報告、ROM／ディスク複製はリポジトリ外の一時領域だけに置く。
書込み対象には、参照diskAから作った使い捨て複製だけを用いる。

## 対象入口と自作データ

第1候補はN88-DISK BASICの直接セクタ入出力 `DSKI$` / `DSKO$` とする。
使い捨てdiskA複製のドライブ1、トラック39、セクタ16だけを対象とし、256文字の
自作文字列を `DSKO$` で書く。書込み後、受け変数を保存値とは異なる256文字へ
代入し、破壊が成立した場合だけ `D8C` を表示する。その後 `DSKI$` で同じ座標を
読み、長さ256かつ自作文字列と完全一致した場合だけ `D8R`、最後まで通過した場合
だけ `D8E` を表示する。不一致時は `D8N` を表示する。

座標はファイルシステムの内容に依存せず、原本を変更しない。公式一式／混成の
各runには同じ原本から作り直した別々の複製を与え、複製間で書込み結果を継承しない。

## 到達条件・対照

直接セクタ書込みの到達は、(1) 自作文字列の生成と `DSKO$` の打鍵が画面へ反映、
(2) FDCの `WRITE DATA` が1件以上発行、(3) 書込み後に変数を別値へ破壊したことを
示す `D8C`、再読出し全長一致を示す `D8R`、末端の `D8E` が順に出る、の全条件と
する。直接セクタ読込みの到達は、(1) `DSKI$` の打鍵が画面へ反映、(2) FDCの
`READ DATA` が1件以上発行、(3) 同じ3マーカーが順に出る、の全条件とする。
`Ok` の表示だけは、どちらの到達条件にも採らない。

陽性対照は、打鍵したプログラムと `D8C`、`D8R`、`D8E` が順に現れる合成画面、
かつREAD/WRITE発行を持つ形とする。陰性対照は、事前破壊に失敗して `D8C` を欠く
形、読戻しが一致せず `D8R` を欠く形、末端へ届かず `D8E` を欠く形とする。
従って構文受理、FDC書込み要求、または破壊前の変数が偶然一致しただけでは合格しない。

## 不採用条件と切替

この環境で `DSKI$` / `DSKO$` が `Syntax error` 等となり、公式一式でも上記入口へ
到達しない場合、その試行の署名は期待値へ採らず、不採用の事実だけを本稿へ残す。
その場合は媒体初期化（公開μPD765の `WRITE ID` / `FORMAT` 系を踏む操作）へ切り替える。
切替時は、その実測より前に、初期化後の使い捨て媒体へ自作データを書き、別値へ破壊後に
読み戻して一致時だけ固有マーカーを出す到達条件と対照を本稿へ追加固定する。

## 観測指標と固定手順

公式一式／混成を各2回実走し、FDCコマンド種別列、`READ DATA`・`WRITE DATA`件数、
main `IN $FC` と `IN $FD` の件数・SHA-256、画面の行数・文字数・SHA-256を測る。
同一モード2回の全イベント列と画面の決定論性、および公式／混成の全長一致を確認する。
最初の公式到達runで署名を出し、期待値を固定してから4runを判定し直す。

期待値は専用TSVへ置き、判定器は表示ラベルを一時パスへ使わず `mktemp` で故障コピーを
作る。生成失敗と期待値0行を必ず失敗とする。合成画面の陽性・陰性対照に加え、
SHA-256破壊、件数破壊、期待値0行の3故障を注入し、空振り0件を必須とする。

ここまでを実測前の事前登録とする。

## 情報境界

記録するのは件数、SHA-256、画面の行数・文字数・SHA-256、自分で打鍵した文字列、
および公開されたμPD765のコマンド名だけとする。画面本文、ディスクのデータ部、
公式の応答値は記録しない。
