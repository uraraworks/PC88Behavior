# m7ah: 2+1+5ラウンド回帰の再診断

測定日: 2026-08-13

`tools/verify_l3.sh` の2+1+5ラウンド試験を現行HEADで再実走すると、現行版は
後続の通常要求へ到達せず、故障注入版だけが落ちるという本来の検出構造が
崩れていた。

原因は実装のrun境界処理ではなく、試験治具の旧期待だった。治具は任意の
2/1/5件要求を先行3交換として扱えると仮定していたが、第31版1.24節で単発
応答が要求別、第32版1.25節で交換#3開始が先行3応答の完遂後と確定したため、
任意要求では交換順序カウンタが進まず、検査対象の交換#3へ入れない。

治具を第31版の公式測定で確定した交換#0〜#2の要求列へ訂正する。判定件数や
合否条件は変更しない。現行版が後続3要求を全件完遂し、通算8件打ち切りを
再現する故障注入版だけが不一致になることを再実走で確認する。
