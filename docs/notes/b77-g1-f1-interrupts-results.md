# B77: F1 の道で、後半のキーの前後の main の割り込みの受け付けを公式と自作で比べる — 結果

記録日: 2026-11-04
規則: [b77-g1-f1-interrupts-preregistration.md](b77-g1-f1-interrupts-preregistration.md) と追補どおり。2 回目で rc=0。記録は `measurements/b77-g1-f1-interrupts.txt`。

## 結果

| 窓（フレーム） | 公式 L2 / L4 | 自作 L2 / L4 |
|---|---|---|
| 11400〜11999（キーの前） | 6445 / 806 | 6445 / 806 |
| 12000〜12599（キーのあと） | 6453 / 804 | **3815 / 475** |
| 12600〜13199 | 6459 / 806 | **3817 / 477** |

入口はどちらも `0x8000` 未満（`rom` の組）である。

## 分かったこと

キーの前は、割り込みの回数まで公式と同じである。**キーのあと、自作は割り込みの受け付けが約 6 割に減る。** 種類は同じで、回数だけが減る。

## 読み方（推定）

キーのあと、自作の上の main は割り込みを止めた（DI）状態で長く待っている。B73 でサブがアイドルの待ちに入っていたことと合わせると、main は要求の始まりの合図を出したあと、サブの受信可の合図を割り込みを止めて待ち続けている可能性がある。B78 で、キーのあと少し経ってからの受け渡しの制御の並びを取る。
