# l4-s6d — 候補M6(COS(x)=SIN(x+π/2)を角度領域でやり直す旧形)の事前登録

記録日: 2026-09-19
状態: 事前登録(測定前)。(i)は記録済み腕への事後照合(参考)、(ii)が
測定前に固定する本命の判定。

## 位置づけ

l4-s6c(`docs/notes/l4-s6c-single-precision-range-reduction-results.md`)
で候補M5が42腕中22腕で完全一致したが、x=50000のCOS(C17)・TAN(C18)だけ
大きく外れた。親が、記録済みの公式値から`COS(x) = SIN(単精度で丸めた
x+π/2)`(SINの手順=M5をやり直す)という候補M6を事後の当てはめとして
見つけ、C17を含む複数腕と矛盾しないことを確認した。

## GWソース上の根拠(現行COSの構造と、M6での最小限の反転)

`MATH1.ASM`(`edf82c2e`)952-966行の現行`$COS`は、`$SIN`と`RR`(範囲縮約)
を1回だけ共有し、縮約後の「回転数の端数」に倍精度で1/4を足してから
`SIN30`(量子化・多項式評価)へ合流する、という**共有型**の実装である
(l4-s6c事前登録の該当節、`docs/notes/l4-s6c-single-precision-range-
reduction-preregistration.md`に既出)。M5はこれを単精度に置き換えた
だけで、共有の構造自体は変えていない。

M6は、この共有をやめ、**角度領域でx+π/2を単精度で加算してから、SINの
手順(範囲縮約を含めて)を丸ごとやり直す**、という、より素朴な(共有を
しない)構造を仮定する。単精度π/2定数は`tools/l4_mbf_oracle_v3.py`の
`PI2`(`MATH1.ASM 1137-1138`、$ATANのATN100ラベルで使われている単精度
π/2、DX=7733O・BX=100511O)をそのまま再利用した(GWソースに他の単精度
π/2定数は無いため、これ以外の選択肢は無い。「無ければπ/2をMBF単精度に
丸めた値」という代替は今回不要だった)。加算は`$FADDS`相当(v2の
`gw_binop`の単精度"+"、正しい丸めと確認済み)。TANは`SIN(x)/COS(x)`
(M0・M5と同一の`$FDIVS`除算、変更なし)。

実装は`tools/l4_mbf_oracle_v6_m6.py`(新規、v3・v5は無改変)。SINは
M5の`sin_impl`をそのまま再利用し、変更していない。係数の当てはめは
行っていない。

## (i) 記録済み40腕への事後照合(参考、事後の当てはめであることを明記)

l4-s6b(19腕、A17・A20除く)+l4-s6c(21腕)の記録済み40腕全てに対し、
M6の予測を単精度ビットで照合した(公式ROMは未使用、既に記録済みの
数値文字列のみを使用)。

**40腕中30腕(75%)がビット完全一致した(M5は22腕、M0は3腕)。**
新たに一致したのはCOS/TANを含む腕(A02・A08・C02・C03・C05・C06・
C08・C11は元々M5と一致していた分を除く新規一致がC17・C18相当を含む)
で、l4-s6cのC17(`cos(50000)`)・C18(`tan(50000)`)もM6では完全一致に
変わった。残る不一致は10腕(A05・A07・A09・A11・A12・A15・A16・C07・
C09・C11)で、うちA11(`cos(200)`)・A12(`tan(200)`)は700ULP前後の
まだ大きな食い違いが残った(新たな外れ値、C17・C18とは別のx)。
A05・A16(2π近傍のSIN)は従来どおり不一致(M6はSINをM5から変更して
いないため)。それ以外(A07・A09・A15・C07・C09・C11)は±1〜6ULPの
小さい食い違いにとどまった。

## 測定方法(l4-s6b・l4-s6cと同一)

`print cdbl(<式>)\n`形式、各腕2走、フレーム計算・関門(G1〜G6)・記録
方法は従来と同一。公式の出力の数値文字列を結果ノートに記録する。

## 判定

- 22腕それぞれについて、公式出力がM5・M6のどちらの予測と一致するかを
  記録し、単精度ビットのULP差(符号付き)も出す。
- 「割れる」12腕でM6一致率がM5一致率よりはっきり高ければ、M6を支持する。
- 「一致(対照)」10腕は、両候補が同じ予測をしている以上弁別力は無いが、
  公式出力がその予測とも異なる場合は、M5・M6のどちらでも説明できない
  残差(x=200型の外れ値)がどの程度の頻度で起きるかを見る目的で残す。
- 外れが残れば、ULP差の分布・傾向を書いて止める(深追いしない)。
