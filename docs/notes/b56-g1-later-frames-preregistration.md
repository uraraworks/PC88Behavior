# B56: スペース後の G1 を 14400 フレームまで、キーの腕も含めて確かめる — 事前登録

記録日: 2026-11-01
位置づけ: [B55](b55-g1-request-16-fixed-results.md) の次段。[B29](b29-g1-graphics-and-keys-preregistration.md) の腕を今の自作 ROM で測り直す。**このノートは測定より先にコミットする。**

## 1. 問い

スペース後とリターン後の G1 は、もっと先のフレームでも画像とテキスト画面が公式と一致するか。

## 2. 条件

腕はいずれも OO・SS 各 2 走。クラウドの実行環境で行う。自作 ROM は現在の配布ビルド。

| 腕 | フレーム | 打鍵 |
|---|---:|---|
| F | 7200 | フレーム 3600 でスペース |
| H | 14400 | フレーム 3600 でスペース |
| I | 28800 | フレーム 3600 でスペース |
| E | 7200 | フレーム 3600 でリターン |
| G | 14400 | フレーム 3600 と 7200 でリターン |

## 3. 記録の白リスト

`arm <腕> frames=<N> image=<same|differ> text=<same|differ> fc-diff=<N|na> first=<N|none|na> left=<N|na> right=<N|na> oo=<same|differ> ss=<same|differ>`

測定前の修正（2026-11-01）: 1 回目は長い走の `--io-log` があふれて止まった。あふれた腕は `IN $FC` の比較を `na` にして、画像とテキストだけで判定する。

画像は B29 と同じく一致かどうかだけを見て、どこへも置かず、開かず、判定のあとで消す。**値は出さない。**

## 4. 判定（事前に決める）

- 腕ごとの行をそのまま書く
- どこまで一致するかを書く。違う腕があれば、最初の違いの番号を書き、次を別のノートで決める
