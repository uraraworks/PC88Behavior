# m7lo: ほかの失敗の形でも「9」は変わらないか——ID CRC・データの目印なし・IDが無効・単密度・削除マーク — 事前登録

## 位置づけ

1.58節の「9が依存しないもの」は、失敗の原因についてはトラック不在・セクタ不在・データのCRCエラーの
3種類まで潰した（[m7jo](m7jo-error-cause-invariance-results.md)・[m7lh](m7lh-data-crc-error-results.md)）。
[m7lm](m7lm-retry-and-response-rework-results.md)で、自作もこの3種類で公式と同じ振る舞いになった。

**まだ試していない失敗の形がある。** 計測に使うエミュレータ（`vendor/quasi88-libretro/src/fdc.c`。第三者の
自由ソフトウェアで、読むことは規律上の禁止対象外）がD88の状態値として扱うもののうち、次の4つと、
**失敗かどうかがはっきりしない形（削除マーク）**を試す。

## 媒体（`tools/make_l3_testdisk.py`。形は40シリンダ・両面・起点1・16セクタで共通。違いは見出しの1バイトだけ）

| 記号 | 引数 | エミュレータのREAD DATAの扱い（fdc.cを読んで） |
|---|---|---|
| **G-OK** | （なし） | 正常に読める（**陰性対照**） |
| **IDCRC** | `--sector-status 0xA0` | 異常終了・ST1=DE。データは渡さない |
| **MAMD** | `--sector-status 0xF0` | 異常終了・ST1=MA・ST2=MD。データは渡さない |
| **IDBAD** | `--sector-status 0xE0` | そのセクタを無視する（IDが見つからない扱い） |
| **SD** | `--single-density` | そのセクタを無視する（IAMが無い扱い） |
| **DEL** | `--deleted-data` | SK=0ならデータを読み、ST2=CMを立てる。**TCがすぐ来れば正常終了＋CM、来なければ異常終了＋EN** |
| **P** | `--cylinders 40 --double-sided --sector-base 200` | セクタ不在（**陽性対照**。公式で96対・最長9） |

**DELがいちばん情報が多い。** 自作の今の判定（ICが00でなければ失敗）では、正常終了＋CMは成功扱いになる見込み。
**公式がDELで粘れば、公式の判断はICだけでは決まっていない。** **ただしこれは見立てであり、予測として登録しない。**

## 場面と測るもの

A:に公式ディスクの使い捨て複製、B:に上の媒体、`FILES 2`（3000フレーム、300で改行、700で打鍵）。
**公式一式と混成（HEADの自作）**の両方で各2回。

各生ログについて（値を出さない）:
1. **READ DATAの件数・連続した対・最長連続**（m7kw・m7lg・m7lhと同じ）
2. **単位の数**（READ DATAが連続したrunの数）と、**長さ1の応答runの数**（m7lkと同じ定義）
3. **最初のエラー結果の公開ビットの復号名**（`tools/compare_l3_entry_fdc.py --after-frame 700`）

## 事前登録する判定（**測定前に固定する**）

**段階0（操作の確認）**:
- G-OK: 公式側で連続0対・エラー結果なし
- P: 公式側で連続96対・最長9（再現）
- **IDCRC・MAMD・IDBAD・SD・DELのそれぞれで、公式側のFDCコマンド種別列または最初のエラー結果がG-OKと違う**
  （**媒体の違いがFDCに届いている**ことの確認）。**DELだけは、G-OKと同じでも操作の失敗とはみなさない**
  ——DELは「失敗かどうか」自体が問いだからである。**DELがG-OKと同じなら、その事実を記録する。**
- 決定論性: 各媒体・各側で2回の数が一致

**どれかが偽なら（DELの例外を除き）、その媒体の主判定は`O`。**

**主判定（公式側。媒体ごとに）**:
- **QA-9**: 最長9・連続96対（単位12）——**「9」は変わらない。** 1.58節の失敗の原因に加える。
- **QA-1**: 連続0対（1件ずつ）——**公式はこの形では粘らない。**
- **QA-X**: 上のどちらでもない——**「9」を動かす形が見つかった。** 件数・最長・単位の数をそのまま記録する。

**副判定（媒体ごとに）: 混成のREAD DATAの件数・連続・最長・単位の数が、公式と一致するか。**
**一致しなければ、`m7kr`の更新の条件「公式と食い違う条件が見つかったとき」に当たる。** 作り直しは本稿ではやらない。

**どの判定になるかは予測しない。**

## 言えないこととして先に書いておくこと

- **エミュレータの上での振る舞いである。** 状態値の扱い（特にDELの終わり方がTCの来るタイミングで変わること）は
  エミュレータの実装に依存する。**実機のμPD765が同じだとは言わない。**
- **QA-9が並んでも、「9」を決める規則は書けない。** 動かない形が増えるだけである。
- **DELでの公式の判断の理由（CMを見ているのか等）は言わない。** 粘ったか粘らなかったか、までである。

## 合格条件（測定の成立）

1. 段階0（上記）。
2. 7媒体×2側×2回＝28本の生ログがそろう（本数を出力に載せ、期待値と一致）。
3. `tools/check_cleanroom.sh`が全項目OK。**`src/`は変えない。**

## 禁止（本稿の測定中も例外なく適用）

公式ROM・公式ディスクのバイト列を読まない・出力しない・逆アセンブルしない。公式ディスクは`cp`で使い捨ての複製を
作るだけ。`private/`の中身・ファイル名を出力しない。FDCデータポート値・シリンダ値・セクタ番号・結果ステータスの
生の値・時刻・frame番号・画面本文を出力しない（エラー結果は公開ビットの復号名だけ）。
