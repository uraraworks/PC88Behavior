## 観測から読める規則（実装の根拠）

括弧なしの比較式（予測どおり、全腕一致）:
- `print 1=1`・`print "a"="b"` のように PRINT の項目として括弧なしで書ける。結果は整数 −1/0。数値・文字列の6演算子、`1<2 and 2<3`、`2+3=5`（算術が先）、`1+1<2`、
  `"a"+"b"="ab"`、`not 1=2`（NOT は関係の後）、`-1=1` は偽、単精度 1/3 と倍精度 1/3# は等しくない。
- **連鎖は左から**: `1<2<3` は −1、`1=1=1` は0、`1=1=-1` は −1。文字列の連鎖 `"a"<"b"<"c"` は ERR 13（2段目が数値と文字列）。
- 記号の並べ替えは同じ意味（`=<`=`<=`、`=>`=`>=`、`><`=`<>`）。**同じ記号の重複は ERR 2**（`1==1`、`1<<2`）。3種そろえた `1<=>2` は −1（常に真）。
- 代入の右辺にも書ける（`a=1=1` は −1、`a="b"="b"` は −1、`a%=2>1` は −1）。文字列変数へ入れる `a$=1=1` は ERR 13。型混在 `"a"=1`・`1="a"` は PRINT でも代入でも ERR 13。

WIDTH（画面）:
- **40桁の折り返し・項目の前改行・コンマ・TAB・SPC の外挿は全て的中**。40桁ちょうどの直後は次行の桁0、41字目は次行の桁1。項目は現在桁＋長さが40を超えれば前改行
  （30＋15 は桁15・行+1、30＋10 は桁0・行+1、37＋数値12345 は桁7・行+1）。コンマは次の14の倍数へ進み、桁14以上のコンマは改行（`"a","b",` は桁0・行+1）。
  TAB(n)・SPC(n) は n mod 40（TAB(45)→桁5、SPC(45)→5個、TAB(10)→桁10、桁6から TAB(5)→桁5・行+1）。
  `width 40` の後に `width 80` へ戻すと80桁の規則（85字は桁5・行+1）。
- **`width` は画面を消し、カーソルを先頭へ戻す**（指定が現在と同じ `width 80,25` でも消える。q印が残らず、カーソルは桁0・先頭との差0）。マニュアルが当たり、GW の「変化なしは何もしない」は外れ。
  誤りになる width（`width 39`）は消さない（q印が残る）。`width lprint 40` は画面に触れない。
- 受理: `width 40`・`80`・`40,20`・`80,20`・`80,25`・`40,25`・`width 20*2`（式）・`width lprint 40`。誤り（ERR 5）: 桁 0・39・41・81・256、行 19・24・26。余分な引数 `width 80,25,3` は ERR 2。
- `locate` は桁・行の上限を超える指定でも**誤りにならない**（80x25 の行23〜25、80x20 の行19・20、40桁の桁39・40）。

BEEP:
- `beep`・`beep 1`→`beep 0`・`beep:beep`・`if 1 then beep`・`beep a`（変数）・`print chr$(7);` は **ポート0x40の bit 5 が立ち上がり、続いて立ち下がる**（他のビットは変化しない）。
  `beep 1` だけなら立ち上がりのみ（鳴り続ける）。`beep 0` だけではポートは変化しない（無音対照 `rem` も同じ）。`print chr$(7);` と `beep` は同じ動き。
- `beep 2` は誤りにならず鳴る（bit 5 立ち上がり→`beep 0` で立ち下がり）。**`beep -1`・`beep 256` は ERR 5 になるが、誤りの前に鳴る**（bit 5 の立ち上がり・立ち下がりがある）。
- プログラム中の `beep`、`beep "a"`（ERR 13）の誤りの捕捉は予測どおり。

## 予測と観測が食い違った8腕

| 腕 | 予測 | 観測 | 規則 |
|---|---|---|---|
| w-ok-rows-only（`width ,20`） | 受理 | ERR 2 | 桁の省略は構文の誤り（行だけの指定は不可） |
| w-ok-cols-trailing（`width 40,`） | 受理 | ERR 22 | 行の欠けた末尾コンマは Missing operand |
| w-ok-noargs（`width`） | 受理 | ERR 22 | 引数なしは Missing operand |
| w-q-rows（`width ,25`） | 消す | ERR 2、画面は消えない | 同上（桁の省略は不可） |
| w-err-lprint-0（`width lprint 0`） | ERR 5 | 受理 | 装置幅 0 は誤りにならない |
| w-err-str（`width "a"`） | ERR 56 | ERR 2 | 文字列の装置名は構文の誤り |
| beep-str（`beep "a"`） | 鳴らない、ERR 13 | ERR 13、**bit 5 の立ち上がり・立ち下がりあり** | 型の誤りの前に鳴る（誤りのbell と区別できていない） |
| beep-extra（`beep 0,1`） | 鳴らない、ERR 2 | ERR 2、**bit 5 の立ち上がり・立ち下がりあり** | `beep 0` が先に実行され余分な `,1` で構文の誤り。鳴るのは誤りの前（`beep-neg`・`beep-256` と同型） |

**beep-extra の結論**: 再測定で、第1回の「誤りの前に立ち上がり」は器具の隙間の産物ではないと確定した（立ち上がり・立ち下がりとも bit 5 で再現。窓の手前の書き込みが比較相手になった）。
誤りになる BEEP（`beep "a"`・`beep 0,1`・`beep -1`・`beep 256`）はいずれも bit 5 が動く。誤りそのものがブザーを鳴らす（誤りの呼び鈴）のか、引数の評価前に鳴らすのかは、この腕では分けていない
（比較式・WIDTH の誤りの腕はポートを採っていないので、誤り一般が鳴るかは未測定）。

## 予測なし17腕の観測（規則の候補。予測の外ではないので記述のみ）

- `width 40.4`・`width 79.6`: どちらも誤りにならない（小数は受理）。
- `width` を引数なしで書いた直後の画面消去（w-q-noarg）: ERR 22 で、q印は残る。
- LOCATE の上限8腕は全て誤りにならない（上記）。
- スクロールの下限（30回 `print` した後の `csrlin` の先頭との差）: 80x25 と 40x25 は **23**、80x20 と 40x20 は **18**（行数−2。最下行をファンクションキー行が使う）。桁数は影響しない。
- `beep 2`: 誤りにならず鳴る。`beep -1`・`beep 256`: ERR 5（鳴る）。
