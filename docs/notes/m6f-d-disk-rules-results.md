## 2. 導出（すべて事前登録・追補1の規則どおり）

| 導出 | 結果 |
|---|---|
| **D1 単位と位置** | **`derived` S=8、o=0**: 番号 k の単位は線形番号 8k〜8k+7 のセクタ。3セクタの位置0〜159は同じ |
| **D2 鎖** | **`link_is_next_index`**: T[k] はファイルの次の単位の番号（I-250 の 16 単位で不一致 0） |
| **D3' 終端** | **`end_plus_used_sectors`、値 0xC0**: 最後の単位の値 = 0xC0 ＋ その単位で書いたセクタ数。新しい記録数の6腕（E-2〜E-33、u=1・2・4・6）で**前向きに**成り立ち、2回目から立てた予想と一致した |
| **D4 先頭単位の欄** | **`derived` 10 バイト目**（0 始まり、6腕で一致） |
| **D5 付け替えの読み込み** | **`relocated_readable`**: 仮説 H1〜H3 で組み直したデータファイル（単位 [20,5]）とプログラム（単位 [30]）を、公式ROM が `INPUT #`・`LOAD`＋`RUN` で読めた。鎖を切った陰性対照・先頭をずらした陰性対照はどちらも読めなかった |
| **D6 ディレクトリ** | **(18,1,1)〜(18,1,12) の 12 セクタ**（削除済みのエントリで埋めた変種で、12 セクタすべての先頭のエントリが名前で見つかった）。**`stops_at_unused`**: 未使用（0xFF）のエントリで埋めた変種では (18,1,1) のエントリしか見つからなかった。陰性対照（エントリなし）は `ZQer` |
| **D7' 使用中の値** | Rused = **0x00〜0xFE の 255 値**（0xFF 以外すべて）。対照（0xFF）は入らなかった。**R\* = 0xA0** |
| **D8 予約の印** | **`reserve_needed`**: 単位 74・75 を空きのまま満杯まで書くと 160 件目まで作れたあと、最初のファイルが読めなくなった（ディレクトリが壊れた）。74・75 を 0xA0 にすると 158 件で `Disk full` になり、最初のファイルは読めた |
| **D9 起動** | (0,0,1) を読めない4通り（無し・CRC エラー・削除マーク・単密度）は**どれも BASIC に届かなかった**（`no_basic`）。対照は予定どおり（0xFF は `no_basic`、0xC9 は `nondisk_basic`） |

2回目の I の6腕に D3' を当てた事後の記録も `end_plus_used_sectors`（値 0xC0）だった。2回目の
I-17 が外れたのは、最後の単位の1セクタに完全な通し番号が入らず、D3 の規則が最後の単位を
見落としたためだった（D3' では 0xC1・u=1）。

## 3. 器具と規則の欠陥（記録）

- **流用した m6f-c の導出器の不具合**: 単位の番号の並びを本体のセクタごとに作っていたため、
  同じ単位どうしを鎖として比べていた（`127ce9c` で m6f-d 側を修正。m6f-c は C4 が決まらず届いて
  いないので結果に影響なし）。
- **D3 の規則の欠陥**: 最後の単位を本体の通し番号で見つけていたため、通し番号の無いセクタだけの
  単位を見落とした。追補1 D3' はエントリから割り当て表をたどる規則に直した。
- **器具どうしの食い違い**: ドライバがエントリの欄を名前のキーなしで書き、導出器が名前で引いた。
  通し検査が逃げ道を使っていて通っていなかった（追補1 §2。記録は値を変えずに包み直した）。

## 4. 行き先

1. **`docs/spec/l3-disk-format.md` 第3版**に、D1〜D4（割り当ての規則）、D6（ディレクトリの広がりと
   探索の止まり方）、D7'・D8（使用中の値と予約の印）、D9（公式ROM で起動できる空の媒体は作らない）
   を規則として起こす。
2. 自作BASIC の `FILES`（ディレクトリの読み取り）と、`LOAD`・`OPEN … FOR INPUT`（割り当て表を
   たどる読み取り）は、第3版だけから実装できる。**割り当て表を書く側（`SAVE`・`OPEN … FOR OUTPUT`）の
   バッファまわりは、このセッションが担当しない**（汚染の記録 2026-09-25）。

## 5. この測定で決まらないこと

- 順次ファイル・プログラムの本体の保存形式（写しただけで中身を見ていない）。
- 終端の値 0xC0（使ったセクタ数 0）や 0xC9 以上が現れるかどうか。
- (18,1,13) のどのバイトが書き込み禁止の印か。エントリの 11〜15 バイト目の意味。
- ドライブ1で同じ規則が成り立つか（割り当てと読み込みはドライブ2で測った）。
