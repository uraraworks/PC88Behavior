# B2 事前登録 追補1 — D0 の候補の絞り込み（P0 の結果を見たあとに決めた規則）

記録日: 2026-10-24
本体: [b2-boot-sector-handoff-preregistration.md](b2-boot-sector-handoff-preregistration.md)（本体は書き換えない）
**この追補の規則は、P0 の結果を見たあとに決めたものである。** P0 では D0 の候補が 2 本
（ROM 書き込みの連続範囲 `C000-E5EB` と `E5F0-FFF8`）になり、第7節に従って止まった
（[結果ノート](b2-boot-sector-handoff-results.md)）。そのうえで「ディスクの有無で変わる RAM 実行番地」に
着目して絞る。結果を見て作った規則なので、**独立の確認を必須**にする（下の D0'-確認）。

## 1. 抽出器の修正（先に直した）

P0 の過程で、ディスク無しでも RAM 上の命令が実行されている（ROM が RAM へコードを置いている）ことが分かった。
旧い抽出器は「書いた命令の PC が RAM なら自作コード候補」としていたため、ROM が RAM に置いたコードの書き込みの値を
控えとして通しうる穴があった。**抽出器を「書いた命令の PC が [X, X+0x100)（X = 生成器に与えた読み込み先）に入るもの
だけ」を控えとして扱うよう直した**（それ以外の RAM 上の PC の書き込みは ROM 側と同じく番地の範囲と件数だけ）。
自己検査に陰性対照 M1 を足した（試験 ROM が別の RAM 番地へ控えを真似る小さなコードを写して実行し、目印の値を書かせる）。
**直す前の抽出器で M1 の判定（J_norecord・J_noleak）が NG になることを先に確かめ、直した後に合格を確かめた。**
この修正は測定（A1〜A6）より前の器具の修正であり、P0 の記録（番地と件数だけ）には影響しない。

## 2. 追加の腕

| 腕 | 内容 |
|---|---|
| N0 | ディスク無し（`--disk` なし）。P0 と同じ器具・同じ `--frames 1200`・同じ取りこぼし回避の4範囲。2走 |

N0 は P0 の対照である。腕として記録する（`measurements/b2-n0-d0.txt`）。

## 3. D0'（本体の D0 を置き換える）

1. P0 の RAM 実行番地の集合（2走で一致）から、N0 の2走の RAM 実行番地の集合（2走で一致が前提）を除く。
   N0 の2走が互いに違えば、違う番地は「揺れる」とし、**除く側には入れない**（保守側）。
2. 残った（ディスクありだけで実行される）番地のうち**最小の番地**を E とする（時刻の順は記録に無いので、番地の順で決める）。
3. P0 の ROM 書き込みの連続範囲（256 以上）のうち E を含むものの先頭を S とする。
4. `X := S`、入口オフセット `E − S`。残りが空、または E を含む範囲が 1 本に決まらなければ **X 不明として止める**。

## 4. 独立の確認（必須）

X・入口で A2（HALT 腕、目印 seq）を組み、**2走**回す。2走とも抽出器が `base_true == X`・`consistent=yes` を返すこと。
1走でも返さなければ X 不明として止め、A1〜A6 には進まない。発行元 PC は実際に実行された番地なので、
D0' が選んだ X とは独立の出所である。

## 5. 変えないもの

本体の第3節（条件）・第5節（白リスト）・第7節（止める条件）・D1 以降は変更なし。
