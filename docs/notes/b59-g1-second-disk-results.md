# B59: G1 の 2 枚目のディスクを入れて、公式と自作がどこまで同じに進むかを測る — 結果

記録日: 2026-11-02
規則: [b59-g1-second-disk-preregistration.md](b59-g1-second-disk-preregistration.md) と追補どおり。測定はクラウドの実行環境で rc=0。記録は `measurements/b59-g1-second-disk.txt`。

## 結果

ファイルの像の数は 3 だった。像 1 を入れる腕 A（フレーム 1 でドライブ 2）、B（7200 でドライブ 2）、C（7200 でドライブ 1 を入れ替え）のどれでも、公式・自作とも移る回数は 71 で、画像・テキストも一致した。

## 分かったこと

スペースとリターンの打ち方では、2 枚目を入れても公式は 71 回より先へ進まない。自作は公式と同じである。B60 の `i`・`s`・F1 のように、キーで先へ進む道があるので、次はそちらを長押しで進める。
