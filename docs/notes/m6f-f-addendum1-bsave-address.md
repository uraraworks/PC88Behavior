## 2. F-B の打鍵（事前登録 §3 の F-B を置き換える）

```
clear ,&hcfff
for i=0 to 15:poke &hd000+i,65:next:bsave "2:qzb",&hd000,16
```

- `clear ,&hcfff`（2-23 の例と同じ上限）で、&HD000 以降を BASIC が使わない領域にしてから、自分の値（0x41）を16バイト書き、その範囲だけを保存する。
- &HD000 は 2-11 の禁止範囲（&H8000〜&H83FF）に入らない。
- 番地の選び方はマニュアルの言語仕様（上の2頁）だけに基づく。ROM のワークエリア番地の資料は使っていない。
- 器具では `--bsave-addr &HD000` と、F-B の打鍵の先頭に `clear ,&hcfff\n` を置く。打鍵列の SHA-256 はこの内容で凍結する。

事前登録のほかの項目は変えない。
