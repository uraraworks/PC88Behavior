# ゴール B 方針 追補5 — G1 の最初の要求の連続の中身を記録する

記録日: 2026-11-01
位置づけ: [追補4](goal-b-policy-addendum4-two-reply-bytes-2026-11-01.md) の後続。これまでのノートは書き換えない。

[B22](b22-g1-differing-replies-results.md) で、違う 2 バイトの直前の要求の連続は長さ 10 の 1 本だった。読み要求の 7 バイトの後ろに別の要求があるように見える。2026-11-01 に利用者と、次の線まで記録してよいと決めた。

**記録してよいもの: G1 の main が起動用セクタの範囲から最初に送る `OUT $FD` の連続（長さ 10）の 10 バイト。** 次の要求（`0x0C` の 709 バイト）の本体は今までどおり記録しない。働きは自作のプローブで測る。
