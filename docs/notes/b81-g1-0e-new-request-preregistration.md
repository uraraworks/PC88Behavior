# B81: `0x0E` のあとを新しい要求として受ける自作 ROM で、G1 の道を確かめる — 事前登録

記録日: 2026-11-04
位置づけ: [B80](b80-sub-0e-after-bulk-preregistration.md) の追補の次段。**このノートは測定より先にコミットする。**

## 1. 変える所

自作サブ ROM は、`0x0E` を受けて読み終えたあと、BASIC の交換 #14 の続きとして同じ要求の受信を続けている。バルクの読みが済んだあと（`POST_BULK_ACTIVE` が 0 でない）は、`0x0E` を独立した要求として扱い、次の先頭バイトを新しい要求として受ける。起動のときの交換 #14 は今のまま続ける。仕様は 1.36c 節（第233版）のとおりで、仕様の変更はない。

## 2. 条件

B69 と同じ 5 腕（B65 の I1、I2、I3、S1、F1）。公式 2 走、自作 1 走。クラウドの実行環境で行う。白リストも B69 と同じ。

## 3. 判定（事前に決める）

- F1 の腕で自作が 74 になり、`IN $FC` が公式との差 4（B48 の位相）に戻れば、直ったと書く
- ほかの 4 腕が B69 から変わらないことを確かめる
- 変わらなければ、見立ては外れと書き、変更を元に戻す
