# m6f-k — KILL・NAME の外から見える挙動 — 事前登録

記録日: 2026-10-02  
状態: **測定前**

## 0. 位置づけ

自作BASICに `KILL "<ドライブ>:<名前>"` と `NAME "<ドライブ>:<旧名>" AS "<ドライブ>:<新名>"` を入れる前に、
l3-disk-format.md・l4-basic.md に無い挙動を公式ROMで測る。既知として使うのは次だけ。

- 削除されたエントリは先頭1バイトが `0x00`、残りは削除前のまま（l3-disk-format 1.2節、m6f-b E5）。
  これは本段でも腕 K-1 で確かめ直す（候補の一つとして扱い、前提にはしない）。
- エントリ・割り当て表・鎖の読み方（1章・2章）。

担当・禁止は m6f-j 事前登録 §0 と同じ。**割り当て表は位置 0〜159 だけを扱い、160 以降は読まない・比較にも使わない**
（[汚染の記録 2026-09-25](contamination-2026-09-25-fat-buffer-overrun-values.md)）。
**ファイルの本体は読まない**（KILL・NAME は本体を書かない前提で、本段の問いに本体は要らない。
本体のセクタは「変わったか」の真偽だけを記録し、値は出さない）。
ディレクトリは (18,1,1)〜(18,1,12) のうち、媒体に置いたエントリと、変化したエントリだけを欄ごとに記録する。
変化したエントリが媒体に置いていない枠だった場合は、位置と「変わった」だけを記録し値は出さない。

構成は m6f-h〜m6f-j と同じ（ドライブ1＝参照 diskA 複製で起動、ドライブ2＝自作媒体、**打鍵は小文字で届く**、
画面は行署名のみ、測定後の像は削除）。打鍵が小文字で届くので、大文字・小文字の問いは**媒体側に大文字の名前を置いて**作る。

## 1. 問い

- **K-I 削除の形**: `KILL` でエントリはどう変わるか（先頭1バイトだけ `0x00` か）。ファイルが使っていた単位は空き（`0xFF`）に戻るか。
  他のエントリと他の単位は変わらないか。
- **K-II 完了の画面**: 完了時に入力待ちの行とは別に `Ok` の行が出るか。
- **K-III エラー**: 名前が無い・書き込み禁止の媒体。
- **K-IV 名前の照合**: 媒体の名前が大文字のとき、小文字で打った名前で見つかるか（l3-disk-format 1.3節の未確定）。
- **N-I 改名の形**: `NAME` でエントリは同じ位置のまま名前欄だけ変わるか。名前欄の後ろ（9〜15バイト目）と割り当て表は変わらないか。
- **N-II 完了の画面**: `Ok` の行が出るか。
- **N-III エラー**: 新しい名前が既にある・旧名が無い・書き込み禁止の媒体。
- **N-IV 新名のドライブ省略**: `AS` の側にドライブを書かないとき、ドライブ2の改名になるか・エラーか。
- **N-V 名前の照合**: K-IV と同じ問いを `NAME` の旧名で。

## 2. 媒体（l3-disk-format 第5版以降だけで作る）

- KM: 空の媒体（m6f-c と同じ）に次の3件を置いたもの。いずれも種別 `0x00`（ASCII プログラム）、本体は 2.6節の形。
  - `qsa`（`10 PRINT 1`、1単位、単位 10、(18,1,1) の第0エントリ）
  - `qsb`（2単位、単位 20→21、21 が終端。(18,1,1) の第1エントリ。本体は 9セクタ以上の ASCII プログラム）
  - `QSU`（大文字、`10 PRINT 3`、1単位、単位 30、(18,1,1) の第2エントリ）
  - エントリの 11〜15 バイト目は `0xFF`（作成直後の値。1.2節）。
- KP: KM に書き込み禁止の印（3節）を付けた媒体。

## 3. 腕（各2走、毎走 KM/KP を作り直す）

| 腕 | 媒体 | 打鍵（`\n` は RETURN） | 観測 |
|---|---|---|---|
| K-1 | KM | `cls:kill "2:qsb"\n` | 画面、3エントリの全欄（前後）、割り当て表 0〜159 の変化した位置と新しい値、他の枠の変化の有無 |
| K-2 | KM | `cls:kill "2:qsc"\n` | 画面（エラー）、媒体不変 |
| K-3 | KP | `cls:kill "2:qsa"\n` | 画面（エラー）、媒体不変 |
| K-4 | KM | `cls:kill "2:qsu"\n` | 画面、`QSU` のエントリが消えたか、媒体不変か |
| N-1 | KM | `cls:name "2:qsa" as "2:qsd"\n` | 画面、3エントリの全欄（前後）、割り当て表 0〜159 の変化、他の枠の変化の有無 |
| N-2 | KM | `cls:name "2:qsa" as "2:qsb"\n` | 画面（エラー）、媒体不変 |
| N-3 | KM | `cls:name "2:qsc" as "2:qsd"\n` | 画面（エラー）、媒体不変 |

## 4. 候補と判定

画面の予測は `Ok` の文字列・エラー表の文言（l4-basic.md のエラー表）と行の位置だけから作る（m6f-j と同じ）。

- K-1: エントリは `first_byte_00_rest_kept`（先頭だけ `0x00`）／`all_ff`（未使用に戻す）／`other`。
  単位は `units_freed`（20・21 が `0xFF`、他は不変）／`units_kept`（割り当て表不変）／`other`。
  画面は `ok_line`／`no_line`／`other`。腕の判定はこの3つの組。
- K-2・K-3・N-2・N-3・N-4: `error_<N>`（媒体不変。N は画面の署名をエラー表と照合）／`no_error_media_unchanged`／`other`。
- K-4・N-6: `case_insensitive`（`QSU` が消えた・改名された）／`error_53_unchanged`／`other`。
- N-1: エントリは `same_slot_name_only`（同じ位置、名前欄 0〜8 だけが `qsd` と詰め物 `0x20` に変わり、9〜15 と割り当て表は不変）／
  `same_slot_other_fields_changed`／`new_slot`（旧エントリが削除され別の枠に作られた）／`other`。画面は `ok_line`／`no_line`／`other`。
- N-5: `renamed_on_drive2`（N-1 と同じ形）／`error_<N>`（媒体不変）／`other`。

2走とも一意に一致した候補名を判定とする。0件・複数は `inconclusive_<腕>`。

## 5. 関門

m6f-j の G1〜G9 のうち本体に関わらないもの（凍結照合で起動0、2走一致、参照 diskA 不変、割り当て表の読み取りが位置 0〜159 に限られる、
媒体の独立検査）に加え、

- **G10**: 本体のセクタ・媒体に置いていないディレクトリの枠について、器具の出力が「変わったか」の真偽と位置だけであること
  （値を出す経路が無いことを自己検査で確かめる。陰性対照として、置いていない枠を書き換えた像を与えて値が出ないことを見る）。
- **G11**: 打鍵の後、画面が入力待ちに戻ったことを `tools/check_l3_entry_screen.py` で確かめてから媒体を読む（書き込み途中の像を読まない）。

## 6. 行き先

`docs/spec/l3-disk-format.md` に「消す側・改名する側」の節、`docs/spec/l4-basic.md` に `KILL`・`NAME` 節を起こす。
その後、自作 main に `KILL`・`NAME` を実装し（main の空きが足りなければ拡張ROMバンク、ext-rom-bank.md）、
(1) 自作 main＋公式 sub、(2) 自作一式で消した・改名した媒体を、公式ROM 一式の `FILES`・`LOAD` で読ませて確かめる。

## 7. 決めないこと

- ドライブをまたぐ `NAME`（ドライブ1の参照 diskA を書き換えうるため測らない）。
- 名前の長さの規則（7文字以上・拡張子の区切り）、ドライブ番号の省略された旧名。
- 開いているファイルの `KILL`、ワイルドカード。
- 割り当て表の位置 160 以降、本体の値（読まない）。
