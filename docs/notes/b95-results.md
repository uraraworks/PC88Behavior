# B95 結果：3080 の SHIFT・カナ・ファンクションキー・同時押し

実施: 2026-11-17、クラウド（公式 ROM と自作 ROM main dbe1b37、G5）。[事前登録](b95_preregistration.md) からの変更は2点。G5 は F7140 頃まで 3080 を呼ばないので打鍵開始を F3600 から F7200 にした。B94 の測定用コアが残っていなかったので、リポジトリ外のプローブで作り直した。値・画面本文は出さない。

## 積んだ文字の列（公式件数/自作件数、一致）

| 腕 | 結果 |
|---|---|
| K-A・K-1・K-TEN8 | 3/3 で一致。35CE の返り値も一致 |
| K-SA・K-S1・K-KANA | 3/4 で1番目から違う。自作は ECDF を2回呼び、35CE は自作19回（公式3回） |
| K-F1 | 1/100 |
| K-UP・K-ESC | 3/100 |
| K-SF1 | 0/113 |
| K-AB | 4/3。ECDF は公式2回・自作1回 |
| K-FULL | 10/11 で3番目から違う。押し始めは両方10回、満杯には達しなかった |

ファンクションキー・カーソル・ESC の腕で自作は毎回積み続け、35CE は約7000回呼ばれた。

## 自作の INKEY$ 対応表との照合

A・1・SHIFT+A・SHIFT+1・カナ+A・テンキー8・A+B・A〜Z で公式が積んだ文字は、すべて自作表と一致した。f1・カーソル上・ESC は自作表に無く（自作表では0）、公式が積んだ文字は自作の6表のどれとも違った。

## その他

- EFF9〜EFFE・EFC4〜EFC7・E6CF の書き込み列は、無入力を含む全腕で1件目（EFF9）から違う。EFF9 の一定値は第12版で「自作の既存値で代用」としたもので、想定どおり。
- ECDF 呼び出し時の BC・DE は、公式・自作とも 3080 入口の値のままではない。単独キーでは毎回同じ値で、押したキーによって変わる。

## 判定

1. SHIFT・カナは、それだけでは押し始めにならない（公式は SHIFT+A で A 単独と同じ3文字・ECDF 1回）。自作は修飾キーの押下も押し始めとして扱っている。
2. 同じ回に2つのキーが押し始めになると、公式は ECDF をキーごとに呼ぶ。自作は1回。
3. 自作表で0のキー（ファンクションキー・カーソル・ESC など）を自作は毎回積んでしまう。公式はキー1回の押下で文字を積む（f1 は1文字）。文字コードは自作表に無いので、BASIC の INKEY$ で測ってから表に足す（値を G5 の測定から写さない）。
4. K-FULL の3番目からの違いと BC・DE の規則は未確定。1・2を直してから測り直す。
