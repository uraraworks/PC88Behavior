# B86 追補5 事前登録（測定前）

需要と規律は B86 および追補4に従う。追補4のクラウド観測では開始印が約340〜377フレーム後に再出現し、64腕は起動から再実行されていた。以前の「3847 単独でセクタ受信」も再実行を含むため根拠にしない。37C9 の A=00/FF では37D2の1回目、A=02では5回目が戻らず、A=01では試した回数が戻った。3847単独は戻らなかった。これらは値なし観測であり内部経路は扱わない。

仮説は 37C9 が A を要求先頭として送り、37D2 が引数1バイトを送り、3847 が1バイトを受け A に返すというもの。37D2 の入力レジスタは未確定。各腕独立起動、SP=F000、DI、腕別 ROM 置き場。自作起動媒体は40シリンダ、両面、各16セクタ、座標刻印付き。自作 0x0C, 60,00,01,00 と256バイトの模様 `(73*i+41) mod 256` を送った後、0x09,60,00,61,00 を送る。0x0C の引数と本体は A を使い、0x09 の4引数だけ A または C/E/L を使う4方式（後者は A=A5 固定）。3847を1、16、256回呼ぶ12腕とし、各戻りAと同じ位置の模様の一致真偽を記録する。書き込み自体は仮説に依存し、失敗時にはレジスタ候補を否定できない。

別に 02,01,00,00,02 → 15,50,00,01,00 → 3847×256 と、15 を省く対照を置く。0x02 は自作ドライブ1の T=0、R=2、座標 (0,0,2) を指定する。3847 の各戻り A を自作セクタの同じ位置と比べ、256個すべて戻り一致したとき全体一致とする。0x02 の受理・待ち状態と 0x15 の可否も含めて観測するため、途中で止まった場合は後続について結論しない。RET と RAM 書き込み・OUT FD の自作 RAM ルーチンを対照として同じ反復を行う。

開始印の再出現は再起動とし、その時点で開始済み・未終了の呼び出しを「戻らない（再起動）」と数え、以後の記録を捨てる。開始印より前は無視し、開始印が無い場合、ログ取りこぼし、印順序の異常は欠測。再起動も終了印もない時間上限は「時間上限内未確認」、未開始の後続は記録しない。無限ループとは断定しない。前後区間の順番、戻り、送受信件数、比較真偽、自作媒体座標のみを集計する。生ログ、媒体、出力はリポジトリ外に保存し、ROM複製と大きな一時出力は腕終了後に削除、I/Oログは圧縮する。既定は2010フレーム・180秒。公式 ROM の値、内部 PC、画面本文は公開しない。

自己検査は PC88_REF_* を外し、自作の RET・陽性対照と順序異常・取りこぼし・再起動の切り捨てを試す。配布用自作 main・sub でも全腕を独立起動し記録する。入口や自作 sub の 09 が未実装ならその腕は記録のみとし、公式の動作の証拠にも自己検査の失敗にも使わない。自己検査 PASS 後にクラウド測定する。
