# B19: `0x0D` で移ったときの割り込みの状態を、自作のコードで測る — 事前登録

記録日: 2026-10-31
位置づけ: 実装 ＋ 確認走行で、自作サブの上の G1 は RAM 上のコードが動くが、記録 A に `0038` への移動が多数出た（公式には無い。[B15](b15-g1-sub-boundary-results.md)）。1.36c 節は割り込みの状態を未測定としている。
**このノートは測定より先にコミットする。** 結果を見てから規則を変えない（変えるときは後続ノートで）。

G1 は使わない。送るコードはすべて自作で、公式の値は記録しない。

## 1. 問い

`0x0D` で番地 A へ移った直後、割り込みは許可されているか。`0x00C1` へ戻って次の要求を受けたあと、同じ状態か。

## 2. 器具

B17 と同じ。自作のコードが `LD A,I` のパリティで許可の状態（IFF2）を調べ、許可なら目印番地 M1、禁止なら M2 へ書く。値は記録しない。書かれた番地だけで分かる。

## 3. 行

| # | 送るもの | 目印 | 狙い |
|---:|---|---|---|
| 1 | `0C`・`0D` で 1 回走らせて `00C1` へ戻る | `7810`/`7811` | 移った直後 |
| 2 | 行1 のあと 2 回目の `0C`・`0D` | `7820`/`7821` | 戻ったあと |
| 3 | 行1 のあと読み要求、そのあと `0C`・`0D` | `7820`/`7821` | 読みのあと |
| 4 | 自作のコードが `EI`、短い待ち、`LD A,I` の順で調べ、`00C1` へ戻る | `7810`/`7811` | 対照: 許可の状態が記録に現れること |
| 5 | 行4 のあと 2 回目の `0C`・`0D`（`EI` なしの調査） | `7820`/`7821` | `00C1` が許可を切るか |

## 4. 判定（事前に決める）

対照: 行4 で M1 が書かれる。2 走が全行で一致する。通らなければ根拠にしない。

- 行1 が M2 なら「`0x0D` で移るとき禁止」、M1 なら「許可」
- 行2・3 を同じように書く
- 行5 が M2 なら「`00C1` へ戻ると禁止に戻る」
- 記録 A の `int` の回数も行ごとに書く
