# m6f-i 追補2 — 結果（LOAD の規則を採る）

記録日: 2026-09-28

## 1. 実行

[追補2](m6f-i-attempt2-and-addendum2.md) §2 に従った。器具 `b31e1f4`、公式ROM起動8回（4腕×2走）。関門 G0〜G15 はすべて真、参照 diskA 複製は不変、
作業先で画面本文を持つファイルは0件。

## 2. 判定

| 腕 | 判定 |
|---|---|
| I-4' | **`ok_line`** |
| E-2' | **`direct_msg_57`** |
| E-3 | **`upto_error`** |
| E-3m | **`direct_msg_57`** |

いずれも2走一致・一意。

## 3. 採った規則（m6f-i 2回目と合わせて）

根拠の腕を括弧内に記す。対象は ASCII 形式（種別 `0x00`、l3-disk-format 第5版 2.6節）のファイル。

1. `LOAD "<ドライブ>:<名前>"` は、それまでのプログラムを**置き換える**（2回目 I-2 `replaces`）。
2. 読み込んだ行は**行番号順**に並ぶ（2回目 I-3 `sorted`）。
3. 読み込みが終わると **`Ok` の行を1行出し**、その後に通常の入力待ちに戻る（I-4' `ok_line`）。
4. 名前が見つからなければ **`ERR 53`**（1回目・2回目 E-1）。名前は大小を区別する（l3-disk-format 1.3節、m6f-i 1回目）。
5. 行番号の無い行に当たると **`ERR 57`**（エラー表の57番のメッセージ、E-2'・E-3m）。**その行より前の行は読み込まれたまま残り**、後ろの行は読み込まれない（E-3 `upto_error`）。
6. `LOAD` はプログラムを置き換えるので、`ON ERROR` による捕捉のプログラムも消え、`LOAD` 中のエラーは直接モードのエラーとして表示される（2回目 E-2 `not_trapped`、事後の読み）。

## 4. 行き先

`docs/spec/l4-basic.md` に第12節「観測 — LOAD（ASCII 形式）」を新設する。種別 `0x00` 以外のファイルの `LOAD` は測っていないので、
自作での扱いは仕様書に「自作側の判断」として別に書く。
