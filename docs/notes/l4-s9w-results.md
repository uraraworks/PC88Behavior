## 塗られる画素の集合（観測）

- 開始点を含む「**境界色でない画素の4連結成分**」を領域色で塗る。壁の画素は変わらない。斜めの壁は越えず、斜めにしか繋がらない隙間・斜めの鎖の通路は通らない（`conn8` は cn-1 で 10/18 腕しか一致しない）。1ドット幅の通路（水平・垂直・L字・2ドット幅）は通る。入れ子の内側・輪の内側は塗られない。
- **境界の判定は画素値（3プレーンの値）の完全一致**。壁の色 wc × 境界色 bc の 49 通りが全て一致（`bd-1`〜`bd-3`）: wc=bc なら壁で止まり、wc≠bc なら壁は境界でなく塗り替わって枠の内側全体が塗られる。ビットの包含などの候補（b-subset・b-any・b-superset）は不一致。
- 領域内にある「別色の障害物」は塗り潰され、**領域色と同じ色の画素・輪も通り抜ける**（輪の内側の空きまで塗る。`stopfill` は sh-1・sh-2 で1セル不一致）。孤立した境界色の点は回り込む。塗り済みの領域に別色を重ねると全域が塗り替わる。領域色 0 は消す。
- **開始点が境界色の画素なら何も起きない**（誤りなし）。境界色省略は領域色と同じ番号（`lk-1`: 枠 7・円 7 のとき領域色 5 で境界省略なら枠も塗り替わり画面全体 128000 画素が 5 になる）。領域色 0・境界省略は開始点（0）が境界なので何も起きない。
- **画面の端は壁**: 端で切れた円の内側は円弧と画面の端で閉じた部分だけ（`ed-2` 8 図形全一致）、壁のない領域は画面全体（`ed-1`）。
- 開始点が画面外（−1・640・200・−5・1000）は **ERR 5**、LP は開始点へ動く。座標が −32768〜32767 の外は **ERR 6** で LP は動かない。小数は四捨五入（14.4,14.6→14,15）。塗ったあとの LP は開始点、STEP は LP からの相対。
- 色: 領域色・境界色の −1・8・255・境界 7.5 は ERR 5、`1e10` は ERR 6、境界 `"a"` は ERR 13、境界が空（`..,5,`）は ERR 22、領域色 `"a"` はカラーで1文字のタイル扱いで ERR 5。0.4→0・6.5→7 の四捨五入。領域色省略は COLOR 第4引数。

## 白黒（`mo-0`・`mo-1`）

領域色が 0 以外ならアクティブページのプレーンに 1 ビット、境界の判定は画素が立っているか（色 3 の枠に境界色 7 でも止まる）。11 セル全一致（プレーン 0・1）。境界色 0 は開始点が境界なので何も起きない。白黒のタイルは1バイト＝1行、ビットが 1 のドットが立つ。

## タイル塗り（観測）

- カラーの文字列は行ごとに 青・赤・緑 の3バイト、MSB が左。**位相は画面の絶対位置（x mod 8、y mod 行数）**。タイルの全 16 セル（tl-2: 開始点・枠の位置を変えても絶対位置）が一致し、開始点基準（tile-start 0/16）・領域の左上基準（tile-region 0/16）は不一致。
- 3文字未満（2文字・空）は塗られない（ERR 5）。余りの文字（4・7・14文字）は無視。タイルの色が境界色と同じでも全域に敷かれる。全 0 の行が 3 回連続するタイル（既定の背景 0）は塗られない（ERR 5）、背景を別パターンにすれば塗られる。タイルの重ね塗りは後のタイルが全域を置き換える。
- **説明できていない観測**: 1行のタイル `"abc"` にバックグラウンド `"abc"`（同じ文字列）を付けると ERR 5（sx-b）。一方、4行のタイルの先頭行と同じバックグラウンドは塗られる（tl-3）。タイルが背景だけの場合に画素が変わらない形（全 0 の2行など）は、塗られた場合と ERR 5 の場合を画素で区別できない。「3回以上連続」を縦に循環して数える可能性があるが、この段の観測では決められない。

## 作業領域（ERR 7 は一度も出なかった）

- 歯 300 本の櫛（既定のスタック 512）、画面幅の点線格子 639×99（既定）、蛇行路、いずれも**誤りなしで完全に塗られた**。`clear ,,N` を 16〜60000 に変えても ERR 7 は出ない。`dim a(N)` で空きを減らしても N=4000・5000・5500 は塗りまで完全で、**N=6000 以上は DIM 自体が ERR 7** になり PAINT に届かない（刻みを細かくしても PAINT の側の ERR 7 は起こせなかった）。「この範囲の条件では作業領域の不足を起こせなかった」。
- **スタックの大きさ（歯 10・20・40 本の櫛3つ。`ws-1` と同じ画面）で結果が変わる範囲がある**: N=16・64・136・160・192・256・512（`ws-1`）は壁が保たれて完全に塗られる（歯 80・160・300 本の櫛の `ws-2`・`2b`・`2c` は 512・2048・16384 で同じ画面）。**N=96・112・120・127・128・129 は誤りなしのまま、歯の壁（境界色 7）3350 画素が領域色 5 に塗り替わる**（枠の外周は残る）。N=96 は塗ったあとの LP も (0,0) になる。境目は (64,96] と (129,136]。PAINT が作業領域の限界で壁の判定を失う誤動作と見えるが、原因は特定できていない（実装者は再現を要求されない異常と考える）。
- 点線格子の腕から、**ラインスタイルの水平線は第2座標から数える**（第9.6節）ことの再確認が取れた（長さ 636 の線。モデルの欠陥で外れていた）。

## 器具・モデルの欠陥と反省

- 参照モデルの LINE を、他の文で確定済みの規則でなく事前登録時の古い規則（lm.PRIMARY）で書いた（l4-s9v の反省と同じ型。流用元の定数が「予測時のもの」だった）。点線のスタイルの数え始めも、仕様に書いてあった規則をモデルに入れていなかった。**他の段の確定済みの規則は、その段の仕様書から引く**。
- 較正の腕の「基準の画素」が塗り領域の内側に入る幾何だった（ハーネスの基準は x+6 固定）。塗る腕では基準の画素の位置も見る。
- 区間が多い腕は、観測を1欄に入れると csv の既定の上限（131072字）を超える。腕の同一性はプログラムの文字列で比べる。
