## 読んだ範囲とGWの手順

CLAUDE.md全文、l4-program.md第8節項目32、既存PRINT記録器の関数・引数と
conform_l4.shの打鍵・PRINT採取の使い方、l4-c8事前登録の「測定方法・関門」
「検出力の自己検査」を読んだ。公式ROMのバイト列・逆アセンブルは読んでいない。
GW-BASIC MIT公開ソースのみを候補の資料にした。CP932/NEL混在を考慮し、
`rg -a`で探索した（通常のgrepの0件を不存在の根拠にしない）。
器具の直接モード呼び出しの確認としてGWMAIN.ASM 2049–2128も読んだ。
読んだ箇所は MATH1.ASM 901–918・2583–2593、MATH2.ASM 230–280・1664–1730、
GWDATA.ASM 633–670、GWMAIN.ASM 3383–3410、BIMISC.ASM 196–241。

GWは24ビット整数状態を乗数214013、加数2531011、法16777216で更新し、
状態を16777216で割った単精度数を返す。初期状態は八進の122・307・117を
低位から並べた整数0x4fc752（5228370）。次の状態の最初の5個は
2035917、10936412、14577071、12243382、13402529。
これはソースの数値例ではなく、初期状態に乗数と加数を掛け足して法で割った
余りを順に計算した固定値である。器具のselftestで再帰計算と照合する。

RND(0)は更新せず現在の状態を返す。正引数は大きさによらず1回更新する。
引数なしは1を渡す。負引数は単精度の格納仮数3バイト（符号を含み、指数と
暗黙の先頭ビットを除く）を状態に入れ、それから1回更新する。
したがって-1と-2の種はともに0x800000、-1.5は0xc00000。
同じ負引数なら直前の状態に依存せず同じ値と後続列になる。

RANDOMIZE nはFRCINTで符号付き16ビットの最近接整数に丸める（1.5は2、ちょうど半分は
絶対値の大きい側）。現在の状態の低位8ビットを残し、上位16ビットに整数のビットを
入れ、その後1回更新する。この1回の値はPRINTせず、次のRNDはさらに更新する。
時刻は参照しない。引数なしは対話入力へ進むので測らない。
RUNC/CLEARCはRNDCOPから状態を復元するのでRUNは先頭に戻る。

## 値の取り出し方

PRINTの単精度6桁表示そのものから24ビットを推定しない。
`a=x*4096:print int(a);int((a-int(a))*4096)` は、xが24ビット固定小数の
[0,1)なら状態整数を上位・下位12ビットに分けて出せる。ただし任意の
小さい単精度値には24ビット固定小数より下の桁があり、この式だけでは失う。
そこで全腕で符号sと二進指数eを採り、絶対値を2倍または半分にして
非零なら[0.5,1)へ正規化してからこの2分割をする。指数を残すため、1/2未満も
負値も1以上も区別できる。零はs=e=h=l=0。
復元式は `s*(h*4096+l)/16777216*2^e`。
2の冪による正規化・乗算は正確で、差は整数部と元の数が十分近いため正確。
正規化後の24ビット仮数を2つの12ビット整数にするのでPRINT表示でも欠損しない。

器具の900–970行が正規化とPRINTを行う。自分で打ったPRINTの固有印`s8`に続く
標本番号・符号・指数・上位・下位だけを整数として記録する。
集計行の印は`s8c`で、零の個数・1の個数・範囲外の個数を記録する。
正数は先頭空白、負数は`-`を認める。印と整数のみの完全一致を要求し、
印の大小文字を同一視する。その他の画面行は本文を出さず件数だけを残す。一時画面写しは削除する。

## 測る腕（22腕、各2走。定数関門7腕を別に付け計29腕）

- 起動列2腕: 余分な待ち0／137フレームでRND(1)をFORループで20個。
- 引数6腕: 最初のRND(0)、RND(1)の後のRND(0)2回、引数なし、2、0.5、1E10。
  後ろ4腕はFORループで各5個を採る。
- 負引数5腕: -1、-2、-1.5、-1E10の値と後続5個、-1を連続2回の後の5個。
- RANDOMIZE 7腕: 0、1、2、100、-1、32767、1.5の後のRND(1)5個。
- 再実行1腕: 10行のFORプログラムをRUN2回、NEW後に器具も打ち直しRUN。
  3つの画面時点を分けて保存し、15個を順に記録する。
- 範囲1腕: 初回から2000個。BASIC側で最小・最大・零・1・範囲外を集計し、
  最小・最大の正規化24ビット表現と3個の計数だけPRINTする。

初回のRND前には器具の行を登録しCLSを打つ。起動列・引数・負引数・
RANDOMIZE・範囲は直接モードのFOR/GOSUBを使い、RUNによる種の変更を混ぜない。
したがって「起動直後」は必須の起動settleと器具入力後の最初のRNDという意味。
追加137フレームは器具入力後、最初の操作の直前に入れる。
既定条件は公式起動settle300フレームで改行、器具入力開始700フレーム、
8フレーム/文字、行間240フレーム。PRINT処理には3000フレーム余裕、
2000回集計には250000フレーム余裕を与える。全BASIC行は小文字。
直接モードは数字で始めず、数字始まりは登録するプログラム行に限定する。

## 固定候補と値の予測

`tools/l4_rnd_measure.py predict --out FILE` はROM不要で全29腕×2候補のTSVを
生成する。R_GWは上記ソースの初期値・更新・引数・RANDOMIZE・RUN規則そのもの。
数値予測を復元可能な整数組で全腕について固定する。
R_GW_Sは同じ更新式・引数規則で、起動時／RUN復元時の共通初期状態だけ未知。
start-0の最初の観測を24ビット状態に戻し、214013の法2^24での乗法逆元を
用いて更新前の共通初期状態を復元する。その最初の値は照合証拠に数えない。
復元値を全腕で共有し、後続、RND(0)初回、RANDOMIZE、RUN、範囲集計も予測する。
負引数腕は初期状態と無関係なので測定前に数値まで固定できる。
初回値が[0,1)の24ビット格子に乗らない場合、後続照合だけでもdifferとなる。
初回腕の採取関門が失敗した場合、共通初期値を使う判定はundeterminedとする。
測定前TSVでは初回観測が必要な予測にその旨を記し、測定TSVでは全候補の
整数組予測も記録する。数値予測の算法はこの時点で固定し測定値に合わせて変更しない。

| 定性的な予測 | R_GW | R_GW_S |
|---|---|---|
| 待ちフレームによらず同じ起動列か | yes | yes（共通の未知初期値） |
| RUNで先頭に戻るか | yes | yes（共通の未知復元値） |
| RND(0)は直前の値か | yes | yes |
| RND(-x)は同じxで同じ値か | yes | yes |
| 正引数の大きさで更新が変わるか | no | no |
| RANDOMIZEが時刻を参照するか | no | no |

待ち条件間の列一致、3回のRUN列一致、同じ負引数の繰り返し一致も観測値から
別途比較する。候補内の未知初期値を腕ごとに別値として採用して定性的予測を
免除しない。外れたらdiffer。新候補は追補を事前登録してから測り直す（l4-s5j方式）。

## 測り方と関門

`measure --rom-dir DIR --out FILE [--official]`。私物のDIRは環境変数
`PC88_REF_ROM_DIR`経由で渡す。既定作業置き場はリポジトリ外の
`../tmp/l4s8a-work`、`--work-dir`で変更可能。公式測定は親が行う。
測定TSVは打った行、各走のPRINT整数組、その他の行の件数、関門、
候補ごとのagree/differを含む。打鍵・採取失敗、標本番号・値形式・件数不正、
2走不一致はgate_failed。全定数対照が通らない測定は全腕gate_failed。

selftestの合成陽性対照は正負・零・1以上・小さい値とPRINT印の抽出、
陰性対照は印の破壊、下位12ビット超過、正規化不足、後続値の1ビット改変。
GW再帰の最初の5個と負引数の種・条件付き予測の再現も確かめる。
自作ROMの直接モードGOSUBでは採取関門が通らなかったため、定数対照は
自作ROMでは10行のプログラムとRUN、公式測定では直接モードで呼ぶ。
正規化・分割・PRINTを行う900–970行は共通で、公式測定で直接モードの
7対照が通らない場合は全腕gate_failedとする。
一時ビルドした自作ROMで0、0.75、1/3、-0.75、1、2、2^-24の7腕を各2走。
誤った0.5の期待値への不一致を陰性対照とする。RND未実装なので自作ROMで
RND腕は測らない。実行する検査はtools/l4_rnd_selftest.shだけで、
run_all_selftests.sh全体は実行しない。
