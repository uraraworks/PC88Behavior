# 事前登録（追補）: m7lt 2回目——I/Oログ指紋の定義だけを直し、関門と判定規則は据え置く

対象: [m7lt 事前登録](m7lt-no-disk-cpu-mode-screen-preregistration.md)。
1回目の結果: [m7lt 1回目](m7lt-no-disk-cpu-mode-screen-results.md)（`gate_failed`。取り消さず残す）。

## 変えたもの

**I/Oログ指紋（`io_log_full_sha256`）の定義だけ。** フロントエンドが見出しに書く
`core`・`rom-dir`・`disk`・`disk2`行（走ごとの作業ディレクトリ名を含む）を除いた
残り全行のハッシュに変えた（単独コミット済み）。

## 変えていないもの

条件7つ・`+0`の構造的定義（`locate_plus0_no_disk`）・関門G0〜G3・判定規則
（優先順位1〜5）・判定ごとの次の行き先は、元の事前登録のまま**一切動かさない**。

## 測定前の段階0（追加）

1回目にはこれが無かったため、器具の欠陥（走ごとのパス行が指紋に混入）に測定後まで
気づけなかった。2回目は、本測定と同じ走から得られるG0・G1の結果自体が段階0を兼ねる:

- **G0（同一性）が真であること** ＝ 同一条件2回（`none`と`m0`）の指紋一致。
  これが陰性対照（パス行以外は同じ走で指紋が揃うこと）を兼ねる。
- **G1（決定論性）が真であること** ＝ 本体と`_repeat`の指紋一致。
  こちらも同種の陰性対照。
- （参考、段階0には含めない）G2の「m1/m2の指紋がm0と異なる」は陽性対照に相当するが、
  これは元の事前登録どおり本測定の一部として扱う。

**段階0（＝G0・G1が本測定の実走で真）が偽なら、2回目も`gate_failed`として止め、
器具をさらに直すところから。** 判定規則・腕・窓は動かさない。

## 禁止の遵守

公式ROM・公式ディスク・`private/`の内容には触れていない。本稿は件数・一致不一致・
判定名だけを書き、交換値・FDC生値・PC・割り込みlevel・絶対clock・画面本文は書いていない。
