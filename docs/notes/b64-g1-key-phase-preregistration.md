# B64: キーを押す時刻をずらして、公式と自作の違いが時刻のずれで説明できるかを確かめる — 事前登録

記録日: 2026-11-02
位置づけ: [B63](b63-g1-key-hold-and-ports-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

キーを押すフレームを 1 つずつずらしたとき、自作の結果は公式の別の時刻の結果と一致するか。

## 2. 条件

フレーム 3600 でスペース、`7200+k`（k=0〜15）で腕のキーを既定の押下時間で 1 回打つ。14400 フレームまで。腕は `2` と `i`。公式・自作とも k ごとに 1 走、公式は k=0 だけ 2 走。クラウドの実行環境で行う。

## 3. 記録の白リスト

- `pair <腕> o<k> s<k'> image=<same|differ> text=<same|differ>`（公式の k と自作の k' のすべての組）
- `run <腕> <o|s><k> cross=<N> fc=<N>`

画像はどこへも置かず、比べたあとで消す。**値は出さない。**

## 4. 判定（事前に決める）

- 公式の k と自作の k' が一致する組があり、k'−k が腕と k によらずほぼ一定なら、時刻のずれと書く。その幅を書く
- 公式どうしで k によって結果が変わるかも書く（時刻に敏感かどうか）
- 一致する組が無ければ、時刻のずれでは説明できないと書く
