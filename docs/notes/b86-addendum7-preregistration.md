# B86 追補7 事前登録

追補6の G2 の並びと G5 の時間順の観測を出発点とし、公式 ROM の内部経路や値は記録しない。これは測定前の計画であり、結果ではない。サブ ROM ソースと src/ は変更しない。

- 3391: 37C9 の A=1、37D2 の A=0,0、369A の BC=0002、HL=C800、carry=0 を基準とし、A と各引数をそれぞれ 00,01,02,FF に振る（基準との重複を除く）。369A が返した HL を変更せず、C900 に変更、369A を省いて C800 を設定の3条件。両地点に固有の OUT 印と RET または無限待ちを配置し、各条件を実行する。前置きが戻らなければ 3391 は欠測。読み込み後に自作コードを配置するため、転送による上書きは識別印を壊さない。印の番地から到達先を区別する。
- 割り込み: IM 2、全ベクタを自作 RAM ハンドラへ接続し VSYNC を許可。受け口はレベル再設定、印、EI; RETI。EI 腕は事前に HALT して受理を確認。割り込み内の腕は受け口から直接準備に移る。対照 RET と、6語 POP 後 RET の陽性対照を先に実施する。各モードの対照または陽性対照が不成立なら対象腕は対照不成立として解釈しない。
- 3080、39CE、3DED、11DF: 自作戻り先の上に異なる自作ダミー0〜6語を積み JP。DI、EI、実際の割り込み受け口内の3条件。戻り先で AF/BC/DE/HL/IX/IY を確保後、LD A,I の P/V で IFF2 を記録。各ダミー語との一致真偽のみを出す。IRQ 腕はハードウェアが積んだ割り込み戻り先より上に自作戻り先を積む。再起動は戻らないと数え、上限到達とは区別する。
- 出力は入口・印・ポート方向と件数・真偽のみ。生 I/O は非公開出力先にのみ置き、既定で集計直後に削除する。各腕は独立 ROM ディレクトリを使い、実行後に削除する。取りこぼしは欠測とする。測定を中断する条件は設けない。
- 自己検査は PC88_REF_* を解除し自作 ROM で対照と受理、生成、再起動、値の非出力を検証する。クラウド測定は既存の PC88_REF_ROM_DIR と PC88_CORE を環境から受け取る。
