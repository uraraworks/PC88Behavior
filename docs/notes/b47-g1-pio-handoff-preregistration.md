# B47: スペース後の G1 で、main の読む値がサブの出した値と同じかを値なしで測る — 事前登録

記録日: 2026-11-01
位置づけ: [B46](b46-g1-sub-event-stream-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

腕ごとに、main の `IN $FC` の値は、その時点でサブが最後に出した `OUT $FD` の値と同じか。違う読みは、公式・自作のどちらに、どこからあるか。

## 2. 器具

コアは変えない。`--io-log` の生の記録から、値を出さずに比べるツールを足す。main とサブの出来事の前後は記録の通し番号で決める。

腕ごとに次の行だけを出す。**値は出さない。**

- `arm <OO|SS> fc=<N> sub-fd-out=<N>`
- `latest arm=<OO|SS> range=<all|76315-76827|76570-76827> compared=<N> same=<N> first-differ=<N|none>`（main の読みと、その時点のサブの最後の `OUT $FD` の比較）
- `stale arm=<OO|SS> range=<76570-76827> prev=<N> next=<N> neither=<N>`（違う読みのうち、1 つ前の `OUT $FD` と同じ数、次の `OUT $FD` と同じ数、どちらでもない数）
- `main-pc arm=<OO|SS> index=76570 <PC が RAM ならその 4 桁 16 進、ROM なら rom>`

器具は G1 なしで自己検査する。陽性対照は合成の記録で同じ・古い・先の値の分類と、前後の順の判定。陰性対照は全部同じ記録で `first-differ=none`、値が出力へ出ないこと。

## 3. 条件

腕 F の 4800 フレーム。OO・SS 各 2 走。自作 ROM は 62254d3 と同じソースの配布ビルド。クラウドの実行環境で行う。

関門: `IN $FC` の差が B44 と同じ（257 件、最初 76570、連続 132）。OO どうし・SS どうしの出力が同じ。取りこぼしが無い。

## 4. 記録の白リスト

第 2 節の行だけ。

## 5. 判定（事前に決める）

- どちらの腕で `first-differ` が 76570 付近にあるかを書く。片方だけなら、その腕の受け渡しが違うと書く
- 両方の腕で `all` の `same` が多く同じなら、受け渡しの形は同じと書く
- 原因は断定しない。ROM が 8255 を設定した状態の違いかは別に測る
