## R_D の最終定義（自足）

Q(v) は厳密値 v を24ビット仮数の MBF 単精度へ最近接丸めする操作で、
ちょうど半分なら絶対値の大きい側へ丸める。非零の表現を `(σ,E,M)` とし、
`σ=0` は正、`σ=1` は負、値は `(-1)^σ × M × 2^(E-152)`、
`0x800000 ≤ M ≤ 0xffffff` とする。E はバイアス付き指数。
零は `σ=E=M=0`。rev24 は24ビット整数の3バイトの順序を逆にする操作。

```
P(σ,M) = (M & 0x7fffff) | (σ << 23)
T(σ,E,M) = Q(((rev24(P(σ,M) XOR 0x00004f) << 8) | E) / 2^32)
```

状態は単精度値 x、次の乗数位置 i（0〜7）、周期位相 c（0〜170）。
起動と RUN は `x=Q(0xcfc752 / 2^24), i=1, c=0` へ初期化する。
NEW 後の RUN も同じ初期化を行う。NEW 単独の効果は未分離。
初期値を記録器の `(符号,指数,上位12ビット,下位12ビット)` で表すと
`(1,0,3324,1874)`。RND(0) の初回もこの値になる。

8乗数は次のとおり。整数表記は厳密に単精度で表現でき、MBF 表記も併記する。

| i | A_i | σ | E | M |
|---:|---:|---:|---:|---|
| 0 | -26514538 | 1 | 153 | `0xca4a35` |
| 1 | 16129081 | 0 | 152 | `0xf61c39` |
| 2 | -11769122 | 1 | 152 | `0xb39522` |
| 3 | 13098250 | 0 | 152 | `0xc7dd0a` |
| 4 | -20161190 | 1 | 153 | `0x99d153` |
| 5 | -10426890 | 1 | 152 | `0x9f1a0a` |
| 6 | -13483109 | 1 | 152 | `0xcdbc65` |
| 7 | 12482518 | 0 | 152 | `0xbe77d6` |

通常更新は以下の順序で行う。積の仮数へ補正を足すのではなく、
丸めた積のバイト反転後の整数 R に補正を足す。

```
y = Q(A_i × x)                         # 以下の σ,E,M は y のもの
c = (c + 1) mod 171
R = rev24(P(σ,M) XOR 0x00004f)
if c == 0: R = R + 0x00ff01
x = Q(((R << 8) | E) / 2^32)
i = (i + 1) mod 8
```

この式の採用範囲は補正後の R が24ビット以内に収まる場合。
24ビット溢れは未観測であり、器具の便宜的な `mod 2^24` は確定仕様に含めない。
今回の全署名一致はその仮の溢れ処理に依存しない。

- **RND(0)**: 現在の x を返す。x・i・c のどれも変えない。
- **正引数の RND と引数なし RND**: 通常更新を1回行い x を返す。
  正引数の大きさは使わない（2、0.5、1E10を測定）。
- **負引数 RND(-y)**: 正の単精度入力 y の E,M を使い、
  `x=T(1,E,M), i=0, c=0` として x を返す。
  乗算・通常更新・c の加算は行わない。前歴を消す。
  十進入力の読み取りは別の規則であり、ここで観測した入力 MBF を出力から逆算しない。
- **RANDOMIZE n**: n を符号付き16ビット整数へ最近接丸めし、半分なら
  絶対値の大きい側へ丸める（1.5→2）。現在の x の E と仮数の最下位バイト
  `b=M & 255` を保ち、以下の置換後、現在の i,c から通常更新を1回行う。

```
P' = ((n & 65535) << 8) | b
σ' = P' >> 23
M' = (P' & 0x7fffff) | 0x800000
x = (-1)^σ' × M' × 2^(E-152)
```

RANDOMIZE は i,c をリセットしない。内部更新も c に1回数え、
周期境界なら補正を行う。連続 RANDOMIZE もそれぞれ1回数える。
値は出力しない。整数種 -32768〜32767 の測定例に基づく規則であり、
丸め後にこの範囲を外れる n の扱いは未確定。

起動から2000更新の測定では全値が `0<x<1`、零と1は各0個だった。
これは有限列の観測であり、未測定の全状態についての範囲保証ではない。

[期待値](../../tests/conformance/expected_l4_rnd.tsv) は値そのものを置かず、
腕ID・測定回・SHA-256先頭16桁・整数組の個数だけを収録する。
`official_round1.tsv` / `official_add1.tsv` / `official_add2.tsv` /
`official_add3.tsv` / `official_add4.tsv` の各関門通過腕の1走目を使い、2走一致を確認した。
`print_values` を JSON 復号して採取順の整数組の配列とし、
Python `json.dumps(rows, sort_keys=True, separators=(',', ':'))` の UTF-8
（空白・末尾改行なし）をハッシュする。番号 j、入力対照、range末尾の3整数計数組も含む。
値の個数はスカラー数でなく整数組の数である。
測定時の器具コミットは `ed7a271ede4eb674172be7a47cd29e62194e54e5`。

再出力があり除外。追補2の負種6腕も入力標本0欠落で除外し、追補3の再採取で
旧関門を変更しない。計9腕の理由を期待値の `# excluded` に残した。
同じ操作でも測定回と腕IDが異なる再採取は別腕として保持した。

器具 `tools/l4_rnd_measure.py check --rom-dir DIR` は各回の元の打鍵・採取順で
1走だけ実行し、採取形式と個数と署名を照合する。既定は **85短い腕**
（個数20以下かつrange以外）。`--all` は **108全腕**。
`--arms 正規表現` は既定の短い腕制限に優先し、長い腕も選べる。
`--all` と併用した場合も正規表現で絞る。
`--expected FILE` で別の期待値を指定でき、対象0腕・測定失敗・署名不一致は終了値1。
不一致は測定回と腕IDで列挙し、画面本文・整数列を出力しない。
既定は自作ROM向けの起動待ちで、公式ROM用には従来同様 `--official` を明示する。
ROMディレクトリは環境変数経由で渡す。

```
python3 tools/l4_rnd_measure.py check --rom-dir "$PC88_REF_ROM_DIR" --official --arms '^add4-history-0-randomize-25-long$'
```

上記は使用例であり本作業では実行していない。長い腕は16画面上限に合わせた
起動からの再生と境界1ページ再採取を含む従来の測定方法を保持する。

selftest は期待値の腕数・全操作列との対応・除外・個数・署名形式、R_Dの
予測から作る全108署名の一致、checkの1走接続と改変・欠落・実行失敗の検出を検査。
負種は独立入力PRINTの MBF を条件とし、追補3の1E20は
`(0,1,67,2775,2285)` を用いる。RND出力を途中状態へ差し込まない。
この検査は期待値と最終候補の整合検査で、未測定の独立確認には数えない。

`bash tools/l4_rnd_selftest.sh --work-dir /private/tmp/l4s8a-spec-selftest`
を実行し、終了値0。上記の追加検査と従来の全検査・自作ROM定数対照が通過した。
公式ROM測定・`--official` は実行していない。
