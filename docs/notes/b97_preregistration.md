# B97 事前登録：自作 ROM で固定入口以外の main ROM 番地へ飛び込まれていないか

記録日: 2026-11-17。[main ROM 入口仕様](../spec/main-rom-entry.md) の 3DED・11DF・39CE・3E0D・30CF は、公式 ROM での需要測定（B84・B86-timeline）に現れたが、自作 ROM の固定入口（`src/build_main_rom.py` の `PINNED_ENTRIES`、9番地）には入れていない。公式の 7071 が RAM の ED36 を経て 11DF に戻るように、公式 ROM 内の流れの一部として現れた番地は、自作 ROM では需要にならない。ゲームの RAM 側のコードが自作 ROM のこれらの番地へ直接入るかを測り、固定入口が要るかを決める。

## 腕

自作 ROM（main dbe1b37）だけを使う。公式 ROM は使わない。

- G2・G3・G5：無入力（N）、スペース（SP）、リターン（RT）の各腕、36000 フレーム。打鍵は B82・B94 と同じ時刻。
- G4・G6：無入力のみ、36000 フレーム（参考。今回の判定には使わない）。

## 記録すること

既存の boundary-timeline（パッチ 0027）で、main の RAM から main ROM（0000〜7FFF、バンク選択時の実体を含む）への横断を全件取り、横断先の番地ごとの件数を集計する。

公開するのは、各腕の
- 横断先が `PINNED_ENTRIES` の9番地・割り込み受け口・RST 番地のどれかに当たった件数
- それ以外への横断の番地と件数（番地は自作 ROM の番地なので出してよい）。特に 3DED・11DF・39CE・3E0D・30CF への横断の有無
- 指定フレームまで I/O が続いたか

ゲームの RAM 側の横断元の番地・命令・値・画面は出さない。

## 判定

- G2・G3・G5 のどの腕でも固定入口以外への横断が0件なら、3DED・11DF・39CE・3E0D・30CF は「公式 ROM 内の流れの一部で、ゲームからの需要ではない」と記し、固定入口は足さない。
- 横断があった番地は、その番地の働きの測定（B86 追補と同じ自作入力の方式）に進む。
- 陽性対照として、固定入口 7071・3080・35CE への横断が G5 の N 腕で1件以上記録されることを確かめる。記録されなければ器具の故障とみなし判定しない。
