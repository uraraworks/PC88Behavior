# B29: G1 のグラフィック画面とキー入力後を、公式と自作で一致だけ比べる — 結果

記録日: 2026-11-01
規則: [b29-g1-graphics-and-keys-preregistration.md](b29-g1-graphics-and-keys-preregistration.md)（f9d3e23）どおり。測定はクラウドの実行環境で 28 走、すべて rc=0。画像はどこにも置かず、判定のあとで消した。記録: `measurements/b29-g1-screens.tsv`。

| 腕 | 条件 | 公式どうし | 自作どうし | 公式対自作（画像） | 公式対自作（テキスト） |
|---|---|---|---|---|---|
| A | 1800 | 一致 | 一致 | **一致** | **一致** |

公式の腕 C と腕 E は画像が一致するので、リターンは効いていない（腕 E・G はキー入力の試験になっていない）。公式の腕 C と腕 F は不一致なので、スペースは効いている。

## 分かったこと

- **打鍵なしでは、14400 フレームまで、自作 ROM の上の G1 はグラフィックを含む画面が公式と一致する**
- スペースを押すと、公式と自作で画面が変わる。次の切り分けの対象である

音は比べていない。
