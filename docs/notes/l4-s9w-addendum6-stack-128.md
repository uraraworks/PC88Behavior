# l4-s9w 追補6 — スタック 128 だけ櫛の壁が塗り潰された件の刻み（事前登録の追補）

状態: 2026-10-09。追補2の観測（`official_add2.tsv`）を、モデルを「点線のスタイルは水平線で第2座標から数える」（l4-graphics 第9.6節、器具の参照モデルの訂正。結果ノート参照）に直して再判定したときに見つけた。

## 見つけたこと

`ws-6a`〜`ws-6d` は同じ画面（歯 20・40・80 本の櫛3つ）で `clear ,,N` の N だけが違う（16・64・128・256）。`ws-6a`・`6b`・`6d`・既定のスタック（512）の `ws-1`・`clear ,,2048` の `ws-2b` は最終画面のハッシュが一致するが、**`ws-6c`（N=128）だけハッシュが違う**。画素の位置と数（8008）は同じで、**歯の壁（境界色 7）の画素 3350 個が領域色 5 になっている**（枠の外周の 7 は残る）。2 走一致の再現性のある結果で、関門は通っている。つまり N=128 のときだけ、PAINT が境界色の壁を越えて塗り潰した（あるいは壁が 5 で描かれた）。モデル（壁は境界で変わらない）とは食い違う。

## 足す腕（`tools/l4_paint_measure.py`）

`ws-10a`〜`ws-10h`: `ws-6a` と同じ形（歯 20・40・80 本の櫛3つ、guard 付き）で N = 96・112・120・127・129・136・160・192。
予測（弱 w。モデルのとおり、壁は変わらず完全に塗られ、誤りなし）。N=128 の再現は `ws-6c` が済んでいるので足さない。結果は壁の画素の数を N ごとに記録するだけにして、境目の N と原因（壁が塗り潰されるのか、壁が別色で描かれるのか）を特定できたかどうかを結果ノートに書く。特定できなければ「できなかった」と書く。
