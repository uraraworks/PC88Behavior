# B77: F1 の道で、後半のキーの前後の main の割り込みの受け付けを公式と自作で比べる — 事前登録

記録日: 2026-11-04
位置づけ: [B76](b76-g1-f1-key-sweep-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

F1 のあと、後半のキー（フレーム 12000 のリターン）の前後で、main が受け付けた割り込みの種類と回数、移った先（割り込みの入口の番地）は、公式と自作で違うか。

## 2. 器具

既存の `--int-log`（main の割り込みの記録）。フレームの窓に分けて数えるため、`--frames` を 11400、12000、12600、13200 にした走の合計の差を取る（B61 と同じやり方）。

## 3. 条件

B65 の F1 の腕と同じ打ち方とディスク。公式・自作とも窓の端ごとに 1 走。クラウドの実行環境で行う。

## 4. 記録の白リスト

`int <O|S> <窓> <種類または段> <入口の番地の組> <回数>`（入口の番地は、RAM 上なら 4 桁 16 進、ROM の範囲なら `rom`）、`total <O|S> <窓> <回数>`。**値は出さない。**

## 5. 判定（事前に決める）

- 窓ごとに、公式にあって自作に無い（または回数が違う）割り込みを書く
- 違いがあれば、その割り込みの元（音源・VRTC・タイマ）を、割り込みの段から推定として書く。原因は断定しない

## 6. 結果の置き場

`measurements/b77-g1-f1-interrupts.txt`、`docs/notes/b77-g1-f1-interrupts-results.md`

## 追補（2026-11-04、1 回目の走のあと）

1 回目は「記録の欠落または件数不一致」で止まった（ファイルなし）。割り込みの記録は 65536 件までで、11400 フレームまで記録するとあふれる。窓の差を取るやり方をやめ、frontend に `--int-log-from-frame N`（フレーム N で記録を始める）を足して、窓ごとに `N` から窓の終わりまでを記録する。窓・白リスト・判定は変えない。
