## 4. 読み（判定には使わない）

- 主問は真。最初の WRITE の手前は `0x14, D`（長さ2の run）。1.36節の「先頭 `0x14`・長さ2」はこの run と読める（1.36節で1件だけだった理由は、この測定では調べていない）。
- **`0x14, D` の後に sub の応答が1バイトある**（S と `0x11` の間）。「sub は `0x14, D` に応答しない」という仮説は、少なくとも「`0x11` までの間に応答が無い」という形では成り立たない。
  この応答が `0x14, D` の run への応答か、続く WRITE 要求への応答かは、この測定では区別していない（run と応答の位置だけを測った）。
- 2回目以降は、run（S＝`0x06`）の直後・`0x11` の前に応答が1バイトあり、直前のコマンドの完了から S までは0件。
  1.35a節の「WRITE ごとに応答1バイト」は **S の後・`0x11` の前** にある。最初の WRITE でも同じ位置（`0x14, D` の後）に1件で、形は一致する。
- 追補3の H3（各 WRITE の完了から次のコマンドまでに応答1件）が全走で成り立っていたのは、この応答が次のコマンドの要求の中にあるためと読める。
