## 手順についての開示

クラウドの判定器は `controls_passed: false` を返した。判定器が、事前登録に無い「行6 の完了」を対照に足していたためである。行6 は飛び先をずらす故障注入なので戻らなくて当然で、事前登録第5節の対照はこれを求めていない。
`tools/judge_b17.py` を事前登録に合わせて直し、**走り直さず同じ TSV へ**掛け直した。結果を見たあとの器具の修正なので、ここに記す。規則は変えていない。

## 判定: **書き込み・実行・復帰、すべて確定**

```
controls_passed: true / writing: confirmed / execution: confirmed / return: confirmed / incomplete: [6]
```

## 確定したこと

- `0x0C, AH, AL, LH, LL` のあとの L バイトを、番地 A から書く（番地も長さも上位が先）
- `0x0D, AH, AL` は番地 A へ制御を移す
- 自作のコードが `00C1` へ jump すると、サブは次の要求を受け付ける。繰り返せる

仕様は `docs/spec/l3-subrom.md` 1.36c 節。実装は仕様書から行い、G1 で確かめる。
