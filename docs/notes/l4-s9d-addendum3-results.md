# l4-s9d 追補3 結果 — FOR の入れ子の深さと、FOR 時の NEXT の検査（ERR 26）

根拠: [事前登録](l4-s9d-addendum3-preregistration.md)。公式ROMの測定は
`../tmp/l4s9d-work/official_add3.tsv`（13腕×2走）。画面本文は記録せず、
自作PRINTの整数とERR番号だけを採った。

## 数え上げ

13腕×2走。関門3腕（定数対照2＋既知 `a3-known-gosub-256`＝ERR 7・深さ23）は全て通過、
観測10腕は skipped 0・採取失敗 0。全13腕で2走の印列が一致した。
`tests/conformance/expected_l4_memlimit_add3.tsv`（13腕）を固定し、
`tools/l4_memlimit_measure.py check` が rc=0（照合一致）を返した。

## 腕1: FOR の入れ子の深さ（NEXT つき。TSVで検算済み。食い違いなし）

`clear ,49152[,n]` の後、溢れは ERR 7。深さ d は成功した段数。

| n | 深さ |
|---|---|
| 64 | CLEAR 自体が ERR 7（深さ未測定） |
| 128 | 2 |
| 256 | 9 |
| 512 | 22 |
| 1024 | 49 |
| 第3引数なし | 22（n=512 と一致） |

- 独立な4点（128・256・512・1024。既定は512と同値で独立な点ではない）に対し、
  `d = floor((n − c)/f)` は **f=19**、**c=76〜85 の整数10値**で全点成立。f=15〜24 のうち
  他の f は成立する c が無い（自分で全探索して確認）。1段約19バイト。
- GOSUB（追補1）は f=7・c=89〜92（同じ4点で再計算して一致）。**f も c も FOR と GOSUB で違う**
  （FOR の1段は GOSUB の約2.7倍）。余白の定数を共通にしてはならない。
- 仮説 F_LIN（一次式）は**支持**。上限到達の腕は無く、全て溢れ（ERR 7）で止まった。

## 腕2: ERR 26 の性質

| 腕 | 内容 | 観測（2走一致） |
|---|---|---|
| a3-nonext | NEXT が全く無い FOR | ERR 26。本体の印は出ない（FOR の直後の印の前） |
| a3-wrongvar | 次行が `next j`（変数名違い） | ERR 1（NEXT without FOR）。本体の印は出ない |
| a3-nextbefore | NEXT が FOR より前の行にあるだけ | ERR 26。本体の印は出ない |
| a3-withnext | NEXT が後ろにある通常の FOR | 本体2回→後続行へ到達（正常） |

a3-wrongvar の印列は `s9da 1 1`・`s9de 2 1`・`s9dd 1 1`。打鍵行を確認すると、本体の印
（`s9dv 2 1`）は FOR と**同じ行**（行20）の FOR の直後にあるのに出ていない。したがって
**ERR 1 は FOR の本体より前、FOR の実行時に出ている**（NEXT 実行時ではない）。
親（依頼文）の読み「FOR が通り NEXT で ERR 1」は TSV と食い違うため採らない。

## 判定

仮説 F_SCAN（FOR 実行時に前方の NEXT の有無を探し、無ければ本体の前に ERR 26）:
- a3-nonext・a3-nextbefore: **支持**（本体印なしで ERR 26。前方のみ走査と整合）。
- a3-wrongvar: 事前登録は「変数名まで照合するなら ERR 26、有無だけなら 26 にならず本体印」の
  二択だった。観測は**どちらでもない**: ERR 26 でなく ERR 1、かつ本体印なし。FOR の実行時に
  前方の NEXT を探して見つけた（有無は満たす）が、変数名が合わないため FOR の時点で
  NEXT without FOR（ERR 1）になった、と読める。**走査は変数名を照合している**（26 にならないのは
  NEXT 自体は存在するため）。ただし ERR 1 の発生が FOR 時であるという読みは、本体印の不在
  1点に依る。
- 解釈は「FOR を実行するとき、それより後ろに NEXT があるかを探し、無ければ ERR 26、
  あるが変数名が合わなければ ERR 1 を、いずれも本体の前に出す」。入れ子の対応や距離は決めない。

## 未測定・決めないこと

- n=64 の FOR の深さ（CLEAR が ERR 7）、n 境界（64〜128）。f=19 の c の10値の絞り込み。
- 走査の範囲（どこまで先を探すか、FOR と NEXT の間の距離・行数への依存）、
  NEXT が文字列中・REM 中にある場合、NEXT の変数省略（`next`）、1行に FOR だけで NEXT が
  別の IF 分岐にある場合。
- a3-wrongvar で ERR 1 が FOR 時に出ることの別腕での確認（本体を FOR と別行に置く等）。
