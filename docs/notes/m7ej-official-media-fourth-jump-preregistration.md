# m7ej: 別の公式媒体で四点目を検査する事前登録

実施日: 2026-09-01

本稿は、別の公式媒体をドライブ2へ置く三系列について、四点目以降のジャンプを検査する
前に、予測、判定規則、停止規則、媒体間比較規則を固定する事前登録である。本稿の作成時には
適合性測定を除くラダー測定を行わず、実測後に予測、条件、上限、比較対象を変更しない。
`m7ed`の固定介入、整数完全一致規則、独立再構築、全名OPEN検証、情報境界を引き継ぐ。
`src/`は変更しない。

## 背景と問い

`m7eh`では系列A（diskA複製、ドライブ2、`2:`接頭辞）の確認済みジャンプN=11,27,43から
`P_O=16`・`V_O=(+258,+1)`が成立し、系列B（自作空媒体）の`P_B=16`・
`V_B=(+258,+1)`と完全一致したため、H-M（間隔と増分が媒体不変）支持となった。
しかし`m7ei`では同じ系列Aの容量端点がN=52と確定し、四点目の予測位置N=59へ到達できなかった。

**現時点で四点目まで確認できているのは自作空媒体（系列B）だけであり、公式媒体で四点目を
観測した例は無い。** 本稿はこの未検査範囲を、別の公式媒体を使う独立な系列で検査するための
事前登録である。

## diskAのN=59を検査できないことの確認

diskA複製の容量を空けてN=59へ到達させる案は採らない。ジャンプ位置を決めているのは
その媒体の初期占有そのものであり、削除等で空きを作れば初期占有が変わって位置も動く。
従って、介入後には「N=59が四点目の予測位置」という前提自体が消える。これは到達手段の
不足ではなく、到達のための介入が対象の定義を壊すためであり、この経路では
**diskAのN=59を原理的に検査できない。**

加えて、公式媒体の既存項目を名指しで削除するには既存名を読んで打鍵する必要があり、
公式媒体の既存名を記録しないという情報境界とも衝突する。

従って、本稿はdiskAのN=59を埋めることを目的とせず、**別の公式媒体で四点目以降を
検査する。** `m7ei`が記録した「公式媒体diskAのN=59は未検査」という範囲は、
本稿に基づく結果によっても埋まらない。

## 実施済みの適合性測定

以下は本事前登録に基づくラダー測定ではなく、**事前登録より前に行った器材確認**である。
この既測値を予測の固定に使うが、本稿の作成に際して新しい測定は行わない。

`private/disk`にあるdiskA以外の3枚について、ドライブ1を公式システムディスク（起動用）、
ドライブ2を各候補の使い捨て複製とし、全名へ`2:`を前置して次を測定した。3枚とも成立した。

- N=0校正: 固定不存在名のOPENが`D9E`、`D9C`、直後`Ok`へ到達した。3枚とも合格した。
- 書き込み可否: `probe-create`で自作名1本を作成し、`normal_success`、WRITE=7、
  媒体SHA-256差、main/sub取りこぼし0/0件を満たした。3枚とも合格した。

N=0校正の入口計数は、判定区間700F以後のmain `IN $FC`、READ、FDC件数の順で次のとおり
だった。既存二系列の既測値も対照として併記する。

| 媒体 | N=0の入口計数 |
|---|---|
| diskA複製（系列A、既測） | 1292 / 7 / 28 |
| 自作空媒体（系列B、既測） | 776 / 5 / 20 |
| 候補1 `ALPHA-MINI DOS 1.5` | 776 / 5 / 20 |
| 候補2 `MUCOM88em` | 1292 / 7 / 28 |
| 候補3 `voiceeditor` | 1292 / 7 / 28 |

**この値から各媒体の既存項目数、ディレクトリ占有量、バイト数、容量を逆算しない。**
観測できたのは、候補1のN=0基準値が系列Bと完全一致し、候補2と候補3のN=0基準値が
系列Aと完全一致したという事実だけである。

## 仮説と識別境界

- **H-M（媒体不変）**: 二系列以上で得た確認済みジャンプの間隔Pと増分ベクトルVは
  媒体によらず同じである。
- **H-M'（媒体依存）**: 二系列以上で得た確認済みジャンプの間隔Pまたは増分ベクトルVの
  少なくとも一方が媒体によって変わる。

H-MとH-M'のどちらも実測前に残し、整数の完全一致だけで判定する。絶対ジャンプ位置は
初期占有に依存し得るため媒体間比較へ使わない。管理形式、管理単位、既存項目数、
ディレクトリ占有量、バイト数、容量をN=0基準値やジャンプ位置から仮定しない。

## 系列の定義と固定介入

本稿では候補媒体ごとに独立した次の三系列を定義する。

- **系列C** = 候補1（`ALPHA-MINI DOS 1.5`複製）
- **系列D** = 候補2（`MUCOM88em`複製）
- **系列E** = 候補3（`voiceeditor`複製）

いずれもドライブ1を公式システムディスク（起動用、固定）、ドライブ2を当該候補の
使い捨て複製とし、全ファイル名へ`2:`を前置し、一覧操作を`FILES 2`へ固定する。
ドライブ1は読出し専用とし、準備runでも測定runでも変更しない。

自作名と作成順は`m7ed`の「N=0校正と自作ファイルの固定規則」に登録済みの生成式を
そのまま使う。

```text
名前(N) = "QD" + CHR$(65 + INT((N-1)/26)) + CHR$(65 + ((N-1) MOD 26))
```

N=1は`QDAA`、N=64は`QDCL`である。実際のファイル指定は名前へ`2:`を前置し、
N-1チェックポイントの新しい複製へ1runで1本だけを登録順に作成する。内容は空とする。
KILL、上書き、順序変更、名前変更、接頭辞変更を行わない。

## 事前登録する予測

H-Mが成り立ち、かつ候補のN=0基準値が示す段が系列Aまたは系列Bと同じ振る舞いをするなら、
確認対象となる正方向ジャンプ候補の位置を次のとおり**予測する。**

| 系列 | N=0基準値が一致する既存系列 | 予測する候補位置 | 四点目に必要な最小容量 |
|---|---|---|---|
| C | 系列B（776 / 5 / 20） | 16, 32, 48, 64 | N=64 |
| D | 系列A（1292 / 7 / 28） | 11, 27, 43, 59 | N=59 |
| E | 系列A（1292 / 7 / 28） | 11, 27, 43, 59 | N=59 |

**この予測は本稿を書いた時点で固定し、実測後に書き換えない。** 予測が外れても、
それだけではH-M否定にならない。H-Mは位置ではなく間隔Pと増分Vについての主張であり、
位置は初期占有に依存して動くことを系列A対系列Bで既に観測している。予測が外れた場合は、
位置の予測が外れた事実と、間隔・増分が一致したかどうかを**分けて**記録する。

## 測定操作と観測量

各系列・各Nの完成チェックポイントの新しい使い捨て複製をドライブ2へ入れ、`m7ed`の
N=0校正と同じ固定不存在OPENを各2run測る。9000フレーム、300Fで改行、700Fで固定
プログラム打鍵、300秒、512打鍵上限、同じROM構成とハーネス引数へ固定し、判定区間は
700F以後とする。単一走は採用しない。

系列`s`をC、D、Eのいずれかとして、一次指標を`m7ed`と同じ整数対へ固定する。

```text
X_(s,N) = (700F以後のmain IN $FC件数, 700F以後のREAD単位)
```

併記する量も`m7ed`から変更せず、main `IN $FC` / `IN $FD`の件数・SHA-256、公開FDC
コマンド種別列と総件数、READ DATA・SEEK・WRITE DATA件数、値を除いたイベント構造の
件数・SHA-256、隣接N間の一致prefixと最初の差の位置、画面の行数・文字数・SHA-256、
取りこぼし件数とする。SHA-256は同一性確認だけに使う。測定runでWRITE DATAが1件でも
出れば不採用とする。

## 差分とジャンプの固定判定規則

差分と分類は`m7ed`の「差分とジャンプの固定判定規則」を**そのまま継承する。** 系列ごとに
隣接差分を独立に定義する。

```text
Delta_(s,N) = X_(s,N) - X_(s,N-1)    (N=1..64)
```

`Delta_(s,1)`は基準差分であり、単独ではジャンプと呼ばない。N=2〜64では次を適用する。

1. 2成分とも直前差分へ完全一致すれば**定常差分**とし、境界へ数えない。
2. 両成分が直前差分以上で、少なくとも一方が厳密に大きければ
   **正方向ジャンプ候補**とする。
3. 両成分が以下で少なくとも一方が厳密に小さければ**負方向変化**、一方が大きく他方が
   小さければ**方向不一致**とし、H-M支持へ数えない。
4. 過去Nで0件だった公開FDCコマンド名の初出を**未見経路候補**とする。語彙が同じでも
   N-1列をstrict prefixとして後続が増えれば**構造的延長**、prefixを保たず順序が
   変われば**構造変化**として分ける。

候補Nでは当該系列の通常走を止め、直前の8本境界アンカーからN-1とNを独立再構築して
各2run再測定する。同じ符号、差分ベクトル、FDC構造分類が完全再現した場合だけ確認済み
ジャンプへ採用する。不一致は支持にも反証にも数えず欠測とする。

数値の幅、割合、誤差許容を導入せず、「近い」「ほぼ同じ」を判定語に使わない。

## 周期性の固定判定規則

周期性は`m7ed`の「周期性の固定判定規則」を**そのまま継承する。** 系列`s`の確認済み
ジャンプを昇順に`J_(s,1),...,J_(s,k)`、ジャンプベクトルを
`V_(s,i)=Delta_(s,J_(s,i))`、隣接間隔を`P_(s,i)=J_(s,i+1)-J_(s,i)`とする。

1. **k=1:** 単発ジャンプであり周期を算出しない。
2. **k=2:** 唯一の間隔は周期候補だが、反復が無いため周期とは確定しない。
3. **k>=3:** 全隣接間隔が同じ正整数`P_s`へ完全一致し、全ジャンプベクトルが同じ
   `V_s`へ完全一致し、ジャンプ間の成立済みNに別ジャンプ、負方向変化、方向不一致が
   無い場合だけ、当該系列の観測範囲で周期成立とする。
4. 間隔または増分が1回でも違えば、外れ値を除かず**非等間隔／増分不一致**とする。
   都合のよい3点や部分列を選び直さない。
5. FDC追加suffix、未見コマンド、値非表示イベント構造は併記する。同じPとVでも構造が
   混在すれば、数値周期は成立、経路の同一性は未確定と分ける。

周期成立後の次予測位置まで全介入が成立しても同じVの確認済みジャンプが無ければ、
その位置を通過した時点で周期破れとする。予測位置より前の容量端点、介入不成立、欠測、
器材上限による打ち切りは周期破れでなく後続周期を**検査不能**とする。数値の幅、割合、
誤差許容や「近い」「ほぼ同じ」を導入せず、全て整数の完全一致で判定する。

## 介入成立と全名OPEN検証

各Nは作成run、媒体SHA-256差、`FILES 2`各2run一致、修正版全名OPEN検証が成立した
場合だけ採用する。`FILES 2`は直後`Ok`、READ非0、WRITE 0、main/sub取りこぼし0件、
2run完全一致、N-1から画面の行数・文字数・SHA-256のいずれかが変化することを要求する。
画面本文と公式媒体の既存名は記録しない。

全名OPEN検証は`m7ed`の「介入成立と全名OPEN検証」にある修正版をそのまま使う。
ホスト側でN=1〜Kの全自作名へ`2:`を前置し、最大8名ずつのリテラルINPUT OPENへ分割する。
全chunkの固有マーカー、WRITE 0、取りこぼし0件が揃った場合だけK全体を合格とする。

ブロック末端K=8,16,...,64の各系列・各Kで、対象Kより先に次の両対照を取る。

- **陽性対照**: 当該系列の受理済みK=8チェックポイントで全名OPENが合格すること。
- **陰性対照**: そのK=8の使い捨て複製から`2:QDAA`をKILLし、WRITE非0、ドライブ2の
  媒体SHA-256差、ドライブ1のSHA-256不変、main/sub取りこぼし0件を確認した後、同じ
  全名OPEN検証が実際に不合格になること。
- 両対照の成立後だけ対象Kを判定する。対照失敗時は対象Kを走らせず器材不成立とする。

終端が8の倍数の途中なら、最後に作成成立したKへ同じ分割版と両対照を適用する。不合格なら
直前の受理済み8本境界からKを1ずつ増やし、最初の不合格Kと最後の合格Kを特定する。
最後の合格Kを受理済み終端とし、先を欠測とする。検証対象の削減や一部名による代用はしない。

同一Nの2runは全イベント列、画面、main受信件数・SHA-256、FDCコマンド種別列の完全一致を
必須とする。介入不成立、到達失敗、取りこぼし、2run不一致、独立再構築不一致は欠測とし、
ゼロ差分、ジャンプ、周期破れへ読み替えない。

## 実施順、準備、再開、上限、打ち切り

実施順は**系列C、系列D、系列E**に固定する。系列Cを先に置く理由は、予測位置の四点目
N=64が器材上限の内側にあるからであり、結果が望ましいと期待するからではない。

上限は**N=64**とする。これは`m7ed`が定めたN=128ではなく、現在の測定器
`tools/ladder_dirfiles.sh`が受け付ける上限である。N=64は媒体容量の仮定ではなく
**器材上限**であり、実測後に延長しない。

作業領域は実行者が絶対パスで指定し、既定値をリポジトリへ焼き込まない。系列別・8本ごとに
ドライブ2のチェックポイント、媒体SHA-256、安全集計、完了フラグを外部manifestへ記録する。
ドライブ1、生ログ、画面、媒体複製もリポジトリ外の永続作業領域だけに置く。中断後は系列名、
N、両媒体SHA-256を照合し、最後の受理済み8本境界アンカーから再開する。

作成が容量／作成上限で成立しなくなった場合、それ自体をジャンプや周期破れへ数えず、
最後に成立したNを当該系列の容量端点として打ち切る。次予測位置より前なら検査不能とする。
一方の系列の端点を他系列へ適用せず、欠測を0差や境界なしへ読み替えない。

容量端点でも器材上限N=64でも打ち切られた場合、四点目は当該系列で検査不能とし、
「四点目が無い」「周期が破れた」へ読み替えない。

系列Cで四点目が確認済みジャンプとして成立した場合でも、系列Dと系列Eは二枚目・三枚目の
独立な公式媒体による確認として実施し得る。実施しなかった範囲は欠測として明記し、成立した
系列の結果を他系列へ広げない。

## 媒体間比較

二系列以上でk>=3の確認済みジャンプが成立した場合にだけ、`m7ed`の「媒体間比較とm7eaへの
橋渡し」にある媒体間比較規則を次のとおり適用する。

1. 両系列のPとVが完全一致すればH-M支持とする。絶対位置と絶対値は使わない。
2. 両系列で周期が成立しても、PまたはVの少なくとも一方が完全一致しなければ
   H-M'支持とする。
3. 一方で周期が成立し、他方はk>=3かつ成立済み範囲内の間隔または増分が内部不一致なら、
   一定PとVが媒体不変というH-Mは不支持、H-M'支持とする。不一致側に存在しない単一の
   PまたはVを作らない。
4. どちらかがk<3、欠測、端点前の打ち切り、または両系列とも単一PとVを成立させられ
   なければ、媒体間比較は**不成立**とし、H-M、H-M'のどちらにも数えない。
5. 数値の幅、割合、誤差許容を使わず、外れ値を除かず、位置合わせや部分列の選び直しを
   行わない。絶対位置と絶対値は比較に使わない。

三系列のうち比較可能な組が複数あれば、各組へ同じ規則を独立に適用する。一組の成立結果を
欠測または比較不成立の系列へ移さない。既存の系列A、系列Bと比較する場合も同じ規則だけを使う。

## 情報境界

対象媒体は市販ソフトのディスクイメージを含む。使うのは私物の使い捨て複製であり、
**リポジトリへは持ち込まない。** 媒体、生ログ、チェックポイント、manifestは
リポジトリ外の永続作業領域に置き、コミットしない。

記録するのはN、件数、差分、位置、frame、clock、SHA-256、画面の行数・文字数・SHA-256、
自分で打鍵した文字列・自作名、公開FDCコマンド名だけとする。**媒体の既存名、画面本文、
公式応答値、データポート値列は表示も転記もしない。** `private/`を開かず、逆アセンブルせず、
媒体は測定器へパスで渡すだけとする。

媒体のパスは`PC88_LADDER_SOURCE_DISK`、`PC88_LADDER_BOOT_DISK`等の環境変数経由でのみ
受け取り、絶対パスをリポジトリへ焼き込まない。作業領域は実行者が絶対パスで指定し、
既定値を焼き込まない。

## この事前登録で決まらないこと

本稿は測定前の登録であり、上記の事前適合性測定以外の結果を含まない。四点目の有無、
各系列の容量端点、H-MまたはH-M'の支持・不支持は本稿では決まらない。管理単位の内部形式、
ジャンプの原因、実機一般性も本稿の対象外である。diskAのN=59は引き続き未検査である。

`docs/spec/`は変更していない。`tools/check_cleanroom.sh`を実行し、全項目OK、rc=0を確認した。
