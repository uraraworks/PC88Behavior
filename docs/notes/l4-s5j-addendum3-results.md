## 採る規則 G_H（go subの詰め）

小文字ASCIIを新しいプログラム行として打ったときの、入力からLIST表示までの規則。
英字で始まり英数字と `.` が続く最大の並びを「名前の連なり」とする。
連なりがちょうど `go` で、直後が空白ちょうど1個と `sub` なら、`GOSUB` に詰める。
`sub` の直後に文字があれば、その文字が何であれ1文字だけ消費する。
消費後の残りの先頭がASCIIの英字・数字・`.`・`&` なら、`GOSUB` の後へ空白1個を足す。
それ以外は足さない。残りの空白は消費せず、そのまま保つ。行末なら `GOSUB` だけ。
残りには既存の語の大文字化等と数値定数の書き直し（l4-basic.md第14.1・14.5節、器具のN_D）を掛ける。

引用符内、ちょうど `rem` の後、ちょうど `data` の後から引用符外の `:` まで、
`'` 以降、名前の連なりの内部は保護する。`go  sub10` のように空白が2個なら詰めない。
`go to` の規則は従来どおりで変更しない。
例: `go sub10` → `GOSUB 0`、`go subx.5` → `GOSUB .5`、
`go subx&h1` → `GOSUB &H1`、`go subx:end` → `GOSUB:END`、
`go sub1  x` → `GOSUB  X`。抽出器は行末空白を落とすので、その有無は確定しない。

## 採る規則 L_C（行番号の途中の空白）

追補1のB群36腕はL_Cがagree 36・differ 0・unstable 0・gate_failed 0。
行頭の数字とASCII空白を読み、番号を0から積み上げる。途中の空白は読み飛ばす。
次の数字を足した値（現在値×10＋数字）が65529以下ならその数字を採る。
65529を超える数字は消費せずそこで止め、数字でも空白でもない文字でも止める。
最後に採った数字の直後へ位置を戻し、そこからを本文にする。
本文の先頭の空白は1個だけ取り除き、それ以外は保つ。
本文の語・数値は既存の表示規則で書き直す。本文が空白だけならその番号の行を削除する。
LISTは番号を10進で書き、本文との間に空白1個を置く。

例: `1 2 3 4 print 1` → `1234 PRINT 1`、`10   print 1` → `10   PRINT 1`、
`130 1+rem x end` → `1301 +REM x end`。
`65530 print 1` は番号6553で止まり、本文 `0 print 1` から `6553 0 PRINT 1` を出す。
`6553  0 print 1` も番号6553だが、本文先頭の空白が1個残る。
`655290 print 1` は番号65529・本文 `0 print 1`。
先行入力で1020番に行があるとき、番号だけの `10 20` はその行を削除し、観測署名は `no_line`。
