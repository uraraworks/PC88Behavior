# 手順の逸脱の記録 — 自作 ROM だけの G1 の走を Mac の Codex に回した

記録日: 2026-11-04

## 何が起きたか

B79 のあと、自作サブ ROM の止まる経路を追うために、Mac の Codex に「自作 ROM と G1 のローカルの複製で F1 の道を走らせ、自作サブ ROM のラベルの通過を数えて直す」作業を頼んだ。公式 ROM は使っていない。G1 の値・画面本文を出力しない条件を付けた。

これはプロジェクトの指示（G1 が要る走行と集計はクラウドの測定スレッドで行い、Codex には触らせない）と、[方針追補2](goal-b-policy-addendum2-remote-measurement-2026-10-31.md) 以降の運用に反する。コーディネーターの指摘（2026-11-04 00:23Z）で止めた。

## 扱い

- Codex を止めた。作業場 `tmp/g1-fix/`（G1 の複製と生の記録を含む）を消した
- Codex が入れた `src/` と `tools/` の変更は採らず、元に戻した。報告の途中に出た「バルクのあとの `0x0E` を独立した要求として扱う」という見立ては、このノートに推定として残すだけにする
- 見立ては、自作の媒体と自作のプローブ（G1 を使わない）でバルクのあとの状態を作り、公式と自作で比べてから採る（B80）

## 再発防止

G1 を使う走は、自作 ROM だけであってもクラウドの測定スレッドで行う。Codex への依頼文に G1 のパスを書かない。
