# B86 追補1 事前登録（測定前）

B86 の値なし集計では 369A と 37C9 が戻り、37D2 と 3847 は応答待ちのまま時間上限に達した。要求の前置きが必要という仮説を検査する。ゲームから使う追加情報は B84 の呼び順 37C9→37D2 と CALL 先番地 3391 のみとし、ゲームの再観察、ゲームの入力値、ROM の中身や内部経路は扱わない。

各腕を独立起動し、SP=F000、割り込み禁止。369A は BC=1,2,0100,0200、キャリー=0,1 と、HL・DE=(D000,D400),(D400,D000),(0000,D000) の直積。37C9 は A=0,1,2,FF と同じ HL・DE の組合せ、BC=1、キャリー=0。D000-D7FF は自作の 00〜FF 繰り返しで初期化する。連続腕は 37C9→37D2、37C9→3847、369A→37D2、369A→3847 とし、最初の入力は A=1、BC=1、DE=D400、HL=D000、キャリー=0。2回目には1回目の戻り状態をそのまま渡す。RET と RAM 変更・OUT FD の自作ルーチンを対照とする。腕の順序は結果によって変更しない。

測定前の追加: 3391 に初回 B86 と同じ10種類の単独腕を設ける。A・BC・DE・HL・F をすべて0とする腕、各々を一つずつ1にする5腕、HL=D000 または DE=D100 とし指す自作 RAM の値を0または1にする4腕とする。他の入力レジスタは0とし、SP と割り込みは上記と同じ。RAM の残りは追補1の繰り返し初期値とする。連続腕に 37C9→3391 と 369A→3391 を追加し、入力と引き継ぎは他の連続腕と同じとする。

起動ディスクはドライブ0、既存 coord-header 生成器の自作媒体（40シリンダ・両面・各16セクタ、識別子 A1）はドライブ1（frontend の --disk2）に置く。媒体は各腕で新規生成する。保存を有効にしないため永続的書き込みは観察しない。

判定と行き先: 各 CALL の直前と直後の OUT 7F の命令位置を印に、区間ごとの開始・戻り・main I/O の方向、ポートと件数、OUT FD の長さ、IN FC の長さを `summary/*.json` に記録する。送信全体および末尾と自作入力の一致だけ真偽で記録する。入力領域との比較は自作初期値が保たれることを前提とするため、2回目の一致は参考値である。受信列または事前・事後の RAM 写し内に自作媒体の256バイト全体が一致したときのみ座標を記録する。部分一致は座標の根拠にしない。

RAM は C100-EFFF の呼び出し前後の差分番地範囲を記録する。これは書き込み履歴ではなく、同じ値への書き込み、対象外や隠れたバンクは見えず、スタックや器具による変化を含む。連続腕の差は全体に対するもの。各 CALL 直前・直後にレジスタを変えない C0C0 への書き込みを置き、メモリ書き込みログ上のその印に挟まれた C100-EFFF の書き込み番地範囲を区間別に記録する。CALL のスタック書き込みも含む。時間上限内に戻らない区間も、ログ取りこぼしがなければ上限までの I/O を数える。開始印がない後続区間は欠測。印の重複、ログの取りこぼし、写しの不足は欠測とする。サイクルは欠測。

生 I/O、メモリ記録、媒体、標準出力等はリポジトリ外の非公開 `raw/` にのみ保存し、値なし集計だけを `summary/` に置く。集計に含める値は自作の腕名・番地・件数・自作媒体座標と一致真偽のみ。公式 ROM 由来の値、画面本文、内部 PC は出さない。自作 ROM による自己検査後にのみクラウドで測定する。自作 ROM の RET は公式の振る舞いの証拠ではない。
