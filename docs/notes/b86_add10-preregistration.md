# B86 追補10: G5 の main ROM 入口、測定事前登録

目的は需要が観測された入口の外部挙動を、自作入力で別途測ること。根拠は G5 境界観測 B90-entry3-add1 (b)。ゲームから採るのは次の入口、移動種別、回数、I/O の方向・ポート・件数に限り、ゲームの値や ROM 内部経路を使わない。

6F6B は CALL 1回、3391 を介した RAM への移動と、そこから 6F96・42F6・43E1・43E9・4353 への JP を経て戻る。7071 は JP 1回で区間 I/O なし。11DF は JP 4回で各 IN 71 が1回、OUT 71 が2回。3E0D は JP、IN 40 の待ちと OUT 31/30/40/51/50/64/65/68。3080 は既測のキー読み取り入口。

## 事前に定める腕と判定

- 8入口それぞれについて CALL と、受け口を1〜3語積んだ JP（追加深さ0〜2語）、DI/EI、自作レジスタ4組。SP は D000 から使い、割り込みは自作 IM2 受け口を使う。復帰、入力対出力の関係、区間 I/O のポート・方向・件数、OUT 各回と入力の関係、RAM 書込の番地・件数を記録。区間前の書込みから前値が分かる場合は変化番地・件数も記録し、前値不明の書込みは別に数える。
- 6F6B は CALL、DI/EI、4組の入力。HL・DE・BC の異なる自作 RAM 上に受け口を置き、到達の真偽と復帰を記録。対象外の飛び先や戻らない場合は到達先を断定しない。
- 3080 は無押下と4種類の単一キー、4通りの自作前回値。対象メモリを既知値で初期化し、行の IN と E6D0+r・E6DC+r の一致・反転・前回値、EFF9・E6CF の変化およびキー行・ビットとの一致を真偽で示す。
- 開始後の再起動または時間上限内の未復帰は「戻らない」。ログ不足・取りこぼし・実行失敗は欠測。受け口や記録印の I/O は区間から除く。値はリポジトリ外の一時領域だけで処理し、集計後に削除する。入力との関係の判定は有効な複数腕が必要で、不足時は未判定。

これは事前登録であり、対照を含む結果は示していない。実測は `tools/b86_add10_run.sh` にリポジトリ外の新しい出力先を渡す。フィルタ使用時は未実行腕を欠測として残す。
