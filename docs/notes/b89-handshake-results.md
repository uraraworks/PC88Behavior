# B89 受け渡し1往復の制御信号比較結果

## 対象と結論

根拠資料 `../../tmp/req09-work/b89-handshake-notes.md` の比較記録を仕様へ反映する。公式subと自作sub（比較対象 `0a748a0`）を比べたところ、メイン側の並びは一致し、相違はサブ側の次の3場面にあった。FC/FDのデータ値は扱わず、記録は件数と制御コマンドの順序に限る。

| 場面 | 公式sub | 自作sub（`0a748a0`） |
|---|---|---|
| 最後の引数バイトの後 | `0x0C` の後、`0x0B` を出さず送出へ | `0x0C` → `0x0B` |
| `0x09` 送出の各バイト | `OUT $FD` 1回 → `OUT $FF, 0x09` → `0x08` | `OUT $FD` → `0x09` → `OUT $FD` → `0x08` |
| 送出後から次の見出しまで | 待機入口で `0x0A`、RFDを下げたままATNを確認し、その後 `0x0B` | G3ではRFDを上げたまま。G1-15では待機入口で`0x0A`、ATN後に`0x0B` |

`0x15`送出は、公式でも `OUT $FD` 2回の形だった。したがって、上の `OUT $FD` 1回という結果は `0x09` の送出に限る。

## 仕様への訂正

第236版の「RFDは次のバイトを受ける予定のときだけ上げる」は一般化が不正確だった。B89で確認した並びは、最後の引数後に `0x0C` の後 `0x0B` を出さず送出へ移ること、`0x09` の各バイト送出が `OUT $FD` 1回・`0x09`・`0x08` の順であること、送出後の要求待ちでは `0x0A` でRFDを下げてATNを見てから `0x0B` を出すことである。第237版の `docs/spec/l3-subrom.md` 1.15節に反映した。

この誤った一般化に基づき自作subを変更したコミット `e034de4` は、`5324fa8` で取り消されている。G3で自作subが2回目の`0x09`送出後に停止した観測は、RFDが上がったままのためmainが次のATNを短く出し、subが取りこぼしたことと整合する。

## 範囲

比較した場面の記録であり、未測定の要求や全送出経路の一般則は主張しない。データポートの値列は記録していない。
