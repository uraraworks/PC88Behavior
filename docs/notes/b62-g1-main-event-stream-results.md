# B62: キーを打ったあと、main の RAM 上のコードの読み書きが最初に違う所を値なしで測る — 結果

記録日: 2026-11-02
規則: [b62-g1-main-event-stream-preregistration.md](b62-g1-main-event-stream-preregistration.md) と追補どおり。公式どうしは 3 腕とも同じだった。

## 結果

1 回目は関門の「キーなしの対照で公式対自作が同じ」が false で止まった。追補の B62b で対照の比較を出すと、次のとおりだった（`measurements/b62b-g1-main-event-control.txt`）。

- 出来事の数: 公式 7285388、自作 7285496（108 の差）
- 最初の違いは**記録の始め**（番号 0、フレーム 7000）で、発行元の `PC` から違う

## 読み方

記録をフレーム 7000 から始めたため、公式と自作でその時点に main がいる場所が違い、列がそろわない。この比較からは分かれ目を言えない。画像とテキストはこの時点で同じなので、main の進み方の位相がずれているだけかもしれない（**推定**）。

キーの読み方が時間に左右される可能性があるので、B63 でキーを長く押す介入と、起動時に ROM が設定するポートの比較を行う。
