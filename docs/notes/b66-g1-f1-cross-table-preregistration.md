# B66: F1 の腕で、自作が公式より 2 回少なく移る所を測る — 事前登録

記録日: 2026-11-02
位置づけ: [B65](b65-g1-held-key-paths-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

B65 の F1 の腕で、公式の 73・74 回目の移りはいつ、どこへ移るか。自作はその手前で何をしているか。

## 2. 条件

B65 の F1 の腕と同じ打ち方と同じディスク。公式 2 走、自作 1 走。あわせて、後半のキーの時刻を 1 フレームずつ 6 段ずらした走を公式・自作で 1 走ずつ（位相の差かどうかを見るため）。クラウドの実行環境で行う。

## 3. 器具

B40 の移りの表（`tools/b40_cross_table.py`）。B65 と同じ `--sub-reg-log`。

## 4. 記録の白リスト

B40 の行（`count`・`C`・`LEFT`・`RIGHT`）と、ずらした走の `shift <k> cross=<左> <右>`。**値は出さない。**

## 5. 判定（事前に決める）

- 公式だけにある移り（`LEFT`）の番号・移る先・fc を書く
- ずらした走で自作も 74 になる k があれば、位相の差として書く。どの k でも 72 なら、自作の道の違いとして次を測る
