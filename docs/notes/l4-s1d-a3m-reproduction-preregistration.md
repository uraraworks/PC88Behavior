# l4-s1d — l4-s1a の A3m（白黒・結合行）の再現 — 事前登録

記録日: 2026-09-15
状態: 事前登録、測定前

## 位置づけ

l4-s1a（[結果](l4-s1a-text-vram-results.md)、`b29bc85`）は、A3m（白黒モード、`CONSOLE ,,,0:COLOR n:PRINT "Q7Z"` を1行で打つ、n=0〜7）で「属性域が8通りとも同一」と記述した。l4-s1c（[結果](l4-s1c-attribute-values-results.md)、`5ca4e85` と末尾の訂正の追記）は、同じ形の B3-mono（n=0,4,7）で n=4・n=7 が n=0 と区別できる値を示し、関門 G7（再現）が偽になった。命令ごとに行を分けた B1 では、白黒モードの値は n=1〜7 でそのまま n、n=0 で既定と同一だった。

どちらの記述が正しいかは、l4-s1a の生データが削除済みのため、既存の記録からは決められない。l4-s1c の記述からは、目印を含む2行（打鍵行のエコーと印字結果）のどちらで値が変わったのかも区別できない。候補は次のとおりである。

- 候補1（行の取り違え）: 打鍵行のエコーは `COLOR` の実行より前に表示されるので、その行の属性域は n によらず既定のまま。l4-s1a の記述はエコーの行の属性域を見たものであり、印字結果の行では n によって値が変わっている
- 候補2（写しの時点）: l4-s1a の写し（`--type-at 300 --type '\n'` の起動settle、`--type-at 700` の打鍵開始、`--frames 2400`、`--vram-dump-at 2300`）と l4-s1c の B3 の写し（`984`、700 + 8×33 + 20、`CONSOLE ,,,0:COLOR n:PRINT "Q7Z"\n` の33文字）は時点が異なり、その間に属性域が変わる
- 候補3（再現しない）: 同じ条件でも走ごとに結果が変わる

## 条件

- `--type-at 300 --type '\n'`（起動settle）、`--type-at 700`（打鍵開始）、`--frames 2400`（公式ROM一式、ディスク無し、コア既定の BASIC モード）
- 腕: n=0〜7 の8腕、各2走
- 1走で写しを2枚取る: l4-s1a と同じ時点（`2300`）と、l4-s1c の B3 と同じ時点（`984`）。`--vram-dump-at` の複数指定
- 目印は `q7z`（l4-s1a の追補2）
- 器具と作法は l4-s1a・l4-s1c と同じ（走ごとに ROM ディレクトリを新規作成、`--mem-write-log`・`--io-log` も採る、生データはリポジトリ外に置き結果ノートの後に削除）

## 解析

- `tools/l4_vram_probe.py` の既存モードで、目印の出現ごとに (row0, col0) と、その行の属性域40バイトを得る
- 目印の2件を次の規則で呼び分ける: col0=0 の出現を「印字結果の行」、col0>0 の出現を「打鍵行のエコー」とする（打鍵行では目印が `print "` の後ろに来るため。l4-s1a の結果ノートの訂正の追記）。この規則に当てはまらない出現があれば、その腕は解析不能として記録する
- 行ごとに、属性域の先頭の (位置,値) 組の値バイトを n ごとに並べる

## 関門

- G1 器具: 測定時 HEAD で vram_dump_selftest.sh・vram_dump_dynamic_selftest.sh・mem_write_log_selftest.sh・mem_write_pc_selftest.sh が OK
- G2 取りこぼし0、打てない文字の警告0
- G3 決定論性: 各腕2走で、写しはファイルの sha256、記録と I/O ログはデータ行の sha256 が一致
- G4 陰性対照: 何も打たない走で目印0件
- G5 起点: 解析道具の出力が origin=0、screen_content_leak_selftest.sh の f2・f2n が OK
- G6 本文漏れ: screen_content_leak_selftest.sh 全項目 OK
- G7 呼び分け: 全腕・両時点で、目印がちょうど2件（col0=0 と col0>0 が1件ずつ）

## 判定

- `row_mixup`（候補1）: 両時点で、打鍵行のエコーの属性域は n=0〜7 で同一、印字結果の行の属性域は n によって異なる
- `timing_dependent`（候補2）: 同じ行の属性域が、2つの時点で異なる
- `nondeterministic`（候補3）: G3 が偽
- `s1a_confirmed`: 両時点・両行で、属性域が n=0〜7 で同一（l4-s1c の B3-mono の記述の方が再現しない）
- `other`: 上のどれにも当てはまらない（形を記述する）
- 判定の前に G1〜G7 がすべて真であること。G7 が偽なら判定せず `gate_failed` とする

## 判定後の行き先

- 結果は `docs/notes/l4-s1d-a3m-reproduction-results.md` に書く
- `row_mixup` なら、l4-s1a の結果ノートの A3m の記述を訂正の追記で改め、仕様書 `docs/spec/l3-main.md` の未確定の項「白黒モードで COLOR が属性域を変えなかった件」を、l4-s1c の B1 の観測（白黒の値は n=1〜7 でそのまま n、n=0 で既定と同一）で置き換える次の版を起こす
