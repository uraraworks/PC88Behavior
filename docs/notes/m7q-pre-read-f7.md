# m7q: sub側222件目とREAD DATA直前の制御出力

測定日: 2026-08-13

## 1. 情報境界

第34版自作sub ROMの混成ログと公式基準ログを、CPU・方向・ポートだけで比較した。
データポート値は伏せたまま使用していない。比較器の自己検査は全件合格した。

## 2. 222件目の構造差

sub側の畳み込み後構造列は221件まで一致した。公式subはSENSE DRIVE STATUSの
結果入力直後、READ DATAのステータス確認へ入る前に制御出力を1件発行する。
自作subはこの制御出力を省き、直接FDCステータス読みへ進んでいた。

公式4条件の同じ遷移で、SENSE DRIVE STATUSの結果入力、制御出力、READ DATAの
ステータス確認が隣接することを確認した。結果フェーズ後のTC三つ組みと異なり、
後続の確認入力を伴わない単発形である。値と方向は仕様書1.5節で確定済みの
`$F7`制御と同じであり、新しい値推測は行っていない。

## 3. 測定時点の到達点

- sub側構造的一致プレフィックス: 221件
- main側構造的一致プレフィックス: 258件
- main側単発送受信列の値一致プレフィックス: 4件
- 混成照合のmain `IN $FD`: 0件

生ログと一時解析物はリポジトリ外に置き、コミットしない。この境界で単発形を
選ぶ内部判定理由は未確定のまま残す。
