# m6f-i — ASCII 形式のファイルの LOAD（画面の反応・置き換え・エラー）— 事前登録

記録日: 2026-09-28  
状態: **測定前**

## 0. 位置づけ

自作BASICの `LOAD`（ASCII 形式、種別 `0x00` のみ）を実装する前に、公式ROM の `LOAD` の外から見える挙動を測る。
本体の形は l3-disk-format.md 第5版 2.6節で決まっている。本稿は**自作の生成器で2.6節どおりに作ったファイル**を公式ROM に `LOAD` させる
（公式ROM が自作のファイルを読めること自体も確かめる）。

構成・観測は m6f-e と同じ（ドライブ1＝参照 diskA 複製で起動、ドライブ2＝自作媒体、`CLS` 基準、行別署名のみ、G0〜G14 の定義を流用）。
打鍵の文字列リテラルは小文字で届く（m6f-a 結果 (i)）ので、画面を予測する腕では打鍵の文字をそのまま予測に使わない（数値と `LIST` の出力だけを予測する）。

## 1. 自作媒体

l3-disk-format.md 第5版だけで作る。名前・中身は自分で決める。

| ファイル | 種別 | 中身（各行 CR LF、最後に `0x1A`） |
|---|---|---|
| `QIA`（プログラム） | `0x00` | `10 PRINT 1` / `20 PRINT 2` |
| `QIB`（プログラム、行番号が逆順） | `0x00` | `30 PRINT 3` / `10 PRINT 1` |
| `QID`（行番号の無い行） | `0x00` | `ABC` / `DE` |

## 2. 腕（各2走）

| 腕 | 打鍵 | 観測 | 事前の候補 |
|---|---|---|---|
| I-1 | `cls:load "2:qia"` → 完了後 `cls:list` | `LIST` 後の画面 | `loads_lines`（`LIST` の2行が `10 PRINT 1`・`20 PRINT 2` と一致）／`other` |
| I-2 | `new` → `10 print 9` → `cls:load "2:qia"` → `cls:list` | 同上 | `replaces`（行10は `PRINT 1`、行20あり、元の行10は残らない）／`merges`（元の行が残る形）／`other` |
| I-3 | `cls:load "2:qib"` → `cls:list` | 同上 | `sorted`（10, 30 の順）／`file_order`（30, 10 の順）／`other` |
| I-4 | `cls:load "2:qia"` の直後の画面（`LIST` しない） | `LOAD` 完了時の画面 | `ok_only`（入力待ち行だけが増える）／`other` |
| E-1 | 誤り捕捉用プログラム（`on error goto` で `ERR` の数値を `PRINT`）の中で `load "2:qzz"`（存在しない名前） | `ERR` の署名 | `err_<N>`（0〜255 のどれか）／`not_trapped` |
| E-2 | 同上で `load "2:qid"`（行番号の無い行のファイル） | 同上 | `err_<N>`／`not_trapped`／`loads_without_error` |

- `LOAD` はプログラムを置き換えるので、E 腕では捕捉のプログラム自体が消える可能性がある。捕捉できなかった場合（`not_trapped`）は
  直接モードの画面の署名だけを記録し、エラー番号は決めない（追補を置く）。
- 予測する画面は `LIST` の出力（l4-program.md 第2節）と `ERR` の数値の `PRINT`（l4-basic.md 第2節）だけから作る。

## 3. 関門

- G0〜G14: m6f-e 本体・追補1と同じ定義（起動前の凍結照合で起動回数0、2走一致、参照 diskA 不変、本文を持つファイル0件、`CLS` 基準）。
- **G15**: 自作媒体が l3-disk-format 第5版どおりである（独立検査器で、エントリ・種別 `0x00`・鎖・終端・2.6節の本文と `0x1A`）。

## 4. 判定

各腕で2走とも一意に一致した候補名。0件・複数は `inconclusive_<腕>`。

## 5. 行き先

- `docs/spec/l4-basic.md` に `LOAD` 節を新設（ASCII 形式のみ。置き換え・並び・完了時の画面・エラー番号）。
- その後、自作 `LOAD` を実装し、本稿の腕を適合試験（行署名の照合）にする。

## 6. 決めないこと

- 通常の `SAVE`（`0x80`）・`SAVE ,P`・`BSAVE` のファイルの `LOAD`（自作は当面扱わない。扱わないときのエラーは自作側の判断として仕様に明記する）。
- `LOAD … ,R`、`MERGE`、`RUN "…"`。
- 1行が長い・行数が多いときの限界。
