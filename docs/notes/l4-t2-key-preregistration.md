## 固定操作・採取

全38腕、各腕独立した2走。候補2種もそれぞれ独立2走で、別起動を使う。画面・ログは成功/失敗ともfinallyで削除し、プロセスstdout/stderrは捕捉する。器具の出力・TSV・ノートは数値、署名、候補ID、一致位置、関門だけ。公式パスはPC88_REF_ROM_DIR経由でハーネスに渡すだけで、列挙・読込み・ハッシュ化しない。ディスクは指定しない。

boot腕は打鍵なしで3000/3300フレームに画面を採る。表示行数は同時採取するハードウェアI/O設定から決め、表示範囲内のみ非空白セル数・署名を残す。起動行数そのものを未知の画面本文から解釈しない。その他はNEW、固定した番号付きプログラム、RUN。打鍵は小文字のみ、各コマンド後はRETURNを含む文字数×8+240フレーム、RUN後3000フレーム待ち、300フレーム離れた2画面を採り、さらに400フレーム走る。実行中への追加入力はしない。操作列は器具program/armsで固定し、TSVのplanに腕の固定条件を保存する。

プログラムはE600〜E60FをFORで0にしてからON ERROR GOTOを設定し、段1・ready=151を書く。各操作前に段印を入れる。setupは10から、KEY等の測る文は40から、後処理は60から各コマンドごと+1、CSRLIN採取80、POS採取81、完了90。各段印と命令は別のBASIC行。ハンドラはERRを先頭で取得し、初回/最終ERRとその段、段別ERR、回数、測定用ERROR_FLAG=1をPOKEする。RESUME NEXTで次の保存行へ進む。最後にfinish=163を書き、GOTO待機する。KEY LISTが出力すれば待機に入った時点の画面を採る。

内部ERROR_FLAG番地は知らず、探さない。公開ERRを捕捉したときの自作印をERROR_FLAGと呼ぶ。E600は現在段、E601=ready、E602=finish、E603=ERROR_FLAG、E604=誤り回数、E605/E606=初回ERR/段、E607/E608=最終ERR/段、E609〜E60C=setup/statement/post/diagnosticの最終ERR、E60D=較正cal、E60E=CSRLIN、E60F=POS。各誤りの全書込み列も残すので同じ段の再発も消さない。ERLやROM内部フラグは測らない。較正POKE213とERROR13を毎測定で必須にする。

数値はRUN打鍵開始からの限定RAM書込みのみ。生ログのPC・パス・見出しを出さず、番地を0〜15の指数にする。画面写しは25行分あるが、ハードウェア設定で表示中と判定した行の表示セルだけを読み、非空白（0/32以外）のセル数、文字数、SHA-256だけ残す。40桁は偶数オフセットのみ。属性は除外。最下行だけでなく全行の個数を出すので、表示行の位置・KEY LISTの非空行数・スクロール前後の位置を本文なしで比較できる。非表示行はstate=hidden（非表示）だけを残し、個数・文字数・署名を持たない。非空行数は表示中のrowsのnonblank>0の件数、本文出力を命令した行数とは区別する。

## 表示候補と判定

assign-1/5/6/10の割り当ては作者が選んだt2abc。候補assignedはt2abc、contrastはt2abd。これらは事前入力であり、公式画面の転記ではない。独立起動でWIDTH 80,25、CLS、LOCATE 0,2、PRINT候補、数値診断、待機する。2走×各2時点一致、印字した5セルの到達、候補の数値関門・誤りなしを要求する。行2先頭5セルの署名を比較用の相対行0として作る。

測る腕の最下行全体には既定の装飾や他のラベルが含まれ得るため、それを候補へ写さない。最下行の各5セル窓（開始桁0〜75）を同じ相対行0で署名化して保存し、事前候補と一致する開始桁を記録する。一致位置を窓署名と候補署名から再計算してTSV読込みで検査する。全行一致とは主張しない。候補外は空の一致位置リストとして残す。5文字未満への切詰めはこの候補では不明。

同じ腕のstmtだけを除いたbaselineも独立起動して比較する。t2abcの非空白文字に変わった最下行セル数をchanged_cellsとして数える。候補署名が2種とも異なり、changed_cells>0のときだけ表示比較valid。それ以外はincomparable（不明）。候補ゼロ一致はvalidかつ候補外で、比較不能とは別。入力セルの関門はKEY文の打鍵エコーではなく、最下行の割り当て文字への変化だけを見る。画面欄の関門落ちはその表示比較欄だけを無効にし、ERR・完了・行別個数・CSRLIN/POSは保持する。

OFF/ONは最下行の個数と署名で消去/復帰を比較する。bottom腕は作者印t2xyzを最下行へPRINTし、CSRLIN/POSとその行の個数を比べる。scroll腕は行22から自作印3行をPRINTし、下端と上移動を行署名で比較する。console腕は窓5..14の下端から自作印を出し、ON/OFFと窓保持の関係を比較する。基準との差は本文を調べずに解釈する。予測外の誤り・値もそのまま残し、関門落ちは欠測とする。
