## 1. 円の画素の規則（確定）

- 単独の全円のセル（ci-1・ci-2・el-1〜el-6・df-1・cl-1 ほか約150セル）で、候補のうち**全セルと一致するのは `gw` だけ**（半分にする前置き切り捨て・掛け算切り捨て・比率整数化の切り捨て・角度を刻む方式は、それぞれ一部のセルで外れる）。
  `gw` ＝ GW-BASIC の構造:
  - 半径 r に対し X=2r、Y=0、和=0。**Y が偶数のときだけ ((X+1)/2,(Y+1)/2) を打つ**（Y≧X で止める）。毎歩 和 += 2Y+1、**和 ≥ 0 なら 和 −= 2X−1 して X を1減らし**、Y を進める。
  - 1組の (a,b) から8方向 (±a,±b')・(±b,±a') に打つ（b'・a' は比率で縮めた値）。
  - 半径0は中心の1画素、半径1は中心の上下左右4画素（中心は立たない）。左右・上下対称、水平方向の広がりは中心±半径ちょうど。
- 画面外は**点ごとに切り捨て**（画面内の画素だけ立つ）。線のような引き直しはしない（cp-ed・cp-ou・cp-bg・ci-b4 が一致）。中心が画面外でも描く。画面にかからない巨大な円（半径2000 など）は何も描かず誤りなし。
- 半径の範囲: 0〜32767（32767 は受理、32768・65535・70000・`1e10` は ERR 6、負は ERR 5、`"a"` は ERR 13）。小数は四捨五入（0.4→0、0.5→1、1.5→2、2.5→3、10.4→10、10.5→11、10.6→11）。**負の符号は丸める前に判定**（-0.4・-0.5・-1・-32768 は ERR 5）。半径が空（`,,7` の形）は ERR 2。

## 2. 楕円と既定の縦横比（確定）

- **既定の比率は 0.5**（省略と明示 0.5 の画素集合が3つの半径で一致: `default_is_half` 的中。比率 1 や 0.4・0.6 とは異なる）。640×200 で円は縦に半分に潰れる（垂直半径 = 半径×0.5）。
- 比率 ≤1: 半径は水平半径、垂直半径 = 半径×比率。比率 >1: 半径は垂直半径、水平半径 = 半径÷比率（el-1・el-2・el-3 の54セル全一致）。比率 1 は真円。
- 比率は **round(比率×256)**（>1 は round(256÷比率)）を整数にして、(v×a+128)>>8 で掛ける（el-5 の 0.4961・0.498・0.4981・0.5016・0.502・0.5023 などの境界を跨ぐ12セルが一致。切り捨ては外れる）。比率 0・1e-10・1e-38 は水平の線、256 以上の大きい比率（1e10・1e38 まで）は水平半径が 0 になって縦の線（誤りなし）。
- **比率が負でも誤りにならない**（el-4）: -0.5 は 0.5 と同じ画素、-1・-2・-100 は真円、-0.001 は水平の線。GW-BASIC と同じく、負の比率は 256 倍した負の整数のまま掛け算に渡り、**下位バイトが 0 なら上位バイトが 0 以外で素通し（真円）・0 で 0 倍、そうでなければ下位バイトだけで掛ける**と説明できる。
- 比率 `"a"` は ERR 13、比率が空（`,` で終わる）は ERR 22、比率の後にもう1つ引数（`..,0.5,1`）は ERR 2。

## 3. 円弧・扇形（確定）

- 角はラジアン、範囲は -2π〜2π。**6.28318 は受理、6.2832・6.3・7・100・1e10・-6.2832・-7 は ERR 5**（0/6.2832 の組も ERR 5）。`"a"` は ERR 13。
- 画素の位置は点数の方式（GW-BASIC の構造）で全セル一致（ar-1・ar-4・ar-5・ar-6 は角を 0.1〜3.5 まで18通り動かし、比率 1 の r=28・r=12 と比率 0.5 の r=50 で全一致）:
  - 1/8 周あたり N=round(r×0.7071) 点。角の点数 = round(|角|/(2π)×8N)。八分円ごとに2Nずつ足して数え、**開始と終了の間の点を打つ**。端点（点数が開始・終了と同じ点）は含む。
  - 比率 1 の開始0・終了π/2 は右上の1/4（端点 (r,0)・(0,−r) を含む）。4象限を足すと全円。
- **開始＞終了は範囲の外側を打つ**（補集合＋境界。ar-2 の (π/2,0)・(3,1)・(6,3) などが一致）。開始=終了は端点の点数に当たる画素だけ（ar-1 の (0,0)・(1,1)）。
- **負の角は絶対値を角度に使い、その端点から中心へ線**（扇形）。両方負なら両端に線、片方だけなら片方だけ。線は LINE と同じ規則（和 ≥ 主軸の差）。開始・終了を入れ替える（開始＞終了）ときは負の印も入れ替わる。
- 6.28318 の組: `(6.28318,0)` は右端の1画素だけ、`(6.28318,6.28318)` も1画素。
- 既定の比率（0.5）の円弧も同じ規則（ar-3）。

## 4. 色・LP・STEP・誤り番号・白黒（確定）

- 色: 0〜7 を受理（0 は消す）。-1・8・255 は ERR 5、`"a"` は ERR 13、`1e10` は ERR 6、色が空（`circle(..),r,`）は ERR 22。1.5→2・0.5→1・0.4→0・6.5→7。省略は COLOR 第4引数（cl-4）。背景色の上の色 0 は黒の穴（cl-5）。
- LP: **CIRCLE 後の LP は中心**。中心を読めた時点で動くので、半径・色・角・比率の誤りでも中心へ移る（lp-b）。中心の座標が範囲外（32768・-32769・`1e10`・(150,32768)）は ERR 6 で LP は動かない（第2座標だけ範囲外でも第1座標へは動かない）。**中心 -32768 は受理**。
  `circle step(dx,dy),r` は LP からの相対（LINE のあとの LP 含む）。半径0でも LP は中心（lp-a）。
- 白黒（`screen 1`）は PSET・LINE と同じ（色が 0 以外ならアクティブページのプレーンに1ビット、mo-0・mo-1）。

## 実装への含意（src/ は触っていない）

1. 円: 上の `gw` 規則（Y 偶数の歩だけ打つ中点法）。比率は round(比率×256) の整数で、下位バイトが 0 のときの扱い（素通し／0倍）、(v×下位+128)>>8。比率 >1 は X 側を縮める。既定の比率は 0.5。
2. 円弧: 点数の方式（N=round(r×0.7071)、角の点数=round(|角|/(2π)×8N)、八分円ごとに b か N−b に 2N の倍数を足す）。範囲外の角は ERR 5。負の角は端点から中心への LINE。開始＞終了は範囲の外側。
3. 画面外は点ごとに切り捨て。半径は負なら（丸める前に）ERR 5、32768 以上は ERR 6。中心の LP 更新は中心を読めた時点。
4. 構文は第5節。末尾が空の引数は ERR 22、引数過多・コンマ過多は ERR 2。
