## 結論 — 使わない

**分量が極めて少なく（3 ページ合計で本文 4.5KB 程度）、記述の世代が
PC-8001 / 初期 PC-8801 寄りで、測定と食い違う。**
`docs/spec/l1-ipl.md` 第5b節の Web 資料（出典の記載が無い個人サイト）と
同格かそれ以下の扱いとする。仕様書に取り込まない。

`/Video` は `/Address_Map` の一部の重複。`/Audio` は 2 文
（システムスピーカーがポート `0x40`。第5a節の「`40` OUT b5 BEEP」と一致）。

## 禁止事項2 の確認

**逆アセンブルリスト・コード断片は無い**（3 ページとも Z80 ニーモニックの並び 0 件。
HTML を自分で取得して確認した）。

判断に迷ったのは次の 2 行である。

- `0x8000-0x800F` — Interrupt Jump Pointer Table（INT7〜INT0 の割り当て）
- `0xFF39-0xFF3C` — Memory Integrity Test Result（"Monitor" が結果を書く場所）

いずれも ROM が使う RAM のワークエリアである。
`docs/notes/contamination-2026-08-07.md` の前例に照らして判定した。
あの記録が汚染としたのは

> `ED2D JP 8FBD` の形式で数件 …
> いずれも「この番地には、この番地への JP がある」という **ROM のコードの内容**である。
> **ポート番号や機能名のような事実ではない。**

というものだった。**今回見たのは番地とその機能名だけで、ROM のコードの内容
（JP 先の値、ROM 内エントリアドレス）は含まれていない。**
前例の基準では「ポート番号や機能名のような事実」の側なので、汚染としない。

ただし境界に近いので、次の 1 点は明示しておく。

### 注意 — `0x8002-0x8003 = INT6 (vertical blank)` は宿題1 に触れている

`docs/notes/m4-l1-impl.md` の宿題1「定常状態の周期が何で駆動されるのか
仕様書に書かれていない」に対し、**垂直帰線の割り込みベクタが存在する**という
手掛かりを与えてしまう。

- **L1 の実装はこれを見る前に完了しており、コミット順序がそれを示す。**
  自作 IPL は仕様書に書かれていないことを推測で埋めない方針から、
  割り込みではなく VRTC ポーリングで定常状態を回している
  （コミット `11f6ee5`、この調査より前）。
- **今後、定常状態を割り込み駆動に書き換えるなら、根拠はこの wiki ではなく
  測定にすること。** 仕様セッションが定常状態の `pc` を見れば決まる（宿題1）。

## 測定と食い違う点（なぜ信用しないか）

| wiki の記述 | 測定・他資料 |
|---|---|
| `0x0A` プリンタデータ出力 / `0x10` Tab キー状態 | `00H`–`0BH` はキースキャン（NEC マニュアル 2 冊 + 測定で一致） |
| `0x52` バックグラウンドカラー（デジタル RGB 3 ビット） | 測定はアナログ 512 色。第5c節 |
| `0x55`–`0x5B` パレット（index = port − `0x54`） | 測定は `54`–`5B` の 8 スロット。第5c節 |
| パレット書式を `0x31` bit6 が切り替える | 第5c節は `0x32` bit5 = PMODE。測定は `32 ← A8`（`0x20` セット）で、`31` に `0x20` を立てる書き込みは無い |
| `0x30`/`0x31` を「PC-8001 Emulator」と記述 | — |

「PC-8000 series machines have a program called Monitor」とも書いており、
**このページは PC-8001 / N-BASIC 側を主に記述している**と読める。
第5a節の書籍（1982年）がアナログパレットで使えなかったのと同じ世代問題である。

**測定と食い違ったら測定を優先する**（第5a節・第5b節）。

## 1 点だけ、構造の裏付けにはなる

`0x54` を「Toggle Background/Foreground color components. bit 8 (mask `0x80`) が
セットなら対象はバックグラウンドカラー」と書いている。

第5c節は測定値 `54 ← 80` / `54 ← C0` を、b7-6 が `10`/`11` なので
**バックグラウンドカラーを 0 にしている**と読んだ。
**別経路の資料が「`0x54` の b7 がバックグラウンド指定」と言っており、
この読みを支持する。** ポート番号もビットの意味も一致している。

ただしこれだけのために資料として採用するには弱い。第5c節の Web 資料
（SR 以降を扱う「PC-8801 覚え書き」）のほうが記述が詳しく、測定とも整合する。
**この一致は「第5c節の読みが独立に支持された」という補強材料として記録するに留める。**
