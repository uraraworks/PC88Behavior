# B17: 自作のコードをサブへ送って走らせ、`00C1` へ戻す — 事前登録

記録日: 2026-10-31
位置づけ: [B16](b16-sub-request-0c-args-results.md) の推定を、自作のコードで確かめる。[B15](b15-g1-sub-boundary-results.md) の番地 `00C1` の働きも測る。
**このノートは測定より先にコミットする。** 結果を見てから規則を変えない（変えるときは後続ノートで）。

G1 は使わない。送るコードはすべて自作で、公式の値を読まない。

## 1. 問い

1. `0x0C, AH, AL, LH, LL, 本体` は番地 A へ L バイト書くか
2. `0x0D, AH, AL` は番地 A へ制御を移すか
3. 自作のコードから `00C1` へ jump すると、サブは次の要求を受け付けるか

## 2. 器具

`DISK.ROM` だけ公式で、main は自作の測定 ROM、媒体は `make_l3_testdisk.py` の coord-header。各行は別の起動で各 2 走。起動後の前置きは B16 と同じ。
記録は `--sub-boundary-log` の A・W と、`--io-log` の件数。

自作のコード（行ごとに番地を変える）: `LD A,5Ah` / `LD (目印番地),A` / `JP 00C1h`。

## 3. 行（この順に固定）

| # | 送るもの | 目印番地 | 狙い |
|---:|---|---|---|
| 1 | `0C 78 00 00 10` と本体 16 バイト | - | 書くだけ。`0x0D` なし |
| 2 | 行1 のあと `0D 78 00` | `7810` | 走って戻る |
| 3 | 行2 のあと、読み要求 `0x02`（T=0,R=1,P1=1）を受け取りまで | `7810` | 戻った後に要求が通る |
| 4 | `0C 60 00 00 10`・`0D 60 00` | `6010` | 別の番地 |
| 5 | `0C 79 00 01 00`（本体 256 バイト）・`0D 79 00` | `7A10` | 長さ 256 |
| 6 | 行2 と同じ本体を送り、`0D 78 03` | `7810` | 故障注入: 飛び先をずらす（`LD (nn),A` の途中）。走った証拠が消える |
| 7 | 行3 のあと、2 回目の `0C`・`0D` と読み要求 | `7820` | 繰り返し |

## 4. 観測

行ごとに、受け取られた件数、測定 ROM の完了の印、記録 W の区間と発行元（`7F00` 以降は別に分ける）、記録 A の飛び先、読み要求の受け取り件数と刻印の座標。

## 5. 判定（事前に決める）

対照: 行1 で記録 A が空で、発行元 ROM の W に `7800-780F` がある。行6 で発行元 RAM の W に目印番地が無い。2 走が全行で一致する。通らなければ根拠にしない。

- **書き込み:** 行1・4・5 の発行元 ROM の W が `番地〜番地+L-1` なら確定
- **走る:** 行2・4・5 で発行元 RAM の W に目印番地があれば確定
- **`00C1` へ戻る:** 行2 の記録 A が `00C1` を 1 回 jump で持ち、行3・7 の読み要求が 256 バイト正しく渡れば確定
- 確定した範囲だけを `docs/spec/l3-subrom.md` に書く

## 6. 記録の白リスト

行番号、件数、区間の番地、飛び先の番地、回数、刻印の座標だけ。公式サブが返す値を出さない。
