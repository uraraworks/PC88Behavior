# m7ac: 高速バルク全位置のREAD座標対応

測定日: 2026-08-13

公式環境を1800フレームで新規実走し、比較器内部だけでデータ値を扱った。
出力したのは出力位置と `(READ回, セクタ, セクタ内位置)` の一致座標、候補数、
順序規則の成立長だけであり、データポート値は表示していない。

値だけを独立に照合すると、定常5632位置はすべて複数のREAD座標と同値であり、
一意位置は0だった。しかし `$FC` と `$FD` を一組に戻して順序を課すと、定常列の
先頭16組は第2 READ・第5セクタ・第2位置から始まる隣接バイト列へ一意に一致した。
その座標から第2 READ残部、第3 READ全体、第4 READ全体、第5 READ全体を連結すると、
11263/11264位置が連続一致した。残る最後の `$FD` 1位置は直前の `$FC` と同じ、
すなわち第5 READ・第2セクタ・第256位置の重複送出だった。

したがって配置は次のとおり確定した。

- バルク位置3は第2 READ・第5セクタ・第1位置。
- 定常部は、その次の位置から第5 READ末尾までをREAD順・セクタ順・位置順に走査し、
  `$FC`, `$FD` の順で交互に割り当てる。
- 最終組だけ、最後の媒体位置を `$FC` と `$FD` の両方へ割り当てる。
- 第1 READ全体と第2 READの先頭4セクタはバルクデータへ配置されない。

順序制約込みの全数対応で一意に決まらない位置は0件。比較器が生成した機械可読な
全座標表は生ログと同じくリポジトリ外で扱い、公開ノートには規則と成立件数だけを残す。
