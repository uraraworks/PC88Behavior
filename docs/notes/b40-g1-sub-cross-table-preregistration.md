# B40: スペース後の G1 で、サブが RAM 上のコードへ移るときの表を値なしで出す — 事前登録

記録日: 2026-11-01
位置づけ: [B39](b39-g1-sub-reg-diff-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

1. 移る時点で、どのレジスタが何番目から違うか。`A` と `F` は分けて見る
2. 公式と自作で移る先が違う最初の移りは、main の `IN $FC` の何番の時点か。B30 の 76570 より前か後か
3. そのとき自作はどの番地へ移るか

## 2. 器具

コアはパッチ 0022 のまま変えない。B39 の生の記録の順番から表を作るツールを足す。

出力の行は次だけである。**値は出さない。** 番地は移る先の `PC` だけを出す。公式の ROM 側の発行元の番地は出さない。

- `# 識別子: G1`
- `count <左> <右>`
- `C <番号> <左の PC> <右の PC> <左の fc> <右の fc> <違うレジスタの名前をカンマで|none>`（両方にある番号のみ。レジスタは `A`・`F`・`B`・`C`・`D`・`E`・`H`・`L`・`IX`・`IY`・`SP`・`A'F'`・`B'C'`・`D'E'`・`H'L'`・`I`・`IFF`・`IFF2`・`IM`・`HALT`。`R` と `PC` を除く。fc はその時点までの `IN $FC` の回数）
- `LEFT <番号> <PC> <fc>`（左だけにある番号）
- `RIGHT <番号> <PC> <fc>`（右だけにある番号）

器具は G1 なしで自己検査する。陽性対照は `A` と `F` の分離、片方だけにある番号、fc の数え方。陰性対照は値が出ないこと、同じ記録で `none` だけになること。

## 3. 条件

腕 F の 4800 フレーム。OO・SS 各 2 走。自作 ROM は ff113bf の配布ビルド。クラウドの実行環境で行う。

関門: `IN $FC` の差が B30 と同じ（257 件、最初 76570、連続 132）。OO どうし・SS どうしの表で違うレジスタがすべて `none`、番号の数と `PC`・fc が同じ。

## 4. 記録の白リスト

第 2 節の行だけ。

## 5. 判定（事前に決める）

- 違う `PC` の最初の行と、その fc を 76570 と並べて書く
- 移りごとの違うレジスタをそのまま書き、初めて現れるレジスタを挙げる
- 違いがあっても原因は書かない。公式の値を知るには、自作のコードと自作の媒体で要求の順を再現する測定を、別に事前登録する
