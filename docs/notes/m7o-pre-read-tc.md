# m7o: sub側203件目とFDC READ系直前の制御出力

測定日: 2026-08-13

## 1. 情報境界

公式main一式と第32版自作sub ROMを組み合わせ、diskA起動・1800フレームで
`tools/diag_l3_mixed.sh --brief`を再実行した。公式ROM・公式ディスクの内容は
読まず、混成ログのデータポート値は解析前に伏せた。比較器の自己検査は全件合格した。

## 2. 203件目の構造差

sub側の畳み込み後構造列は202件まで一致した。交換#3の5件目を受信して受理解除を
提示した直後、公式subはFDC READ系へ入る前に制御出力を1件発行する。自作subは
この制御出力を省き、直接FDCステータス読みへ進んでいた。欠落した制御出力は、
結果フェーズ後の三つ組みとは異なり、後続の確認出力・確認入力を伴わない単発形だった。

既存の公式4条件も構造だけで再集計し、同じ通信終了からFDC READ系へ移る箇所で、
この単発制御出力が両者の間に隣接することを確認した。値と方向は仕様書1.21節で
確定済みのTCと同じである。FDCコマンドのデータ値は使用していない。

## 3. 測定時点の到達点

- sub側構造的一致プレフィックス: 202件
- main側構造的一致プレフィックス: 258件
- main側単発送受信列の値一致プレフィックス: 4件
- 混成照合のmain `IN $FD`: 0件

生ログと一時解析物はリポジトリ外に置き、コミットしない。FDC READ系の個々の
コマンド値と、この境界で単発TCを選ぶ内部判定理由は未確定のまま残す。
