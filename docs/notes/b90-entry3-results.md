# B90 — サブ ROM 入口版の比較結果

記録日: 2026-11-12  
対象: 入口版（1150e6f）での G2・G5・G1・G3 の再比較

## 比較

- **G2** は動作する。
- **G5** は 6F6B 以降で停止する。
- **G1** は公式 ROM に対して 1F ずれる。この差は入口版の応答タイミングに起因する。
- **G3** は入口版でもほぼ不変。

## G5 の停止原因

G5 はサブ側 4000 番地のゲームコードからサブ ROM の 02DB・02DC を読み、その2バイトを CALL 先として使う。公式 ROM でこの CALL のあと最初に実行へ入った番地は 07D6 だった。これはゲーム実走で観測した CALL 後の PC であり、ROM の内容を読んだ結果ではない。

02DB・02DC の内容は、ゲームの呼び先として観測した番地 07D6 から決める（ROM の中身を読んだのではなく、CALL のあとに入った番地という観測）。本人がこの扱いを選んだ（2026-11-12）。これは [goal-b-policy 第2節](goal-b-policy-2026-10-24.md) の分担に沿い、ゲーム実走から需要の番地・回数を記録し、ROM 領域のデータ読みについては値を記録しない方針を保つ。ここでは読み出し値を転記せず、制御移動後の観測番地を仕様化する。

## 根拠

- B90 の G5 サブ 02DB・02DC 観測、および entry3 summary・add1（クラウド資料）。ゲーム実走 ID と観測条件は各資料を参照。読み出し値は記録しない。
