# 資料判定 — 起動直後の固定交換の意味論を探す

調査日: 2026-08-13
位置づけ: `docs/notes/m7c-round0-is-independent-of-disk-content.md` の次段

## 1. 目的と方法

起動直後のメイン CPU とサブ CPU の間で行われる固定 2 バイト要求／
1 バイト応答が何を意味するかについて、散文による説明を手持ち資料から
探した。

資料の可否判定は使い捨ての判定係にだけ行わせ、内容の抜き書きは行わせて
いない。判定係は実装に関与しない。交換された値やバイト列は、本稿には
記録しない。

## 2. 資料ごとの判定

### 『PC-8801FA／MA プログラマーズガイド』（epub）

**読まない。** 序文は本書の扱う範囲を「プログラミング環境」および
「高度・実用的テクニック」としている。ROM 解析に当たる範囲を章単位で
排除できる構造になっていないため、『PC-8801 マシン語活用マニュアル』と
同じ理由づけで対象外とする。

### 『PC-8801FA／MA n88-BASIC／n88-日本語BASIC リファレンスマニュアル』（epub）

**可。** 「BASIC の機能を解説」と明記された言語仕様書である。ただし、
今回の問いに該当する記述は見当たらなかった。

### 『NEC PC-8801mkIIMR USER'S GUIDE 1986年』

**可。** 「設置・接続」「周辺機器」「必要な知識・資料」を扱うと明記
されている。候補は資料編「資料2 入出力インタフェース」p.6 の
ハードウェア仕様である。「第7章3 ディスクユニット」p.135 は周辺機器の
概説であり、仕様ではない。

### 『PC-Techknow8801 Vol.1 1982』

既存判定どおり、付録6「I/O ポート一覧表」p.286 と本文第1章・第4章のみ
可とする。付録2・3・4・5・7 は開かない。今回の問いに該当する散文説明は
確認できなかった。

### 『PC-8801 マシン語活用マニュアル』

`docs/notes/refs-machinego-not-opened.md` の判定どおり対象外とする。

## 3. 手順違反の申告と是正

判定係は「目次から入らない」という手順に反し、候補探索の過程で
『PC-Techknow8801 Vol.1』の目次 p.4–9 を見たと自己申告した。本文および
ROM 内容は見ていない。判定係は使い捨てで実装には関与しないため、実装側の
汚染は無いが、この手順違反を隠さず記録する。

手順を次のように是正する。

**候補箇所の特定も、可否判定と同じくカバー・まえがき・序文の範囲で
行わせる。目次が要る場合は、見たページ番号を必ず申告させる。**

## 4. 結論

**起動直後のサブ CPU 交換の意味を説明した散文は、手持ち資料の
「読んでよい範囲」には見つからなかった。** ポート番号・信号仕様のレベルの
資料はあるが、交換の意味論には届かない。

## 5. 残った選択肢

次の一手はここでは決定せず、候補だけを記録する。

1. mkIIMR 資料編「資料2 入出力インタフェース」p.6 を実際に確認する。
   低コストで確認できるハードウェア仕様である。
2. Web 資料を使い捨ての判定係経由で探す。出典記載の無い Web は格付けが
   最下位である。
3. 介入測定で意味を機能的に特定する。応答値を変えたときのメイン側の挙動の
   違い（起動継続／エラー／別ルート）を観測し、その 1 バイトが何を選択して
   いるのかを測る。由来の鎖としてはこれが最もクリーンであり、規律の
   「測定 > 書籍」にも合う。
