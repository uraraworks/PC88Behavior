## 固定手順と取り出し

全腕は新規プログラム、CLS、RUNで開始。登録行以外の直接命令は数字で始めず、
全行80文字未満、小文字のみ。1文字は押下4・解放8フレーム、計12フレーム。
同一キーを続けても8フレーム離し、ポーリング2回ぶんの隙間を確保する。
行間240、自作開始100、公式開始700（起動RETURNは300）。
RUNのRETURN押下フレームをRとし、採取R+18000、終了R+18100。
追加打鍵の時刻は下表のR相対値。predict・measureのTSVには自作用と公式用の
全イベントの絶対フレーム・押下・解放時間、入力したプログラム行を記録する。
既定作業場は `../tmp/l4s9c-work`。selftestラッパーだけは指定なしなら
書込み可能な一時領域を作り、終了時に削除する。

文字列を表示せず、`ik n LEN 各ASC`、集計は`iks 試行数 非空回数 最大LEN`、
完了は`ikd 1`。印は大小同一視、正数の前の空白を要求し、整数のみ完全一致。
長さとASC個数、0〜255、番号順、行数、完了印を厳密検査する。
今回の表示可能上限は1読み取り8文字であり、これを超える結果は関門失敗。
LEN>1の結果を1文字に切り捨てない。長さとASC個数を保存して
「1回1文字以下」という候補を検査する。
印以外の画面行は件数のみ。本文・測定器のstdout/stderrを表示・保存しない。
画面写しは成功・失敗ともfinallyで削除。一時ROMとビルド成果も削除する。

## 腕（20腕＋定数3腕、各2走）

| 腕ID | 手順・追加打鍵 | 固定時刻 |
|---|---|---|
| idle-once | RUN直後1回だけ読みLEN・ASC | なし |
| idle-100 | RUN直後100回読み、非空回数と最大LEN | なし |
| run-return | 最初の1回、FOR 3000回待ち、その後8回読み | なし |
| key-a / key-z | 最初の1回を別記、その後空の間は待ちループ、a / z | R+600 |
| key-0 / key-9 | 同上、上段0 / 9 | R+600 |
| key-space | 同上、空白 | R+600 |
| key-bang / key-question / key-plus / key-bracket | 同上、! / ? / + / [ | R+600 |
| key-return | 同上、RETURN。コード予測なし | R+600 |
| buffer-ab / buffer-abcde / buffer-aab | 最初の1回、FOR 3000回待ち、その後8回読み | R+100から12フレームごと |
| early-ab | 同じ待ちを入れ、RUN直後の先行ab | R+24から12フレームごと |
| echo-idle | 最初の1回後、10000回ポーリング、非空回数・最大LEN・先頭8文字以上を保存 | なし |
| echo-a | 同じ窓、aを単発。echo-idleとの印以外の行数比較 | R+600 |

通常の待ちループは `a$=inkey$:if a$="" then ...`。
10000回の窓では画面印刷を窓終了後に行い、印刷中のキー入力を減らす。
蓄積文字列は長さ8未満の間だけ追加し、最大LENと非空回数を別に取る。
定数対照は長さ2・97,98／長さ0／長さ3・101,108,108を既知値とする。
ON ERRORは今回は不要であり登録しない。終わらない待ちループも完了印欠落として
関門失敗にし、エラー本文やタイムアウトからキーコードを推測しない。

## 固定候補

- **K_BUF**: 押した順にバッファされ、呼び出し1回で先頭1文字を取り除く。
- **K_LAST**: 未読は最後の1文字だけ残り、読めば消える。
- **K_NONE**: キーを離した後は保存されず、呼んだ瞬間の押下だけを読む。

候補の共通初期条件は、RUNのRETURNが準備として消費され、最初の読みは空。
idle-onceは長さ0、idle-100は非空0・最大0を全候補で予測する。
通常単発キーは最初の読みが空、待ちループの結果が1文字で指定ASCIIと予測する。
buffer/earlyは最初の読みが空、続く8回はK_BUFで打った全文字順＋空、
K_LASTで最後の文字＋空、K_NONEで全部空と予測する。
run-returnは全9回空を予測する。
RETURN単発・echo・holdの回数は予測なし。predictはその列をJSON nullにし、
measureはunpredictedと記録する。SKIPやunpredictedを照合合格にしない。
機械可読の全候補列・プログラム・イベントは `predict --out FILE` で固定生成する。

RUNのRETURNまたは先行キーが最初の読みへ混ざったら、共通初期条件の違反であり、
候補の採否には使わない。結果を観測として残し、準備の排出手順を別の追補で
事前登録する。最初の読みやFOR待ちの終端を外部から時刻測定していないため、
buffer-ab/abcde/aabでは、最初の追加打鍵の直前と、全打鍵終了後16フレームに
追加の画面写しを採る。両方で初回ikだけが存在し、2回目以降・完了印がない
ことを要求する。これで印刷完了後から連続読み開始前というFOR待ちの範囲内で
打ったことを関門にする。追加写しも削除し、本文は残さない。early-abは早期入力
そのものが対象なのでこの関門を課さず、初回への混入も保存する。
準備混入はpreparation_contaminated列に真偽を保存する。現登録からキー到着・
読み始めの厳密時刻を断定しない。

エコー判定は同じプログラムのecho-idle対比で、印以外の行数増加の真偽を保存。
件数が増えれば画面への追加を支持する。件数が同じでも既存行内の変化は
検出できず、「絶対にエコーしない」とは決めない。
リピートの非空回数0は窓内未捕捉、1は単発、2以上は複数の観測。
細かな回数・間隔を仕様にはしない。

## 関門・check・selftest

各腕の打鍵・採取失敗、形式不正、完了欠落、2走の印行または他行件数不一致は
関門失敗。定数3腕すべての2走が既知整数列と一致することが全体関門。
対照が欠けても合格にしない。関門通過は観測形式の信頼性であり、候補への一致を
意味しない。採否は関門通過後のagree/differ列と上記の時間・準備条件で判断する。

`check --expected FILE --measured FILE [--candidate K_BUF]` は腕集合と
2走・番号・関門・整数列の完全一致を要求する。予測なしを含む全予測TSVでは
合格を返さない。未知腕・重複期待行・不正JSONも拒否する。

selftestは合成画面の陽性・印破壊・個数不整合・1文字改変・短い写しの陰性、
全23腕2走の合成再生、定数改変の全体関門伝播、打鍵失敗を検査する。
時刻対照は生成イベントを待ち窓へ渡す合成対照と、実フロントエンドで自作ROMの
INPUTへ`a`＋RETURNをフレーム0（入力待ち前）／R+600（INPUT待ち後）に
打つ対照。後者だけが既知のLEN=1・ASC=97と完了印を得ることを要求する。
INKEY$のない自作ROMでINPUTを代用し、時刻指定が走行結果を変えることを検査。
自作ROMを一時ビルドし、定数3腕×2走の既知値とcheckの期待値改変拒否も検査する。
実行コマンドは `bash tools/l4_inkey_selftest.sh < /dev/null` だけ。
run_allにはstrfunc直後に1行だけ登録する。公式ROM測定・全体selftest・git add・
コミットは行わない。
