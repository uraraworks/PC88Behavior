# B21: 読み込んだコードが走ったあとの要求 `0x06` の応答を、自作のコードで測る — 事前登録

記録日: 2026-10-31
位置づけ: G1 の確認走行で、自作サブは `IN $FC` の 8962 件中 2 件だけ公式と違い（番号 3840 から）、その直後に受け渡しが止まる。件数の内訳（RAM 側の送信 5120、ROM 側の送信が公式より少ない）から、違うのは ROM 側が返す応答である可能性がある（**推定**）。1.37 節は読みのあとの `0x06`→`0xC0` だけを扱っている。
**このノートは測定より先にコミットする。** 結果を見てから規則を変えない（変えるときは後続ノートで）。

G1 は使わない。送るコードはすべて自作である。

## 1. 問い

`0x0C`・`0x0D` で走らせたコードが `00C1` へ戻ったあと、要求 `0x06` に公式サブは何を返すか。読みが成功・失敗したあとでは何を返すか。

## 2. 器具

B17 と同じ。`0x06` を送り、応答を 1 バイト受け取る（時間切れ付き）。**応答の値は記録する。** これは自作の刺激に対する外部の入出力で、読みのデータではない（1.37 節の `0xC0` と同じ扱い）。応答より後のバイトは読まない。

## 3. 行

| # | 手順 | 狙い |
|---:|---|---|
| 1 | 読み要求（T=0,R=1,P1=1）の `0x06` まで | 対照: `0xC0` が既知 |
| 2 | 読み要求（P1=0、失敗）の `0x06` まで | 失敗の応答 |
| 3 | 何も読まず、`0C`・`0D`・`00C1` へ戻る、`0x06` | 走ったあと |
| 4 | 読み要求を最後まで、`0C`・`0D`・`00C1`、`0x06` | 成功のあとで走ったあと |
| 5 | 行3 のあと、もう 1 回 `0x06` | 応答が変わるか |
| 6 | 自作のコードが FDC で READ DATA（T=0,R=1,N=1）を出して結果まで読み、`00C1` へ戻る、`0x06` | コード自身の読みのあと |
| 7 | 行6 と同じで、存在しない R を読む | コード自身の読みの失敗のあと |

各行 2 走。

## 4. 判定（事前に決める）

対照: 行1 の応答が `0xC0`、2 走が全行で一致。通らなければ根拠にしない。
行ごとの応答の値、または「応答なし」をそのまま書く。規則は値が揃った範囲だけ書く。
