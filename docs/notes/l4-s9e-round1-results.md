## 測定で裏付けた規則

資料と読んだ範囲は事前登録の「読んだ範囲と資料の規則」に従う。
新たな資料閲覧は行っていない。

- 6演算子（`=` `<>` `<` `>` `<=` `>=`）は、左右の文字列を先頭から符号なしバイトで比べ、
  最初に違う位置の大小で決まる。最後の1文字違い・最初の1文字違いとも前後入替で逆転
  （`lit-lastlt-*`・`lit-lastgt-*`・`lit-firstlt-*`・`lit-firstgt-*`）。
- 接頭辞は短い方が小さい（`lit-prel-*`・`lit-prer-*`、`var-ab-abc-*`）。
  長さ先比較ではない（`lit-firstlt-*`で "ab"<"ba"）。
- 空は最小、空どうしは等しい（`lit-ee-*`・`lit-ene-*`・`lit-nee-*`、`var-e-e-*`）。
- 128以上は0〜127より大きい（符号なし）。chr$(200)>"a"、chr$(128)>chr$(127)
  （`lit-hil-*`・`lit-hir-*`・`lit-h127-*`・`lit-h128-*`、`var-c200-a-*`）。
- chr$(0) は普通のバイトで、長さで比べる。"a"+chr$(0) は "a" より大きく、
  chr$(0) は空より大きい、chr$(0)<chr$(1)、途中の0の後の違いも効く
  （`lit-z-pre-*`・`lit-z-prer-*`・`lit-z-e-*`・`lit-z-z-*`・`lit-z-1-*`・`lit-z-mid-*`）。
- 大小文字は別のコード（"a">chr$(65)）（`lit-case-*`・`lit-caser-*`）。
- 結果は整数で、真は-1・偽は0。関数結果・連結との比較も同じ（`func-01`〜`func-17`）。
  `str$(5)=" 5"` は真、`"5"` とは偽（`func-12`・`func-13`）。
- IF の条件に使える。`a$=""`（未設定は真、"x"・chr$(0) は偽）、`a$<>""`、
  AND/OR/NOT 併用、関数結果、chr$(200)（`if-01`〜`if-16`）。
- 結果の整数が AND/OR/NOT/加算/単項マイナスへそのまま渡る。`("a"="a")+1` は0、
  `("a"="b")+1` は1、`-("a"="a")` は1、`not ("a"="a")` は0（`logic-01`〜`logic-10`）。
  括弧なしの `"a"="a" and 1=1` は-1、`"a"="b" or 1=1` は-1、`1=1 and "a"="b"` は0
  （`logic-11`〜`logic-13`）。比較は AND/OR より優先順位が高い。
  比較結果どうしの比較（`logic-14`〜`logic-16`）も予測どおり。
- 連結 `+` は比較より先に評価される（`"a"+"b"="ab"` が真、`"a"+"b"<"ab"` が偽。
  `func-08`〜`func-11`）。
- 型混在はすべて ERR 13。両順（文字列-数値、数値-文字列）、`=` `<` `<>`、
  空文字列と0、`"1"` と1、変数 `a$=1` を含む（`type-01`〜`type-10`）。

誤りはERR番号の観測。公式画面のメッセージ文言は測定・転記していない。

## 決めなかったこと

- 漢字（2バイト文字）の比較、比較の速度、INKEY$ そのもの。
- `"a"<"b"<"c"` のような比較の連鎖。
- type群以外の型混在（倍精度等）。
- 自作実装の状況: 事前登録の記載どおり、自作ROMはIFの文字列比較が
  Type mismatch になる既知の未実装があり、文字列比較は自作で測っていない。
  実装は別段で行う。
