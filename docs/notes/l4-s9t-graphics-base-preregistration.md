公式の保存観測（`tests/conformance/` の期待値・`../tmp` の生ログ・過去の結果ノートの個別数値）は、予測を書くためには使っていない。
使った既存知識は `docs/spec/` の記述（l1-ipl 第5c・5d節〔ポート 31・32・5C〜5F、`docs/notes/refs-vraminfo.md` が出典、判定「採用」〕、l4-program 5.4・5.6の COLOR/CONSOLE）と、
直前の段 `l4-s9q`〜`s9s` の結果ノート（COLOR の第2〜4引数の受理範囲・ポート 0x54 の2回書き込み）。

## 目的（任務の6項目）

1. **グラフィックVRAM**（ハードウェアの事実、CLAUDE.md の (a)）: プレーン数・1ラインのバイト数・ビットとドットの対応・色とプレーンの対応を、
   「こちらが描かせた点が VRAM のどこに立つか」で確定する。メインCPUからの見え方（ROM がどのポートで切り替えて書くか）も、ポート書き込み列として観測する。
2. **座標系**: 画面の大きさ、範囲外・極端な値・小数の座標、STEP（相対座標）、最終参照点（LP）の更新規則。
3. **PSET/PRESET/POINT**: 色引数の範囲・省略時の色・PRESET の色、POINT の返り値（カラー/白黒）、誤り番号。
4. **グラフィックの色**: COLOR の第2引数（背景）・第4引数（前景）が描画に効くか（s9q/s9r の観測とつなぐ）、白黒モードでの書き込み。
5. **消去**: `CLS n` の n ごとに、グラフィックだけ・テキストだけ・両方のどれが消えるか。LP の動き。
6. **表示の切替**: `SCREEN` 文の引数の受理範囲、表示 ON/OFF（画面スイッチ）の制御ポート。

## 読んだ資料（(a) 種別・言語仕様のみ）

- **N88-BASIC リファレンスマニュアル**（`refs/manual_squashed.txt`、NEC mkIIMR リファレンスマニュアルのテキスト。判定「可」、refs-nec-manuals-2026-09-04.md）。
  `grep` と行の切り出しで読んだ（ページ画像ではなくテキストの切り出し。**手順 2 の例外**で、これまでの段と同じ）。読んだ範囲（本文中のページ見出し `page_N`／印字ページ）:
  CLS（印字 2-27）、COLOR（印字 2-29・2-30。`page_92〜93`）、COLOR=（2-31 の冒頭）、POINT 文（`page_239`。参照先は印字 2-176）、POINT 関数（`page_240`〜`241`、印字 2-177〜2-178）、
  PRESET（`page_244`）、PSET（印字 2-191 の項）、SCREEN（`page_272`〜`274`、印字 2-209〜2-211）。
  切り出しの際に隣の項（POKE・POS・SEARCH・SET・SGN の言語仕様）が視界に入った。いずれも言語仕様の散文で、メモリマップ・ROM 内部の記述は無い。
  `PSET` の語を `grep` した際に、他の項（LINE・PUT@・ROLL 等）の実行例の行が一部表示された。言語仕様の例で、ROM 内部の記述は無い。
- マニュアルから採った事実（表現は写さず事実だけ）:
  - `PSET (Wx,Wy)[,色]` は色を省略すると COLOR 文の**フォアグラウンドカラー**（第4引数）で描き、実行後に LP は (Wx,Wy) へ移る。`STEP(x,y)` で LP からの相対指定。
  - `PRESET (Wx,Wy)[,色]` は通常色を省略し、COLOR 文の**バックグラウンドカラー**（第2引数）でドットを描く（消去）。色を指定したら PSET と同じ。実行後 LP は (Wx,Wy)。
  - `POINT (Wx,Wy)`（文）は LP だけを設定する。関数 `POINT(n)`（n=0〜3）は LP を、0・1 がワールド座標の X・Y、2・3 がスクリーン座標の X・Y で返す。
    関数 `POINT(Sx,Sy)` はスクリーン座標のドットの**パレット番号**（カラーモード）、白黒モードでは点があれば 1・なければ 0、ビューポートの外なら **−1** を返す。
  - `COLOR [機能][,バックグラウンド][,ボーダー][,フォアグラウンド]`。バックグラウンドはグラフィック画面の地の色で、カラーモードでは `CLS` が塗りつぶす色。
    フォアグラウンドはグラフィックを描くときのパレット番号（省略時に使われる）。ボーダーは意味を持たない。パレット番号は 0〜7（0黒・1青・2赤・3紫・4緑・5水色・6黄・7白）。
  - `CLS [n]`: 1（省略時）＝テキスト画面のスクロールウィンドウ内、2＝グラフィック画面のビューポート内（カラーモードでは背景色で塗る）、3＝両方。
    グラフィックをクリアしたら LP はビューポートの左上へ移る。
  - `SCREEN [画面モード][,画面スイッチ][,アクティブページ][,ディスプレイページ]`: 画面モード 0＝カラー（640×200）・1＝白黒（640×200、3ページ）・2＝専用ディスプレイ（640×400）。
    画面スイッチは 2 ビット（bit1＝グラフィックマスク〔描かれたパターンを一時的に消す〕・bit0＝高速書き込み）。アクティブページ 0〜2＝書き込むページ、ディスプレイページ 0〜7＝表示するページのビット指定
    （白黒3ページモードのみ有効）。SCREEN の実行で ウィンドウ・ビューポート・LP は初期状態（LP は (0,0)）へ戻る。白黒モードでは色指定は 0 か 0 以外かで黒/白を決める。
    N88-日本語BASIC の 3・4 は日本語モード。
  - マニュアルに**誤り番号・範囲外座標の扱いは書かれていない**（測定で決める）。
- **GW-BASIC の公開ソース**（`refs/GW-BASIC/GENGRP.ASM`）: 冒頭〜120行（ヘッダ・RAM 域の宣言・`SCAN1`/`SCAND`）だけ読んだ。座標は `(X,Y)` または `STEP(X,Y)`（グラフィックAC＝LP からの相対）、
  **座標を読み取った時点でグラフィックACが新しい値に更新される**（後続の色引数の誤りより前）。コードの転載はしない。`grep` で PSET の語を探したが当該ファイルに無く、他は開いていない。
- ハードウェア資料（ポート定義）は**新たに開いていない**。プレーン構成・ライン長・ビット順は、`docs/spec/l1-ipl.md` 第5c節（`5C`/`5D`/`5E`＝GVRAM0 青・1 赤・2 緑の選択、`5F`＝メインRAM）、
  第5d節（`31` の bit3 グラフィック表示・bit4 グラフィックカラー・bit0 640×200×3）と、PC-8801 の一般的な構造（200 ライン×80 バイト×3 プレーン）から予測する。
- ROM 内部の解析記事・ROM の逆アセンブルは開いていない。

## 器具

- **ハーネスの拡張**（本段で追加）: `retro_q88h_gvram`（コア側。メインCPUの C000〜FFFF に重なる 3 プレーンを 0x4000 バイトずつ書き出す）と `--gvram-dump PATH --gvram-dump-at FRAME`（フロント側）。
  テキストVRAM写し（`--vram-dump`）と同じ時点（`retro_run()` の直前）で採る。生バイトは作業置き場（リポジトリ外）に書き、器具が採取後に消す。コミットしない。
  故障注入の環境変数 `Q88MEASURE_FAULT_CORRUPT_GVRAM_DUMP`（写しの 1 バイトを化けさせる。自己検査用）。
- **測定器具** `tools/l4_gfx_measure.py`（s9r の型）。打ち込むのは自作のプログラムだけ。各プローブは `on error goto` で誤りを捕まえ（`resume next`）、
  `s9t<番号>:誤り,LP-X,LP-Y;`（描画・消去・screen のプローブ）か `s9t<番号>:誤り,値;`（POINT 関数のプローブ）を印字し、最後に終了の印 `s9tz` を印字して `goto` の自己ループに入る。
  採るのは次の数値・記号だけで、公式が出した文字・画面本文、公式が自分で描く図形は記録しない。
  - **グラフィックVRAM**: プレーンごとの統計（0 バイト数・0xFF バイト数・その他の数・最初と最後の非 0 オフセット）、非 0 バイトの数、オフセット 16000 以上の非 0 バイト数（tail）、
    非 0 バイトが 100 個以下のときだけ `[オフセット, 青, 赤, 緑]` の一覧（lit。起動直後の腕 `base-boot` は一覧を取らない）。
    **復号の仮説 H**: 1 ラインは 80 バイト、オフセット＝y×80＋x÷8、x%8==0 が bit7（左端）、プレーン 0＝青（色の bit0）・1＝赤（bit1）・2＝緑（bit2）。H は判定側（解析側）の道具で、生の lit も記録する。
  - **結果行**（テキストVRAM写しから）、印の `qqq`（cls の腕）の個数、終了の印の個数。
  - **制御ポート**: 0x30・0x31・0x32・0x34・0x35・0x53・0x54〜0x5F の OUT の値の初出順と最後の値。VRAM 切替系（0x34・0x35・0x5C〜0x5F）は連長圧縮列（先頭 60 件）と総数。制御ポートの値は記録してよい
    （s9o〜s9s と同じ判断）。**データポート（0x20 台以下・0xFx）は採らない**。
  - **画素**（`sw-*`・`map-a` だけ）: こちらが描いた点（位置 (400,150)）の画素 2 行と、6 画素右の参照画素。
- 各腕2走。2走が完全一致することが関門。

## 予測（外れてよい。強 s・中 m・弱 w。表に書いていない量は**予測なし**）

判定項目は器具が機械的に付ける（`prediction_judgement` に `agree:強さ`／`differ:強さ`）。強さの意味: s＝ハードウェアの構造や言語仕様に直接書かれている、m＝マニュアル・GW-BASIC の構造から読める、w＝推測。

### 1. グラフィックVRAM の構造（map・base・acc。lit の判定）

| 量 | 予測 | 強さ |

| 構造 H | 3 プレーン（青・赤・緑）、1 ライン 80 バイト（640 ドット）、200 ライン（16000 バイト）、y×80＋x÷8、左端が bit7 | s |
| 色 | パレット番号 c の点は、プレーン 0 に c の bit0、プレーン 1 に bit1、プレーン 2 に bit2 | s |
| 範囲 | どの点を描いても 16000〜16383 番のバイトは光らない（tail=0） | s |
| 上書き | 同じ点に別の色を `pset` すると 3 プレーンとも新しい色に置き換わる（`pset(..),7` のあとの `pset(..),2` は赤だけ）。色 0 は全プレーンを消す | s |
| `cls 3` のあと | 3 プレーンとも全て 0 | m |

## 関門

2走とも成功し、2走の観測が完全一致。
- **各腕**: 終了の印が 1 か所だけ見つかる（プログラムが最後まで走った）、結果行の数が印字プローブの数と一致、グラフィックVRAM写しが 0xC000 バイト。
- **較正**: `map-a` が各腕の関門を通り、光点が 1 つ以上あり、オフセット 16000 以上に非 0 バイトが無く、点 (400,150) の画素が参照画素と違う（グラフィックが画面に出ている）。かつ `base-cls3` が関門を通る。
  これが崩れたら全腕を関門落ち。
- 関門が落ちたら、**器具を曲げず追補の事前登録を先にコミット**してから再測定する。
- 自作ROMでの対照（selftest）: 合成のグラフィックVRAM・結果行・I/O記録での解析と判定の陽性・陰性、手計算のモデル、較正の陰性、2走不一致の関門落ち、
  自作ROMで 2 腕が走ること、ハーネスの故障注入（写しの 1 バイトを化けさせると lit に現れる）。

## 決めないこと

画面本文、公式が出した文字・公式が自分で描く図形、ROM内部の構造、アナログパレット（`COLOR=`）、LINE・CIRCLE・PAINT・GET/PUT・VIEW・WINDOW、400 ラインモード（`screen 2`/`4` は誤り番号の記録だけ）、
ブリンク、白黒3ページの表示ページ（ディスプレイページ引数）の効果、`console` との相互作用、高速書き込みスイッチの効果。
