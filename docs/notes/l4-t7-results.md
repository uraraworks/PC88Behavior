# l4-t7 AUTO・RENUM — 公式測定の結果

2026-11-07。事前登録 `l4-t7-auto-renum-preregistration.md`（追補1まで）の器具を、クラウドの測定環境で
公式ROMに対して走らせた。20腕すべて独立2走一致・関門通過。記録は `measurements/l4-t7/official.json`。

元のプログラムは行 5,7,12,30,31,40,50 の7行（旧番号）。各行は自分の印を立て、
GOTO 7 / GOSUB 40 / IF 1 THEN 30 / ON 1 GOTO 31 / RESTORE 40:RUN 50 / RETURN:DATA / END の参照を持つ。

## RENUM

| 腕 | 打鍵 | 新しい番号（旧の順に） | 誤り |
|---|---|---|---|
| default | `renum` | 10,20,30,40,50,60,70 | なし |
| start | `renum 100` | 100〜160 の10刻み | なし |
| start-old | `renum 100,12` | 5,7 はそのまま、12以降を 100〜140 | なし |
| between | `renum 100,8,10` | 5,7 はそのまま、8より後の最初の行（12）から 100〜140 | なし |
| step | `renum 100,12,5` | 5,7 はそのまま、12以降を 100〜120 の5刻み | なし |
| omitted | `renum ,,20` | 10〜130 の20刻み | なし |
| overflow | `renum 65525,5,10` | 変わらない | 5 |
| zero | `renum 100,5,0` | 変わらない | 5 |
| empty | プログラム無しで `renum` | — | なし |
| program | 行90 `on error goto 95:renum:end` を実行 | 10刻みで振り直される（旧の行は新しい番号で残る） | なし |
| undefined | 旧5行目の参照を `goto 999` にして `renum` | 10〜70 | 下記 |

- どの腕でも、振り直した後の RUN で通る印の順は振り直す前と同じ（GOTO・GOSUB・THEN・ON GOTO・RESTORE・RUN の行番号参照が書き換わっている）。
- undefined 腕: 振り直しは行われ、表示が1行出る。その行は、作者が候補として用意した文字列 `Undefined line 999 in 5` の行署名と一致した（行番号は**振り直す前**の番号、999 はそのまま残る。振り直した後の RUN は旧5行目＝新10行目の `goto 999` で止まる）。
- 誤り 5 のときは1行も変わらない。

## AUTO

| 腕 | 打鍵 | 入った行 |
|---|---|---|
| default | `auto` | 10,20,30 |
| start | `auto 100` | 100,110,120 |
| step | `auto 100,5` | 100,105,110 |
| omitted | `auto ,20` | 10,30,50 には入っていない（開始番号は未確定） |
| collision | 行10がある状態で `auto` | 10,20,30（10は打ち直した内容に置き換わる） |

- 番号の表示: `auto` の次の行に行番号が出て、その後ろに本文を打つ。作者の候補 `10` の行署名と一致した（番号の後の空白は署名の正規化で落ちるため、空白の有無は確定しない）。
- 既にある行の番号が来たときは、候補 `10*` の行署名と一致した（番号の直後に `*`）。
- STOP キーで止まり、直接モードに戻る（止めた後に打った直接文が動いた）。
- `auto ,20` の開始番号は追加測定が要る（0・20 などを候補に goto で確かめる）。
