# B70: ドライブ 2 を読む `0x0E` を、公式と自作で比べる — 結果

記録日: 2026-11-02
規則: [b70-sub-request-0e-drive2-preregistration.md](b70-sub-request-0e-drive2-preregistration.md) どおり。公式どうし・自作どうしは一致した。G1 は使っていない。記録は `measurements/b70-sub-request-0e-drive2.txt`。

## 結果

5 行とも、FDC のコマンドと引数、読み先の番地と刻印は公式と自作で同じだった。

- D=1 はドライブ 2 を読む（`sense_drive_status(1)`、`read_data(1,...)`）
- ドライブ 2 へ `0x17` を送らないと、T=2 は C=2・H=0 として読まれる（行 3）。1.36a 節の `0x02` の規則と同じである
- ドライブ 2 が空なら FDC への出力は無い（行 4）

違いは、自作だけが `7B00`〜`7D08` を書くこと（自作のサブ ROM の作業域）である。`7F` 台の小さな変化は両方にある。

## 読み方（推定）

`0x0E` の読み方そのものは公式と同じである。B69 で自作が止まるのは、**G1 の `0x0E` の読み先が自作の作業域（`7B00`〜`7D0B`）に重なり、自作の作業域を壊している**ためではないかと考える。公式はこの範囲を使わない（B38 で「未書き込み」）。

B71 で、G1 の F1 の道の `0x0E` が書く番地の範囲を、B51 の器具で値を出さずに測る。
