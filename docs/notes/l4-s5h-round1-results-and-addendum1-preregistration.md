## 追補1（**事後**の候補 M_B と追加87腕。測定の前に登録する）

初回の食い違いを見たあとに立てる候補なので、事後の規則である。当たるかどうかは、初回で見ていない新しい
腕で確かめる。

### M_B

M_A に次を足す。実装は `tools/l4_listkw_measure.py` の `predict_body_b`。

1. 本文は先に小文字にする（打鍵は小文字で届く）。
2. 文頭には、`:` の直後に加えて THEN／ELSE の直後も数える（THEN／ELSE の直前が英数字でないとき）。
3. REM／DATA は、直後が英字でないときだけ語として認める（`remabc` `datax` は名前）。
4. 文頭の `?` は `PRINT` に展開し、直後が英数字のときだけ空白を1個入れる。
5. `go` + 1個以上の空白 + `to` は `GOTO`、`go` + 空白 + `sub` は `GOSUB` に詰める。
6. 数値定数は予測しない（大文字化のみ）。食い違いは記録される。

M_B は初回600腕のうち M_A が外した腕のうち、数値定数の2腕（c38・c39）を除く全部を再現する（選び方が事後）。
