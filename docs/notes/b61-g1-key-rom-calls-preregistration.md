# B61: キーを打った前後に、公式の G1 が main の ROM のどこを使うかを測る — 事前登録

記録日: 2026-11-02
位置づけ: [B60](b60-g1-single-keys-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

公式の G1 が使う main の ROM の 8 か所（B1 の記録 A）は、キーを打った前後でそれぞれ何回使われるか。キーで回数が変わる飛び先はどれか。

## 2. 条件

公式のみ、2 走。フレーム 3600 でスペース、7200 で腕のキー、14400 フレームまで。腕は `2`、`i`、F1、ESC と、キーなしの対照。クラウドの実行環境で行う。

## 3. 器具

`--boundary-log` に加えて、記録 A の各飛び先へ移った回数をフレームの区間ごとに数えるツールを足す。区間は 0〜3599、3600〜7199、7200〜7799、7800〜14399。値は持たない。

## 4. 記録の白リスト

`calls <腕> <飛び先> <区間> <回数>`、`total <腕> <区間> <回数>`。**値は出さない。** 飛び先は B1 で記録済みの 8 か所だけで、ほかの番地は `other` にまとめる。

## 5. 判定（事前に決める）

- 7200〜7799 の区間で、対照より回数が増える飛び先を、キーを読む働きの候補として書く
- 候補が出たら、その働きを自作のプローブと自作の媒体で測る事前登録を書く。G1 の値は使わない
- 候補が出なければ、ROM 以外の経路（割り込み、ポートの初期設定）を次に測る
