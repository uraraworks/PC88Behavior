# B41: G1 でサブが `7812` へ移るときの移り方を値なしで測る — 結果

記録日: 2026-11-01
規則: [b41-g1-sub-cross-origin-preregistration.md](b41-g1-sub-cross-origin-preregistration.md) どおり。測定はクラウドの実行環境で OO・SS 各 2 走。関門 8 項目はすべて通った。値は記録していない。記録は `measurements/b41-g1-sub-cross-origin.txt`。

## 結果

- 公式も自作も、すべての移りは同じ 1 か所の発行元からで、SP の差は 0 である。`7812` だけ別の道を通っているのではない
- 自作の `DE` はすべて 0 である
- 公式の `DE` は、大きなデータのやり取りのあとの `7812`（番号 5、8、11、14、17、21、24、27、32 など）で 0 でない。`7812` でも、やり取りのない番号 28、30、33 では 0 である
- `DE` は `HL` とも `BC` とも一致しない

## 読み方（推定）

- 公式の `0x0D` の経路は 1 つで、`DE` はそれまでの経過で変わる。待ちの回数のような値かもしれない
- B40 の fc は、番号 0〜27 で公式が 4 多い。公式は RAM へ移るのが自作より遅く、**RAM 上のコードと main の位相が違う**可能性がある
- B38 の `BC`・`HL` の違いと、RAM の内容に関わる違いが見当たらないこととも合う。値の違いがタイミングで出ているかは、次の B42 で介入して確かめる
