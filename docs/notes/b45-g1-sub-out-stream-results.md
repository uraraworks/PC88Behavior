# B45: スペース後の G1 で、サブが main へ出す列の違いと、違う部分の出どころを値なしで測る — 結果

記録日: 2026-11-01
規則: [b45-g1-sub-out-stream-preregistration.md](b45-g1-sub-out-stream-preregistration.md) どおり。測定はクラウドの実行環境で OO・SS 各 2 走。ドライバのビルドの指定の誤りで 2 回止まり、直して 3 回目に走った。関門 5 項目はすべて通った。値は記録していない。記録は `measurements/b45-g1-sub-out-stream.txt`。

## 結果

- `OUT` の列の最初の違いは `$FB` の番号 1 で、両方とも ROM 側である。`$FD` は番号 0 から違う。ROM ごとに起動のやり取りが違うので、この番号どうしの比較は RAM 上のコードの分かれ目を示さない
- `IN $FC` の 76570 から 132 件は、公式・自作のどちらも、自分の列の前の部分にも、相手の列にも現れない

## 読み方（推定）

別の場所を送り直しているのではない。公式と自作で、この 132 バイトは別の中身として作られている。RAM 上のコードの計算か読みのどこかで分かれているはずである。B46 で RAM 上のコードだけの出来事の列を比べる。
