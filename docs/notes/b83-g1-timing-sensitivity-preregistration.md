# B83: B82 の散らばった違いは、公式どうしでもわずかな時刻のずれで出る型か — 事前登録

記録日: 2026-11-05
位置づけ: [B82](b82-g1-long-run-divergence-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

B82 で I1・S1・F1 に、1〜3 点だけ公式と違ってすぐ戻る点が散らばった。自作は `IN $FC` が公式より 4 少ない（B48 の位相）。
この散らばりは、G1 の画面がわずかな時刻のずれで変わる性質から来るものか、自作だけに出るものか。

## 2. 対照

公式 ROM のまま、打鍵の時刻をすべて 1 フレーム遅らせた走（OO-K1）を、ずらさない公式の走（OO-1）と比べる。
これは B48 の位相と同じものではない。「わずかな時刻の違いに、画面のハッシュがどれだけ敏感か」を、公式だけで測る物差しとして使う。
同じ条件で自作の走（SS-1）も OO-1 と比べ、B82 を再現できるかも見る。

## 3. 条件

- 腕は I1・S1・F1。打鍵の並びと長さ（108000 フレーム）、画面ハッシュの間隔（600）は B82 と同じ
- 各腕で OO-1、OO-K1、SS-1 の 3 走。クラウドの実行環境で行う

## 4. 判定（事前に決める）

- SS-1 と OO-1 の違う点が B82 と同じフレームに出なければ、器具か走の揺れを疑って先へ進まない
- OO-K1 にも、短く（3 点以下）違ってすぐ戻る点が散らばり、終わりの画像が同じなら、「公式どうしでも時刻のわずかなずれで同じ型の違いが出る」と書き、B82 の散らばりは追わない
- OO-K1 が 180 点すべて一致すれば、散らばりは自作に特有と書き、次の段で S1 の最初の点（13200）の前後を詳しく見る
- OO-K1 が分かれたまま戻らなければ（4 点以上続く、または終わりの画像が違う）、この物差しは強すぎると書き、結論を出さない
