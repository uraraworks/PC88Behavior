# m7jh: セクタ番号の起点をずらして「読めないまま」Nを振る — 事前登録

## 位置づけ

[m7jg](m7jg-double-sided-reach-results.md)で初めて**介入が対象に届いた**状態の
測定ができ、主判定はAB2（9のまま）だった。ただし**情報を持つ点は1つ（N=4）
だけ**で、H1派生を強く反証したとは言えない。原因は設計側にある——
**Nを大きくすると読めてしまい、土俵が消える**ため、土俵が成立する水準が
N=4とN=8の2つしか無かった。

本稿は`m7jg`の「次に何を測れば絞れるか」の1番目を実行する。
**セクタ番号の起点をずらし、Nを大きくしても土俵が消えない条件を作る。**

## m7jgの開示への対応（判定の到達可能性を先に確かめる）

`m7jg`は「AB1が構造上到達できない設計だった」ことに測定後に気づいた。
本稿は**段階1で、判定が到達可能かを先に確かめる**。段階1で土俵が成立した
水準が1つ以下なら、主判定を**O'''（判定が到達不能）**として打ち切る。
**当たるまで条件を変えて続けない。**

## 座標の確認（m7jfの表を引き継ぐ）

| 座標 | 本稿の扱い |
|---|---|
| ユニット（ドライブ） | B:固定。到達指標R'に含める |
| シリンダ（C） | `--cylinders 40`固定。R'に含める |
| ヘッド（H） | `--heads 2`（両面）固定。R'に含める |
| **セクタ（R）** | **本稿で振る軸の相手役。起点をずらして「見つからない」を保つ** |
| サイズ（N） | 256バイト固定。振らない |

到達指標R'の定義は`m7jf`のまま変えない。

> **到達指標R'**: 入口区間（`frame >= 700`）の`READ DATA`のうち、
> **(ユニット, シリンダ, ヘッド)の組に対応するトラックが自作ディスク上に
> 存在するもの**の件数。**値は出さず件数だけを見る。**

## 道具の拡張（`tools/`のみ。`src/`は触らない）

`tools/make_l3_testdisk.py`に**セクタ番号の起点を指定する引数**
（`--sector-base`）を足す。1トラックのセクタ番号を
`base, base+1, …, base+N-1` とする。

- **既定は現行どおり`base = 1`とし、引数を与えない生成物は拡張前と
  バイト一致すること**（`conform_l3.sh`の`unreadable_disk`が引数なしで
  呼んでいる）。**合格条件に入れる。**
- `--cylinders`・`--sectors-per-track`・`--heads`と**組み合わせて**使えること。
- `base + N - 1 > 255` は**明示的にエラーで落ちる**こと（1バイトに収まらない）。
- 公式媒体を入力しない性質を変えないこと。

## 起点の値を測定前に固定する（1つだけ。当たるまで動かさない）

**起点 B0 = 200 に固定する。**

選んだ理由は次の2つだけである。**公式ディスクのセクタ番号を推定した結果では
ない。**

1. `1`始まりの連番では、Nを増やすと**同じ番号集合が伸びていく**ため、
   どこかで読めてしまう。**起点を大きくずらせば、Nを増やしても
   小さい番号は一切現れない。**
2. `base + N - 1 ≤ 255` を満たす必要があり、最大の水準 N=26 でも
   `225` で収まる。

**B0を変えて再試行しない。** 段階1が通らなければ打ち切る（上記）。

## 段階0（本稿）: 事前登録を測定前にコミットする

本稿は測定を1回も走らせる前に単独でコミットする。測定後の書き換え・amendは
行わない。道具の拡張も本コミット後に行う。

## 測定条件（`m7jf`と同一）

- 条件Oのみ。A: は`disk#8`（`650cfac8`。`stage_disk_by_digest.sh`経由）に固定。
- B: は各水準の自作D88（両面・`--cylinders 40`・`--sector-base 200`）。
- 打鍵は水準E。摂動は当てない。窓は`frame >= 700`。

## 段階1: 判定が到達可能かを先に確かめる

**セクタ数 N ∈ {4, 8, 16, 26}** の4水準を、`--sector-base 200`で**1回ずつ**測り、
各水準について次の2つだけを見る。

- **R' > 0**（3座標すべて）
- **土俵が成立したか**（エラー真が1件以上あり、かつ長さ2以上のrunが現れる）

**中止規則**:

- いずれかの水準で **R' = 0** → 主判定 **O**。その水準でどの座標が外れて
  いるかを件数と真偽だけ記録する。
- 土俵が成立した水準が **0個** → 主判定 **AC4**（起点をずらしても読めてしまった）。
- 土俵が成立した水準が **1個** → 主判定 **O'''（判定が到達不能）**。
  **B0を変えて測り直さない。**
- 土俵が成立した水準が **2個以上** → 段階2へ進む。

## 段階2: run長を読む（段階1が2個以上で成立した場合のみ）

段階1と同じ4水準について記録する（すべて値を出さない）。

- **到達指標R'**——水準ごとに確認する
- FDCコマンド総数、`READ DATA`総数
- `READ DATA`のrun長の並びと多重集合
- エラー真の件数と、**エラーの公開ビット復号名の内訳**
- SEEK件数、相異なるSEEK目的シリンダの個数（基数のみ）

## 陽性対照（器材が`m7jg`と同じであることの確認）

**`--sector-base`を与えない N=8・両面・シリンダ40**を1水準として同時に測り、
`m7jg`の対応する水準と**すべての指標が一致すること**を確かめる
（FDC 144・READ 108・エラー真 108・SEEK 12・run長`{9:12}`・種別`NO DATA`）。
一致しなければ器材が変わっているので、**主判定をOとする。**

## 事前登録する判定（測定前に固定。後から動かさない）

**土俵が成立した水準**＝エラー真が1件以上あり、かつ長さ2以上のrunが現れる水準。

- **AC1（追随する）**: 土俵が成立した水準のうち、**`N=8`以外の2つ以上で
  run長がその水準の`N`と一致する。**
- **AC1a（1点だけ追随）**: 同じくちょうど1つ。
- **AC2（9のまま）**: 土俵が成立した全水準でrun長9が現れ、**`N`と一致する水準が
  1つも無い。**
- **AC3（別の値）**: run長が`N`とも9とも違う長さ2以上のrunになる水準がある。
- **AC4（土俵が消えた）**: 土俵が成立した水準が0個。
- **O'''（判定が到達不能）**: 土俵が成立した水準が1個。
- **O（測定不能）**: 既定生成物が拡張前とバイト一致しない、生成が再現しない、
  決定論性が確認できない、陽性対照が`m7jg`と一致しない、**いずれかの水準で
  `R' = 0`**。

**どの判定になるかは予測しない。**

## セクタ番号を推定しないこと（事前に縛る）

- 各水準について記録するのは**「土俵が成立したか」の真偽**までとする。
- **「起点200では読めず、起点1のN=16では読めた」から、FDCが要求する
  セクタ番号（R）の範囲を絞る記述をしない。**
- これは禁止事項5（データポートの値を推論で復元しない）の適用である。

## 事前登録する合格条件（測定前に固定）

1. `tools/recv_run_field_leak_selftest.sh`が全項目OK・rc=0。
2. `tools/analyze_error_exchange_shape_selftest.sh`がrc=0。
3. **既定の非回帰（最重要）**: `--sector-base`を与えない生成物が拡張前と
   **SHA-256・バイト単位とも一致**。引数なし・`--heads 2 --cylinders 40`・
   `--sectors-per-track 26`の3通りで確認する。
4. **到達の確認**: **全水準で`R' > 0`**。
5. **生成の再現性**: 各水準で2回生成しSHA-256が一致すること。
6. **決定論性**: 各水準で生ログが独立2回でバイト一致すること。
7. **元ディスクを壊さない**: `disk#8`の原本ダイジェストが不変であること。
8. **実行した水準数を出力に載せ、期待値（4水準＋陽性対照1）と一致すること。**
9. `tools/check_cleanroom.sh`が全項目OK。
10. **陽性対照が`m7jg`と全指標一致**（上記）。

## 言えないこととして先に書いておくこと

- **AC2が出ても「9は内部固定カウンタである」と断定はしない。**
- **AC1が出ても「9は公式ディスクのセクタ数である」とは言えない。**
- **AC4は失敗ではない。** 「起点をずらしても読めてしまう」という事実であり、
  何が読めるかを決めているのはセクタ番号ではない、という手がかりになる。
- **セクタ番号を推定しない**（上記）。
- 自作ディスクは公式と形が違う。形の違いが効く可能性を排除していない。
- 条件O・水準E・A:=`disk#8`固定という1つの使い方しか見ていない。

## 委譲する場合の指示に必ず含めること

- 値・バイト列を報告に書かない。
- **公式ROM/ディスクの実ファイル名・実パスを書かない**
  （`tools/stage_disk_by_digest.sh`を使う）。
- 画面本文を出力・転記しない。
- **既定の振る舞いを変えないこと**を理由込みで明示する。
- **起点B0を変えて測り直さないこと。**

## 禁止（本稿の測定中も例外なく適用）

- 公式ROMのバイト列を読まない・出力しない・保存しない。逆アセンブルしない。
- **公式ディスクのイメージを直接読まない。** **自作ディスクの構造は読んでよい。**
- FDCデータポート値、**シリンダ値・セクタ番号**、PCN値、受信run・応答runの
  バイト値を出力しない。**到達指標R'は件数であって値ではない。**
- **読めた／読めなかったの境目からセクタ番号を推定しない。**
- 画面本文の生の行を報告・ノート・コミットメッセージ・ツール出力へ書かない。
- **公式ディスクの実ファイル名を展開して表示しない。**
- **トレースバックを集計ファイルへ流さない**（`m7iw`の事故）。
- 第三者の逆アセンブルリスト・解析記事のコード断片を参照しない。
