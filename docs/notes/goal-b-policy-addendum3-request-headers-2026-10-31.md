# ゴール B 方針 追補3 — G1 の要求の見出しだけを記録する

記録日: 2026-10-31
位置づけ: [goal-b-policy-2026-10-24.md](goal-b-policy-2026-10-24.md) の後続。方針ノート本体は書き換えない。
このノートより前に、ゲームの要求の値を記録した測定はない。

## 1. 経緯と決定

[B13](b13-g1-sub-fdc-results.md) で、公式の上の G1 はサブの RAM 上のコードでディスクを読むと分かった。自作サブで動かすには、コードをサブへ送って走らせる要求が要る。
どの要求かは G1 の振る舞いにしか無い。2026-10-31 に利用者と、次の線まで記録してよいと決めた。

**記録してよいもの: G1 が main からサブへ送る要求の、先頭バイトと長さ。**

これは方針ノート第2節の「ゲームは『どこを』」の範囲である。ゲームから採るのは需要で、働きは今までどおり自作のプローブで測る。

## 2. 変えないこと

- **送られるコードやデータの本体は記録しない。読まない。** 先頭バイトより後の値はすべて捨てる
- サブの RAM の内容を読まない。ゲームのコードを逆アセンブルしない
- 働きの根拠にしない。先頭バイトと長さから「こういう要求らしい」と推定しても、仕様書には自作のプローブで測ったものだけを書く
- 方針ノート第4節のその他の「記録しないもの」はそのまま
