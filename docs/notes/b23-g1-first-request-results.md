# B23: G1 の最初の要求の連続の中身を記録する — 結果

記録日: 2026-11-01
規則: [b23-g1-first-request-preregistration.md](b23-g1-first-request-preregistration.md) どおり。測定はクラウドの実行環境（SS は 008d75f のビルドの生ログを再利用）。記録: `measurements/b23-g1-first-request-*`。

## 結果

```
OO: 02 0F 00 00 02 15 50 00 0F 00
SS: 02 0F 00 00 02 15 50 00 0F 00
```

両者は一致する。

## 読み方（推定。B24 で確かめる）

- 前半 `02 0F 00 00 02` は読み要求（P1=15、T=0、R=2）で、B10 の形そのもの
- 後半 `15 50 00 0F 00` は別の要求に見える。`0x0C` と同じ形なら、番地 `0x5000` から長さ `0x0F00` = 3840 バイトを main へ渡す要求である。読みのバッファが `0x5000` であること（B15・B17）と、受け取りの 3840 バイトに合う
- 違う 2 バイトは、この 3840 バイトの直後である
