# l4-s1b — 事前登録の追補（測定前）

記録日: 2026-09-15
状態: 事前登録の追補、測定前

本体 [l4-s1b-key-matrix-preregistration](l4-s1b-key-matrix-preregistration.md)（`a8f7b05`）は書き換えず、Q2 の腕の範囲だけを改める。問い・関門・判定の名前は変えない。この追補が本体に優先する。

## Q2 の腕の範囲

本体は Q2（修飾を重ねたときの文字コードの変化）の腕を「修飾5種×英字26種＝130腕」としている。これでは、キーから文字を組み立てる対応の大部分が測られない。

- SHIFT を重ねると、数字キーや記号キーからも別の文字（記号）が出る
- カナを有効にすると、英字キーだけでなく数字キー・記号キーにもカナが割り当てられている
- GRPH も、英字以外のキーに図形文字が割り当てられている

改めた Q2 の腕は次の規則で作る。

- Q1 の測定を先に行い、判定が `writes_code(xx)` となったキーの集合 K を得る
- Q2 の腕は、修飾5種（SHIFT・カナ・GRPH・CTRL・CAPS）それぞれと K の各キーの組とする。腕の数は 5×|K| で、Q1 の結果によって決まる
- K は Q1 の結果ノートの表から機械的に作り、手で選ばない。K を作るスクリプトと、そこから作った腕の一覧（ポート・ビット・修飾）は Q2 の測定の前にコミットする
- Q1 で `no_write` となったキーは Q2 の対象にしない。修飾を重ねたときにだけ文字を書くキーがありうることは、この範囲では測らない（言えないこととして結果ノートに書く）
- 修飾の押し方（同時押しか、切り替えてから押すか）と押すフレーム・保持は本体と、本体が定める予備走の結果に従う
