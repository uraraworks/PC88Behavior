# m7s: READ DATAパラメータの生成規則

測定日: 2026-08-13

## 情報境界

公式ROM・公式ディスクのバイト列は表示・保存せず、共通クロック付きI/Oログを
比較器のメモリ内だけで扱った。出力したのは位置、同値件数、同値グループ数、
構造的一致長だけである。生ログと介入ROMはリポジトリ外に置いた。

## 位置対応

120フレーム中のREAD DATA 9件について、コマンドを除くパラメータ8位置を、
直前要求、SEEK対象、SENSE INTERRUPT STATUS結果、SENSE DRIVE STATUS引数と比較した。
直前要求の各位置から全9件一致する組は0件だった。直前SEEK対象とSENSE INTERRUPT
STATUSのPCN位置は、ともにREAD DATAパラメータ位置1へ9/9一致した。パラメータ位置
4〜7は各位置とも9件で不変だった。交換#3の最初のREADでは要求7位置との同値組が
複数残り、単独の同値比較だけでは座標を一意化できなかった。

## 規則介入

公開FDC仕様に沿い、交換#3について次の規則を一組として介入した。

- 要求位置4をSEEK対象へ転記し、その同じ対象をREAD DATAのC位置へ引き継ぐ。
- 要求位置6をREAD DATAのR位置とEOT位置へ転記する。
- unit/head、H、N、GPL、DTLは既存のFDC仕様由来の既定規則を維持する。

この介入でREAD DATAは結果7件だけで終わらずデータ部へ入り、sub側構造的一致
プレフィックスは255件から752件へ伸びた。交換#4の256バイト送信にも到達し、
FDCから読んだバッファをそのまま送った。値の候補探索は行っていない。

## 4指標

- sub側構造的一致プレフィックス: 255件 → 752件
- main側構造的一致プレフィックス: 258件 → 258件
- main側`IN $FC`値一致プレフィックス: 4件 → 4件
- 混成main `IN $FD`: 0件 → 0件

次のsub側分岐は753件目であり、本サイクルでは未診断とする。期待値・比較条件は
変更していない。
