# B45: スペース後の G1 で、サブが main へ出す列の違いと、違う部分の出どころを値なしで測る — 事前登録

記録日: 2026-11-01
位置づけ: [B44](b44-g1-entry-flags-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

1. サブの `OUT` の列は、どのポートの何番目で初めて公式と違うか。発行元は ROM 側か RAM 側か
2. main が読む `IN $FC` の違う部分（番号 76570 から 132 件）は、同じ走の列の別の位置と同じか。つまり、同じデータの別の場所を送っているのか

## 2. 器具

コアは変えない。`--io-log` の生の記録から、値を出さずに比べるツールを足す。

- `port OUT <4桁16進> compared=<N> differ=<N> first=<N|none> left=<N> right=<N>`（サブの `OUT` のポートごと）
- `first-out-difference: none|<4桁16進> <N> <hi|lo> <hi|lo> <左の発行元 PC が hi なら4桁16進、lo なら lo> <右の同じもの>`（発行元の別。ROM 側の番地は出さない）
- `block <左|右> self-match <N|none>`（その腕の `IN $FC` の 76570 から 132 件が、同じ腕の列の 76570 より前で最初に現れる位置）
- `block <左|右> other-match <N|none>`（その腕の 76570 から 132 件が、もう片方の腕の列全体で最初に現れる位置）

器具は G1 なしで自己検査する。陽性対照は OUT の違いの番号と発行元の別、ずらした列の位置の検出。陰性対照は同じ列で `none`、値が出力へ出ないこと。

## 3. 条件

腕 F の 4800 フレーム。OO・SS 各 2 走。自作 ROM は 62254d3 の配布ビルド。クラウドの実行環境で行う。

関門: `IN $FC` の差が B44 と同じ（257 件、最初 76570、連続 132）。OO どうし・SS どうしの出力が同じ。

## 4. 記録の白リスト

第 2 節の行だけ。

## 5. 判定（事前に決める）

- `first-out-difference` の発行元を書く。RAM 側なら RAM 上のコードの出力の番地を書く
- `other-match` が見つかれば、同じデータの別の場所を送っているとして、位置の差を書く
- どれも `none` なら、列の別の場所には無いと書く
- 原因は断定しない
