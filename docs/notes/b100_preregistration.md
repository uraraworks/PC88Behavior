# B100 事前登録：起動中に媒体が抜けたとき、公式はいつ再試行を打ち切るか

記録日: 2026-11-17。[実走確認](v-2d122aa-results.md) で、G5 を F3600 でリセットして R+5／R+60 で媒体を抜くと、公式も SENSE DRIVE STATUS を約120万回出すが R+960／R+1057 で止まり、自作は R+1800 まで出し続けた。公式の打ち切りの条件（時間か回数か、どの応答で止めるか）と、止めた後の行き先を測る。値・画面本文は出さない。

## 腕

公式・自作（その時点の main）の両方。G5 を2枚入れて F3600 でリセットし、次のフレームで媒体を抜く。リセット後 3600 フレーム。

| 腕 | 抜くフレーム | 抜くドライブ |
|---|---|---|
| E-5 | R+5 | 両方 |
| E-60 | R+60 | 両方 |
| E-200 | R+200 | 両方 |
| E-600 | R+600 | 両方 |
| E-5-D1 | R+5 | ドライブ1だけ |
| E-5-D2 | R+5 | ドライブ2だけ |
| E-NONE | 抜かない | — |
| E-EMPTY | リセット前から両方空（G5 を動かした後に抜き、それからリセット） | — |

## 記録すること

- FDC コマンドの種別ごとの件数と、各種別の最後のフレーム。SENSE DRIVE STATUS の最初と最後のフレーム、回数、どのドライブ（US）を指したかの件数。
- sub と main の PIO のやり取り（ポート・方向・件数だけ）がいつ再開・終了したか。
- main が BASIC の入力待ちに着いたか（`tools/check_l3_entry_screen.py`）と、そのフレーム。
- 打ち切りの時刻が「抜いたフレームから一定」か「リセットから一定」か「回数で一定」かを、E-5/E-60/E-200/E-600 の比較で判定する。

## 判定

打ち切りの規則（時刻・回数・ドライブの扱い）と、打ち切った後の行き先（BASIC へ行くか）が分かれば、自作の sub の起動処理に同じ打ち切りを入れる（l3-boot-sector / l3-subrom の仕様に追記してから）。規則が一つに決まらなければ、自作は「公式の最短の打ち切りより短くならない一定時間」で止める案を本人と相談する。
