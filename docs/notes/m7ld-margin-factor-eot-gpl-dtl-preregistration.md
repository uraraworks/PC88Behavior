# m7ld: 余白を作る——EOT・GPL・DTLの送出列を集約する（純粋なコード移動） — 事前登録

## 位置づけ

[m7lc](m7lc-generator-window-gate-fixed.md)で生成器の窓の関門を直し、**既定ビルドの余白9バイトが
実装を足せる上限としてビルド時に見えるようになった。** `m7kr`の再試行（+11バイト）は、
今の生成器ならビルドの時点で止まる。**先に余白を作る。**

**窓（`0x0800`）は動かせない**——計測ハーネス（と実機のサブシステム）はサブROMの先頭2KBしか
読まない。**だから既存のコードを縮める。** 前例は`abf6d02`（m7fu・m7fv）で、
「一字一句同一の命令列をサブルーチンへ集約する。命令列は1バイトも変えない」だった。

## 何をするか

**WRITE DATA・単発READ DATA・バルクREAD DATAの3ルーチンは、FDCへ送るパラメータ枠の末尾が
一字一句同じである。**

```
call FDC_OUT            ; EOT（Aの値は3ルーチンで違う。ここより前で決まる）
ld   a,0x0E / call FDC_OUT   ; GPL = N=1短GAP
ld   a,0xFF / call FDC_OUT   ; DTL
```

これを`FDC_OUT_EOT_GPL_DTL`（入口でA=EOT）へ集約し、末尾は`jp FDC_OUT`で抜ける
（`ret`が要らない）。**3箇所の13バイトが、それぞれ`call`3バイトになる。**

**試しの書き換えで測った**（測定前。自作コードの大きさだけ）: **全長2039→2022（17バイト減）、
関門を通過、窓までの余白26バイト。**

**レジスタと状態の確認**: 集約した列は元と同じ命令である。`FDC_OUT`はAF・DEを保存して戻るので、
共有列から戻った時点のA・フラグ・DE・HL・Bは、元の列を実行し終えた時点と同じになる。
違うのは**共有列の実行中にスタックが1段深い**ことだけである（`abf6d02`と同じ。STACKの空きは約3KB）。
**`FDC_ABORT`の立ち方も変わらない**（同じ`FDC_OUT`を同じ順に呼ぶ）。

**変わりうるのは実行サイクルだけ**である（`call`が1回増える）。`m7kz`のR2で、実行経路へ
NOPを9バイト足しても判定行445行がBASEと一致したので、影響しない見込みだが、**見込みは
合格条件にしない。測る。**

## 事前登録する合格条件（**測定前に固定する。1つでも偽なら採用しない**）

1. **判定行の全集合が、同じ実行群のBASEと一致し、総合判定は適合。**
   （色コードを落として、行頭が`OK`・`NG`・`--`の行を比べる。m7lbと同じ指標。）
2. **データを運ぶポートのイベント列が、全iologでBASEと一致する。**
   対象は**main IN `$FD`・`$FC`**（適合条件の中核）と**sub OUT/IN `$FB`**（FDCの
   コマンド・結果・データ）。**`(cpu, kind, port, value)`の並びをSHA-256で比べる。**
   **ステータスとハンドシェイクのポーリング（main `$FE`・`$FF`、sub `$FA`・`$FE`・`$FF`等）は
   比べない**——**ポーリング回数はサイクル数で変わりうるので、コード移動でも一致するとは
   限らないからである。** この範囲は**測定前にここで決めた。**
   比較器（`PC88/tmp/m7ld-cmp.py`）は、BASEの1回目と2回目で70本すべて一致（偽陽性なし）、
   窓越えで壊れたB12とは不一致を拾う（検出力あり）ことを測定前に確かめてある。
3. **決定論性**: 書き換え版を独立2回走らせ、判定行の集合が一致する。
4. **全長2022で関門を通る**、`tools/run_all_selftests.sh`がrc=0、`tools/check_cleanroom.sh`が全項目OK。

**比べないと決めたポーリングのポートに差が出ても、合否には使わない。** **差があれば
件数を記述として載せる。** **後から比較対象を広げたり狭めたりしない。**

## 採用したら

- `src/`の変更として単独でコミットする（本稿の結果ノートを根拠にする）。
- **余白は26バイトになる。** 次に`m7kr`の合格条件3を再挑戦する。

## 言えないこととして先に書いておくこと

- **実行のタイミングが同じだとは言わない**（ポーリングは比べていない）。
- **本稿は自作の実装を測っている。公式の振る舞いは測っていない。**

公式ROM・公式ディスクのバイト列を読まない・出力しない・逆アセンブルしない。`private/`の中身を

画面本文を出力しない（比較器はハッシュの一致・不一致と本数だけを出す）。
