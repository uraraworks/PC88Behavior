# m7ae: 高速バルク先頭位置の実装と再測定

測定日: 2026-08-13

第47〜48版に従い、意味未特定の位置1観測応答と、計算可能な位置2の転送組数を
高速バルクの先頭へ実装した。観測応答値は本ノートには記録しない。公式mainとの
混成環境を1800フレーム新規実走し、値は比較器内部だけで照合した。

公式期待5635件との先頭一致は0件から2件へ伸びた。値一致長779、main側構造258、
sub側構造752、混成main `IN $FD` 5635件だった。位置1介入だけの中間測定は先頭一致
1件、最終測定は位置2も加えて2件であり、両規則の効果を個別に確認できた。

第47版の全配置規則自体は確定済みだが、現在の実装は交換#14の第1 READしか保持せず、
規則の起点である第2 READ・第5セクタを保持していない。さらに第2〜第5 READの
unit/head/C/H/R生成元には第45版からの同値候補が残る。このため位置3以降の配置実装は
行わず、未確定なFDC座標値を推測で埋めなかった。
