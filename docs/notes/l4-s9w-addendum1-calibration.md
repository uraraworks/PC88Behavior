# l4-s9w 追補1 — 較正の腕 cal-vis の幾何の訂正（事前登録の追補）

状態: 2026-10-09。公式ROMの最初の走り（38腕×2走、`official_main.tsv`、器具 fe585b7）で**較正の関門が落ち、全腕が gate_failed**になった。器具を曲げる前に、原因と直し方をここに先に残す。

## 何が落ちたか

`cal-vis`（事前登録 9788b63 の定義: `line(395,145)-(410,155),7,b` と `paint(401,150),4,7`）は、画素数 176・tail 0・2走一致で**画素の集合は期待どおり**だった。落ちたのは較正の「見える」判定で、PPM の (401,150) の画素と**基準の画素**（ハーネスの `pix_stat` は x+6 = (407,150)）の色が同じ（どちらも緑）だったため。(407,150) も塗られた領域（x=396〜409）の内側だった。

**原因は器具の幾何（較正用の枠を、基準の画素まで塗りつぶすほど広く取った）**で、PAINT の挙動でも公式ROMでもない。`base-cls3`（VRAM が空）は通った。他の腕の観測は 2 走一致しており、関門のうち落ちたのは較正だけ。

## 直し

- `cal-vis` の枠を `line(395,145)-(404,155),7,b` に狭める（内側 x=396〜403、y=146〜154）。塗る文は同じ `paint(401,150),4,7`。(401,150) は塗られ、基準の (407,150) は枠の外の背景のままになる。
- 期待する画素数は 枠 2×(10+11)−4 = 38 と内側 8×9 = 72 で **110**（`CAL_N`）。
- 予測・他の腕・他の関門・判定は変えない。直したあと、**公式を全腕やり直す**（一部の腕だけを前の走りと混ぜない）。前の走りの全腕の画素数・結果行の個数・速さの腕のフレーム数は、この診断のとき（全腕の gate を見るために）画面に出してしまった。予測や腕の変更には使っていない（変更は cal-vis の幾何だけ）。やり直しの走りは、前の走りと全腕で同じ画素・同じ結果になるかも照合する（2走×2の再現）。

## 同じ走りで見つけたもう一つの器具の欠陥

測定 TSV の 1 欄が 131072 字を超える腕（区間の多い腕）があり、`csv` の既定の欄の上限で読み戻しが失敗した。書き出しは無事。`csv.field_size_limit` を上げる直しを入れた（観測の中身は変わらない）。
