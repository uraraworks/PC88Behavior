# B69: `0x0E` を実装した自作 ROM で、G1 の F1 の道を確かめる — 結果

記録日: 2026-11-02
規則: [b69-g1-request-0e-preregistration.md](b69-g1-request-0e-preregistration.md) どおり。測定はクラウドの実行環境で rc=0。記録は `measurements/b69-g1-request-0e.txt`。

## 結果

4 腕（I1、I2、I3、S1）は B65 と同じだった。F1 の腕は、移る回数が公式 74、自作 72 のままで、**自作の `IN $FC` が 112813 から 112685 に減った**。

## 読み方（推定）

`0x0E` を入れる前の自作は、`0x0E` のあとの `0x15` の 128 バイトを返していた。入れたあとは返していない。自作の `0x0E` がそこで止まっている。

B65 の腕はドライブ 2 に像 1 を入れている。G1 の `0x0E` がドライブ 2 を読むなら、B68 で測っていない場面である（B68 の行 3 はドライブ 2 が空）。B70 でドライブ 2 に自作の媒体を入れた `0x0E` を、公式と自作の両方で測る。
