  例: `CONSOLE 0,10,1,1`＝最上行から10行をスクロールウィンドウにし、ファンクションキーを表示し、カラーモードにする。`CONSOLE 0,25,0,1:WIDTH 80,25` の形の例もある。

  `COLOR@` の項の座標は WIDTH で指定した桁数・行数の範囲（ウィンドウとは別）。EDIT の項に「スクロールウィンドウを3行以下にすると…」の注意書き（受理されること自体の示唆）。
  **誤り番号・範囲外の扱いは書かれていない**（測定で決める）。
- CRTC RESET の5パラメータの定義（l1-ipl 第5d節、採用済み）: P5＝`AT1 AT0 SC A4–A0`。`AT1–AT0` が表示モード（`00,0`＝トランスペアレント白黒、起動時の値 0x13）、`A4–A0` が最大アトリビュート数−1。

## 測り方（画面本文を扱わない）

新器具 `tools/l4_console_measure.py`（s9r の型。走り方・窓・io-log・自己検査を踏襲。**スクリーンショットは使わない**）。打ち込むのは自作のプログラムだけで、
各プログラムは `on error goto` で誤りを捕まえ（`resume next`）、最後に終了の印 `s9sz` を桁30・行0に打って `goto` の自己ループへ入る。
採る数値・記号は次のものだけで、公式が出した文字・画面本文は一切記録しない。

- **ac 腕（誤り番号）**: 1走20プローブ以内。各プローブ `e=0:<文>:gosub 800:c$=c$+chr$(65+e)`（`800` は `console ,,1,0` の戻し）。終わりに `console 0,R,1,0` で戻して
  `s9sr<英字列>s9sd` を1行打つ。英字 `chr$(65+誤り番号)` を数値に戻す（A＝誤りなし、F＝ERR 5、C＝ERR 2、W＝ERR 22）。先頭プローブは戻し文そのもの。
- **sc/cm 腕（画面の状態）**: **はしご** `for r=0 to m: locate 10,r: print chr$(65+r) を3連` で、行 r の桁10 に自作の目印（AAA, BBB, …）を置く。
  採取（自己ループに入ってから）のテキストVRAM写しから、**行ごとの記号1文字**: 目印の英字／何も無い行は `.`／それ以外（公式のファンクションキー行など）は `?`。
  `?` の中身は見ない・記録しない。属性域は行ごとに `M`（(0x80,0x00)×20）・`C`（(0x80,0xE8)×20）・`O`（その他）の1文字と、`O` の行の (位置,値) 組（自作の `color` の値だけ）。
  自作の印 `zzz` と終了の印 `s9sz` の位置（行,桁）。
- **カーソル**: 窓内の CRTC カーソルコマンド（0x80/0x81）の列を連続重複で畳み、**終了の印を打つ直前の位置**（`cur_pre`）と最後の位置を採る。
- **制御ポート**: 0x30・0x32・0x52〜0x5B の値の初出順、および**設定系 OUT の順序列**（0x30・0x50/0x51〔カーソルコマンドとそのパラメータは除く〕・0x52〜0x5B・0x64・0x65・0x68）の先頭150件。
  0x31・0x32 は周期書き込みなので順序列から除く。制御ポートの値は記録してよい（s9o〜s9r と同じ判断）。**データポート（0x20 台以下・0xFx）は採らない**。
- 各腕2走。2走が完全一致することが関門。

### 2〜3. ウィンドウ・ファンクションキー表示の効果（sc。予測119項目）

## 関門

2走とも成功し、2走の観測が完全一致。
- **較正**: `sc20-full-none` のはしごが行0〜18（A〜S）、行19が非空（`?`）、行20〜24 が空（`.`）。`ac20-1` の戻し文が誤りなし。かつ全ての sc/cm 腕で終了の印が1か所だけ見つかる（プログラムが最後まで走った証拠）。
- 自作ROMでの対照（selftest）: 合成のVRAM・I/O記録・観測での解析と判定の陽性・陰性、手計算の予測モデル、較正の陰性4種、2走不一致の関門落ち、
  自作ROMでの4腕（はしご・スクロール・ac・cm）と故障注入（はしごの1行が欠けた写しで較正が落ちる）。本文非出力の検査（偽の公式文字を含む合成写しで記録に出ない）。
- 関門が落ちたら、**器具を曲げず追補の事前登録を先にコミット**してから再測定する。自作ROMは公式のファンクションキー行を持たず戻し文も誤りになるため、較正の2条件だけを自作では免除する（器具の `strict` フラグ。公式は常に厳格）。
