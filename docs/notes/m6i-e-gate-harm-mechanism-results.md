### G4（挿入の直交をバイトで示す）

本測定の主張を支える関門である。12項目すべて OK だった。

- 4腕の `N88.ROM` はすべてバイト一致し、m6i-c の C0 のものと一致する
- E0 の `DISK.ROM` は m6i-c の C0 のものと、E1 の `DISK.ROM` は C2 のものと
  バイト一致する（E0 の ROM 一式の SHA-256 は m6i-c の C0 の凍結値
  `4c2fe213…` と一致した）
- **E0・E2・E3 の `DISK.ROM` の相違位置の和集合は、ちょうど連続6バイト**
  （組ごとの相違は E0-E2 が4、E0-E3 が6、E2-E3 が2 バイト。挿入バイトに
  共通部分があるためで、追補1 のとおり）
- その6バイトの中身は登録値と一致した。
  E0 = `DB FE E6 08 28 FA`、E2 = `DB FE 00 00 00 00`、E3 = `00`×6
- 共通5ファイルは4腕で同一、7ファイルすべてが所定サイズ

**したがって E2 と E3 は、挿入した6バイトの中身以外が完全にバイト一致する。**
配置も長さも命令数も同じで、違うのは**`IN A,($FE)` を1回行うか、何もしないか**
だけである。

関門の検出力も退行注入で確かめた。6バイト直交の検査を常に真へ倒すと自己検査が
rc=1 になる。検査項目それぞれに陰性対照を1つずつ置き、`passed=false` に
なっただけでなく NG になった項目の集合まで照合している。

## 4. 総合判定

**`m6i_e_single_read_is_the_cause`**。

`e2_failure` かつ `e3_success` である。すなわち:

- **ラウンド#0応答の直後に `IN A,($FE)` を1回行うだけで、その後の初回の通常
  READ が成立しなくなる。** 要求 run は0件で、要求そのものが走らない。
- **配置ずれは効いていない。** 同じ位置に同じ長さの NOP 6個を入れた E3 は、
  挿入なしの E1 と同じく256位置一致で成立した。
- したがって、完全なゲートの `AND` と `JR Z` は成否に関与していない。
  ゲートの害は**その先頭1命令**に尽きる。

## 5. 得られたこと

- **測定用の停止ゲートが m6i-b を汚染した経路が、命令1つまで特定できた。**
  m6i-b →（交絡を解く）m6i-c →（詰まっていないと分かる）m6i-d →（1命令に
  絞る）m6i-e と、4段かけて器具の害を追い込んだ形である。
- **「無害なはず」の根拠がコードの短さだったことが、はっきり誤りだと分かった。**
  3命令6バイトのうち、1命令2バイトで結果が反転する。
- **ポートCの読みは、この時点では副作用を持つ。** 読んで捨てただけで、
  main↔sub のハンドシェイクが成立しなくなる。
- ただし**何が消費されているかは本測定では決まらない**（次節）。

## 6. この測定で決まらないこと

- **読みが何を消費しているかは決まらない。** ラッチが落ちるのか、受信可の
  一段が進むのか、別の機序かは測っていない。成否が変わることだけを測った。
- **`$FE` 固有か、どの `IN` でも同じかは決まらない。** 本測定は別ポートを読む
  腕を持たない。無害と確かめられたポートが無いため、推測で選ばなかった。
- **挿入位置を一般化しない。** 本測定はラウンド#0応答の直後に固定している。
  m6i-b の B2・B4 はラウンド#0より前にゲートを持ち、成立していた。
- **通常READを許してよい最早時点は決まらない。** `docs/spec/l3-subrom.md`
  1.65節は未確定のままであり、本稿は規則を1つも起こさない。
- 挿入もゲートも測定専用の介入であり、公式 sub がそのような命令を持つとは
  主張しない。**本稿で分かったのは器具の性質である。**
- 公式ROM内部の実装、公式の送受信値、実機での絶対時間は決まらない。
- 別媒体、WRITE、複数セクタREAD、BASIC命令一般へ一般化しない。

## 7. 行き先

事前登録 §5 の `m6i_e_single_read_is_the_cause` の行き先に従う。

1. **m6i-f: `$FE` 固有かを確かめる。** 別ポートを読む腕を足す。
   ただし「無害なポート」を推測で選ばない。**sub が既に同じ場面で読んでいる
   ポートのうち、読みが状態を進めないと仕様書で確定しているもの**を選ぶか、
   それが無ければ**「どのポートを読んでも壊れる／$FE だけ壊れる」を
   区別できる最小の組**を事前登録で決める。
2. **m6i-g: m6i-b の境界判定7種を取り直す。** 機序が分かったので、
   **ラウンド#0より後のsub側に一切の I/O を足さない停止方式**が必要だと
   分かる。B1〜B5 のうち、ラウンド#0より後に介入を持つのは B5 だけである
   （B1・B2・B3・B4 はいずれもそれより前）。**m6i-b の B0〜B4 は本測定の
   害を受けない位置にある**が、そのことは本測定が直接示したものではないので、
   取り直しの事前登録で改めて関門に置く。
3. 1.65節への規則の追加は、m6i-g が境界を確定させるまで行わない。

**本稿の §5・§7 の読みを、次の稿の期待値として凍結しない。**
m6i-f・m6i-g はそれぞれの事前登録で判定を先に固定する。
