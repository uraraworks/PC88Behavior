# B85: サブ要求 09 の自作プローブ — 事前登録

記録日: 2026-11-12。測定より先に確定し、結果を見て変更する場合は後続ノートに記す。ゲームは使わない。B84 から用いる事実は、09 見出しの後に main が計5バイト送ること、直前が長さ26の要求 0E であること、自作 sub は1バイト目の後に IN $FE 待ちで止まることだけである。働きと入力は自作プローブで調べる。

## 腕

各腕は別起動、2走。前置きは自作 main の初期化と 00、17、0F。0E の内容は使わず、今回は前置しない。0E が必要かはこの実験では決められない。

| 腕 | 送る自作値 | 目的 |
|---|---|---|
| 1 | なし | 09 を送らない陰性対照 |
| 2 | 09 00 00 00 00 | 基準 |
| 3 | 09 01 00 00 00 | 第1引数 |
| 4 | 09 00 01 00 00 | 第2引数 |
| 5 | 09 00 00 01 00 | 第3引数 |
| 6 | 09 00 00 00 01 | 第4引数 |
| 7 | 09 | 不足の陰性対照 |
| 8 | 09 00 00 | 不足の陰性対照 |

1バイトごとに時間切れを設け、未送信分は送らない。媒体は自作 coord-header D88 を走ごとに新規生成し、公式ディスクは使わない。公式 ROM はクラウドで `PC88_REF_ROM_DIR` の `DISK.ROM` のみ。自作 main と自作 sub の陽性・陰性・故障注入で器具を先に検査する。

## 記録と関門

各腕の 09 開始から観測終了まで、sub が受けたバイト数、sub の送信数と main の受信数・応答長、時間切れ、FDC コマンドの種類と数、媒体の開始・終了の同一性、sub RAM の変化番地を記録する。RAM は要求なし腕の同条件スナップショットとの差を番地のみで示し、初期化や時間経過の差が含まれ得る。生ログ・媒体・スナップショット・値はリポジトリ外に置く。返答や RAM の値、FDC 引数、画面本文、内部 PC は公開しない。ログ欠落・未完了・スナップショット欠落は `instrument_invalid`。同一腕の2走の公開項目が異なれば `not_reproducible`。自作どうしの陽性・陰性と故障注入の検出が不成立なら `controls_failed`。

全関門を通った場合だけ、腕2と腕3〜6の差を `observed_difference`、差がなければ `no_difference_observed` とし、この範囲での観測に限る。送信完了だけで受理や働きを確定しない。不足腕で応答や媒体変化があっても、そのまま記録し仕様とはしない。

公開可能な番地・件数・種類・真偽だけを `measurements/b85-sub-09-*.json`、判定を `docs/notes/b85-sub-request-09-results.md` に置く。結果の測定はまだ行わない。
