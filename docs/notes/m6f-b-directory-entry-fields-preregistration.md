# m6f-b — ディレクトリのエントリの欄と、名前の大文字・小文字の扱い — 事前登録

記録日: 2026-09-24  
状態: 測定前

## 0. 位置づけ

[m6f-a 結果](m6f-a-directory-by-save-diff-results.md) は、**ディレクトリのセクタを
(C=18, H=1, R=3) と導出した**（D1、事前登録どおりの規則で一意）。一方で、名前は
ディスク上で**小文字**で入っていて、大文字を探した D2 が見つからず、D3〜D6 が連鎖して
not_found になった。割り当て表（D7）は、各腕が同じ最初の空き位置へ本体を書くために
本体が候補に混ざった。

本稿は、m6f-a で**観測として**見えた事柄（エントリの欄の配置、削除・未使用の印）を、
**先に固定した導出規則で新しい走から**取り直す。あわせて、大文字・小文字の扱いと、
割り当て表の所在を切り分ける。

境界の規則は m6f-a 事前登録 §1 と追補2（古い値はセクタ単位・最小8個）・追補3（複製の
書き込み保護を外す）をそのまま引き継ぐ。**公式ディスク固有の事柄（既存ファイル数・
空きの状況・割り当て番号の具体値）はノートに書かない**（m6f-a 結果 §7）。

## 1. 問い

- **主問1 大文字・小文字**: ファイル名を大文字のバイトで与えたとき、小文字のバイトで
  与えたとき、キーボードから打ったとき、ディスク上にはそれぞれ何が入るか。
- **主問2 エントリの欄**: 名前欄の始まりと長さ、詰め物、エントリ長、削除の印、
  未使用エントリの表現。
- **副問**: 割り当て表のセクタの所在。プログラムとデータファイルでエントリの
  名前直後のバイトが違うか。

## 2. 刺激（腕）

すべて順次ファイル（`OPEN … FOR OUTPUT`）で作る。**名前は `CHR$` で1バイトずつ
与え、打鍵を経由させない**（G3・G8 を除く）。本体の中身は腕ごとに変える（§4 E7 の
ため）。各腕2走、各走は新しい使い捨て複製から始める。

| 腕 | 名前の与え方 | 本体 | 狙い |
|---|---|---|---|
| G0 | （何もしない） | — | 陰性対照 |
| G1 | `CHR$(81)+CHR$(90)+CHR$(55)+CHR$(65)`（`QZ7A` の大文字の符号） | `"X"` | 大文字で与える |
| G2 | `CHR$(113)+CHR$(122)+CHR$(55)+CHR$(97)`（`qz7a` の小文字の符号） | `"Y"` | 小文字で与える |
| G3 | 打鍵した `"QZ7A"` | `"W"` | キーボード経由（m6f-a と同じ経路） |
| G4 | G1 の名前と、最後を `CHR$(66)` にした名前の2件 | `"X"`・`"X"` | エントリ長 |
| G5 | G1 の名前で作った後、`KILL` に同じ `F$` を渡す | `"X"` | 削除の印 |
| G6 | `QZ7ABC` の大文字の符号6個 | `"X"` | 名前欄の長さと詰め物 |
| G7 | `QZ7D` の大文字の符号 | `STRING$(200,"V")` を300行 | 割り当て表（大きい） |
| G8 | 打鍵した `10 END` を `SAVE"QZ7E"` | （プログラム） | 副問: プログラムとデータの違い |

打鍵はすべて 512 打鍵の上限の内側に収まる（最長の G7 で約120打鍵）。

## 3. 前提として使うもの

- **ディレクトリのセクタ S = (18, 1, 3)**。m6f-a の D1 の導出結果（事前登録どおりの
  規則で一意）を入力とする。関門 G8 で、G1 が S を変えることを確かめる。

## 4. 導出規則（測定前に固定する）

符号の並びを次のとおり名付ける。

- `U` = `51 5A 37 41`（`QZ7A` の大文字の符号）
- `L` = `71 7A 37 61`（`qz7a` の小文字の符号）

**E1 大文字・小文字**: G1・G2・G3 のそれぞれについて、S で変わったバイトの新しい値の
中に `U`・`L` が連続して現れるかを調べ、`U` / `L` / `both` / `none` の4通りに分ける。

- `case_stored_as_given`: G1=`U`、G2=`L`、G3=`L`。**ROM は与えたとおりに格納する。**
  キーボード経由の打鍵は小文字で届いている（ハーネスの注記「大文字として入る」は誤り）。
- `case_folded_to_lower`: G1・G2・G3 がすべて `L`。**ROM が小文字へそろえる。**
- `case_folded_to_upper`: G1・G2・G3 がすべて `U`。（m6f-a の SAVE では小文字だったので、
  この場合は SAVE と OPEN で扱いが違うことになる。）
- `case_other`: 上のどれにも当たらない。

**E2 名前欄の始まり**: G1 で E1 が見つけた並び（`U` か `L`）の S 内の位置 p。p が S で
変わった区間のどれかの先頭と一致することを要求する（名前がエントリの先頭から始まる）。
ちょうど1か所なら `derived`。

**E3 エントリ長**: G4 の2件について、それぞれの名前の並びの位置の差。両方がちょうど
1か所ずつ見つかれば `derived`。

**E4 名前欄の長さと詰め物**: G1（4文字）と G6（6文字）のそれぞれで、位置 p から始まり
「名前の文字、続いて `0x20` の並び」からなる最長の連続の長さ。**G1 と G6 で長さが同じ**なら、
その長さを名前欄の長さ、`0x20` を詰め物として `derived`。違えば `not_found`。

**E5 削除の印**: G5 の S の新しい値と、G1 の S の新しい値を、エントリの範囲（p から E3 の
エントリ長ぶん。E3 が not_found なら E4 の長さ＋2）で比べ、違う位置とその G5 側の値。

**E6 未使用エントリの表現**: G1 の S について差分器が出したセクタ単位の一様な古い値
（追補2 の条件を満たしたときだけ出る）。出ていなければ `not_found`（理由
`old_values_withheld` を区別して記録）。

**E7 割り当て表のセクタ**（副問）: S を除き、**G1・G2・G3 のすべてで変わり、かつ3腕で
変化（位置と新しい値）がまったく同じ**セクタ。そのうえで G7 がそのセクタで G1 より多くの
バイトを変えることを要求する。本体は腕ごとに中身（`X`・`Y`・`W`）が違うので、3腕で同じに
なる本体セクタは無い。**候補は複数でもよい**（集合として記録する）。0個なら `not_found`。

**E8 プログラムとデータの違い**（副問）: G8 と G1 の、エントリの名前欄の直後のバイト
（p＋E4 の長さ）の新しい値をそれぞれ記録する。

2走で導出結果が一致しない導出は `ambiguous` とする。

## 5. 関門

m6f-a の G1〜G7・G5b を引き継ぐ（全自己検査、クリーンルーム検査、差分器の自己検査、
陰性対照 G0 の差分が空、複製の SHA と保護解除の検査、生出力をリポジトリ外、凍結）。
**G1（全自己検査）は測定ドライバの中では回さず、腕の前に親が1回通す**
（m6i-i・m6f-a で委譲先が毎回埋め込んだため明記する）。加えて:

- **G8 ディレクトリのセクタの再確認**: G1 の腕が S を変える。変えなければ §3 の前提が
  崩れているので、腕の結果を解釈しない。

## 6. 判定名

- `gate_failed` / `unreached`（WRITE DATA が0件、または差分が空）
- 各導出: `derived` / `ambiguous` / `not_found`（E1 は上の4名）
- 総合:
  - `m6f_b_entry_fields_derived`: E1 が `case_other` 以外、かつ E2・E3・E4・E5 が `derived`。
  - `m6f_b_entry_fields_incomplete`: 上を満たさない。
  - `m6f_b_inconclusive`: 関門は通ったが1腕以上 `unreached`。

E6・E7・E8 は個別に記録し、総合判定に入れない。

## 7. 行き先

- `m6f_b_entry_fields_derived`: エントリの欄を `docs/spec/` に規則として起こし
  （新しい仕様書 `docs/spec/l3-disk-format.md`）、次稿で**空の公式形式ディスクを自作の
  生成器で作り、公式ROM がそれを受け入れるかを測る**。割り当て表の空きの印など差分から
  読めないものは、そこで挙動から再構成する。
- E1 が `case_stored_as_given` なら、**ハーネスの注記を直す**（打鍵は小文字で届く）。
  これまでの測定の画面比較は公式と自作を同じ打鍵で比べているので影響は受けないが、
  注記の誤りは記録として残す。
- `m6f_b_entry_fields_incomplete`: 候補の分布を記録し、刺激を足す追補を置く。

## 8. この測定で決まらないこと

- エントリの名前以外の欄の意味（割り当て番号とみられる欄も含む）。
- 割り当て表の中身の意味と空きの印。
- ファイル名の最大長を超えた場合の扱い、使えない文字の扱い。
- プログラム本体・データファイル本体の保存形式。
