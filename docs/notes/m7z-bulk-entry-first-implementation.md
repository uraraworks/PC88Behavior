# m7z: 高速バルク入口・第一実装の混成実走

測定日: 2026-08-13

仕様第44版の入口5フェーズを、交換#14のrun終了（mainがSEND側へ転じたことを
示すbit1）で起動する第一実装を公式mainとの混成環境で1800フレーム実走した。
ログはリポジトリ外で`tools/redact_iolog.py`を適用してから構造比較した。

結果は値一致長779件、main構造258件、sub構造752件、main `IN $FD` 0件で、
直前から一指標も伸びなかった。混成subは交換#14の12件目を通常RECVで完遂した後、
入口へ進まず次のRECV開始を先出しし、`IN $FE`で待ち続けた。公式subは12件目の
通常RECV完遂直後、run終了合図を待たず入口5フェーズへ進む。

したがって入口判定を汎用run終了処理に置いたことが誤りである。交換順序が第三READ対
完了済み、かつ交換#14の受信累積が12件になった時点で、通常RECV完遂から直接入口へ
分岐する必要がある。データポート値は使用・表示していない。
