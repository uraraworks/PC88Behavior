# B41: G1 でサブが `7812` へ移るときの移り方を値なしで測る — 事前登録

記録日: 2026-11-01
位置づけ: [B40](b40-g1-sub-cross-table-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

公式で `DE` が違う `7812` への移りは、`7800`・`7803` への移りと同じ ROM の場所から、同じ形で移っているか。

## 2. 器具

コアにパッチ 0023 を足す。B39 の `C` の記録へ、移る直前の発行元の `PC` と `SP` を足す。既定は無効で、無効なら動作を変えない。生のファイルは開かず、コミットせず、ライブラリへ置かない。

ツールは次の行だけを出す。**値は出さない。** 公式の ROM の番地も出さない。

- `# 識別子: G1`
- `O <腕> <番号> <移る先の PC> <発行元の組> <SP の差> <DE が 0 か yes|no> <DE が HL と同じか yes|no> <DE が BC と同じか yes|no>`

発行元の組は、その腕の中で初めて現れた順の番号である（番地を出さない）。SP の差は移る直後の `SP` から移る直前の `SP` を引いた値（-4〜+4 の範囲のみ、外は `other`）。

器具は G1 なしで自己検査する。陽性対照は組の番号付け、`JP (HL)`（差 0）と `RET`（差 +2）の区別、`DE` の 3 つの述語。陰性対照は番地と値が出ないこと、無効時の動作が変わらないこと。

## 3. 条件

腕 F の 4800 フレーム。OO・SS 各 2 走。自作 ROM は ff113bf の配布ビルド。クラウドの実行環境で行う。

関門: `IN $FC` の差が B30 と同じ（257 件、最初 76570、連続 132）。OO どうし・SS どうしの出力が一致する。

## 4. 記録の白リスト

第 2 節の行だけ。

## 5. 判定（事前に決める）

- `7812` の行と `7800`・`7803` の行で、組と SP の差が同じか違うかを、腕ごとに書く
- `DE` の 3 つの述語を腕ごとに書く
- 公式の値は知らない。述語で足りなければ、自作のコードと自作の媒体で再現する測定を別に事前登録する
