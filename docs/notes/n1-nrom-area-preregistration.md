# n1 — N-BASIC ROM 領域の事前登録

登録日: 2026-11-08。以下は本走前に固定した計画であり、予測は仮説。
公式ROM・private/ は使わない。自作 N88.ROM、N80.ROM、DISK.ROM、拡張ROMのみを使う。画面は採取しない。対象はこのハーネスの QUASI88-libretro であり、実機の証拠ではない。

- RAM 8000以上に試験コードをコピーして実行し、ROMモードのまま 31h に既知の値を書き、その写しから bit2 のみを変える。切替直後に 0100h、5FFFh、6000h、7FFFh を読み、復帰後も読む。仮説: N80 と N88 が切り替わる。31h 入力は出力の写しではないため入力値も記録する。
- 71h と 32h で拡張バンク0を選び、N88、N、復帰の 6000h/7FFFh を測る。仮説: N が拡張窓に優先する。
- IM1・VSYNCを有効化し、N選択のまま RAM の待機ループに留まる。N80 の 0038h に独立の印付き入口を置き、RAMに回数を書き、N88 側にも別の入口を置く。5回以上の N側入口と int-log 上のRAM戻り先を必須とする。割り込みなしまたは欠落では合格させない。
- 欠落、短い（先頭 16KB）、長い（32KB+1）N80 と、識別値変更の腕を用意する。先頭、短い領域の末尾、欠落領域、末尾を観測する。仮説: 欠落や短い領域は FF、長い場合は先頭32KBを使う。読み込み失敗時の実際の挙動を記録する。
- OUT直後の次の読み出しで識別する。遅延は命令単位でのみ判定し、Tステートを主張しない。起動モード N88 V2/V1H/V1S/N の各腕では双方の自作ROMに同じ起動スタブを置いて試験する。ポート30入力を併記し、異なるDIP値が得られなければ独立性の判定範囲を限定する。
- Q0/Q6 は core の memory.c、libretro.c と WebQ88 の README・ROM読込コードを調べる。優先順、欠落時と短いファイル時の挙動を区別する。

器具自己検査は標準・N80欠落・パターン変更を実行し、標準判定が両陰性対照で変わることを必須とする。各本走腕を2回独立起動し、RAM結果・割り込み件数・DIP入力が一致することを必須とする。記録は measurements/n1 に自作値のみ保存する。実行失敗・完了印欠落・割り込み不足は未判定として明記し、成功扱いしない。
