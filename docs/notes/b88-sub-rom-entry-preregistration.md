# B88: サブ ROM 入口の働き — 初回事前登録

これは測定前の計画であり、結果ではない。ゲームから得たのは依頼で示された番地、移動の種類、回数と戻りの有無だけである。ゲームの値やレジスタは用いない。公式 ROM の測定に先立ってこの計画と器具の版を固定する。利用者の指示により今回コミットしない。

## 入口と由来

| ゲーム | 番地と境界観測 |
|---|---|
| G2 | 0010 CALL 95・戻り95、00ED JP 21、048F JP 2、06A6 CALL 2・戻り2 |
| G5 | 0010 213、0018 7790、0020 182、0263・02A4・02B4・035B 各 CALL 26、02A7 JP 26、07D6 CALL 2・JP 24 |

0010・0018・0020 は CALL と RST を別々に試す。06A6、0263、02A4、02B4、035B は CALL、00ED、048F、02A7 は戻り先を積んで JP、07D6 は CALL と JP の両方で試す。CALL/RST の別をゲーム実走時の事実として推定しない。

## 入力と腕

基準入力は A=00、F=00、BC=0001、DE=6000、HL=6100、SP=7E00 とし、6000・6100 は 00 に初期化する。各入口・入り方について、基準と、A=01、BC=0002、DE=6200、HL=6300、F=01、HL 指示先の内容を 01、DE 指示先の内容を 01 にした各腕を設ける。他の入力は基準のままとし、変更したポインタの先も 00 に初期化する。入力はすべて自作である。呼出し命令直前の SP と、CALL・RST・JP それぞれの戻り先の積み方を明示して比較する。サブ RAM の RET を呼ぶ陰性対照、自作の既知動作ルーチンを呼ぶ陽性対照を同じ方法で加える。各腕を独立起動し 2 走とする。

## 実施と集計

自作起動セクタが要求 0C で自作プローブをサブ RAM に送り、要求 0D で実行する。プローブは入力の設定後、対象を呼び、戻り直後の AF・BC・DE・HL・SP を保全してから 00C1 に戻る。main は既存要求で結果領域を読み出す。ROM の内部 PC や ROM 読出し値を記録しない。

呼出し直前と戻り直後の印で区間を切り、サブ側 I/O をポート・方向・回数、FDC をコマンドの種類と回数で集計する。RAM は呼出し前後の比較によって実際に変化した番地と回数だけを出す。書込み件数だけを変化件数と呼ばない。戻り時の各レジスタ・フラグ・SP は入力との一致の真偽、および基準腕との関係の真偽だけを出す。値付きの一時記録はリポジトリ外に限り、集計後に削除する。腕ごとに ROM 置き場を分ける。生ログは容量上限を設け、取りこぼしや区間が確定できない場合は該当観測を欠測とする。

戻り印がないまま時間上限になった場合、または再起動の印が現れた場合は「戻らない」と数え、理由は別に示す。開始印がない場合や器具の起動自体が失敗した場合は欠測とし、戻らないと混同しない。戻らない場合の I/O と RAM は取得できた区間に限る。2 走の一致は、同じ条件の値なし集計を比較して示す。測定の途中で事前登録の判定や入力を変更しない。

公式 ROM やゲームを使う前に、PC88_REF_* を外して自作サブ ROM で陰性・陽性対照、復帰、入力との比較、区間、再起動、欠測、値なし出力と一時ファイル削除を自己検査する。ディスク使用は数 GB 以内とし、腕を逐次実行する。結果は本ノートに追記せず後続の記録に分ける。

## 器具の実行方法

`bash tools/b88_selftest.sh` は `PC88_REF_*` を外し、通信試験、130腕各2走、対照、故障注入、値なし集計と後片付けを検査する。作業先はリポジトリ外の一時ディレクトリである。

本実行は `bash tools/b88_run.sh "$OUT"`。OUT はリポジトリ外の未使用ディレクトリを指定する。`PC88_REF_ROM_DIR` があれば、そのディレクトリの ROM 一式を各腕・各走専用の置き場へコピーする。無ければ自作 IPL と既存の自作サブ ROM を生成する。自作 IPL が配置するのは初段256バイトだけで、後続512バイトは自作ディスクから FDC 経由で読み込む。後続コードは 0C・0D・09 の順に通信し、結果を main の CF00–CF0B、完了印を CFF1 に置いて停止する。

既存の計測済み QUASI88 ソースを OUT 内にコピーし、`b88_capture.c` を組み込んで構築する。元ソース、既存 frontend、`src/`、`docs/spec/` は変更しない。ソース置き場の既定はリポジトリ隣の `vendor/quasi88-libretro`、変更時は `PC88_CORE_SOURCE` で指定する。Python 3・C/C++ コンパイラ・make が必要。`PC88_CORE` の既存バイナリを B88 用フックの代わりには使わない。

フックは自作コードの呼出し命令直前と戻り先だけで区間を判定し、ROM 内部 PC・ROM 読出し値を記録しない。4000–7FFF の RAM 前後像はホストメモリ内だけに保持する。集計の「変化番地」は区間前後の不一致、「値変化回数」は書込前と書込値が異なる回数であり、元に戻した書込は後者だけに現れる。CALL/RST が積む戻り先の変化は区間内、JP 用の事前 PUSH は区間外になる。FDC は MSR の RQM/DIO/CB でコマンド先頭を区別し、引数や転送データを種類として数えない。

未帰還でもフレーム上限で区間を閉じる。上限は自作120・公式2010フレーム、実時間120秒。`B88_FRAMES`（1–10000）と `B88_TIMEOUT`（1–600秒）で変更でき、`B88_FILTER` は部分検査用の腕名正規表現である。通常は指定せず全腕を走らせる。各子プロセスの出力ファイルは32 MiBを上限とし、ログ欠落・不正形式・実行失敗は欠測にする。

生データとコピーした ROM は OUT/raw 内だけで扱い、各走の集計後に削除する。腕間比較用の一時レジスタ値も最終集計後に削除する。残す `summary.json`・`row.json`・`comparison.json` は番地・種類・件数・入力や基準腕との一致の真偽のみである。`python3 tools/b88_summarize.py "$OUT"` で残した値なし記録から再集計できる。自作サブの任意入口が戻らなくても器具失敗とは扱わず、全腕で開始を確認し、未帰還・再起動と対照の既知動作を検査する。
