# m7dw: 自作ファイル本数ラダー前半実測（N=0〜8）

実施日: 2026-08-28

本稿は`m7dv`で事前登録したディレクトリ拡張境界探索のうち、最初のチェックポイント群
N=0〜8を公式環境で実測する結果ノートである。`src/`は変更しない。公式ROM・公式
ディスクの内容、データポート値列は表示・転記せず、生ログ、媒体複製、チェックポイント、
manifestは全てリポジトリ外で扱う。

## 測定前補遺: ブロック末端検証器の表記だけを訂正

N=1〜8の準備後、測定を始める前に`m7dv`記載のBASIC側`CHR$`式による全名OPEN検証を
試したところ、末端マーカーへ到達しなかった。切り分け用の自作マーカーだけを集計した
別runでは、N=1/N=8の文字コード算術と文字列長は想定どおりだった一方、生成文字列は
登録済み自作名と一致しなかった。媒体については先頭名`QDAA`と末尾名`QDAH`を直接
リテラルでINPUT OPENする別runがいずれも固有マーカーと直後`Ok`へ到達し、取りこぼし
0件だった。従って媒体作成失敗として受理条件を緩めるのではなく、検証器の名前生成表記
だけがこのBASIC環境に適合しなかったものとして、以下を**N=1〜8の測定前に固定する**。

- `m7dv`の名前規則からホスト側で生成した`QDAA`〜`QDAH`を、作成順に各1行のリテラル
  `OPEN ... FOR INPUT AS #1:CLOSE #1`として打鍵する。
- 8名すべてを同一runで開き終えた場合だけ、登録済みのブロック末端マーカー`V008`を
  表示する。実行時エラー、マーカー欠落、直後`Ok`欠落、取りこぼしは従来どおり不合格とする。
- 名前集合、順序、全名OPENという適用範囲、9000フレーム、二段打鍵、2run測定、到達条件、
  差分とジャンプの判定規則は一切変えない。公式既存名・内容は参照しない。

これは介入の適用範囲を狭める変更ではなく、同じ自作名集合の全存在検証を成立させるための
表記訂正である。最初の失敗runと切り分けrunは測定値へ採用しない。

Delta_1は登録どおり境界と呼ばない。Delta_2〜8も全て0件・0単位であり、これは
**ファイル追加に伴うアクセス件数の変化が無いゼロ差分**である。m7dtの1292件・7単位
のような「追加ごとに非ゼロの一定コスト」とは呼ばない。正方向の数値ジャンプ、負方向変化、方向不一致、構造的延長、
未見FDCコマンドは0件だった。従って、N=0〜8ではH-Xを支持する数値境界を観測して
いない。独立確認によりファイル追加と媒体依存検索の両介入が成立したため、操作上の結論は
**「固定した不存在OPENのアクセス件数は、追加0〜8本の範囲ではファイル数に依存しない」**
である。上限N=64へ達していないため、全探索の陰性結論にはまだ進まない。

### 値非表示イベント構造

`cpu/kind/port/pc`だけの入口イベント列は各N 177610件だった。隣接列を比較すると、
N=1は探索下端の構造候補、N=6は同件数のままstrict prefixを保たない構造変化だった。
それ以外は完全一致した。

| 遷移 | 共通prefix件数 | 最初の差の位置 | 分類 |
|---|---:|---:|---|
| 0→1 | 28914 | 28914 | 探索下端の構造候補 |
| 1→2〜4→5 | 177610 | なし | 同一 |
| 5→6 | 33378 | 33378 | 構造変化 |
| 6→7、7→8 | 177610 | なし | 同一 |

N=6はH-Cのいう**異なる値非表示制御構造の候補**には当たる。ただしmain `IN $FC`、
READ、FDCコマンド件数・種別順はいずれも変わらず、新しい公開FDCコマンドも無い。
従って「追加管理領域を読んだ数値境界」やディレクトリ内部形式の証明とはせず、今後の
系列で再現性と水準の持続を見る構造候補として分離して残す。N=1は直前Deltaが無いため、
登録どおり数値ジャンプとは呼ばない。

### 固定署名の再判定と故障注入

各Nのrun1で固定した件数・SHA-256・READ単位・画面署名へrun2を再判定し、9条件全て
一致した。件数、SHA-256、READ単位、取りこぼし、到達マーカー、入口I/Oをそれぞれ
破壊した6種の故障注入を全て不一致にできた。入口I/O 0件をゼロ差分へ採る空振りも
検出できた。

### 完了範囲、未了範囲、解釈限界

- **完了範囲はN=0〜8**で、最初の8本ブロックは全条件・各2run合格した。数値ジャンプは
  無く、介入成立を独立確認したうえでアクセス件数のゼロ差分を得た。このブロック内での
  境界再構築確認は発生していない。
- **未了範囲はN=9〜64**である。N=8アンカーから次の8本ブロックを作成・検証して再開する。
  未実施Nを実施済み、0差、陰性とは扱わない。
- N=6の値非表示構造変化は、どの処理や媒体管理形式が原因かを直接観測していない。
  ディレクトリ、割付情報、検索比較など特定機構へ帰属しない。
- 本結果は固定した公式diskA基準への自作空ファイル追加0〜8本、固定不存在OPEN、
  QUASI88上の範囲に限る。元媒体の総項目数や絶対境界へ一般化しない。
