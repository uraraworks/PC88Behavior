# B39: スペース後の G1 で、サブの BC と HL が最初に違う時点を値なしで測る — 事前登録

記録日: 2026-11-01
位置づけ: [B38](b38-g1-sub-ram-diff-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

1. `BC`・`HL` は、ROM から RAM 上のコードへ移る時点ですでに違うか
2. 移ったあと RAM 上のコードの中で初めて違うなら、main の `IN $FC` の何番の時点か
3. RAM 上のコードは `LD A,R` や `LD A,I` を実行するか

## 2. 器具

コアに `--sub-reg-log FILE` を足す（パッチ 0022）。既定は無効で、無効なら動作を変えない。次を作業場の生のファイルへ書く。**生のファイルは開かず、コミットせず、ライブラリへ置かない。**

- サブが発行元 `0x2000` 未満の命令から `0x2000` 以上の命令へ移るたびに、`PC` と全レジスタ
- main の `IN $FC` のたびに、その時点のサブの `PC` と全レジスタ
- サブの発行元 `0x2000` 以上で実行した `LD A,R`（`ED 5F`）と `LD A,I`（`ED 57`）の回数と、それぞれ最初の発行元の `PC`

比較ツールは 2 つの生のファイルを読み、次の行だけを出す。**値は出さない。** 番地のうち出すのは RAM 上のコードの `PC` だけである。

- `# 識別子: G1`
- `cross count <左> <右>`
- `cross first-pc-differ <N|none>`
- `cross first-reg-differ <レジスタ名> <N|none> <PCが4桁16進|none>`（レジスタごと、`R` を除く）
- `fc count <左> <右>`
- `fc first-reg-differ <レジスタ名> <N|none> <pc-same|pc-differ|none>`（レジスタごと、`R` を除く）
- `opcode <LD_A_R|LD_A_I> <左の回数> <右の回数> <左の最初のPC|none> <右の最初のPC|none>`

器具は G1 なしで自己検査する。陽性対照は移る時点のレジスタの違い、`IN $FC` の時点の違い、`LD A,R`・`LD A,I` の検出。陰性対照は同じ走で違いが出ないこと、発行元 `0x2000` 未満の `LD A,R` を数えないこと、値が出力へ出ないこと、無効時の動作が変わらないこと。

## 3. 条件

腕 F の 4800 フレーム。OO・SS 各 2 走。自作 ROM は ff113bf の配布ビルド。クラウドの実行環境で行う。

関門: 同じ走の `IN $FC` の差が B30 と同じ（257 件、最初 76570、連続 132）。OO どうし・SS どうしの比較で `first` がすべて `none`、回数が同じ。

## 4. 記録の白リスト

第 2 節の比較ツールの行だけ。

## 5. 判定（事前に決める）

- `cross first-reg-differ` が `none` でなければ、ROM から移る時点の問題の候補とし、番号とレジスタを書く
- すべて `none` で `fc first-reg-differ` が `none` でなければ、RAM 上のコードの中で生じたとし、番号を B30 の 76570 と並べる
- `LD A,R` が RAM 上のコードにあれば、そのことを書く。公式との違いが R によるかは、この記録だけでは断定しない
- 原因は断定しない
