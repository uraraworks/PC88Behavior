# B88 追補2: 割り込み状態と 0263・06A6（事前登録・公式未測定）

B88 初回・追補1の由来、値なし集計、各腕各走の独立 ROM 置き場、2走、未帰還・欠測・時間上限・再起動・後片付けを継承する。利用者が提示したゲーム由来の事実は、0263 直前の入口の並びと回数、区間のポート番号と回数、未帰還と割り込みの有無だけであり、ゲーム由来のレジスタ・メモリ・ディスク値は使用しない。これは計画であり、測定結果ではない。コミットしない。

`tools/b88a2_arms.py` に腕を列挙する。各入口の入力状態は追補1と同じ自作レジスタ・RAMを基準とする。0010 と 0018 は追補1と同じ main の通信協力を使う。各入口の直前で DI または EI を実行し、命令境界で IFF1・IFF2 と割り込みモードを観測する。EI の遅延と、入口へ到達する前に割り込みを受けた場合を区別する。戻り直後の状態も同じ境界で採り、未到達・未帰還の場合は欠測とする。観測に使うのは器具側の境界のみで、ROM内部の経路は保存しない。

0263 腕は 07D6、035B、02A4、0020 を7回、02A7 の順に事前処理し、各段の未帰還を区別する。自作入力とする9バイトの READ DATA コマンドは `b88a2_arms.py` に固定する。ブート後に座標入り自作媒体を装着し、C/H/R/N=0/0/4/1 の256バイトを指定する。結果7バイトはエミュレータの FDC が返したものだけを記録可能とする。結果とセクタデータの書込み先は、区間中の FDC 読出しとサブ RAM 書込みの対応を観測し、自作データとの一致によって識別する。偶然の一致や途中での上書きだけを根拠に転送先を断定せず、対応を決定できない場合は不明とする。区間 I/O、戻りと戻りレジスタは既存の値なし方式に従う。

06A6 は main が入口到達後に自作値を送る。1バイトと、順序を入れ替えた2バイトの3条件で、送信完了数、サブ側の受信数と配置番地、入力との一致、戻りレジスタを調べる。送信途中で戻った場合は実際に完了した数を分けて記録する。陽性・陰性対照を置く。

公式測定より先に PC88_REF_* を外し、自作の対照で IFF1・IFF2・IM、EI遅延、通信の1・複数バイト、9バイトのコマンドと結果7バイト、データ配置、先行処理未帰還、時間上限、再起動、欠測、値漏れと後片付けを検査する。器具は `tools/b88a2_run.sh`、自己検査は `tools/b88a2_selftest.sh`、再集計は `python3 tools/b88a2_summarize.py OUT` とする。公式ROMでの測定結果は本ノートに含めない。


## 実行条件と観測の範囲

- 27腕（入口10個×DI/EI、0263×DI/EI、06A6×3送信条件、陽性・陰性対照）を各2走する。既定は全腕。`B88A2_FILTER` は腕名の正規表現、`B88A2_FRAMES` はフレーム上限（自作120、公式2010）、`B88A2_TIMEOUT` は各走の実時間上限秒（120、最大600）。出力先はリポジトリ外の未使用ディレクトリとする。
- 各走で独立したROM置き場を作る。`PC88_REF_ROM_DIR` がなければ既存の自作ROMビルダーを呼ぶ。公式ROMは同変数の場所からコピーするだけで、器具のPythonコードで中身を読まない。ディスクはブート用・測定用とも自作であり、参照ディスク変数を使用しない。自作ROMに対照コードを入れる機能は公式指定時に拒否する。
- 初期IMは1、SP・レジスタ・RAM入力は追補1の基準値とする。DI/EIはCALL/JP直前に置く。呼出し命令直前、指定入口に実際に達した命令境界、器具の戻り先の3点でコアのIFF1・IFF2・IMを採る。復帰後の退避処理はDIで保護する。IFF2を含め、記録は当該エミュレータの状態であり実機CPUの適合性を主張しない。
- EIの遅延分岐を器具の呼出し直前に限って計数する。コア内の同じ実行ループで継続した場合はこの分岐を通らないため、計数0だけで遅延なしとは判断しない。別に割り込み受理フックで前処理中・入口到達前・到達後を数える。IRQハンドラを入口到達と誤認せず、内部PCや経路は保存しない。
- 0263の準備は07D6、035B、02A4、0020を7回、02A7の11段階。02A4直前のAにコマンド先頭、各0020直前に続く7バイト、02A7直前に最終バイトを入れる。02A7は器具の戻り先を積んだJP。各段階もDI/EI条件を適用する。これは未確認の入口の働きを仮定した入力であり、9バイトが実際にFDCへ受理されたかを別に照合する。
- 測定用媒体は識別子0x42の座標入り媒体。READ DATAのMF=0に合わせた単密度で、C/H/R/N=0/0/4/1を指定する。ブート完了後、サブの自作プローブ先頭で測定用媒体へ交換する。ブート用媒体は従来の倍密度のまま。媒体交換に失敗すれば欠測。
- FDCデータ・結果の追跡範囲は前処理開始から0263の帰還（未帰還なら時間上限／再起動）まで。0263本体の区間I/Oは別に保持する。結果フェーズは読出し前のFDC状態から識別する。公開する値列は、自作媒体を確認し、9バイトのコマンドを照合し、7バイト全部を受信できたFDC結果だけ。部分受信・不一致・別コマンドでは値を出さない。
- 配置は、各読出しから次のデータ読出しまでの一致するRAM書込みを候補にする。候補番地・終端までの維持・容量超過を残し、複数候補、上書き、追跡不足は不明とする。自作セクタ256バイトの全受信一致と、全位置で単一候補が連続する場合だけ範囲を報告する。これは動的な対応候補であり、命令解析によるデータ由来の証明ではない。単なるRAM内の一致検索で配置を断定しない。
- 06A6は入口到達後にmainが協力し、受信順の入力との一致、送信完了数、サブ受信数、配置候補、戻りAと各入力の一致を残す。全戻りレジスタは入力との一致・基準腕との一致・2走の一致へ縮約する。mainが送信途中でもサブが帰還すれば後続送信を打ち切る。
- 生ログ・ROMコピー・媒体・生レジスタの一時ファイルは成功／失敗とも削除する。残すのは器具ラベル、実行状態、値なし行・関係・集計、およびビルドした計測コアとビルド記録。実時間上限で強制終了し観測終端がない場合は欠測とし、フレーム上限で正常に観測を閉じた未帰還と区別する。

## 自己検査

`tools/b88a2_selftest.sh` はPC88_REF_*および外部の腕選択・故障注入設定を除去し、一時ディレクトリで全27腕×2走を実行する。既存自作ROMの未実装入口による未帰還を成功と偽らず、0263の先行処理未帰還を分ける。続いてブート完了後に自作コードだけを配置し、既知のIFF1・IFF2・IM、保留IRQとEI遅延、1・2バイト通信と順序反転・途中帰還、FDCコマンド9バイト・データ256バイト・結果7バイト・配置範囲を実走確認する。破壊・重複書込み・途中上書き・結果の部分受信・11段階それぞれの未帰還・再起動・時間上限・ログ破損・許可外の値列を陰性対照とする。生ログ削除後の再集計一致と後片付けも検査する。

クラウド実行例（PC88_REF_ROM_DIRは非公開環境で利用者が設定、出力先は未使用パス）: `bash tools/b88a2_selftest.sh && bash tools/b88a2_run.sh /tmp/b88a2-run`
