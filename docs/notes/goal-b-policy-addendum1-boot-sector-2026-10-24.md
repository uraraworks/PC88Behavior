# ゴール B 方針 追補1 — 起動用セクタの受け渡しまで線を引き直す

記録日: 2026-10-24
位置づけ: [goal-b-policy-2026-10-24.md](goal-b-policy-2026-10-24.md) の後続。方針ノート本体は書き換えない。
このノートより前の日付で、起動用セクタの受け渡しを測った測定コミットは存在しない。

---

## 1. 経緯

[b1-g1-demand-results.md](b1-g1-demand-results.md) で、自作 ROM 上の G1 は RAM 上の命令を1つも
実行しなかった。原因は不具合ではなく、**自作 ROM の配布ビルドに「起動用セクタ (0,0,1) を読んで
実行する」処理が無い**ことだった（起動時の READ は検査用ビルド `--enable-main-sub-read` だけにある）。

この先は、2026-09-25 に利用者と決めた線の向こう側にある。
[l3-disk-format.md](../spec/l3-disk-format.md) 第4節:
「これより先は ROM の内部の入口を探すことに近づくので進めない」。
当時はゴール A（データディスクだけ）が目標で、起動できる空の媒体を作る理由が無かった。

## 2. 決定（2026-10-24 利用者と）

**起動用セクタの受け渡し**——ROM が起動用セクタを RAM のどこへ読み込み、どんな状態で制御を渡し、
戻ったらどこへ行くか——を、**自作のセクタのコードで測る**ところまで線を引き直す。

これは ROM の内部ではなく、「媒体 → RAM → 実行」という外から観測できる受け渡しである。
市販ソフトは必ずこの受け渡しを通って動き始めるので、ゴール B の最初の需要になる。

## 3. 測ってよいもの

刺激はすべて自作する。媒体は [l3-disk-format.md](../spec/l3-disk-format.md) の規則で作る
自作媒体で、(0,0,1) に自作の短いコードを置く。そのコードが自分で測って、自分の領域に書き残す。

1. **読み込み先**: コード自身の番地（`CALL` の直後で `POP` する等、自分の位置を自分で知る）
2. **入口のレジスタ**: 入った直後の AF・BC・DE・HL・IX・IY・SP、割り込みの許可状態
3. **戻り先**: スタックの先頭2バイト（＝ `RET` したときに行く番地）**だけ**。戻った後に ROM の
   どこへ進んだかは、境界の記録器具（53986de）の RAM→ROM の飛び込み型として番地だけ取る
4. **読み込まれた量**: 他のセクタに自作の目印を置き、それが RAM のどこに現れるかを、
   コードが自分の領域の続きを調べて確かめる。あわせて、ROM が RAM へ書いた番地の範囲を
   書き込み記録（番地のみ）で取る
5. **戻らなかったとき**: コードが戻らずに止まる腕で、ROM がその後に何かを要求するか
   （入出力ポートの列。値はこれまでどおり伏せる）

読み出しは、コードが書き残した領域をハーネスの書き込み記録で取る。書き残すのは
自作コードが作った値（自分の番地・レジスタ・目印の位置）だけである。

## 4. 測らないもの（新しく足す線）

- **自作コードから ROM 領域を読まない。** 起動用セクタのコードは、自分のセクタ・自作の目印の
  範囲・スタックの先頭2バイト以外のメモリを読まない。ROM のバイト列を RAM へ写す、ROM の番地を
  呼んで返り値を見る、はしない（後者はゴール B の働きの測定として、番地ごとに別の事前登録で扱う）
- **スタックの2バイト目より奥を読まない。** 奥には ROM の内部の呼び出しの連なりが積まれている。
  戻り先1つは受け渡しの一部だが、その奥は ROM の内部の構造である
- **入口のレジスタの値が指す先を読まない。** HL などが番地らしい値を持っていても、その番地の
  中身は読まない（値そのものは受け渡しの観測として記録してよい）
- ゲームのディスクは使わない。この追補の測定は自作媒体だけで閉じる
- 方針ノート第4節の「記録しないもの」はすべてそのまま

## 5. 範囲の外（この追補でも扱わない）

- 起動用セクタの**中身による分岐の規則**の全体（どの値なら戻るか等）。9/24 の掃引で分かった
  ことは使うが、新たに中身を総当たりで掃引することはしない。要る場合は別に事前登録する
- 2セクタ目以降の読み込みを ROM に頼む手段（ROM の番地を呼ぶこと）。それはゴール B の
  「番地の働き」の測定で、番地ごとに事前登録する
- 自作 ROM への実装。測定と仕様書（[l3-disk-format.md](../spec/l3-disk-format.md) か新しい節）が先で、
  実装はそのあと

## 6. 順序

1. この追補のコミット
2. 起動用セクタの測定の事前登録（腕・自作コードの仕様・判定・記録の白リスト）
3. 器具の自己検査（自作コードが自分の番地・レジスタを正しく書き残すことを、公式 ROM を使わず
   自作 ROM の検査用の起動で確かめる。陰性対照つき）
4. 公式 ROM での測定 → 結果ノート → 仕様書 → 自作 ROM への実装
