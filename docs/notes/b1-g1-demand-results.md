## 5.2 公式と自作

- 自作 ROM の走は `instr: ram=0`（RAM 上の命令が1つも実行されない）。ROM 内に留まり、
  ゲームのコードへ一度も制御が移らない = 「早期停止」に該当。A・B・C は空。
  公式との集合差は O−S がそのまま全部（A 8 番地、C 16390 番地）で、S−O は 0。
  「別の番地へ飛ぶ」の分析は成立しない（飛ぶ前に止まっている）。
- 画面の署名比較（official-1 対 self-1）: **不一致**。

## 5.3 ROM のデータ読み（B）

公式でも 0 番地（ゲームが ROM 領域をデータとして読んだ記録なし）。区間なし。

## 5.4 共有 RAM 番地（C）

公式で 16390 番地。区間は 847D-8481（5）・84A2・84B0・84B3・84B6・84B9・84BE-84C0（3）・
C000-FFF8（16377 番地）。ROM 読み 16376・ROM 書き 16390・RAM 読み 16390・RAM 書き 16390 番地。
大半は C000 以降の連続域（ROM 側コードと RAM 側コードの両方が書く領域）。847D-84C0 の
小さな塊が個別のワーク番地の候補。
