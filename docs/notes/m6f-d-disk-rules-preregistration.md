# m6f-d — 割り当ての規則、自作ファイルの読み込み、ディレクトリの広がり、予約の印、起動 — 事前登録

記録日: 2026-09-25  
状態: 測定前

## 0. 位置づけと担当

[m6f-c 結果](m6f-c-blank-disk-acceptance-results.md) §8 の次稿である。m6f-c は空の媒体の受け入れまで
決めたが、割り当ての規則（単位・鎖・終端・先頭単位の欄）は、割り当て表の位置 160 以降に ROM が
書いた不定値が「変わった位置」に混ざって導出できなかった。あわせて、自作のファイルを公式ROM が
読めるか、ディレクトリの広がり、予約の印、起動できる媒体（利用者と決めた段階1）を測る。

**担当**: m6f-c と同じセッション（`make_n88_blank_disk.py`・QUASI88 `src/image.c` を読んでいない）。
ただし [汚染の記録 2026-09-25](contamination-2026-09-25-fat-buffer-overrun-values.md) により、
このセッションはディスクBASIC の**割り当て表バッファまわりの実装**からは外れている。本稿は
測定と仕様書であり、その実装には当たらない。委譲先にも同じ禁止を渡す。

**既知の値を前提にしない。** 予約の印は全値を掃引する。§5 の観察は「仮説」として置き、
測って確かめる。

### 0.1 出力の制限（汚染の再発防止）

- 割り当て表の値を出力・記録してよいのは**位置 0〜159 だけ**。位置 160 以降は一切出力しない
  （「変わったか」も使わない）。
- 本体のセクタの中身は出力しない。付け替え（§4.2）は器具の中で写すだけにする。
- エントリは、名前欄（自分で与えた名前）と 9〜15 バイト目だけを出力してよい。
- 生の像・入出力ログ・結果は `PC88/tmp/m6fd-work/` に置き、リポジトリへ入れない。

## 1. 問い

- **D-I 割り当ての規則**: 単位の大きさと位置の対応、鎖、終端の値、エントリの先頭単位の欄。
- **D-II 自作ファイルの読み込み**: 仕様の仮説どおりに組み直したファイルを、公式ROM が
  `INPUT #`・`LOAD` で読めるか。
- **D-III ディレクトリの広がり**: どのセクタのエントリを ROM が名前で見つけるか。未使用（0xFF）の
  エントリで探索が止まるか。
- **D-IV 予約の印**: 割り当て表のどの値を「使用中」とみなすか。トラック18のヘッド1の単位
  （74・75）に印が要るか。
- **D-V 起動**: (0,0,1) を読めない媒体で、公式ROM がディスクBASIC として立ち上がるか。

## 2. 媒体と構成

**基本の媒体 B0**（仕様書 第2版 §4）: 割り当て表の3セクタは全バイト 0xFF、(18,1,13) は全バイト 0x00、
それ以外は全バイト 0xFF。生成器 `make_m6fc_blank_disk.py`（`--sector-fill` 等）を使い、足りない
規則は同じ生成器に足す。

**構成**（D-I〜D-IV）: m6f-c 追補2と同じ。ドライブ1に参照 diskA の複製（書き込み保護は解除しない、
G8 で不変を確かめる）、ドライブ2に媒体。打鍵のファイル名は `2:` 付き。FDC コマンドは装置番号1
だけを数える。**D-V だけは、ドライブ1に媒体を入れ、ドライブ2は空。**

打鍵は小文字、目印は `print chr$(90);chr$(81);"xx"`（以下 `ZQ"xx"`）、`90` 行は m6f-c と同じ誤り処理。
各腕2走。

## 3. §5 の観察から置く仮説（D-II・D-III・D-IV の器具が使う）

- **H1** 番号 k の単位は、線形番号 L=(C×2+H)×16+(R−1) が 8k〜8k+7 のセクタ。
- **H2** 単位 k の割り当て表の値 T[k] が 160 未満なら、ファイルの次の単位の番号。160 以上なら
  その単位が最後で、値は終端の値。
- **H3** エントリの 10 バイト目がファイルの最初の単位の番号。

## 4. 腕

### 4.1 D-I 割り当ての規則の測り直し

媒体 B0。打鍵は m6f-c の A3・A4 と同じ（`2:` 付き、名前 `QZ7B`、記録
`right$(str$(100000!+i),5);string$(120,"v")` を n 件書いて読み戻す）。

| 腕 | n | フレーム数 |
|---|---:|---:|
| I-250 | 250 | 30000 |
| I-1・I-3・I-6・I-10・I-17 | 1・3・6・10・17 | 12000 |

### 4.2 D-II 付け替えたファイルの読み込み（2段の腕）

1段目で ROM にファイルを書かせ、器具が**仮説 H1〜H3 で**そのファイルを読み解いて、新しい B0 へ
別の名前・別の単位で組み直す。2段目で ROM に読ませる。

- **付け替えの規則**: 1段目の像のドライブ2から、エントリ（名前で探す）の 10 バイト目を先頭として
  H2 で鎖をたどり、各単位の 8 セクタを H1 で写す。新しい媒体では、単位を指定した列に並べ直し、
  T[新しい kᵢ] = 新しい kᵢ₊₁、最後の単位は**元の終端の値をそのまま**入れる（3セクタとも同じ）。
  エントリは (18,1,1) の先頭に置き、名前を差し替え、10 バイト目を新しい先頭にし、9・11〜15 バイト目は
  元のまま写す。器具は写したバイトを出力しない。

| 腕 | 1段目（打鍵） | 付け替え先 | 2段目（打鍵） | 期待 |
|---|---|---|---|---|
| II-d | I-17 と同じ（`QZ7B`、17 件） | 名前 `QZ7R`、単位 [20, 5] | `QZ7R` を 17 件読み、不一致数を `ZQ"rb"` | `ZQrb 0` |
| II-p | `10 ZQ"ld"` を `save"2:q7l"` | 名前 `q7r`、単位 [30] | `load"2:q7r"` → `run` | `ZQld` |
| II-neg1 | II-d と同じ | II-d と同じだが T[20]=0xFF（鎖を切る） | II-d と同じ | `ZQrb 0` にならない |
| II-neg2 | II-d と同じ | II-d と同じだがエントリの 10 バイト目を 21 にする | II-d と同じ | `ZQrb 0` にならない |

2段目のフレーム数は 12000。II-neg1・II-neg2 は、器具が読み込みの失敗を見分けられることの陰性対照。

### 4.3 D-III ディレクトリの広がり（2段の腕）

1段目は I-1 と同じ（`QZ7B` に 1 件）。付け替えで、名前 `QD` ＋ 2 桁の r（例 `QD07`）のエントリを
**(18,1,r) の先頭**に置き、単位 [20] に写す。(18,1,1) の元のエントリは置かない。

| 腕 | 置く場所 | 他のディレクトリ候補 (18,1,1)〜(18,1,12) の中身 |
|---|---|---|
| III-FF-rr（r=1〜12） | (18,1,r) | 0xFF のまま（未使用のエントリ） |
| III-00-rr（r=1〜12） | (18,1,r) | 置いたエントリ以外を全バイト 0x00（削除済みのエントリ） |
| III-none | 置かない | 0xFF |

2段目の打鍵: `f$="2:"+（QDrr の符号）` を `open … for input`、1 件読んで通し番号が 1 なら `ZQ"ok"`、
違えば `ZQ"ng"`、誤りは 90 行。フレーム 8000。III-none は `QD01` を探す（陰性対照、`ZQer` を期待）。

### 4.4 D-IV 予約の印

**IV-R（R=0x00〜0xFF の 256 腕）**: B0 の割り当て表の3セクタを、位置 20 だけ 0xFF、他の全位置を R に
する。打鍵は m6f-c の SW（`2:` 付き、`QZ7A` を作って 1 件書き、読み戻す）。フレーム 8000。

**IV-fill（2腕）**: 媒体は B0（IV-fill-free）と、B0 の割り当て表の位置 74・75 を R\*（§5 D4）にしたもの
（IV-fill-res）。打鍵:

```
10 on error goto 90:for n=1 to 200:f$="2:"+chr$(81)+right$(str$(1000+n),3):open f$ for output as #1:print #1,"x":close #1:next
20 print chr$(90);chr$(81);"nf":goto 100
90 print chr$(90);chr$(81);"fe";err;n:resume 100
100 on error goto 190:f$="2:"+chr$(81)+"001":open f$ for input as #1:input #1,a$:close #1:print chr$(90);chr$(81);"ck";-(a$="x"):end
190 print chr$(90);chr$(81);"cx";err:end
run
```

フレーム 60000。入出力ログは導出に使わないので、取りこぼしは記録して続ける（m6f-c §5.2 と同じ扱い）。

### 4.5 D-V 起動

ドライブ1に媒体、ドライブ2は空。媒体は B0 の (0,0,1) だけを次のように変える。

| 腕 | (0,0,1) |
|---|---|
| V-missing | トラック (C=0,H=0) に R=1 のセクタが無い（R=2〜16 の 15 セクタ） |
| V-crc | D88 のセクタ状態をデータ CRC エラー（0xB0） |
| V-deleted | 削除マーク付き（0x10） |
| V-single | 単密度（0x40） |
| V-ff（対照） | 読める。全バイト 0xFF（m6f-c では読み続けた） |
| V-c9（対照） | 読める。全バイト 0xC9（m6f-c では非ディスクBASIC） |

打鍵（フレーム 700）: `print chr$(90);chr$(81);"bt"\n10 on error goto 90:open "qz" for output as #1:print #1,"x":close #1:print chr$(90);chr$(81);"ok":end\n90 print chr$(90);chr$(81);"er";err;erl:end\nrun\n`。
フレーム 8000。

## 5. 導出規則

用語: T = 測定後の像のドライブ2の (18,1,14)、**P = { k : 0 ≤ k ≤ 159、T[k] ≠ 0xFF }**。
本体のセクタ・書いたセクタ・線形番号は m6f-c と同じ。

### 5.1 補足（測定前、2026-09-25、1回目の停止を受けて）

1回目（器具 `a26fe77`、G1 rc=0）は、I-\* の6腕の後、IV-fill 以外の腕で入出力ログの取りこぼし
（6381 万件）が出て `gate_failed run_summary` で止まった。器具が止まった腕を記録しておらず、
どの腕かは分からない（結果は見ていない。1回目は捨てる）。

**入出力ログの座標を導出に使うのは I-\* の腕だけ**（D3 の u）で、D-II〜D-V は目印とエントリの欄
だけを使う。そこで、取りこぼしで止めるのは I-\* の腕だけとし、他の腕は取りこぼし数を記録して
座標を null にする（m6f-c §5.2 と同じ理屈）。止まったときは腕と走の番号を理由に含める。

**D1 単位と位置**（I-250）: m6f-c C4 と同じ規則を、P を上の定義にして適用する。あわせて
(18,1,15)・(18,1,16) の位置 0〜159 が T と同じかを記録する。

**D2 鎖**（I-250、D1 が derived）: m6f-c C5 と同じ。

**D3 終端**（I-* の6腕、D1 が derived）: m6f-c C6 と同じ（`end_constant` / `end_plus_used_sectors` /
`end_other`）。u は最後の単位の**書いたセクタ**の数。各腕の e と u を記録する。

**D4 先頭単位の欄**（I-* の6腕）: m6f-c C7 と同じ（0 始まり 10〜15 のうち k₁ と等しい位置）。

**D5 付け替えの読み込み**: II-d が2走とも `ZQrb 0`、II-p が2走とも `ZQld`、かつ II-neg1・II-neg2 が
2走とも `ZQrb 0` でない、なら `relocated_readable`（H1〜H3 が読み込みの規則として正しい）。
II-d・II-p のどちらかが通らなければ `not_readable`。陰性対照が `ZQrb 0` になったら `control_failed`。

**D6 ディレクトリの広がり**: 変種（FF・00）ごとに、2走とも `ZQok` だった r の集合を記録する。
- 00 の変種で見つかった r の集合を**ディレクトリのセクタ**とする（連続でなくてもそのまま記録）。
- FF の変種で、00 の変種では見つかったのに見つからなかった r があれば `stops_at_unused`
  （未使用のエントリで探索が止まる）、無ければ `scans_past_unused`。
- III-none が `ZQer` でなければ `control_failed`。

**D7 使用中とみなす値**（IV-R）: 2走とも `ZQok` で、かつエントリの先頭単位の欄（D4 が derived なら
その位置、でなければ 10 バイト目）が 20 だった R の集合 Rused。R=0xFF は Rused に入らないことを
期待する（入れば `control_failed`）。
**R\*** = Rused のうち 0xA0 以上 0xFE 以下で、D3 で観測した終端の値のどれでもない最小の値。
無ければ Rused の最小値。Rused が空なら IV-fill-res は回さない。

**D8 予約の印の要否**（IV-fill）: 各腕の `fe` の ERR と件数 n、`ck` の値（1 ならエントリが無事）を
記録する。
- `reserve_needed`: IV-fill-free で `ck 1` が出ない（`cx` または `ck 0`）、かつ IV-fill-res で `ck 1`。
- `reserve_not_needed`: 両方で `ck 1`。
- それ以外は `reserve_other`。

**D9 起動**: 各腕を `disk_basic`（`ZQbt` と `ZQok`）、`nondisk_basic`（`ZQbt` のみ、`ok`・`er` なし）、
`error_after_boot`（`ZQbt` と `ZQer`）、`no_basic`（`ZQbt` なし）に分ける。V-missing〜V-single のうち
2走とも `disk_basic` の腕の集合を記録する。対照 V-ff が `no_basic`、V-c9 が `nondisk_basic` で
なければ `control_changed` と記録する。

2走で結果が一致しない導出は `ambiguous`。

## 6. 関門

m6f-c の G1〜G8 を引き継ぐ。G1（全自己検査、`PC88_SELFTEST_EXCLUDE` で2本を除外）は腕の前に親が1回。
加えて:
- **G9 出力の制限**: 導出器・付け替えの器具の出力（標準出力・結果・導出）に、割り当て表の位置
  160 以降の値と本体のセクタの中身が含まれないことを、自己検査で確かめる（合成媒体の該当範囲に
  目印のバイト列を置き、出力に現れないこと。陰性対照つき）。
- **G10 付け替えの器具の自己検査**: 合成媒体で、仮説 H1〜H3 に従うファイルを正しく組み直すこと、
  鎖が壊れた入力を拒否すること。
- コアの abort（rc=134）は m6f-c 追補3 §3.1 と同じく最大2回回し直す（全ドライバで）。

## 7. 判定名

- `gate_failed`
- 各導出: `derived` / `ambiguous` / `not_found` と上の固有名
- 総合: **`m6f_d_rules_confirmed`**: D1〜D4 が derived、D5 が `relocated_readable`、D6 の 00 の変種で
  1 つ以上見つかった。そうでなければ **`m6f_d_incomplete`**。D7〜D9 は個別に記録する。

## 8. 行き先

- `m6f_d_rules_confirmed`: 仕様書 第3版に、割り当ての規則（D1〜D4）、ディレクトリの広がりと探索の
  止まり方（D6）、予約の印（D7・D8）を規則として起こす。D9 で `disk_basic` の腕があれば、起動できる
  空の媒体の作り方として書く。無ければ「公式ROM で起動できる空の媒体は作らない（データディスク
  だけ）」と書く（利用者と決めた段階2）。
- `m6f_d_incomplete`: 決まらなかった導出の分布を記録し、追補を置く。

## 9. 決まらないこと

- 順次ファイル・プログラムの本体の保存形式（本稿は写すだけで中身を見ない）。
- (18,1,13) のどのバイトが書き込み禁止の印か。
- エントリの 11〜15 バイト目の意味。
- ドライブ1で同じ規則が成り立つか（D-V はドライブ1の媒体を使うが、測るのは起動だけ）。
