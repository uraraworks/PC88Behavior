# B73: G1 の F1 の道で、`0x0E` の前後のサブの ROM 側の動きを公式と自作で比べる — 事前登録

記録日: 2026-11-02
位置づけ: [B72](b72-sub-request-0e-followups-preregistration.md) の器具を作る途中で、自作のプローブでは `0x0E` のあとの `0x15`・`0x0D` を自作も受けられると分かった。G1 の場面では何が違うかを直接測る。**このノートは測定より先にコミットする。**

## 1. 問い

B65 の F1 の腕で、`IN $FC` の番号 112680〜112830 のあいだ、サブの ROM 側は公式と自作でそれぞれ何をするか。

## 2. 器具

- B51 の `--sub-rom-access-log`（窓 112680,112830）を公式・自作の両方で。値は持たない
- io ログ（窓の前後のフレーム）から、サブが FDC へ出したコマンドの**名前の並び**だけを出す（引数は出さない）。G1 の要求の値に当たるため

## 3. 条件

B65 の F1 の腕と同じ。公式 2 走、自作 2 走。クラウドの実行環境で行う。

## 4. 記録の白リスト

- B51 と同じ `A` の行に腕（`O`・`S`）を付けたもの
- `fdc <O|S> <コマンド名の並び>`

## 5. 判定（事前に決める）

- 自作も `4000-4FFF` を書くか、FDC のコマンドの並びが公式と同じかを書く
- 違う所の前後を、そのまま書く。原因は断定しない
