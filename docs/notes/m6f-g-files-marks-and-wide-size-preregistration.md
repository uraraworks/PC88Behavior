# m6f-g — FILES の種別の印（0xA0・0x01）と3桁の大きさ — 事前登録

記録日: 2026-09-27  
状態: **測定前**

## 0. 位置づけ

l4-basic.md 第11節の未確定のうち、(a) 種別バイトが `0x80`・`0x00` 以外のときの印、(b) 大きさが3桁のときの表示を測る。
(a) の値は m6f-f で測った `SAVE ,P`＝`0xA0`、`BSAVE`＝`0x01`（l3-disk-format.md 第4版）に限る。ほかの値は測らない。

構成・器具・関門は m6f-e 本体と同じ（ドライブ1＝参照 diskA 複製で起動、ドライブ2＝自作媒体、`CLS` 基準の後に `CLS:FILES 2`、
行別署名だけを残す、G0〜G14）。媒体は m6f-e の生成器に種別バイトと大きさを指定できるモードを足して作る（名前は自分で決めた ASCII）。
**打鍵の文字列リテラルは小文字で画面に届く**（m6f-a 結果 (i)。m6f-e 追補3の失敗を繰り返さないため、打鍵をそのまま予測に使う腕は置かない）。

## 1. 問い

- **G-I**: 種別バイト `0xA0`・`0x01` のエントリを `FILES` がどう表示するか（印の文字、表示しない、大きさの有無）。
- **G-II**: 大きさ（割り当て単位の数）が 100 以上のときの表示。

## 2. 候補

セルの規則（名前欄先頭6バイト、印1文字、名前欄末尾3バイト、空白1つ、大きさの10進、16桁セル×5件、l4-basic.md 11.1）は既知として固定し、
次だけを振る。

### 2.1 G-I（種別ごとに 191 候補）

- `mark_<XX>`: 印が文字コード `XX`（`0x20`〜`0x7E` の 95 通り）で、大きさを表示する。
- `mark_<XX>_nosize`: 印が `XX` で、空白と大きさを表示しない（95 通り）。
- `hidden`: そのエントリを表示しない（件数・配置からも除く）。

### 2.2 G-II（2 候補）

- `size_min_digits`: 大きさを最小桁数の10進で表示する（m6f-e で1桁・2桁まで確認済みの規則をそのまま3桁へ延ばす）。
- `size_other`: それ以外（どの形か特定しない。一致しなければこちら）。

## 3. 腕（各2走）

| 腕 | 媒体の生きたエントリ（ディレクトリ順） | 目的 |
|---|---|---|
| G-P | 1件: 種別 `0xA0`、1単位 | `0xA0` の印 |
| G-B | 1件: 種別 `0x01`、1単位 | `0x01` の印 |
| G-M | 5件: `0x80`・`0x00`・`0xA0`・`0x01`・`0x80`、各1単位 | 1行に混ざったときも G-P・G-B と同じ規則か（照合） |
| G-Z1 | 1件: 種別 `0x80`、100単位 | 3桁の大きさ |
| G-Z2 | 1件: 種別 `0x80`、158単位（予約74・75を除く全単位） | 3桁の大きさ（最大） |

名前は腕ごとに別の9文字（自分で決めた大文字の ASCII、媒体に直接書くので大小の問題は無い）。本体は自分で決めた一様値。
G-Z2 は割り当て可能な単位（0〜159 のうち 74・75 を除く 158 個）をすべて1つの鎖にする（l3-disk-format.md 第4版 2.3〜2.5節）。

## 4. 凍結

- 媒体の manifest の SHA-256。
- G-P・G-B・G-Z1・G-Z2 の候補ごとの行署名表（G-I は 191×2、G-II は `size_min_digits` の1つ。`size_other` は「どれとも一致しない」なので表を持たない）。
- G-M の判定に使う予測器のソースの SHA-256（G-M の予測は G-P・G-B で残った候補の組から作るため、表ではなく予測器を凍結する）。

凍結は公式ROM起動前に行い、照合に失敗したら起動回数0で止める。

## 5. 判定

- G-P・G-B: 2走とも一意に一致した候補名（例 `mark_2A`）。0件なら `inconclusive_<腕>_no_candidate`、複数なら `inconclusive_<腕>_multiple`。
- G-M: G-P・G-B の候補の組で予測した行署名と一致すれば `mixed_row_consistent`、しなければ `mixed_row_inconsistent`。
- G-Z1・G-Z2: 両方とも `size_min_digits` に一致すれば `size_min_digits`、どちらかが外れれば `size_other`。
- 関門失敗は `gate_failed`。

## 6. 行き先

`docs/spec/l4-basic.md` 11.1節の規則3（種別の印・大きさ）に追記し、11.3節の未確定から該当項目を外す。
自作 FILES の実装（`src/ext_bank/bank1.asm`・`src/l4_basic/files.asm`）を仕様に合わせ、`tools/conform_files.sh` の期待値に本稿の腕を足す。

## 7. 決めないこと

- `0x80`・`0x00`・`0xA0`・`0x01` 以外の種別バイト。
- 種別バイトのビットの意味。
- `LFILES`。
