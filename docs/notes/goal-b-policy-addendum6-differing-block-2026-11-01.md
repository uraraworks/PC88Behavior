# ゴール B 方針 追補6 — G1 の違いの前の要求と、違う先頭だけを記録する

記録日: 2026-11-01
位置づけ: [追補5](goal-b-policy-addendum5-first-request-bytes-2026-11-01.md) の後続。これまでのノートは書き換えない。

[B30](b30-g1-space-key-results.md) の 257 バイトの違いの正体を決めるため、2026-11-01 に利用者と次の線まで記録してよいと決めた。

**記録してよいもの: 最初に違う `IN $FC` の直前の `OUT $FD` の連続（末尾 64 バイトまで）と、違う箇所の先頭 8 バイトの公式と自作の値。**

**データの本体だった場合は破棄する。** これを事後でなく事前に実行する。器具が先に、公式の 256 バイトをディスクのセクタと比べ、一致すれば値を出さず座標だけを出す。

働きは今までどおり自作のプローブで測る。
