# B63: キーを長く押すと自作でも反応するか、起動時のポートの設定が公式と同じかを測る — 結果

記録日: 2026-11-02
規則: [b63-g1-key-hold-and-ports-preregistration.md](b63-g1-key-hold-and-ports-preregistration.md) どおり。測定はクラウドの実行環境で rc=0。値と画面本文は記録していない。記録は `measurements/b63-g1-key-hold-and-ports.txt`。

## 長押し（60 フレーム）

| キー | 画像 | テキスト | 移る回数 公式 / 自作 |
|---|---|---|---|
| `i` | 同じ | 同じ | 87 / **87** |
| F1 | 同じ | 同じ | 72 / **72** |
| `2` | 違う | 同じ | 71 / 71 |
| なし | 同じ | 同じ | 71 / 71 |

**長く押すと、自作でも `i` と F1 に公式と同じに反応した。**

## ポートの最後の値（3600 フレーム、打鍵なし）

main が `OUT` したポート 39 種のすべてで、最後の値は公式と同じだった。回数は `31`・`32`・`50`・`51`・`71` で自作が多い（14→104 など）。`44`・`45`・`E4`・`FD`・`FF` は数百の差がある。

## 読み方（推定）

- 自作でキーが効かなかったのは、短い押下（既定の押下時間）を G1 が読む時刻に公式と自作で差があるためと考える。押下が長ければ同じに反応する
- B62 でフレーム 7000 の時点の main の位置が違ったことと合う。起動のどこかで、公式と自作の時間の進み方がずれている
- ポートの最後の値はそろっている。回数の差（`31`・`71` など）は自作の ROM の起動の手順の違いと考える
- `2` は長押しでも画像が違う。時刻の差で、押している間に動く量が違う可能性がある

B64 で、押す時刻を 1 フレームずつずらして、公式と自作の結果が「ずれた時刻どうし」で一致するかを確かめる。
