## 見立てと事前の予測

追補1の照合は機械語から戻った後の BASIC 式評価で行ったため、一時的な数値作業域が上書きされた可能性がある。入口で照合し直す。既知番地の仮定は置かず、所在地は測定だけで決める。候補符号化は既存器具の整数・MBF整数生成規則に基づく自作値。候補の一致以外のRAM値を出力しない。

較正2腕と次の13腕、計15腕をそれぞれ独立起動で2走する。数値は int / single / double 各4腕。

|末尾|入力の形（型ごとに接尾辞なし / ! / #）|介入|予測・用途|
|---|---|---|---|
|expr12345|usr0(12000+345)|なし|A=02/04/08、12345候補あり、23456候補0件|
|expr23456|usr0(23000+456)|なし|逆方向クロス対照。23456候補あり、12345候補0件|
|variable|x%=12345 等を用意し usr0(x%) 等|なし|変数保持分の一致が増える仮説|
|mutate|expr12345と同形|主候補がちょうど1件なら1234へ全長書換|戻り値1234、返却型が入口型のままという仮説|
|string-expr|usr0("t4"+"own")|なし|A=03。長さ5で参照先がt4ownの記述子を探索。先頭一致番地と入口DEとの差0を仮説|

数値腕の実際の呼出しは `y=usr1(usr0(式))`。usr1は別の自作ルーチンで入口Aだけ保存してRETするため、yへの代入による型変換より前にUSR0の返却型を観測する。数値腕はUSR0とUSR1の定義を段1、呼出しを段2とする。文字列は段1定義・段2呼出し。

## 入口走査と除外

入口A/BC/DE/HL/SPを自作印へ保存した直後、AF/BC/DE/HLをスタック保護して走査する。終了時はレジスタ・フラグ・SPを復元する。自作コード由来のスタック退避値が一致する可能性もあり、件数だけで引数作業域と断定しない。

候補開始番地を0x8000から昇順に全探索する。候補の全長が0xFFFFまでに収まるときだけ読む。0x0000〜0x7FFFは読まない。0xC000〜0xC35Fに一部でも重なる候補開始位置を除く。コードは0xC000から最大277B、候補は0xC280/0xC290、器具内部ポインタは0xC2A0、返却型採取コードは0xC2E0、観測印は0xC300〜0xC35F。候補置場は予約域に含まれる。

数値は主候補・異値候補を各1回走査する。文字列記述子は開始位置の3Bを照合し、参照先がRAM内で5B全部を読め、予約域と重ならない場合だけ自作文字列と比較する。ROM参照先は照合しない。記述子自体の3Bを生出力しない。

各候補の件数は255で飽和し、最初の4件の番地だけ記録する。未検出の番地欄は初期値0であり、観測された番地ではない。照合と介入が終わってから機械語完了印219を書きRETする。介入は主候補の件数がちょうど1件の場合のみ。複数一致は不明のまま、最初の1件を恣意的に変更しない。異値候補の走査も介入前に行う。

待ち時間の保守的見積りは、数値2走査で65536開始候補未満×最悪約1000T（8B比較・件数記録を含む）=約6554万T、4MHzで約16.4秒。文字列は1走査で同じ上限を下回る。実行後待ちは公式36000フレーム（60Hz換算600秒）、自作7200フレーム（120秒）。前者には既存の初期化・誤り復帰の余裕を含める。打鍵時間は別途積算。ホスト実行制限は既存の180秒。時間切れは不明とし、待ち時間を結果を見て変えて成功扱いにしない。

## 記録欄と判定

TSVは固定plan、反復番号、限定RAM書込順と最終印、段別最初/最後ERR・回数・復帰印・関門を保存する。画面本文は保存・表示しない。

|欄|意味|
|---|---|
|p21 / p22〜p29|入口A / BC・DE・HL・SP（下位先）|
|p30 / p31|実行213 / 走査完了219|
|p32 / p33〜p40|主候補件数 / 最初4件の番地（各下位先2B）|
|p41 / p42〜p49|異値候補件数 / 最初4件の番地（文字列では未使用）|
|p52〜p53 / p54〜p55|主/異値候補の最初番地−入口HL、16bit剰余（文字列は主番地−入口DE）|
|p65 / p66|数値y=1234 / y=元の引数の真偽（0/1）|
|p68 / p70|単一一致介入の実行印1 / usr1入口A＝USR0返却型|

差は事後に保存済み番地だけから計算する。生RAMの再照合はしない。件数0・エラー・未実行の場合の差や真偽の初期値は根拠にしない。符号付き差は記録値が32768以上なら65536を引いて解釈する。

同型のexpr12345とexpr23456で、主候補が各1件、両方向クロス0件、両走一致し、主候補番地が同じなら値に依らない置き場を支持する。違えば今回の置き場仮説を棄却し偶然候補として扱う。複数一致・クロス一致は場所未確定。variableの増分も対照であり、一時作業域を確定する単独証拠にはしない。

介入腕は非介入腕の場所判定と併せ、主候補1件・p68=1・当該段ERR0・復帰77・走査完了219・p65=1が揃って初めて書換の効力ありとする。返却型はp70を入口p21と比較し、yの代入型から推測しない。文字列では最初番地のDE差と、先頭4件中にDE自体があるかを区別する。

## 関門・自己検査

measure冒頭で毎回、第1回・追補1の固定署名と従来の陽性/陰性検査に加え、追補2の固定署名、実生成Z80を動かす合成検査を実施する。公式ROMは合成器に入力しない。既知番地の陽性、候補なし0件、255飽和、末尾境界・予約域除外、全長書換、0件/複数件で介入なし、レジスタ/フラグ/SP復元を確認する。記述子の陽性・不一致・ROM側参照先・末尾越境の陰性も検査する。

実際のZ80実行で得た陽性の印を正常な段列に差し込み関門通過を確認し、完了印だけ削る陰性と、件数・番地だけを壊す陰性が狙いの判定で落ちることを確認する。入力行は全行80文字未満、打鍵総数は8192以下（最大2784）。測定は打鍵拒否・取落し・書込順・初期化・段/ERR整合・完了・600フレーム安定・較正・2走同一を要求する。関門落ちの画面比較欄だけを無効化し、ERR履歴は保持する。完了しない腕は不明。

自作ROMではUSR未実装のため、機能の予測を自作のERRに合わせない。自作試走は全腕の捕捉関門通過だけを確認し、機能一致とは数えない。
