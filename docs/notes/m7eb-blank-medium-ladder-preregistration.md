# m7eb: 自作空フォーマット媒体によるディレクトリ拡張ラダーの事前登録

実施日: 未実施（本稿は事前登録のみ）

本稿は`m7ea`で容量端点N=52に阻まれた後続周期を、公式diskAとは独立に生成する自作の
空フォーマット媒体で検査する手順を固定する。測定、媒体生成、N=0校正はまだ行わない。
`m7dv`と`m7dy`の整数完全一致規則を引き継ぎ、実測後に条件、上限、閾値、比較対象を
変更しない。`src/`は変更しない。

公式ROM・公式ディスクの内容、画面本文、データポート値列は表示・転記しない。公式ROMは
測定器へパスで渡すだけとし、`private/`を開かない。自作媒体、生ログ、画面報告、媒体複製、
チェックポイント、manifestは全てリポジトリ外で扱う。

## 仮説と識別境界

- **H-P（同一管理範囲内の定常費用）**: 追加した自作ファイルが同じ管理範囲へ収まる間、
  固定不存在OPENのmain `IN $FC`件数、READ単位、FDCコマンド種別列は同じで、隣接差分は
  0になる。非0の一定差分が反復する場合も、同じ1本当たり費用であり新しい境界とはしない。
- **H-X（管理範囲拡張）**: あるNで新しい管理読出し範囲へ跨ぐと、main `IN $FC`または
  READ単位が正方向へ跳ね、公開FDC列にREAD、場合によってはSEEK等の追加が現れる。その後は
  次の境界まで新しい水準へ留まると予測する。
- **H-M（媒体不変）**: 確認済みジャンプの間隔Pと増分ベクトルVは媒体によらず同じである。
  公式diskA系列で確定した比較値は`P=16`、`V=(+258,+1)`である。
- **H-M'（媒体依存）**: 確認済みジャンプの間隔Pまたは増分ベクトルVの少なくとも一方が
  媒体によって変わる。

H-MとH-M'は実測前に分離し、どちらの結果もそのまま受け入れる。自作媒体ではジャンプ系列を
N=0から新しく観測し、公式媒体のジャンプ位置11,27,43を候補位置、予測位置、確認位置として
持ち込まない。絶対位置は初期占有に依存し得るため、媒体間で比較するのは**確認済みジャンプの
全隣接間隔と全増分ベクトルだけ**である。

## 自作空フォーマット媒体の生成と固定

### 採用する生成方法

既存`tools/make_l3_testdisk.py`は、公開D88コンテナを公式媒体なしで決定論的に生成する点は
再利用できる。しかし生成物は8シリンダ・片面のL3読出し検証用規則媒体であり、N88-BASICの
ファイルシステムを持たないため、本ラダーのN=0媒体には採用しない。

第10段で専用の`tools/make_n88_blank_disk.py`を作り、次の公開規則だけから新規生成する。

1. D88の32バイトヘッダ、164本のトラックオフセット表、セクタごとの16バイトIDとデータを
   `make_l3_testdisk.py`と同じ機械生成方式で書く。
2. GPL第三者実装QUASI88の公開
   `vendor/quasi88-libretro/src/image.c`にある`d88_append_blank`と`d88_write_format`の
   規則を固定して使う。媒体種別は2D、40シリンダ・両面の先頭80物理トラック、各トラック
   16セクタ、各セクタ256バイト、書込み保護なしとする。QUASI88のブランクD88と同じく
   84トラック分の固定領域を確保し、N88-BASICデータディスク用の公開初期値を先頭80トラックへ
   決定論的に配置する。
3. 通常セクタ、管理用セクタ、未使用トラックの各初期値は上記公開生成規則へ完全一致させる。
   公式媒体を入力、複製元、差分元、テンプレートのいずれにも使わない。

生成コマンドは次の2回へ固定する。生成器に入力媒体や可変形状オプションは持たせない。

```sh
python3 tools/make_n88_blank_disk.py "$PC88_M7EB_WORK_DIR/generation-a/N88_BLANK.D88"
python3 tools/make_n88_blank_disk.py "$PC88_M7EB_WORK_DIR/generation-b/N88_BLANK.D88"
```

両SHA-256と構造検査が一致した後、`generation-a`側だけをN=0原本として外部作業領域の
`checkpoints/n000.d88`へ複製し、原本を読出し専用化する。ラダーはA:へこの自作媒体だけを
装着する。公式ディスクディレクトリや公式ディスクパスを生成器・ラダーへ渡さない。

BASICの直接`FORMAT`候補は`m7cw`で構文不受理かつ`FORMAT TRACK` 0件だったため採用しない。
生成器は公開D88構造と第三者実装の公開N88-BASICデータディスク生成規則だけを入力とし、
公式ディスクの内容を1バイトも取り込まない。

### 同一性と空状態の確認

第10段の実行前に生成器の自己検査を用意し、少なくとも次をANDで要求する。

1. 別々の一時ディレクトリへ同じ固定引数で2回生成し、媒体SHA-256が完全一致する。
2. D88総サイズ、媒体種別、保護フラグ、トラックオフセット、C/H/R/N、トラックごとの
   セクタ数・サイズが上記固定規則へ完全一致する。
3. 自作したファイルシステム管理領域を同じ公開規則で検査し、使用中ファイル項目が0件である。
   自作媒体なので自作初期値は検査してよいが、画面本文や公式媒体は参照しない。
4. SHA-256、生成器の追跡コミット、固定引数をリポジトリ外manifestへ記録する。再開時は
   N=0媒体を再生成し、SHA-256一致を確認してから同一媒体とみなす。

生成器の2回一致、構造検査、空状態検査のいずれかが不成立なら、媒体を手修正せず実測前
不成立として打ち切る。生成後に初期値、形状、保護状態を変更しない。

## N=0校正

固定不存在名`QZ9X`を次の固定プログラムでINPUT OPENする。

```basic
10 ON ERROR GOTO 100
20 OPEN "QZ9X" FOR INPUT AS #1
30 PRINT "D9N":END
100 IF ERL<>20 THEN PRINT "D9N":END
110 PRINT "D9E"
120 RESUME 130
130 PRINT "D9C":END
RUN
```

N=0で`D9E`へ到達せずOPENが成功した場合、固定不存在名という介入が成立しないため、全系列を
実測前不成立として即時打ち切る。実測後に名前を変更しない。`D9E`、`D9C`、直後`Ok`、
`D9N`なし、入口I/O非0、WRITE 0、main/sub取りこぼし0件を全て要求する。

## 自作ファイルの固定規則

媒体間比較を成立させるため、`m7dv`と同じ名前生成式、作成順、空内容を使う。

```text
名前(N) = "QD" + CHR$(65 + INT((N-1)/26)) + CHR$(65 + ((N-1) MOD 26))
```

N=1は`QDAA`、固定上限N=128は`QDEX`である。各準備runはN-1チェックポイントの新しい
複製へ対象名を`OPEN ... FOR OUTPUT AS #1`し、直ちに`CLOSE #1`する。内容は書かず、
1runで1本だけを作る。KILL、上書き、順序変更、名前変更は行わない。

各作成runは固有作成マーカーと直後`Ok`、WRITE非0、媒体SHA-256のN-1からの変化、
取りこぼし0件を要求する。成立後の媒体を読出し専用チェックポイントとし、そのSHA-256を
外部manifestへ記録する。不成立runの媒体は採用せず、受理済みN-1から同じNをやり直す。

## 測定操作と観測量

測定runは`m7dv`と同じ固定不存在OPENプログラムを使う。完成チェックポイントの新しい
使い捨て複製へ保存せず、m7dvと同じ公式ROM構成で各Nを2run測る。参照ROMは
`PC88_REF_ROM_DIR`で測定器へ渡すだけとし、公式ディスクは渡さない。単一走は採用しない。

測定条件は全Nで**9000フレーム、300F/700Fの二段打鍵、300秒、512打鍵上限、同じ
ハーネス引数**へ固定する。判定区間は700F以後とし、測定runの条件を変更しない。

一次指標は次の整数対である。

```text
X_N = (700F以後のmain IN $FC件数, 700F以後のREAD単位)
```

併記する観測量も`m7dv`と同じく、main `IN $FC`/`IN $FD`の件数・SHA-256、公開FDC
コマンド種別列と総件数、READ・SEEK・WRITE件数、値を除いたイベント構造の件数・SHA-256、
隣接N間の一致prefixと最初の差の位置、画面の行数・文字数・SHA-256、取りこぼし件数とする。
SHA-256を大小や近さの判定へ使わない。測定runでWRITEが1件でも出れば不採用とする。

## 差分とジャンプの固定判定規則

`m7dv`規則1〜4をそのまま適用する。

```text
Delta_N = X_N - X_(N-1)    (N=1..128)
```

`Delta_1`は基準差分であり、単独ではジャンプと呼ばない。N=2〜128では次を適用する。

1. 2成分とも`Delta_(N-1)`へ完全一致すれば**定常差分**とし、新しい数値境界へ数えない。
2. `Delta_N`の両成分が`Delta_(N-1)`以上で、少なくとも一方が厳密に大きければ
   **正方向ジャンプ候補**とする。
3. 両成分が以下で少なくとも一方が厳密に小さければ**負方向変化**、一方が大きく他方が
   小さければ**方向不一致**とし、H-X支持へ数えない。
4. 過去Nで0件だった公開FDCコマンド名の初出を**未見経路候補**とする。語彙が同じでも
   N-1列をstrict prefixとして後続が増えれば**構造的延長**、prefixを保たず順序が変われば
   **構造変化**として分ける。

任意の件数幅、割合、誤差許容、近さは導入しない。候補Nでは通常系列を止め、直前の8本境界
アンカーからN-1/Nを独立再構築して各2run再測定する。同じ符号、差分ベクトル、FDC構造分類を
完全再現した場合だけ確認済みジャンプへ採用する。不一致は支持にも反証にも数えず欠測とする。

## 周期性の固定判定規則

`m7dy`規則1〜5をそのまま適用する。確認済みジャンプを昇順に`J'_1,...,J'_k`、
`V'_i=Delta_(J'_i)`、隣接間隔を`P'_i=J'_(i+1)-J'_i`とする。

1. **k=1:** 単発ジャンプであり周期を算出しない。
2. **k=2:** 唯一の間隔は周期候補だが、反復が無いため周期とは確定しない。
3. **k>=3:** 全`P'_i`が同じ正整数`P'`へ完全一致し、全`V'_i`が同じベクトル`V'`へ
   完全一致し、ジャンプ間の成立済みNに別ジャンプ、負方向変化、方向不一致が無い場合だけ、
   **自作媒体の観測範囲でP'本間隔・同一増分の周期**とする。
4. 間隔または増分が1回でも異なれば、外れ値を除外せず**非等間隔／増分不一致**とする。
   都合のよい3点や部分列を選び直さない。
5. FDC追加suffix、未見コマンド、値非表示イベント構造は各点で併記する。同じP'・V'でも
   構造が混在すれば、数値周期は成立、経路の同一性は未確定と分ける。

周期成立後の予測位置`J'_k+P'`まで全介入が成立しても同じV'の確認済みジャンプが無ければ、
その位置を通過した時点で周期破れとする。さらに後の点へ付け替えない。予測位置より前に
容量端点または介入不成立で打ち切られた場合は周期破れでなく後続周期を検査不能とする。

## 媒体間比較の固定判定規則

公式diskA系列の比較値は`P=16`、`V=(+258,+1)`へ固定し、再測定や選び直しを行わない。

1. 自作媒体で確認済みジャンプがk>=3得られ、全隣接間隔が`P'`、全増分ベクトルが`V'`へ
   完全一致した場合だけ、自作媒体の周期を成立とする。
2. `P'=P=16`かつ`V'=V=(+258,+1)`なら**H-M支持**とする。位置`J'_i`は比較しない。
3. 周期が成立してもP'またはV'の少なくとも一方が完全一致しなければ**H-M'支持**とする。
   「近い」「ほぼ同じ」「同程度」は使わない。
4. k>=3でも間隔または増分が内部で一致しなければ、`m7dy`どおり非等間隔／増分不一致とし、
   公式媒体と同じ一定P・Vを持つH-Mは不支持、媒体依存形のH-M'支持とする。ただし存在しない
   単一のP'やV'を作らない。
5. k<3しか得られなければ媒体間比較は**不成立**とし、H-M、H-M'のどちらにも数えない。

自作媒体でP'、V'、または内部周期性が公式媒体と違っても、公式媒体の三点を疑って作り直さず、
自作媒体側の都合のよい部分列も選ばない。容量端点や欠測をゼロ差分へ読み替えない。

## 介入成立と全名OPEN検証

各Nは作成run、媒体SHA差、固定`FILES`各2run、修正版全名OPEN検証が成立した場合だけ採用する。
`FILES`は直後`Ok`、READ非0、WRITE 0、取りこぼし0、2run完全一致、N-1から画面行数・文字数・
SHA-256のいずれかの変化を要求する。出力量増加で打鍵行が最終画面からスクロールしても、それ
だけでは不合格にしない。

全名OPEN検証には`m7ea`で訂正した分割版を使う。ホスト側でN=1〜Kの全自作名を生成し、
最大8名ずつのリテラルINPUT OPENへ分割する。全chunkの固有マーカー、WRITE 0、取りこぼし
0件が揃った場合だけK全体を合格とする。動かなかった`CHR$`式の原形は使わない。

ブロック末端Kは8,16,...,128へ固定する。各Kの判定セッションごとに、対象Kの検証より先に
次の陽性・陰性対照を毎回取る。K=8では対象チェックポイント自身を陽性対照に兼用し、以後は
SHA-256を固定した受理済みK=8チェックポイントの新しい使い捨て複製を使う。

- 陽性対照はK=8チェックポイントのN=1〜8全名OPENが合格すること。
- 陰性対照は同じK=8の使い捨て複製から`QDAA`をKILLし、固有マーカー、WRITE非0、媒体SHA差、
  取りこぼし0件を先に確認する。その後、同じ全名OPEN検証が実際に不合格となること。
- 両対照が成立した後にだけ対象KのN=1〜K全名OPENを判定する。対照失敗時は対象Kを走らせず、
  器材不成立として停止する。

系列が8の倍数の途中で容量端点または介入不成立へ達した場合は、最後に作成成立した終端Kへ
同じ分割版と両対照を適用する。終端Kの全名OPENが通らなければ、直前の受理済み8本境界から
終端KまでKを1ずつ増やして同じN=1〜K全名検証を行い、最初の不合格Kと最後の合格Kを特定する。
最後の合格Kを受理済み終端とし、先を欠測とする。検証対象を減らしたり一部名だけで代用したり
しない。

同一Nの2runは全イベント列、画面、main受信件数・SHA-256、FDCコマンド種別列が完全一致する
ことを必須とする。介入不成立、到達失敗、取りこぼし、2run不一致、独立再構築不一致は欠測とし、
ゼロ差分、ジャンプ、周期破れへ読み替えない。

## 準備、再開、上限、打ち切り

上限は**N=128**とし、実測後に延長しない。128は8の倍数で、公式媒体で未到達だった予測位置
59を数値上69本超え、16本間隔なら複数の後続区間を観測できる固定探索幅である。これは
N=128まで媒体容量があるという仮定ではなく、探索上限である。

作業領域は実行者が絶対パスで指定する`PC88_M7EB_WORK_DIR`とし、既定値を焼き込まない。
8本ごとにチェックポイント、媒体SHA-256、各runの安全集計、完了フラグを外部manifestへ記録する。
生ログ、画面、媒体複製も同じ外部作業領域だけへ置く。中断後はmanifestと媒体SHA-256を照合し、
最後の受理済みアンカーから再開する。N=0から恣意的に取り直さない。

正方向ジャンプ候補を得たら通常系列を停止し、独立再構築確認を先に行う。確認後は受理済み
アンカーから再開する。複数候補を同じ規則で扱い、最初の候補だけを選ばない。

N<128で空ファイル作成が容量／作成上限エラーとなった場合、それ自体をジャンプや周期破れへ
数えず、最後に成立したNを容量端点として打ち切る。周期の次予測位置より前なら検査不能とする。
全Nが成立してもk<3なら媒体間比較不成立、確認済みジャンプ0件なら観測範囲内で未観測とだけ
記録する。上限到達後に延長したり、名前、媒体形状、空内容、作成順を変えたりしない。

## 解釈限界

- 結果は自作の空フォーマット媒体、空ファイル、固定作成順、固定不存在OPEN、QUASI88上の
  観測に限る。内容ありファイル、削除・再利用、異なる作成順、他媒体、実機一般へ一般化しない。
- 媒体間でPとVが一致しても、観測管理単位がディレクトリエントリ、セクタ、クラスタ、
  割付表、検索ブロック等のどれかは決まらない。追加READを特定機構へ帰属しない。
- PまたはVからエントリ長、セクタ長、媒体上のバイト数・アドレスを逆算しない。
- 公式媒体と自作媒体で絶対ジャンプ位置が一致または不一致でも、初期占有を観測していないため
  H-M/H-M'の判定へ使わない。
- 自作媒体で新しい公式ROM経路を観測しても、自作subへの実装採否は別事前登録へ分ける。

## 情報境界

記録するのはN、件数、差分、位置、frame、clock、SHA-256、画面の行数・文字数・SHA-256、
自分で打鍵した文字列・自作ファイル名、自作媒体の公開構造値、公開μPD765コマンド名だけとする。
画面本文、公式ディスクの既存名・内容、公式ROM・公式ディスクの応答値、データポート値列は
記録しない。公式媒体は生成、校正、測定、比較用再測定のいずれにも渡さない。
