# B86 追補12 事前登録

G5 の値なし観測から、6F6B後に OUT 31、JP 7071、JP 11DF を4回、JP 3E0D、以後3080という需要を得た。7071から最初の11DFまではI/Oなし、以後の11DF間は各 IN 71×1・OUT 71×2。最後から3E0Dまでは同じ71のI/Oの後に IN 40 約7000回、OUT 31×3・30×1・40×2・51×3・50×5・64/65/68各2。追補10では単独の3E0Dは復帰し、7071と11DFは起動のやり直しに入った。ゲームの値は採らない。

自作入力による測定。各腕のROM置き場を分離し、JPの前に自作戻り先を積む。7071はポート31の自作値を5通りに振る。11DFと3E0DはA・B・C・HLをそれぞれ独立に5通り振る。他の入力は固定しDIで実行する。各腕で戻り・再起動・区間I/Oの方向とポートと件数、OUT各回と入力の関係、戻りレジスタと入力の関係、C000〜FFFFへの書込み番地と既知の前値との差を記録する。7071ではC800の自作RAM印への到達も判定する。11DFのIN 71とOUTの関係は、区間内最後のINとの比較であり、時系列上の直前INとは限らない。入力を変えても同じ出力は値を出さず「定数（値はリポジトリ外）」とし、2例未満は未判定。入力との一致は候補であり、固定入力との一致や相関から因果を断定しない。

制約: この器具にはROM内部の11DFへの進入回数や、その場のROM/RAM分類を測る機能がない。自作印以外の移動先は未確定、11DF進入回数は未計測とする。よって4回で抜ける条件は本器具だけでは確定できない。main RAM全域の初期値も取得しないため、前値不明の書込みと既知の前値からの変化を分け、低位RAMは対象外とする。これらを観測結果で補完したことにしない。

再起動または上限内未復帰は戻らない。ログ欠落・取りこぼし・入口未到達は欠測。ROM、媒体、生ログ、一時値はリポジトリ外にのみ置き、集計後に削除する。画面本文、ROM内部PC、入力と無関係な値は集計しない。公式測定は `PC88_REF_ROM_DIR` を指定し `tools/b86_add12_run.sh` にリポジトリ外の未使用出力先を渡す。`B86_ADD12_FILTER`、`B86_FRAMES`、`B86_TIMEOUT` で腕と上限を変更できる。公式ROM未指定なら器具確認用の自作対照を使う。実行後の再集計には削除済みの一時値が必要なため対応しない。
