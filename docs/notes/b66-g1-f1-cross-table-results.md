# B66: F1 の腕で、自作が公式より 2 回少なく移る所を測る — 結果

記録日: 2026-11-02
規則: [b66-g1-f1-cross-table-preregistration.md](b66-g1-f1-cross-table-preregistration.md) どおり。測定はクラウドの実行環境で rc=0。記録は `measurements/b66-g1-f1-cross-table.txt`。

## 結果

- 番号 71 までは公式と自作で移る先が同じ
- 公式だけに番号 72（`7812`、fc 112817）と 73（`780C`、fc 112817）がある
- 自作も fc は 112813 まで進む（差 4 は B48 の位相）。番号 71 のあと 128 回の `IN $FC` は公式と同じに受けている
- 後半のキーの時刻を 0〜5 フレームずらしても、公式 74、自作 72 で変わらない。**位相の差ではない**

## 読み方（推定）

番号 71 のあとの 128 バイトのやり取りまでは同じで、そのあとの要求で公式は `7812` と、これまで出ていない `780C` へ移る。自作は移らない。自作に無い要求か、要求の形の違いがある。B67 でそのあたりの要求の先頭バイトと形（方針追補3の範囲）を出す。
