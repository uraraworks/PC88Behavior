# B86 追補8 事前登録

G5 の値なし観測（3080 へ JP、割り込み非受理、RET 系でスタック先頭へ復帰、IN 00〜0B 各1、OUT E4 2・51 1・50 2）と追補7のやり直しを動機とする。ゲームの値や ROM 内部経路は使わない。これは測定前の計画であり結果ではない。

自作プローブは DI、固定の自作 AF/BC/DE/HL/IX/IY と自作戻り先1語を用い、RAM C800 または C900 に自作 JP 3080 を書いてそこから入る。ポート31は出力なし、00、08、10、20、40、80 の7条件とし、ROM 選択や全 RAM 化に関係する bit1・bit2 を変えず、その他の単一ビットを振る。各条件に無打鍵と行0 bit0、行3 bit2、行7 bit4、行11 bit7 の打鍵を組み合わせる（70腕）。各腕は独立した ROM ディレクトリ、同じ条件の無打鍵腕を比較対象とする。起動後に待ち、キーはフレーム0から保持する。

自作印の間の I/O を方向・ポート・件数で数え、上記の形との完全一致を真偽で出す。C000〜FFFF の書き込みは mem-write-log 内の自作開始・戻り・再起動印で区切り、番地と回数だけ出す。戻らない腕は再起動印か時間上限までの部分区間である。ログ取りこぼしや印なしは欠測とする。戻り直後の AF を含む各レジスタと入力の一致、および LD A,I の P/V による IFF2（EI状態）を真偽で出す。再起動は戻らないと数え、時間上限とは区別する。

キー比較は各腕の区間で最後に書かれた値を非公開一時領域内で照合し、両腕で書かれて値が異なる番地のみを行・ビットに対応付ける。片方のみ書かれた番地は別欄で示し、値が変化したとは断定しない。両腕が戻らなければ比較は欠測。初期値や書込み前後の値は記録しない。生ログ、画面、ROM 複製、ディスクは実行後に削除し、割り込みや実行失敗による終了時も削除する。容量を抑えるため腕ごとに実行し、値付きログは集計終了まで非公開出力先だけに保持する。停止条件は設けない。

自己検査は PC88_REF_* を解除し、自作 ROM の既知のキー依存書込み・戻り・入力一致、区間切り出し、再起動と取りこぼし、値なし集計を確かめる。公式 ROM 実測は別途クラウドで行う。
