# B71: G1 の F1 の道で、`0x0E` が書くサブ RAM の範囲を値なしで測る — 事前登録

記録日: 2026-11-02
位置づけ: [B70](b70-sub-request-0e-drive2-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

B65 の F1 の腕で、`0x0E` のあいだに公式のサブの ROM 側が書くサブ RAM の範囲はどこか。自作の作業域（`7B00`〜`7D0B`、`7F00` 以降のスタック）と重なるか。

## 2. 器具

B51 の `--sub-rom-access-log`（パッチ 0025）。窓は main の `IN $FC` の番号 112680〜112700（B67 の `0E` の前の fc は 112689）。値は持たない。

## 3. 条件

B65 の F1 の腕と同じ。公式 2 走のみ。クラウドの実行環境で行う。

## 4. 記録の白リスト

B51 と同じ `A <R|W> <開始>-<終了> <増える|同じ> <回数> <fc>`。**公式の ROM の範囲の短い読みは B51 と同じく伏せる。**

## 5. 判定（事前に決める）

- 256 バイト単位の増える書きの範囲を書く。自作の作業域と重なれば、そのことを書く
- 重なれば、自作の作業域を G1 が使わない所へ移す。移す先は、B34・B38・本測定で G1 も公式の ROM も使わないと分かった範囲から選ぶ
