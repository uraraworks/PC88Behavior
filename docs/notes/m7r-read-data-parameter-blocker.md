# m7r: sub側256件目のREAD DATAパラメータ診断

測定日: 2026-08-13

## 1. 情報境界

第35版実装後の混成ログと公式4条件ログを、CPU・方向・ポート・件数だけで比較した。
FDCデータポート、通信データポート、公式ディスクの値は表示・記録していない。
候補比較では値そのものを出さない一致プレフィックス長だけを用いた。

## 2. 256件目の構造差

第35版実装後、sub側構造的一致プレフィックスは255件へ伸びた。次の256件目では
公式subがFDCデータ入力を続ける一方、自作subはTC出力へ進む。READ DATA区間を
値なしで数えると、公式4条件はいずれもコマンド出力9件・入力263件で一致した。
入力263件は仕様書1.21節の実データ256件＋結果7件と整合する。自作subはコマンド
出力9件の後に入力7件だけで終わり、データフェーズへ入らず結果部だけを受けていた。

## 3. 候補介入と停止判定

要求8位置からシリンダ・セクタ引数を選ぶ全位置組み合わせを、使い捨て自作ROMで
値非表示のまま介入した。入力263件へ到達する組み合わせは複数残り、構造測定だけでは
一意に決まらなかった。残った各候補を公式mainの`IN $FC`列と位置のみ比較したが、
値一致プレフィックスは4件のままで、交換#4先頭の5件目を一致させる候補は無かった。

したがって必要なのは、公式subがREAD DATAへ与える正しい座標・関連パラメータ、または
それを要求と内部状態から生成する規則である。FDCデータポート値は伏せ字対象であり、
現在の外部構造測定だけでは決定できない。推測値や総当たりで実装を埋めず、仕様書は
第35版、実装は255件到達の状態に留める。PLAN第5節の追加方針を適用するかは次回判断とする。

## 4. 最終到達点

- sub側構造的一致プレフィックス: 255件
- main側構造的一致プレフィックス: 258件
- main側単発送受信列の値一致プレフィックス: 4件
- 混成照合のmain `IN $FD`: 0件

生ログ・候補ROM・一時解析物はリポジトリ外に置き、コミットしない。期待値・判定基準は
変更していない。既知のディスク無し時I/O不適合も残る。
