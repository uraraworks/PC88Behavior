## 実施の訂正（腕の設計の誤り。結果を見る前に気づいたもの）

追補2の最初の走で、本文が数字で始まる4腕（b01 `1+rem...`・b05・b18・b21）が、それ以外の腕の観測を1行ずつ
ずらした。**公式は行番号の途中の空白を読み飛ばす**（`130 1+rem x end` が行 `1301`、本文 `+REM x end` になる）ため、
その行は別の番号に入り、位置で対応づけていた器具が取り違えた。直したのは次の2点で、どちらも M_C の規則や
判定の基準とは無関係:

1. 器具: 取り出した行を**先頭の行番号で**打った行に対応づける（位置では対応づけない。番号が見つからない・
   複数ある腕は `gate_failed`）。
2. 腕: 4腕の本文を `x=1+rem x end` `x=1rem x end` `x=1+data x end:end` `x=1+?1` に変えた。

この直しのあと、全腕を公式ROMで2走し、署名は全一致、`gate_failed` 0（[署名](l4-s5h-round3-signatures.tsv)）。
初回600腕と追補1の87腕の署名は、行の位置が変わらないので前の結果と同じである。

## 結果（公式ROM、723腕、2走）

M_C と一致 694腕。食い違いは次の29腕。

- **数値定数 24腕**（c38・c39・n02〜n14・n17・n18・n22〜n28）: 前のノートのとおり、値として読み直されて書き直される。
  **実装しない**（END の症状と無関係。自作は打鍵どおりに出す。仕様書に未実装として記す）。
- b05 `x=1rem x end` → `X=1 REM x end`: 数字の直後の `rem` は REM と読まれ、**空白が1個入る**。
  数字で始まる連なりは名前ではなく数値であり、その直後から新しい語が始まる。
- b16 `a=1 data x end` → `A=1#ATA X END`: `1 d` が指数部 `1d`（倍精度）と読まれ `1#` になる。これも数値定数の読み直し。
- b24 `?a?b` → `PRINT A PRINT B`、b25 `x?y` → `X PRINT Y`: `?` の展開は、**直前が名前の文字（英数字）なら
  前にも空白を1個入れる**。
- b32 `go sub10` → `GOSUB 0`: `go sub` の直後に数字が接すると、語の詰め方が M_C と違い、数字の一部も落ちる
  （理由は不明）。`go to10`（b03）は詰められない（`GO TO10`）ので、`go to` と `go sub` は同じ規則ではない可能性がある。
  **`go sub` の詰めは `go sub` の直後が名前の文字でないときだけ採る（g07 `go sub 10` → `GOSUB 10` で確認）。
  `go sub10` は未確定。**

M_C の規則のうち、追補2で**見ていない位置の腕で確かめられたもの**（一致）:

- REM は位置を問わず「名前の連なりがちょうど `rem`」で認識される（`a=rem` `(rem` `a,rem` `a;rem` `a rem`
  `a$rem`、`rem` の直後の `$` `%` `!` `#` `=`、`a=1:  rem`。`a.rem` は名前）。DATA も同じ（`a$data`・`data$`・
  `x=1+data` を含む）。
- `?` は文字列の外ならどこでも PRINT に展開される（`a=?1` `x=1+?1` `print ?1` `?"x"?1`）。文字列の中・REM の中・
  `'` の中は展開されない（b26・b27・b28）。
- `go to` の詰め（`go to to` `a go to 10` `go to 10 go to 20` `go to:end`）は M_C のとおり。`go  sub 10`（空白2個）・
  `go tox`・`go to.5` は詰められない。

## 採る規則（実装の対象）

M_C に、追補2で分かった2点を足したもの。「名前の連なり」は**英字で始まり**、英数字と `.` が続く並び
（数字で始まる並びは数値で、数字と `.` だけを取り、その直後から新しい連なりが始まる）。

1. 二重引用符の中（閉じ引用符が無ければ行末まで）は打鍵どおり。`'` 以降は打鍵どおり。
2. 連なりがちょうど `rem` なら `REM` にして、以降は打鍵どおり（位置を問わない）。
3. 連なりがちょうど `data` なら `DATA` にして、以降は `:`（引用符の外）まで打鍵どおり。
4. `go` + 空白ちょうど1個 + 連なり `to` は `GOTO`、連なり `sub` は `GOSUB` に詰める（`sub` の直後が名前の文字のとき
   `go sub10` は未確定。実装は詰めない）。
5. `?` は文字列の外ならどこでも `PRINT` に展開する。直後が `[a-z0-9.&]` なら後ろに空白を1個、
   直前の出力が英数字・`.` なら前にも空白を1個入れる。
6. それ以外の英字はすべて大文字。語の前後に空白は足さない。打った空白は保つ。

**実装しないと決めたもの**（仕様書に未実装として残す）: 数値定数の読み直し（`1e5` → `100000!` など）、
`1rem` の空白、`1 d` の指数読み、`go sub10`、行番号の途中の空白の読み飛ばし（`10 20 print` が行 1020 になる。
自作は行番号を連続した数字として読む）。
