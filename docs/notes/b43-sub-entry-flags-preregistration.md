# B43: `0x0D` で移るときのフラグを、自作のコードで測る — 事前登録

記録日: 2026-11-01
位置づけ: [B35](b35-sub-entry-registers-results.md) の不足を埋める。[B42](b42-g1-sub-entry-delay-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

`0x0D` で番地 A へ移った直後の `F` は何か。場面で変わるか。公式と自作でどう違うか。

## 2. 器具

B35 と同じ。自作のコードが入った直後に `F` を含むレジスタを自分の領域へ書き、`0x00C1` へ戻る。`F` は `PUSH AF` と `POP` で取り、`HL` を先に保存する。媒体もコードも自作で、G1 は使わない。

## 3. 行

B35 の行 1〜6 と同じ。各行 2 走。公式と自作の両方で測る。

## 4. 判定（事前に決める）

対照: 2 走が全行で一致し、`a`・`bc`・`de`・`hl`・`ix`・`iy`・`sp`・`i` が B35 と同じ。

`F` を行ごとに書く。公式で場面によらず同じか、未定義のビット（bit 3・bit 5）を含めて値を書く。実装に渡す仕様は、この判定で確定した範囲だけを `docs/spec/l3-subrom.md` に書く。
