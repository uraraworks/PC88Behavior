# ゴールB: ゲームディスクの実ファイル名が現れる箇所を1点に閉じた

方針は [goal-b-policy-2026-10-24.md](goal-b-policy-2026-10-24.md) 第4節・第7節の3。
前例は [m7gp-disk-name-leak-path-closed.md](m7gp-disk-name-leak-path-closed.md)。
第7節は書き換えず、本ノートを足す。

## 何を閉じたか

ゲームは `G1`, `G2` … の識別子（`^G[1-9][0-9]*$`）だけで呼ぶ。実ファイル名・タイトル名が
端末に現れうる箇所は次の2本に閉じた。

- `tools/stage_game.sh <識別子> [出力ディレクトリ]`: 全ディスクを `<識別子>-<番号>.d88`
  の中立名で複製し、複製先パスをディスク番号順に1行1本だけ標準出力へ出す。
- `tools/register_game.sh <識別子> <番号> <パス>`: ユーザーが自分の端末で実行する登録用。
  標準出力は「`G1-2` を登録した（ハッシュ先頭16桁）」だけ。

置き場は環境変数 `PC88_GAME_DIR`（未設定はエラー、既定パスなし）。直下の `games.tsv` に
`識別子<TAB>番号<TAB>中身のSHA-256先頭16桁` を持つ。**対応表に実ファイル名は書かない**。
名前でなく中身のハッシュで引くので、改名しても対応は崩れない（自己検査で確認）。
エラー文は識別子・番号・件数・ハッシュだけ。`set -x` なし、候補一覧の表示なし。

## 使い方の例

    export PC88_GAME_DIR=...        # 自分の端末で。値はノートに書かない
    tools/register_game.sh G1 1 "$PC88_GAME_DIR/（ディスク1）"
    tools/register_game.sh G1 2 "$PC88_GAME_DIR/（ディスク2）"
    paths="$(tools/stage_game.sh G1)"      # 中立パスが番号順に2行

## 自己検査

`tools/stage_game_selftest.sh`（`run_all_selftests.sh` に登録）。合成ダミー
`TOPSECRET_TITLE_*` で、2枚組の番号順・バイト一致・元ファイル不変・改名耐性・
各エラー条件（形式不正／対応表なし／識別子なし／番号の重複・欠番／一致0本・2本）の rc≠0 と、
成功・エラー全経路の出力に名前が出ないことを検査する。陰性対照は、実ファイル名を
標準エラーへ出す1行を注入した壊れた版で、同じ漏れ判定が名前を検出することを確認する。

## 限界

m7gp と同じ。**このヘルパを通さずにパスを組み立てる（`ls $PC88_GAME_DIR`、
手書きの `--disk` 引数など）と閉じない。** 閉じているのはヘルパの出力であって、
端末全体ではない。また `register_game.sh` に渡すパス引数は、ユーザーが打つコマンド行に
名前が残りうる（シェル履歴等）。補完を使わず置き場内のファイルを別途用意するか、
履歴の扱いを各自で判断すること。
