## サブ ROM への飛び先: **1 番地だけ**

| 飛び先 | total | call | jump | int | ret |
|---|---:|---:|---:|---:|---:|
| `00C1` | 17 | 0 | 17 | 0 | 0 |

OO の RAM 上のコードから公式サブ ROM へ入る番地は `00C1` だけで、すべて jump 型である。SS は 0 件。

## 読み方

分かること:

- G1 が公式サブ ROM に要るのは、入口の番地としては `00C1` の 1 つである。自作サブでは、この番地に同じ働きを置く必要がある
- OO の ROM は G1 の track 0 の 15 セクタの長さ（3840 = 0xF00 バイト）と同じ大きさの範囲 `5000-5EFF` へ書く。`7800-7AA7` は 680 バイトで、`0x0C` の 709 バイトに近い
- RAM 上のコードは `4000-53FF` へ書く（1024 バイト×5 と同じ大きさ）
- 自作サブの RAM の使い方は公式と違う。`7800` 以降を G1 が使うなら、自作の作業域と衝突しうる

推定（確認していない）:

- `0x0C` は `7800` から本体を RAM へ書く要求である可能性が高い。引数の形は分からない
- `00C1` は要求を待つ場所へ戻る入口である可能性がある。17 回という回数は要求の数に近い
