# B20: 公式の上の G1 で、サブの割り込みのモードと飛び先を見る — 結果

記録日: 2026-10-31
規則: [b20-g1-sub-interrupts-preregistration.md](b20-g1-sub-interrupts-preregistration.md) どおり。測定はクラウドの実行環境で c3d6809、OO・SS 各 2 走、すべて rc=0。対照は一致し、2 走も一致した。記録: `measurements/b20-g1-interrupts-*`。

## 判定: **受理あり**

| 腕 | 受理 | 上限で落ちた | モード | 飛び先（割り込まれた領域）と回数 |
|---|---:|---:|---|---|
| OO | 65536 | 15401 | **0** | `796F`(hi) 61406、`0300`(lo) 4096、`7A3D`(hi) 12、`7982`(hi) 11、`01CE`(lo) 9、`0336`(lo) 2 |
| SS | 19484 | 0 | **1** | `0038`(hi) 15366、`0038`(lo) 4118 |

OO の受理は記録の上限に達しているので、回数と番地の種類はその範囲のものである。

## 読み方

- **公式サブはモード 0、自作サブはモード 1 で割り込みを受ける。** 自作では G1 のコードの実行中に `0038` の処理が割り込む
- OO の「飛び先」は多数の番地に分かれていて、割り込まれた領域と同じ側にある。このコアのモード 0 では、受理しても制御が決まった番地へ移らないように見える（**推定**。記録 A に `int` が 0 件であることと合う）
- これはエミュレータの動きの観測である。実機のモード 0 でバスに何が載るかは、この測定からは言わない

## 実装への要求

`docs/spec/l3-subrom.md` 1.36c 節（第226版）。自作サブは、`0x0D` で移るときモード 0 にする。
