# m7ar: ネガティブコントロールの帰属を2×2で確定、適合条件4を達成

測定日: 2026-08-18

## 情報境界

公式main ROM一式・公式サブROM（`DISK.ROM`）を**実行して**測定した。読んで
いない（`cp` で配置しただけ）。ディスクは**与えていない**（ネガティブ
コントロールなので当然だが、公式ディスクの値には一切触れていない）。
本ノートの数値はすべて **I/O イベントの件数**であり、値は1バイトも含まない。

## 1. 長らくのNGは、測っている対象を取り違えていた

`tools/verify_l3.sh` は「ディスク無しでも sub が11533件のI/Oを発行した
（1.1節を満たさない。既知の未達成）」を NG として報告し続けていた。
これを自作サブROMの欠陥だと解釈していた——実際には**サブROMの性質を
測っていなかった**。

ディスク無しで、main側ROMとsub側ROMを独立に入れ替えた2×2を実測した
（30フレーム・120フレームの両方で同じ傾向。下表は30フレーム）。

| main側 | sub側 | sub の I/O 件数 | main の I/O 件数 |
|---|---|---|---|
| 公式 | 公式 | 0 | 7523 |
| 公式 | **自作** | **0** | 7523 |
| 自作（試験用ドライバ） | 自作 | 2575 | 1670 |
| 自作（試験用ドライバ） | **公式** | **208437** | 59 |

読み取れること:

- **2行目**: 自作サブROMは、公式mainを相手にすればディスク無しで完全に
  無音（0件）。**適合条件4を満たしている。**
- **4行目**: 公式サブROMでも、試験用mainドライバを相手にすると20万件規模の
  I/Oを出す。もし公式サブROMがディスク無しを検出して自ら停止しているなら、
  相手役が誰であれ無音のはずである。**そうならない。**

したがって、11533件（=3行目の系統）は**試験用mainドライバがディスク無しでも
サブを走らせてしまう**ことの結果であって、サブROM側の性質ではない。
自己検証層はこの条件を**構造的に判定できない**（相手役の main が公式で
ないと成立しない条件だから）。[[feedback_selftest_both_sides_selfmade]] と
同型の限界が、今度はネガティブコントロールに出ていた。

## 2. 長らくの未確定も1つ解けた

仕様書1.1節には「この条件がハードウェアレベルの事実なのか、公式DISK.ROM側の
ソフトウェア的な自己診断なのかは判別できない（未確定）」と書いてあった。
4行目がこれを解いた——**公式サブROMはソフトウェア的には無音にならない**。
無音を作っているのは main 側（ディスクが無いと公式mainはサブを起動しない）
か、その下のハード側である。仕様書1.1節を更新した。

なお2行目が0件であることは、自作サブROMが**リセット直後の最初の命令すら
実行していない**ことも示す（自作サブROMの起動は `OUT $F7,0x08` から始まる
ので、1命令でも実行されれば必ずI/Oイベントが立つ）。1.1節の「1命令も
実行しない」という表現と整合する。

## 3. 判定の置き場所を移した（条件を消したのではない）

- `tools/conform_l3.sh` に「適合条件4のネガティブコントロール」を新設した。
  公式main + 自作サブROM・ディスク無し・30フレームで sub の I/O が0件で
  あることを要求する。**陽性対照つき**——同じ数え方で、試験用mainドライバ
  構成が非0（2575件）と数えられることを毎回確認する（0件判定が空検査に
  なっていないことの確認）。2026-08-18時点で両方OK。
- `tools/verify_l3.sh` は NG をやめ、**判定不能（`--`）**として理由・2×2の
  結果・どこで判定しているかを毎回表示する形にした。黙ってOKにはしない。
- `tools/run_all_selftests.sh` の `verify_l3.sh` の期待rcを 1 → 0 へ変更した
  （宣言側の更新。理由をスクリプト内のコメントに残した）。

**これは「テストを緩めてPASSにした」のではない**——判定できない層から
判定できる層へ移し、移した先では陽性対照つきで実際に判定している。
移していなければ、条件4は誰も判定しないまま消えていた。

## 4. 残るもの

適合条件2（diskB起動時に `$FC` を一切使わないこと）・条件3（サブの割り込み
受理がmainの直接I/O操作を直前イベントとしないこと）は未判定のまま。
条件2はdiskBのイメージがあれば同じ型（公式main + 自作サブROM）で測れる。
