# m6i-c 準備 — m6i-b 結果ノート §6 の前提の訂正

記録日: 2026-09-22

## 1. 何を訂正するか

[m6i-b 結果](m6i-b-first-request-timing-results.md) §6「残った問い」は、B5 と
B6-A0 の食い違いを述べる際に、両者について

> sub 側の停止ゲートが同一（どちらも `inject_m6ib_b5`）

と書いた。**これは誤りである。** 両者の sub ROM は同一ではない。

**測定の数値・判定・総合判定は訂正しない。** 誤っていたのは結果の読みであり、
結果そのものではない。m6i-b 結果ノートの §1〜§5 と総合判定
`m6i_b_inconclusive` はそのまま有効である。本ノートは §6 が挙げた切り分け項目
の前提だけを差し替える。

## 2. 事実

`tools/build_m6ib_measure_rom.py` の `_base_cli_arm()` は腕ごとに別のフラグを
基底ビルドへ渡す。

- B5 → `--inject-m6ib-b5`
- B6 の各枝 → `--enable-main-sub-read`（`--inject-m6ib-b5` を渡さない）

基底ビルドの `src/build_main_rom.py` は、このフラグを
`build_disk_rom(outdir, m6ib_arm=...)` へ流し、`src/l3_service/make_subrom.py`
の `--inject-m6ib-b5` に渡す。sub 側ではこのフラグが真のときだけ、ラウンド#0
応答の直後に `_emit_m6ib_release_gate("M6IB_B5_AFTER_ROUND0_GATE")` が出る。
このゲートは PIO のポートC を読み、main の通常SEND開始を示すビットが立つまで
その場で回り続ける。

したがって:

- **B5 の sub ROM はラウンド#0直後にスピンゲートを持つ。**
- **B6-A0 の sub ROM はそれを持たない。**

なお器具の側はこの差を意図して作っており、`_base_cli_arm()` には
「B6はB5と同じmain前置きを使うが、前置き後に停止するB5専用sub介入は
引き継がない」というコメントが最初から付いている。**器具は正しく、
結果ノートの読みだけが器具を誤って記述していた。**

## 3. 裏取り

両腕の ROM 一式を `tools/build_m6ib_measure_rom.py` で生成し、同名ファイル
どうしを機械的に比較した。バイト列そのものは転記せず、相違バイト数だけを記す。

| ファイル | 長さ | 相違バイト数 |
|---|---:|---:|
| `N88.ROM` | 32768 | 70 |
| `DISK.ROM` | 8192 | 125 |

`DISK.ROM` の相違が 0 でないことが、§2 の主張を成果物の側から裏付ける。
`N88.ROM` の相違は枝タグ格納とそれに伴う配置のずれである。

## 4. 影響

m6i-b 結果 §6 は切り分けるべき対象を2つ挙げていた。前提が変わるので、
1つ目を次のように読み替える。

- 旧: 「B5 と B6-A0 の ROM 差分（枝タグの格納）が要求の成否に効いているか」
- 新: **「B5 と B6-A0 は main 側（枝タグ格納）と sub 側（ラウンド#0直後の
  スピンゲートの有無）の2点で違う。どちらが要求の成否を決めているか」**

2つ目（sub 側の停止ゲートがラウンド#0の後に置かれたとき、main の通常SEND開始を
取りこぼすことがあるか）は、そのまま残る。むしろ §2 により、**ゲートを持つのは
B5 だけ**であることが確定したので、この問いは B5 に固有の問いになる。

2要因が同時に動いていたため、m6i-b の B5 対 B6-A0 の比較は交絡していた。
**どちらの要因が効いたかを m6i-b の結果から読むことはできない。** 切り分けは
m6i-c の 2×2 要因設計で行う（[事前登録](m6i-c-b5-b6a0-divergence-preregistration.md)）。

## 5. この訂正で決まらないこと

- どちらの要因が要求の成否を決めているかは、本ノートでは決まらない。ここで
  示したのは「2要因が同時に動いていた」ことだけである。
- スピンゲートが main の通常SEND開始を取りこぼすかどうかも決まらない。
- m6i-b の総合判定 `m6i_b_inconclusive` と境界判定7種の不成立は変わらない。
- `docs/spec/l3-subrom.md` 1.65節が未確定として残した点も変わらない。
