# m7l: 交換#3観測応答のブラックボックス介入

測定日: 2026-08-13

## 1. 目的と情報境界

交換#3の意味未特定1バイト応答について、公式ROMを読まず、自作側から全256候補を
与えたときに公式挙動と一致する条件を探索した。`private/`は直下の名前だけを確認し、
参照ROM・参照ディスクのパスを`PC88_REF_ROM_DIR`と`PC88_REF_DISK_DIR`で測定
プロセスへ渡した。公式ROM、公式ディスク、その実データのバイト列は読まず、表示せず、
保存せず、逆アセンブルしていない。

公式側の値、先行3応答の再構成値、交換#3の一致候補、候補順は比較器のメモリと
一時自作ROMの中だけで扱った。本ノートに値は記録しない。

## 2. 検出力と介入位置の関門

本測定前に`tools/cmp_io_selftest.sh`と`tools/diag_l3_mixed.sh`の検出力selftest
a〜lを通した。一時比較器でも既知の同一入力を一致、意図的な値差・構造差を相違と
判定することを確認した。

第29版で永続実装の送信経路が変わっているため、m7jの一時介入をそのまま再利用せず、
自作生成器の一時コピーで最初の4応答だけを位置カウンタにより差し替えた。候補間の
自作ROM差分が候補セル1か所だけであること、先行3応答が公式と一致すること、候補差が
最初に現れるのが4件目であること、介入前の構造的一致区間を壊さないことを関門にした。

先行3応答はm7j条件Cと同じく、その場の非表示乱順介入で新規に再構成し、各段階を
追加走で再現してから交換#3探索へ進んだ。これらは測定条件を作るためだけに用い、
交換#3以外の値を永続実装へ採用していない。

## 3. 探索手順と結果

公式対照は600フレームを2走し、探索対象までの値列と構造列が再現することを確認した。
候補側は35フレームとし、各走を同期実行、15秒で打ち切る自前タイムアウト、異常時は
同一条件を最大8回再試行する方式にした。

交換#3の256候補を非表示のランダム順に並べ、main側`$FC IN`の値一致
プレフィックス長が3件から伸びる最初の候補で停止した。採用系列では88試行目に候補が
見つかり、値一致プレフィックス長は**3件から4件**へ伸びた。発見走に加えて同候補を
新規に2走し、合計3走すべてで同じ一致長を再現した。

main側の構造的一致プレフィックスは**258件のまま**で、259件を越えなかった。
したがって交換#3の値一致は達成したが、構造分岐の原因を単独では解消しない。

## 4. 異常と是正

- 公式側を35フレームに短縮した最初の試行は3応答までしか到達せず、観測窓不足として
  関門停止した。m7jどおり公式側だけ600フレームへ戻した。
- 現行永続実装はm7jの先行3応答介入を含まないため、最初の位置関門は成立しなかった。
  先行3件を新規に再構成してから本探索を行うよう修正した。
- 旧単発送信サイトへの限定は第29版の経路変更後の4件目へ効かず、手組みの命令洞窟を
  使う次の試行は応答前にデッドロックした。いずれも採用せず、自作生成器の一時コピーへ
  同じアセンブラAPIで位置カウンタを追加する方式へ改めた。
- 600フレーム公式走で一過性の実行失敗が発生した。同条件の再試行で正常終了し、候補値に
  固定された異常ではない。過去にもある一過性終了の根本原因は未特定のままである。

## 5. 記録場所と限界

確定値を書くのは`docs/spec/l3-subrom.md`と`src/l3_service/make_subrom.py`だけに
限定した。仕様書は実装者へ渡す外部挙動の唯一の根拠、実装はその挙動を生成する必要箇所
だからである。本ノートは測定手順と由来を証明する記録であり、値を重複させる必要がない。
候補値は**意味未特定・挙動から再構成した観測応答**で、公式ROMを読んで得た値ではない。
意味が判明した場合は観測定数をやめ、意味に基づくルール生成へ差し替える。

- 同一の公式ROM一式、同一コア、同一参照媒体、1起動系列での観測に限る。
- 値一致は4件目までであり、その後の応答や制御フローの適合を示さない。
- 構造的一致プレフィックスが伸びない根因は本測定では特定していない。
- 生ログ、一時ROM、一時生成器はリポジトリ外だけで扱い、測定後にファイルを個別に
  `unlink`し、ディレクトリを`rmdir`した。再帰削除は使っていない。

## 6. 実装後の検証

- `tools/run_all_selftests.sh`: 終了コード0。
- `tools/verify_l3.sh`: 交換#3/#4境界、交換#4の自作ディスク内容一致、既存の
  回帰項目は合格。別件の「ディスク無しでもsubがI/Oを発行する」既知未達成を
  そのまま検出したため終了コード1。期待値は弱めていない。
- `tools/conform_l3.sh`: 参照環境を設定して本体を実走。比較器selftestと混成ROM
  差し替えselftestは合格、公式ROM一式による本番は適合、公式mainと自作subの
  混成は不適合で、全体は終了コード1。本体のSKIPは無い。

観測応答の実装後も構造的一致プレフィックスが伸びず、混成適合も達成しなかった
結果と整合する。不適合を通すための期待値変更や判定緩和は行っていない。

## 7. 検証結果（コミット前再検証）

2026-08-13に`PC88_REF_ROM_DIR`と`PC88_REF_DISK_DIR`を設定し、各コマンドへ
10分の自前タイムアウトを付けて再検証した。いずれもタイムアウトせず、本体のSKIPも
無かった。期待値の変更や判定緩和は行っていない。

- `tools/run_all_selftests.sh`: 終了コード1。`tools/analyzer_redaction_selftest.sh`が
  期待終了コード0に対して実際は1、`tools/conform_l3.sh`も期待終了コード0に対して
  実際は1となり、全体をNGと判定した。`tools/verify_l3.sh`の終了コード1は宣言済みの
  想定内失敗として、この集約テスト上はOKと判定された。
- `tools/verify_l3.sh`: 終了コード1。交換境界や回帰項目は通ったが、別件の既知未達成
  である「ディスク無しでもsubがI/Oを発行する」を検出し、L3不適合となった。
- `tools/conform_l3.sh`: 終了コード1。公式ROM一式の本番照合は合格した。公式mainと
  自作subの混成照合では対象イベントを抽出できず、通し番号1件目より前での分岐として
  不適合となった。比較器へ意図的な不一致を与える検出力selftestは、すべて意図どおり
  不一致を検出した。
