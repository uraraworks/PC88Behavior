# B4 追補1: 構成 Q のドライブ2の入れ方（器具の不備と、その直し方）

記録日: 2026-10-26
親: [b4-media-timing-preregistration.md](b4-media-timing-preregistration.md)（f30a6c9）

## 1. 何が起きたか

本走（器具 a48ee43）の構成 Q の FILES・LOAD 22走が、**すべて走る前に引数エラーで終わった**
（終了コード 2、`--disk2 には --disk が要る`）。`q88measure` の `--disk2` は、ドライブ1・2を
同時に装填する経路（`retro_load_game_special` に2枚を渡す）でしか使えず、ドライブ1を空にする
`--insert-disk1` と組み合わせられなかった。ドライバの試走は目印腕（ドライブ2を使わない）だけで行い、
この組み合わせを試していなかった。

エミュレータは1フレームも走っておらず、**Q の FILES・LOAD について結果は1つも得ていない**
（画面署名も照合も無い）。だからこの走を作り直しても、結果を見てから条件を選び直すことにはならない。
事前登録第7節「J-insert を満たさない走は無効とし、同じ腕を再試行しない」は、走ったうえで挿入が
確かめられなかった場合を想定した規則で、今回は走っていない。無効の22走は記録に残したうえで、
次の直し方で Q の FILES・LOAD だけを回し直す。

## 2. 直し方（Q だけ）

- ドライブ2を `--insert-disk2 <媒体> --insert-disk2-at 0`（最初の `retro_run()` の直前に挿入）で入れる。
  B3（`b3-boot-decision-preregistration.md` 第3節）で使った既存の器具。
- フレーム 0 の挿入は CPU が1命令も実行する前であり、ドライブ2だけの媒体は起動の判定に効かない
  （l3-boot-sector 1.4節、B3 の D2 腕）。だから P・R の `--disk2`（装填時に入れる）との違いは
  「入れる手段」だけで、ゲストから見た状態は同じと見込む。**ただしこれは見込みであって測っていない。**
  差が気になる結果（Q だけ一致しない等）が出たら、まずこの違いを疑う。
- ドライブ1（`--insert-disk1 … --insert-disk1-at 200`）・打鍵・腕・判定規則は事前登録のまま変えない。
- 結果の表には、無効の22走（`RUN_FAILED`）と回し直しの22走の両方を残す。
