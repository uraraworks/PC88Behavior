# B90 entry6 の結果

2026-11-13。entry6（16a1537）の再照合を記録する。根拠はクラウド集計とコーディネータ経由の値なし要約。画面本文・データポート値列は記録しない。

- 画面ハッシュ一致は G2・G5 とも 0/60、G3 は変化なし。G1 は S1 が 60/60 に復帰し、F1 は従来の1点（F28200）のみ。
- G5 は 07D6 の戻りと、0263 から戻るまでの FDC 入出力 3100 件が公式と一致。それでも 0263 の戻りは異なった。ヘッド1の正常読込みでは ST0 の HD bit が立つため、戻り A は `(ST0 AND 0xC0) OR ST1 OR ST2`、Cy は A≠0 で1と整理できる。ST0 のマスクは 0xC0〜0xF8 のどれでも観測と矛盾せず、範囲内のどれかは未確定。
- G2 は 048F が公式どおりセクタを読むようになった。048F は読んだデータをサブのバッファに置くだけで送信しない。後続の 00ED(A=06) は状態1バイトだけを返す。通信は OUT $FD 1回→0x09→0x08→0x0B で、[l3-subrom](../spec/l3-subrom.md) の 06 と同じ。セクタデータの送信は要求 0x12 で行う。

仕様への反映: [sub-rom-entry 第6版](../spec/sub-rom-entry.md)。
