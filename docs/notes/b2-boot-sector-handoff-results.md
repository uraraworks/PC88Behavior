# B2: 起動用セクタの受け渡し — 結果（段階2、P0 で停止）

記録日: 2026-10-24
規則: [b2-boot-sector-handoff-preregistration.md](b2-boot-sector-handoff-preregistration.md)（8ba40d0）どおり。規則の変更なし。
条件: 公式 ROM、ドライブ1に自作媒体（(0,0,1)=全バイト 0xC9、目印 seq）、打鍵なし、`--frames 1200`、`nice -n 10`。
記録: `measurements/b2-p0-d0.txt`（番地と件数のみ）。生の出力は作業場 `PC88/tmp/b2-boot-work/` にだけ置いた。

## 取りこぼしと範囲の分け方（第3節の手順）

範囲 `0000-FFFF` の1走は取りこぼしが約 200 万件で使えなかった。二分を繰り返し、
`E5EC-E5EF`（高頻度に書かれる4バイト。4つを単独にすれば各 0 件だが合算で溢れる）を除くと
`0000-E5EB` / `E5F0-E7FF` / `E800-EFFF` / `F000-FFFF` の4範囲が取りこぼし 0 件で取れた。
以降は同じ走をこの4範囲で取る（範囲ごとに別走。決定的に再現した）。`E5EC-E5EF` の ROM 書き込みは未記録。

## D0

- P0 の2走（run1, run2）で、ROM 書き込みの範囲（連続 256 以上）も RAM 実行番地も完全に一致。
- ROM 書き込みの連続範囲: `C000-E5EB`（332640 件）と `E5F0-FFF8`（1291823 件）の 2 本。RAM 上で実行された番地は
  `C000`（1番地）と `E7EE`〜`EDFF` 付近の散在（ROM が RAM へ写した別のルーチン。ディスク無しの対照でも同じ散在が出る
  ことを事前登録外の診断で確認。`C000` はディスクがあるときだけ出る）。
- 規則どおりに数えると候補は 2（`C000-E5EB` と `E5F0-FFF8`）。**第7節「候補が 2 以上」に該当し、X を確定せずここで止めた。**
  A1〜A6 には進んでいない。
- 参考（結論ではない）: `C000` はディスクがあるときだけ実行される RAM 番地で、`C000-E5EB` の先頭に一致する。
  ただし ROM 書き込みの範囲は RAM 全体の初期化と連続しており、「256 バイトを読み込んだ範囲」を単独に切り出せていない。

## 次に要る判断

候補の選び方（「ディスクの有無で変わる RAM 実行番地に限る」等の絞り込み）は事前登録の規則の変更に当たるため、
後続のノートで理由を残してから進む。

## 追補1後（D0'）

規則: [b2-boot-sector-handoff-addendum1.md](b2-boot-sector-handoff-addendum1.md)（**P0 の結果を見たあとに決めた規則**。独立の確認つき）。
抽出器は先に修正済み（PC が [X, X+0x100) のものだけ控えとして扱う。自己検査 M1 は直す前に NG、直した後に合格）。

- N0（ディスク無し、2走）: RAM 実行番地は 32 番地、2走一致。ROM 書き込みの連続範囲は P0 と同じ 2 本（件数のみ差）。記録: `measurements/b2-n0-d0.txt`。
- P0 の RAM 実行番地 34 のうち、N0 でも実行される 32 番地を除くと **`C000` と `EDFF` の2番地**が残る。最小は `C000`（E）。
  E を含む ROM 書き込み範囲は `C000-E5EB` で S = `C000`。**X = `C000`、入口オフセット 0**。
- 独立の確認: X=C000・入口0で組んだ A2（HALT 腕、目印 seq）を2走。**2走とも抽出器が base_true=C000・consistent=yes（probe_rows=33、不一致0）**。
  発行元 PC が実際に C000 台であること（A2 のコードが C000 から実行された）で、D0' の選択と独立に X が裏づけられた。記録: `measurements/b2-a2-confirm.txt`。
  A1・A3〜A6 にはまだ進んでいない。

## 気づいたこと（記録のみ）

G1 の需要測定（811ad44）にも、ROM が RAM に置いたコードからの横断が混ざっている可能性がある
（ディスク無しの対照が無い）。b1 の後続で扱う。
