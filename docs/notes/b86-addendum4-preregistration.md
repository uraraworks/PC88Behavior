# B86 追補4 事前登録（未測定）

3847 が戻るために 37D2 の反復が関係するか、自作入力で調べる。需要は既存の G5 境界時系列のみとし、ゲームの入力、ROM の内容・内部経路を使わない。追補3の単独 3847 は読みを含み戻り印がなく、G5 では 37C9→37D2×165 の後に 3847 が多数戻った。因果関係は未確定。

各腕は独立起動、SP=F000、DI、BC=1、IX=IY=0。D000-D7FF は自作の繰り返し値。37C9 を1回、37D2 を N=1,2,8,165 回、3847 を M=1,2,256,257 回呼ぶ直積とする。入力組 (37C9 の A, 37D2 の A, HL, DE) は (0,0,D000,D400)、(1,1,D000,D400)、(2,0,D400,D000)、(FF,FF,0000,0000) の4通り。37D2 の毎回に指定 A・HL・DE を再設定し、それ以外は前の戻り状態を引き継ぐ。3847 は毎回戻り状態を引き継ぐ。器具の回数管理は C100-C101 とスタックを使い、呼び出し先の共有 RAM に対する介入は行わない。RET と RAM 書き込み・OUT FD を行う自作 RAM ルーチンで同じ反復を検査する。

起動用自作媒体は追補3と同じ。各 CALL の直前直後に印を置き、印の通し順で各 3847 区間の開始、戻り、main の OUT FD と IN FC の件数を記録する。戻り時 A は終了印で非公開ログに収め、区間中に256バイト全体が受信列に一致した自作セクタのうち、A と一致する全位置のみを座標とともに集計する。1バイト一致だけで座標を認定せず、受信済みセクタに限るため空欄は媒体全体に一致がないことを意味しない。再起動・印順序異常・取りこぼしは欠測。開始後に終了印がない場合は時間上限内未確認、後続は欠測とし、無限ループとは断定しない。

腕ごとの ROM 置き場を分け、生ログ・自作媒体・標準出力はリポジトリ外の非公開 raw に置く。ROM 複製とディスク画像は腕終了後に削除し、必要な生 I/O は腕ごとに圧縮して保持する。集計は判定・件数・自作媒体座標と位置のみで、公式 ROM 由来値・内部 PC・画面本文を出さない。腕ごとの上限は既定 2010 フレーム・180秒、変更可能。ログ取りこぼしは欠測として扱う。PC88_REF_* を除いた自作 ROM の自己検査で対照、反復、欠測、漏出を検査し PASS 後に公式 ROM 測定する。
