# m7ip: 入口場面より前の要求を全位置で掃引し、非対称を埋める — 事前登録

## 位置づけ

[m7io](m7io-early-exchange-sweep-results.md)は判定R2に終わり、
**交換run列の`main→sub` 30本すべてに到達して79armでrun長9が一度も動かなかった**
ことを記録した。同時に、**閉じていない経路を3つ**挙げた。その第1が本稿の対象で
ある。

> **入口場面より前の18本は位置0しか触っていない。** 交換run36については
> 6位置すべてを8ビットずつ壊したのに対し、この18本は各runの先頭1バイトだけ
> である。**この非対称を結論に持ち込まない**と`m7in`は事前に書いていた。

**本稿はその非対称を埋める。** 18本の**全位置**に摂動を当て、
「位置0だけだった」という弱点を消す。

## 本稿が決めること（結論の使い道を先に書く）

- **C型（9以外のrun長）が出れば**、「9」が動く条件が初めて見つかる。
- **C型が出なければ**、`m7ii`（40）・`m7ik`（12）・`m7im`（9）と本稿（70）で
  **のべ131armとなり、`main→sub`方向の要求について
  「交換run列の全runの全位置を少なくとも1回壊した」**ことになる。
  **これをもって「要求のバイト列を触る経路では『9』に届かない」を
  3節へ記録する。**

**後者でも「『9』の出所はROM内部である」とは主張しない。** 言えるのは
**「この経路では届かない」**までである（`m7in`・`m7io`と同じ線引き。
3節・第28版が231条件の全滅を「直接読めるハードウェア状態からは導けなかった」と
書いたのと同じ書き方に留める）。

## 段階0（本稿）: 事前登録を測定前にコミットする

本稿は測定を1回も走らせる前に単独でコミットする。測定後の書き換え・amendは
行わない。

## 測定条件（`m7io`と同一に固定する）

- 条件Oのみ（公式ROM一式）。A:=`disk#8`（`650cfac8`）、B:=`disk#10`
  （`0c6f7a53`）。
- 打鍵は水準E（`--type-at 300 --type '\n' --type-at 700 --type 'FILES 2\n'
  --frames 3000`）。
- 基準（摂動なし）は**FDC総数195・READ DATA 117・単発9本＋run長9が12本**。

## 水準（測定前に固定）

`m7io`が列挙した候補18本の**全位置**に`XOR 0xFF`を当てる。

| run | 長さ | | run | 長さ | | run | 長さ |
|---:|---:|---|---:|---:|---|---:|---:|
| 0 | 2 | | 12 | 6 | | 24 | 2 |
| 2 | 1 | | 14 | 2 | | 26 | 1 |
| 4 | 5 | | 16 | 1 | | 28 | 12 |
| 6 | 8 | | 18 | 5 | | 30 | 6 |
| 8 | 2 | | 20 | 5 | | 32 | 2 |
| 10 | 1 | | 22 | 8 | | 34 | 1 |

**長さの合計は70。すなわち70 arm。armを後から追加しない・除かない。**

**位置0は`m7io`で既に測っているが、本稿でも測り直す。** 一致することを合格条件に
入れるためである（後述）。

**候補runの長さは`m7io`が測定済みの値を使う。** 段階1で列挙し直し、上の表と
一致することを確認する。**一致しなければ判定Oとする。**

## armの分類（`m7ih`の定義をそのまま使う。測定前に固定）

- **A型（保持）**: 並びが基準と完全一致。
- **B型**: run長が1と9だけで、run長9の本数が**12未満**。
- **C型**: **9でも1でもないrun長**が1本以上現れる。
- **D型**: 上のどれでもない（FDC総数が基準195の10倍＝1950超は無条件にD型）。

**追加で印を付ける（分類は変えない）**: READ DATA総数が**20未満**のarmは
**「入口場面へ到達していない可能性」**として印を付ける（`m7in`と同じ）。

## 事前登録する判定（測定前に固定。後から動かさない）

- **S1（「9」が動いた）**: C型のarmが1つ以上ある。
- **S2（「9」は動かないが影響はある）**: C型が無く、B型またはD型が1つ以上ある。
- **S3（何も変わらない）**: 70armすべてがA型。
- **O（測定不能）**: 基準が再現しない、候補runの長さが上の表と食い違う、
  位置0の結果が`m7io`と食い違う、決定論性が確認できない。
- **O'（介入が届かなかったarmがある）**: `changed`が0のarmは判定に用いず記録
  する。全armが該当した場合は主判定をO'とする。

**どの判定になるかは予測しない。**

## 事前登録する合格条件（測定前に固定）

1. `tools/recv_run_field_leak_selftest.sh`が全項目OK・rc=0。
2. `tools/analyze_error_exchange_shape_selftest.sh`がrc=0。
3. **基準の再現**: 摂動なしの条件OがFDC総数195・READ DATA 117・run長9が12本。
4. **`m7io`との一致**: 18本の**位置0**のarmについて、FDC総数・READ DATA総数・
   run長の並びが`m7io`の記録と**18本すべてで一致すること**。食い違えば判定O。
   **これは「同じものを見ている」ことの確認である。**
5. **介入が届いていることをarmごとに確認**: 各armで`changed>=1`。
6. **決定論性**: 基準と、**C型に分類された全arm**、および
   **A型・B型・D型それぞれの最初の1arm**について、生ログが独立2回でバイト一致
   すること。
7. **実行したarm数を出力に載せ、70であることを確認する**（`m7ig`でzshの語分割に
   よりループが1回しか回らなかったため）。
8. `tools/check_cleanroom.sh`が全項目OK。

## 実務上の取り決め（測定前に固定）

- 各armの生ログは指標を取り出した直後にscratchpad内で削除する。決定論性の
  確認対象は**その場で2回走らせて比較**してから消す。
- 暴走armは実行時間も長くなりうる。掃引が長引く場合はバックグラウンドで
  走らせてよいが、**測定中に`git stash`・ブランチ切替・`src/`の編集はしない。**

## 言えないこととして先に書いておくこと

- **本稿は`XOR 0xFF`しか当てない。** `m7ig`は交換run36で1ビット反転が
  `XOR 0xFF`と違う結果を出すことを示している（位置3・4は上位ビットにだけ感度が
  あった）。**したがって「全位置を触った」と言えても「全ビットを触った」とは
  言えない。** この限界を結論に持ち込む——本稿が閉じるのは「位置」の非対称で
  あって「ビット」の非対称ではない。
- **`sub→main`方向（応答）は本稿でも触らない。** `m7io`が挙げた第2の未閉経路は
  残る。
- **入口へ到達していないarmは「9が動かなかった」の証拠として弱い。** 印を付けて
  区別する。
- run長や本数から元の値を逆算しない（禁止事項5）。
- 条件O・`disk#10`という1本のディスク・1条件である。一般性は主張しない。

## 禁止（本稿の測定中も例外なく適用）

- 公式ROMのバイト列を読まない・出力しない・保存しない。逆アセンブルしない。
- **公式ディスクのイメージを直接読まない**（D88のヘッダ・セクタ情報を含む）。
- 受信run・応答runのバイト値、FDCデータポート値、シリンダ値、PCN値を出力しない。
  出してよいのは件数・run長・位置番号・交換run番号・clock・**ビットマスクの
  指定値**・真偽値・rcのみ。
- **値を掃引・推論で復元しない。run長や本数から元の値を逆算しない。**
- 画面本文の生の行を報告・ノート・コミットメッセージ・ツール出力へ書かない
  （禁止事項7）。
- 公式ディスクの実ファイル名を展開して表示しない。
- 第三者の逆アセンブルリスト・解析記事のコード断片を参照しない。
