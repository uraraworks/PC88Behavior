# B57: G1 にキーを続けて打って、公式と自作がどこまで同じに進むかを測る — 事前登録

記録日: 2026-11-02
位置づけ: [B56](b56-g1-later-frames-results.md) の次段。スペースの腕は 7200 フレーム以降 `IN $FC` が増えなかった。先へ進むにはさらに入力が要ると考える。**このノートは測定より先にコミットする。**

## 1. 問い

キーを続けて打つと、公式の G1 はディスクをさらに読むか。そのとき自作は同じに進むか。

画面を読んで操作を決めない。**画面本文は誰も見ない。** 進み具合は「移る回数」と `IN $FC` の回数で測る。

## 2. 条件

打ち方は、フレーム 3600 から 1200 フレームごとに同じキーまたは順のキーを打つ。全部 28800 フレーム。クラウドの実行環境で行う。

| 腕 | キー |
|---|---|
| R | リターン |
| S | スペース |
| 1 | `1` |
| 2 | `2` |
| Y | `y` |
| M | スペースとリターンを交互 |

各腕を OO 2 走、SS 1 走。ディスクは G1 の 1 枚目だけで、ドライブ 2 は空。

## 3. 器具

コアは 0018〜0025 のまま。B39 の `--sub-reg-log` の `C`・`F` の行の数を使う（io ログはあふれるので使わない）。画像とテキストは B29 と同じく一致だけを見て、どこへも置かない。

## 4. 記録の白リスト

`arm <腕> oo=<same|differ> image=<same|differ> text=<same|differ> cross=<左> <右> fc=<左> <右> first-cross-pc=<N|none> `

`first-cross-pc` は移る先が最初に違う番号である。**値は出さない。**

## 5. 判定（事前に決める）

- 公式の `cross`・`fc` が B56 より増える腕を「進む腕」と書く
- 進む腕で自作が一致するかを書く。違えば `first-cross-pc` を書き、B46 の器具で次を測る
- どの腕でも増えなければ、打つキーの候補を増やす前に、キーを読んでいるかを別に測る
