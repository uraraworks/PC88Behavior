# B58: スペースのあとに別のキーで G1 が進むかを測る — 事前登録

記録日: 2026-11-02
位置づけ: [B57](b57-g1-key-sequences-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

スペースの腕の 71 回のあと、別のキーを打つと公式の G1 は先へ進むか。進むなら自作も同じか。

画面を読んで操作を決めない。進み具合は B57 と同じく、移る回数と `IN $FC` の回数で測る。

## 2. 条件

フレーム 3600 でスペース、7200 から 600 フレームごとに、腕のキーを順に打つ。全部 36000 フレーム。公式 2 走、自作 1 走。クラウドの実行環境で行う。

| 腕 | キー |
|---|---|
| D | `0`〜`9` |
| L | `a`〜`z` |
| C | 上下左右のカーソル |
| F | ファンクションキー 1〜5 |
| E | ESC、TAB、STOP に当たるキー、DEL |
| T | テンキーの `2`、`4`、`6`、`8`、`5` |

コアに無いキーは、腕の行に `untypable=<数>` で書く。

## 3. 記録の白リスト

`arm <腕> untypable=<N> oo=<same|differ> image=<same|differ> text=<same|differ> cross=<左> <右> fc=<左> <右> first-cross-pc=<N|none>`。**値は出さない。**

## 4. 判定（事前に決める）

- 公式の移る回数が 71 より増える腕を「進む腕」と書き、自作が同じかを書く
- どの腕でも増えなければ、キーでは進まないと書く（画面の変化までは言わない）
