## Q4: 繰り返しの開始を1フレーム分解能で決める

**問い**: 文字キー(`q`)と→キーで、(1)押し始めから最初の1文字が書かれる
までのフレーム差、(2)押し始めから1回目のリピートまでのフレーム数
（遅延）、(3)以降のリピート間隔、が**1フレーム分解能で**一致するか。
一致しなければ`different_delay`（間隔は同じで遅延だけ違う）か
`different_phase`（遅延の測り方・基準点自体がキーごとに異なる、または
押すタイミングに依存する）かを切り分ける。

これまでのQ1（30フレーム間隔→本走で最小5フレーム間隔）・Q2（HOLDを
τ,Iから逆算した離散的な数値でしか振っていない）は、いずれも遅延・
間隔を「範囲」としてしか決めていない。l4-c6追補が見つけた
「offset=50で公式7・自作6」という1件差は、遅延26〜31フレームという
幅の中のどこで実際に遷移するかを1フレーム単位で決めない限り、
「文字キーと→で繰り返しの位相が違う」のか「範囲の測り方が粗いだけ」
なのか区別できない。

### 方法

#### qキー（文字キー）

`--vram-dump`は1走最大16枚（`VRAM_DUMP_MAX`）なので、窓をずらして
複数走に分ける。写しはすべて「押す前(D0)との差分件数」だけを見る
（Q1と同じ、`diff_cells`のwas_blank件数）。

- **q-F1（最初の1文字）**: offset 1〜15（1フレーム刻み、15枚）。
  押し始めのフレームから最初の1文字がVRAMに現れるまでのフレーム差を
  求める（件数が0→1に変わる最初のoffset）。
- **q-F2（1回目のリピートの候補窓）**: offset 20〜34（1フレーム刻み、
  15枚）。件数が「1」から「2」に変わる**ちょうどのoffset**を求める
  （事前登録本体・追補が「範囲」としてしか出せなかった遅延を、1フレーム
  で確定させる）。
- **q-F3（間隔の確認窓）**: offset 35〜49（1フレーム刻み、15枚）。
  件数が「2→3→4→5→6→7」と増える**それぞれのoffset**を直接読み、
  隣接するoffset差をそのまま「その回の間隔」として記録する（平均では
  なく、回ごとの実測値。間隔が4フレーム固定か、3.98フレームのような
  端数が周期的に3/4/5フレームへ揺れているかを区別できる）。

#### →キー

→はカーソル移動だけでVRAMを書かないため（`s1h_q2_*`の
`pretarget_diff_count`が常に0だったとおり）、Q1と同じ「写しを複数枚
取る」方法が使えない。代わりに、**HOLDを1フレームずつ振り、離した後に
目印`w`を打って着地列（移動数）を読む**（`s1h_q2_*`と同じ手法、HOLDの
刻みだけ1フレームにする）。

- **arrow-F1**: HOLD = 20, 21, 22, ..., 49（30通り、1本ずつ独立した
  q88measure実行）。着地列（移動数）をHOLDごとに記録する。移動数が
  「1」から「2」に変わる境目のHOLD値が→の遅延、以降「2→3→…」に
  変わるHOLD差が→の間隔（qと同じ考え方）。

### 位相依存の確認（3.）

押し始めのフレーム自体（settle後、HOME/CLR直後に押すか、数フレーム
ずらして押すか）で遅延・間隔が変わるかを、qと→それぞれ1腕ずつで見る。

- **q-phase**: q-F2と同じ窓（offset 20〜34）を、押し始めのフレームを
  **+2フレームずらして**（間隔4の倍数ではない値をずらし幅に選ぶ——
  もし内部的に押下フレームに依存しない共通のグローバルカウンタに
  同期しているなら、ずらすと相対offsetでの遷移点が動くはず）再実行する。
- **arrow-phase**: arrow-F1のHOLD=20〜34の範囲を、同じく押し始めの
  フレームを+2ずらして再実行する。

判定: 元の窓と位相をずらした窓で、件数(または移動数)が「1→2」に
変わる相対offset(またはHOLD)が変わらなければ`phase_independent`
（押下起点の相対タイマーで動いている）。変われば`phase_dependent`
（何らかの絶対クロックに同期している）とする。

## 判定名（測定前に決める）

- `same_timing`: qと→で、最初の1文字までのフレーム差(qのみ該当。
  →には対応する量が無い——移動はカーソル位置の変更であって文字の
  書き込みではないため)を除き、**遅延（1フレーム精度）・間隔（1フレーム
  精度、複数回分）がすべて一致**する。
- `different_delay`: 間隔（複数回分の刻み）はqと→で一致するが、
  1回目のリピートまでの遅延（1フレーム精度）が異なる。
- `different_phase`: 遅延・間隔のいずれか、または両方が、qと→で
  単純な定数差ではなく説明できない（位相依存の結果と合わせて、
  「共通の絶対クロックに同期しているためキーの種類や押すタイミングで
  実効遅延が変わる」ことが示唆される場合）。
- `inconclusive`: 1フレーム分解能でも遷移点が2走で一致しない、または
  q・→どちらかの窓に遷移が収まらなかった場合。

## 関門（既存の各節を流用、新設分のみ追記）

- G1: 器具は`tools/l4_key_repeat_record.py`の`run_sweep`
  （offsetsを1フレーム刻みのリストにするだけ）・`run_arrow_arm`
  （HOLDをループで1フレームずつ振るだけ）をそのまま使う。新規の
  q88measure呼び出し方は増やさない（オフセット・HOLDの値だけが変わる）
  ため、新設の自己検査は不要と判断する
  （`tools/l4_s1h_multidump_selftest.sh`が同じ「1走で複数写し」の
  組み合わせを既に検査済み。HOLDを1ずつ振る方はQ2の`s1h_q2_*`と同じ
  1走3写しの構造そのままで、HOLD値が違うだけ）。
- G2: 取りこぼし0・警告0（全走のstderr）。
- G3（決定論性）: 全30+通りのHOLD・全offsetを2走ずつ取ると量が
  大きくなるため、**代表点のみ2走**にする: q-F2（offset20〜34の窓
  全体）・arrow-F1のうちHOLD=26,30,34（遅延候補の代表3点）を2走。
  他は1走（Q4は「境目のちょうどの値」を1フレーム分解能で特定する
  ことが目的であり、Q1本体・Q2本体で既に決定論性〈G3〉を確認済みの
  同じ器具・同じ種類の測定を、値だけ変えて追加するもの）。
- G9: q-F1〜F3・q-phaseはいずれもHOME/CLR直後の空白画面を使うため、
  Q1と同じくD0（押す前）が全行非空白0件であることを確認する。
