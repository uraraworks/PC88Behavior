# 汚染記録 2026-08-07

`CLAUDE.md`「汚染したとき」に従って記録する。隠さない。

## 何が起きたか

『PC-Techknow 8801 Vol.1』(アスキー出版, 1982) の EPUB から
**付録6「I/O ポート一覧表」の位置を特定しようとして**、
EPUB のページ 280〜305 の**各ページ先頭 80 字**を一覧表示した。

その範囲に付録5側の内容が含まれており、次のものが目に入った。

- N88-DISK-BASIC 使用時の**フックアドレステーブル**（EPUB p.281）
- 同 **アドレスと内容の対**（p.282, p.283）— `ED2D JP 8FBD` の形式で数件
- 同 **I/O 処理ルーチンのジャンプテーブル**（p.284）
- 同 **DISK 命令のジャンプテーブル**（p.285）
- 同 **ON 割込みアドレステーブル**（p.286）

いずれも「この番地には、この番地への JP がある」という**ROM のコードの内容**である。
ポート番号や機能名のような事実ではない。`CLAUDE.md` 禁止事項2 の
「他人が公開している解析記事のコード断片も読まない」に該当する。

## なぜ起きたか

目次で付録6が印刷ページ 286 からと分かっていたので、
EPUB のページ番号とのずれを確かめるために前後を広めに走査した。
**隣が禁止領域だと分かっていながら、その上を通る方法で位置合わせをした。**

「見出しだけ 80 字」に絞れば安全だと考えたのが誤りだった。
アドレス表は 1 行が短いので、80 字あれば中身が数件入る。
**禁止領域の隣を走査するなら、出力の長さを絞るのではなく、
そもそも表示しない方法を採るべきだった**（ページ番号だけを出し、
目次の印刷ページ番号と突き合わせてオフセットを決める、など）。

## 範囲

見たのは **N88-DISK-BASIC のフック／ジャンプテーブルの断片**であり、
数件のアドレス対に限られる。全体を通読してはいない。

**影響しない範囲**:
- L1（起動時のハードウェア初期化 / I/O ポート）。今回見たものと領域が違う
- `docs/spec/l1-ipl.md` の全内容。測定と、ポート仕様の資料だけから書いている

**影響する範囲**:
- L3 のうち **ディスク関係のサービスルーチンの入口**
- ゴール B の **ROM 内エントリアドレスの配置**

## 手順の是正

禁止領域を含む資料から特定の章だけを取り出すときは、
**内容を一切表示せずに位置を決める**こと。

- 目次に印刷ページ番号がある場合は、既知の 1 点（本文の章扉など、安全なページ）で
  EPUB ページとのオフセットを確定し、そこから計算で目的の範囲を出す
- 走査が要る場合でも、出力してよいのは**ページ番号と、章見出しに現れる語の有無**
  （`grep -l` のように、一致したかどうかだけ）に限る
- 「短く切れば安全」は成り立たない。表形式の資料は 1 行が短い
