# m6f-c 追補3 — 「書き込み禁止」を決めているセクタの掃引 — 事前登録

記録日: 2026-09-25  
状態: 測定前（本測定4回目は `m6f_c_no_free_mark`）

## 1. 経緯 — 本測定4回目

追補2の構成（ドライブ1＝参照 diskA の複製で起動、ドライブ2＝自作媒体）で回した。
器具 `6724701`、G1 は除外2件で rc=0。結果は `PC88/tmp/m6-work/m6fc-run4-2026-09-25/`（リポジトリ外）。

- GB-FF・GB-00 の4走とも `ZQbt`。F\* = 0xFF。G8（ドライブ1不変）は全走で真。
- **SW の 512 走（V=0x00〜0xFF、各2走）は、すべて `ZQer 61 20`**（20 行で誤り番号 61）。
  2走の食い違いは無い。総合判定 `m6f_c_no_free_mark`。
- SW の全走で、ドライブ2に対する READ DATA は同じ順
  **(18,1,14)・(18,1,15)・(18,1,16)・(18,1,13)・(18,1,1)**、WRITE DATA は0件。

**誤り番号 61 は、マニュアルの番号表（`docs/spec/l4-basic.md` 第6節、出所は
`docs/notes/refs-manual-error-messages.md`）で「File write protected」である**（「Disk full」は 68）。
自作媒体の D88 ヘッダの書き込み保護は 0x00（保護なし）なので、**ROM は媒体の中身から
書き込み禁止と判断している。** 割り当て表の値 V をどう変えても 61 のままなので、
判断は割り当て表以外のセクタで決まっている。割り当て表の3セクタのほかに読まれたのは
(18,1,13) と (18,1,1) だけで、どちらも詰め物 0xFF である。

したがって、4回目の `m6f_c_no_free_mark` は「空きの印が無い」ことを示していない
（書き込みより前で止まっている）。

## 2. 刺激

生成器に規則を足す: **指定したセクタの 256 バイトすべてを値 W にする**（`--sector-fill C,H,R=W`、
複数可。既定では何もしない。既定のときの生成物は `6724701` の生成器とバイト一致させる）。

追補2の構成（ドライブ1で起動、ドライブ2に媒体）で、打鍵は SW と同じ、フレーム 8000、各2走。

| 掃引 | 媒体（ドライブ2） | 腕 |
|---|---|---|
| P13 | `B(0xFF, 0xFF)` の (18,1,13) を W | `P13-00`〜`P13-FF` |
| P1 | `B(0xFF, 0xFF)` の (18,1,1) を W | `P1-00`〜`P1-FF` |

**W は全値を掃引し、特定の値を本命として置かない。**

## 3. 導出規則

各走を SW と同じく目印で分類する（`ok` / `ng` / `er`＋ERR・ERL / `none`）。

- **Q1 書き込み禁止を外す値**: 掃引ごとに、2走とも「目印が `er` で ERR=61」**ではない**
  W の集合 Wclear13・Wclear1。2走で分類が食い違った W は外して列挙する。
- **Q2 対象のセクタと W\***: Wclear13 が空でなければ対象は (18,1,13)、W\* = min(Wclear13)。
  そうでなく Wclear1 が空でなければ対象は (18,1,1)、W\* = min(Wclear1)。
  両方空なら `protect_sector_not_found`。
- **Q3**（副）: 各 W について、分類（ERR を含む）と、ドライブ2への READ DATA・WRITE DATA の
  座標の列を記録する。Wclear の各 W で ERR が何に変わったか（68 等）も記録する。

### 3.1 補足（測定前、2026-09-25）

1回目の掃引は、P13 の途中でコアが abort（rc=134）し、`gate_failed emulator_run` で止まった
（腕の目印は見ていない）。診断で同じ媒体（P13、W=0x11）を2回回すと2回とも正常に終わり、
**abort は非決定的**だった。本測定4回目（516 走、`--save-to-disk-image` あり）では起きていない。
次のとおり補って回し直す。

1. abort した走は、媒体を作り直して**最大2回まで回し直す**。回し直した回数を記録する。
   3回とも abort なら、その走の分類を `abort` とする。abort 以外の異常終了は `gate_failed`。
2. q88measure の引数を本測定ドライバとそろえ、`--save-to-disk-image` を付ける
   （ドライブ1が変わらないことは G8 で確かめる）。
3. **Q1 の Wclear は、2走とも目印（`ok`・`ng`・`er`）が出て、どちらも「ERR=61 の `er`」で
   ない W に限る。** 目印なし・`abort` の走を含む W は Wclear に入れず、`no_marker_or_abort` として
   列挙する（元の文言では、目印なしや異常終了が「外れた」に数えられてしまう）。

## 4. 行き先

- Q2 が決まった: 生成器の規則に「対象のセクタは W\*」を加え、**追補2の構成で本測定
  （GB・SW・段階2）を最初から回し直す。** 導出規則・判定名・行き先は事前登録のまま。
  4回目の結果は消さずに結果ノートへ残す。
- `protect_sector_not_found`: 一様値では書き込み禁止を外せない。ROM が読むセクタを
  広げて測る追補を置く。

## 5. 決まらないこと

- 対象のセクタのどのバイトが効いているか（一様値の掃引では分からない）。
- 対象のセクタの他の役割。
- マニュアルが述べる書き込み禁止の設定手段（言語仕様）と、この印の関係。

## 6. 結果（2026-09-25 追記）

器具 `6607d73`、G1 は除外2件で rc=0。P13・P1 各 256 腕 × 2 走、abort の回し直しは0回。
結果・導出は `PC88/tmp/m6-work/m6fc-protect2-2026-09-25/`（リポジトリ外）。result の SHA-256 は
`6a1031bfbe1c7dfd71bd478729bc58676e985f84ba02399a00ca88aea50dca06`。

- **P1（(18,1,1)）**: 512 走すべて `ZQer 61 20`。Wclear1 は空。
- **P13（(18,1,13)）**: 256 走が `ZQok`、256 走が `ZQer 61 20`。2走の食い違い・目印なしは無し。
  **Wclear13 は、0x10 のビットが 0 の W の 128 値**（0x00〜0x0F、0x20〜0x2F、…、0xE0〜0xEF）。
- **Q2 `derived`: 対象は (18,1,13)、W\* = 0x00。**

**解釈（決定ではない）:** (18,1,13) のどれかのバイトの 0x10 のビットが、媒体の書き込み禁止の
印になっている。どのバイトかは一様値の掃引では決まらない（§5）。

**副次の観察:** Wclear13 の W では、割り当て表が全面 0xFF のままで SW のプログラム（作成・
書き込み・読み戻し）が `ok` まで通った。空きの印の結論は本測定の SW に任せる。

§4 に従い、生成器の規則に「(18,1,13) は 0x00」を加え、追補2の構成で本測定を最初から回し直す。
