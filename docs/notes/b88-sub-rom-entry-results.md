# B88 サブ ROM 入口 — 初回・追補1の結果

2026-11-12。仕様は [sub-rom-entry.md](../spec/sub-rom-entry.md)。ゲームの値や ROM のバイト列は記録しない。

## 測定 ID と方法

- **B87**: 公式環境のゲーム G2・G5 のサブ RAM→ROM 境界。G2 は 3000F まで、G5 も 3000F までの記録。番地・移動種別・回数と戻りを観測した。0010・0018・0020 の CALL/RST の別は境界集計から確定しない。
- **B88**: 自作プローブによる初回。事前登録 `979be34`、ローダから未確定の要求 0F を除く訂正 `09d9bfb`。訂正前の260走は入口未到達であり結果に含めない。訂正後は130腕×2走、欠測0、戻り114走・時間上限146走、全腕で2走の値なし集計が一致。陰性・陽性対照は期待どおり。
- **B88-add1**: 追補1、事前登録 `d87ead3`。628腕×2走、確認1180走・時間上限52走・欠測24走。値なし集計の2走一致は616/628腕、残り12腕は欠測。両対照を確認。自作媒体・入力、main 側の通信協力、媒体交換などを使用。自己検査 `b88a1_selftest.sh`・`b88_selftest.sh` は PASS。

## 番地ごとの需要と結果

| 番地 | 需要（B87） | 働き（プローブ） |
|---|---|---|
| 0010 | G2 95回・戻り95、G5 213回 | B88 は main 無応答で時間上限。B88-add1 は CALL/RST とも main の4値を受信し A に返る。A・F以外不変。 |
| 0018 | G5 7790回 | B88 は main 無応答で時間上限。B88-add1 は CALL/RST とも A を1バイト送る。OUT FD 1回、A・F以外不変。 |
| 0020 | G5 182回 | B88・B88-add1: MSR 読取り後に A を FB に送る。全レジスタ不変。 |
| 00ED | G2 JP 21回 | B88・B88-add1: A=0 で初期化・シーク後に戻る。A=1 は時間上限。戻る腕ではレジスタが一定だが、追補の一定値集計は空。 |
| 048F | G2 JP 2回 | B88 は SENSE DRIVE STATUS を繰り返し時間上限。B88-add1 はドライブ2媒体ありの到達腕だけ戻る。 |
| 06A6 | G2 CALL 2回・戻り2 | B88・B88-add1 は時間上限。働き未確定。 |
| 0263 | G5 CALL 26回 | B88・B88-add1 は時間上限。働き未確定。 |
| 02A4 | G5 CALL 26回 | B88・B88-add1: 0020 と同様に A を FDC へ送り、7F0C にも A を書く。 |
| 02A7 | G5 JP 26回 | B88・B88-add1: 0020 と同様に A を送る。02A4 の途中の入口。7F0C は書かない。 |
| 02B4 | G5 CALL 26回 | B88・B88-add1: I/O なしの計算。追補1では A 全256値と F=00/01 の512入力×2走で戻る。 |
| 035B | G5 CALL 26回 | B88・B88-add1: OUT F7 1回、戻り A は出力値と一致、7F0B に書く。 |
| 07D6 | G5 CALL 2回・JP 24回 | B88 は SENSE DRIVE STATUS を繰り返し時間上限。B88-add1 はドライブ2媒体ありの到達腕だけ戻る。 |

追補1の準備待ち腕は A、ドライブ1・2の媒体、00ED 前処理を変えた。A=1 で前処理ありの腕は前処理が戻らず対象入口に到達しないため欠測。時間上限は永久に戻らない証明ではない。00ED はドライブ2媒体の有無にかかわらず A=0 で戻り、A=1 で時間切れ。

02B4 の追補1の関係集計は、測定した F=00/01 の両条件で戻り A=00、F=44 を示す。入力 F の他のビットは振っておらず、他条件への一般化はできない。035B は測定した A=00/01/35/80/FF、F=00/01/40/FF の範囲で戻りレジスタが基準腕と一致し、出力値と戻り A が一致する。出力値の具体値や他の入力条件との関係は集計から確定しない。

## 追補2・追補2b

- **B88-add2**（事前登録 `0890ee2`）: 公式環境で27腕×2走。自己検査 PASS、確認32走・戻らない18走・欠測4走で、2走のレジスタ一致と対照を確認。戻った入口では IFF1・IM を呼出し前の状態のまま保つ。00ED・048F・07D6 はこの条件では戻らなかった。0263 は先行処理が完了せず、入口未到達で全腕欠測となった。06A6 は通信データを受信した後も待ち続けた。
- **B88-add2b**（事前登録 `0307a85`）: 公式環境で64腕×2走。自己検査 PASS、確認80走・戻らない48走・欠測0。0263 は対象腕すべてで戻り、FDC の結果相から7バイトを読み出す。各バイトにつき IN $FA と IN $FB を1回ずつ行い、7F0D〜7F13 に順に書く。06A6 は main から4バイトを受信すると戻り、1〜3バイトでは待ち続けた。戻った入口は引き続き IFF1・IM を呼出し前の状態のまま保ち、00ED・048F・07D6 はこの器具の条件では戻らなかった。
- **戻り時 IFF の範囲**: 追補2で戻った入口は 0010・0018・0020・02A4・02A7・02B4・035B、追補2bではこれに0263・06A6を加えて確認。00ED・048F・07D6 の IFF は未確定。時間上限は永久に戻らない証明ではない。
