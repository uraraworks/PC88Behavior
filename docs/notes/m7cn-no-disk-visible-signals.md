# m7cn — no_diskの可視信号と待ち手前の分岐

日付: 2026-08-24

## 結論

公式環境で4 armを実走し、rc=0、4/4採用、全run取りこぼし0件だった。採取窓は
700–799Fである。`no_disk`を正常B:と区別できる信号は自作subから見える。しかし、
公式の待ちを模した介入は800F画面を再現せず、mainタイムアウト仮説は否定された。
本当の次境界は待ちの実装ではなく、その手前ですでに異なるmain→sub要求の
**公式5バイト対混成6バイト**の分岐である。

## 自作subから見える信号

混成既定ROMの`no_disk`と正常B:を比較した。公開ビット16項目のうち差は3項目だった。

- SENSE DRIVE STATUS / ST3はbit6 WRITE PROTECTEDとbit3 TWO SIDEに差があり、
  bit5 READYを含む他6ビットは差がなかった。
- FDC MSRはbit5 NON-DMA MODEだけに差があった。
- `IN $F8` / `$FC` / `$FE`の24ビットはすべて差がなかった。
- READ DATAのST0/ST1/ST2とSENSE INTERRUPT STATUSのST0は片条件だけの観測で、
  比較不能だった。

時間・完了外形では、SENSE DRIVE STATUS発行件数が`no_disk` 1件／正常7件、
READ DATAが1件／7件で、READ DATAは完了状態と所要clock集合にも差があった。
SEEKは0件／6件、SENSE INTERRUPT STATUSは0件／6件、RECALIBRATEは差なしだった。
自作subタイムアウト印は`no_disk` 17件、正常B: 0件である。

従って`no_disk`を区別できる信号は存在する。ただし、公開μPD765仕様からST3 bit6/bit3を
「媒体無し」とは読めない。QUASI88のD88取り扱いの副作用を測った可能性を残す。
本プロジェクトで既に採っている「エミュで測った値はエミュの実装を測っている」という
扱いに従い、区別可能という定性的結論だけを採り、定量精度や実機一般性は主張しない。
公開仕様上の意味へ無理に寄せない自作subタイムアウト印17件／0件の方が、より素直な
区別信号である。

## 公式の待ちの外形とm7ciとの照合

公式ROM一式`no_disk`はSENSE DRIVE STATUS 52277件、522.770件/Fで、単位Fの範囲は
0..1295件だった。混成介入`no_disk`は66150件、661.500件/Fで、範囲は661..662件だった。
密度比は1.265倍（66150:52277）で大差ではないが、公式はバースト的、介入は均一であり、
待ち方の分布が異なる。両者とも窓内のsub→main応答は0件だった。

公式の52277件は、m7ciが「採用ログ全体で52277件」と記録した数字と完全一致した。
前回51800件と食い違って見えたのは、入口判定区間とframe窓の区間定義が異なったためで、
観測系は相互に裏が取れた。この照合では数字を換算して辻褄を合わせていない。

## mainタイムアウト仮説の否定

応答を返さずSENSE DRIVE STATUSを反復し続ける混成介入の800F画面は2行90字、
公式期待値は8行193字で、画面署名も不一致だった。従って「subが応答しなければmainが
自分でタイムアウトして公式エラー画面へ進む」という仮説は否定された。**mainは自分では
諦めていない。** 公式も窓内ではsub→main応答0件なのに、800F時点で公式だけが
エラー画面へ到達する、という妙な点が残る。

m7clの構造解析どおり、分岐直前の要求は公式main→subが長さ5、混成が長さ6であり、
待ちへ入る前からすでに経路が分かれている。次に追うのはこの5対6を選ぶ分岐である。
**待ちの形を真似る方向へは進まない。**

## 行き止まりと作業上の事故

- 採取を20フレーム窓へ縮めた対処は空振りだった。固定長観測容量を避ける代わりに
  現象そのものを落とし、比較可能な公開ビットが0項目になった。
- シェルで`local a=... b="$a"`と同じ宣言内の変数を参照する形が3箇所あり、bash 3.2の
  `set -u`で未定義変数として落ちた。公式環境がある経路でしか踏めず、委譲先の確認を
  すり抜けた。宣言と代入を分離して対処した。
- 反復密度の節に「公式」というラベルを付けたが、実際は混成既定と混成介入という
  自作sub同士の比較だった。そのためm7ciの51800件と食い違って見え、前周の測定を
  疑いかけた。公式armを含む再実走で対象を正し、上記52277件の完全一致を確認した。
