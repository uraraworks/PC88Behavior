# B86 追補6 事前登録（測定前）

需要の出所は G2・G5 の番地、回数、呼び順だけとする。働きは自作入力によって測り、ゲームのレジスタやメモリの値を使わない。対象は 3391、3080、11DF、3DED、39CE、6F6B。G2 は 3391×3、37C9、37D2×2、369A、3391 の順で計8回呼ぶ。G5 の後半は 3080 への JP が22967回、11DF への JP が4回、6F6B の CALL が1回あり、3DED・39CE への JP もある。3DED・39CE は G2 にもある。

各腕は別起動・別 ROM 置き場とし、媒体は座標刻印付きの自作媒体を用いる。37C9 の A は要求、37D2 の A は引数、369A は B=シリンダ×2+面、C=セクタ、HL=転送先、キャリーは読み書き指定として扱う。方向の仮定を結果に混ぜず、キャリーの両値を試す。37C9 と各 37D2 の A は独立に選び、00、01、02、FF を基準から一つずつ変える。369A は基準 B=00、C=02、HL=D000 から B=01、02、C=01、03、HL=D400、E000、およびキャリーを一つずつ変える。自作媒体と転送先には再現可能な異なる模様を用いる。順序は 37C9 → 37D2 → 37D2 → 369A → 3391 とし、各区間に開始・終了印を置く。3391 区間のサブ要求は IN FC で区切った OUT FD 連続の先頭バイトと長さだけを出す。未完の末尾は未完と明記する。

3391 から RAM へ制御が移る場合は最初の移動先の番地と実際のメモリ種別、移動時 HL、369A の指定転送先との関係を記録する。移動先が RAM の場合、その実行開始位置の内容が自作入力と一致するかを真偽で比較する。比較範囲と取得の可否も示し、値や ROM 内部経路は出さない。通常の戻り先への復帰とそれ以外の移動を区別する。移動が観測できない場合は欠測と未発生を区別する。

3080・11DF・3DED・39CE は CALL せず JP で入る。SP=F000 に自作戻り先を積む腕と、同じ位置に自作の非戻り先を置いて積まない腕を用意し、実際にスタック先頭にある番地に到達したかを調べる。積まない腕もスタック先頭の値は自作とし、偶然の一致を防ぐ。DI と EI の両方で、A、HL、DE、BC を基準値からそれぞれ独立に変える。戻り先到達時のレジスタ・フラグ・SP の変化は入力との一致・変化と自作値との差だけで示す。区間の I/O はポートと方向ごとの件数、RAM は前後で異なる番地範囲だけを出す。到達前の再起動、時間上限、取得不能は別にする。EI は割り込み受理を保証しないため受理の有無も記録する。

6F6B は CALL し、A・HL・DE・BC を同じ方式で独立に変える。戻り、レジスタ・フラグ・SP の変化、I/O 件数、RAM の変化番地を記録する。RAM の前後比較は対象範囲と器具自身の書き込みを明示し、未帰還では前後比較不能とする。自作 RET と、既知のレジスタ・フラグ・RAM・I/O 変化を起こす陽性対照を置く。

追補5と同様、開始印の再出現で未終了の区間を「戻らない（再起動）」と数え、それ以降を捨てる。開始印がない、ログ取りこぼし、印の順序異常は欠測。終了印も再起動もない場合は時間上限内未確認とし、無限ループとは断定しない。要求見出しを除き測定値の列を集計に出さない。ROM 由来バイト、画面本文、ゲームデータ、ROM 内部 PC は出さない。生ログはリポジトリ外に限定し圧縮、ROM 複製と大きな一時出力は腕ごとに削除する。失敗腕も記録して残りを継続し、停止条件は設けない。

自己検査は PC88_REF_* なしで、対照、JP の両スタック条件、DI/EI、レジスタ・フラグ・SP、RAM と I/O、移動先の分類と一致判定、未帰還、再起動、欠測、順序異常、値の非出力を陽性・陰性対照で検証する。配布用自作 ROM は実装の有無を問わず結果を記録する。自己検査 PASS 後にクラウドで測定する。
