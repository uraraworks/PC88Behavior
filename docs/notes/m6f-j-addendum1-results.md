# m6f-j 追補1 — 結果（SAVE ,A の規則を採る）

記録日: 2026-09-29

## 1. 実行

[追補1](m6f-j-attempt1-and-addendum1.md) §2 に従った。器具 `1d577b2`、J-4・J-5・J-6 の3腕×2走、公式ROM起動6回。G1〜G9 はすべて真。2走一致。

| 腕 | 判定 |
|---|---|
| J-4（書き込み禁止の媒体） | **`error_61`**（媒体不変） |
| J-5（空きの無い媒体） | **`error_68`**（媒体不変） |
| J-6（未挿入のドライブ） | **`waits_for_media`**（挿入後に保存された） |

## 2. 採った規則（1回目の J-1〜J-3 と合わせて）

1. `SAVE "<ドライブ>:<名前>",A` は ASCII 形式（l3-disk-format 2.6節）で本体を書き、種別 `0x00` のエントリを作る（J-1・J-2）。
2. 完了しても `Ok` の行を足さない（J-1 `no_line`。`LOAD` とは異なる）。
3. 同じ名前のファイルがあれば、**そのエントリの位置に上書き**し、**古いファイルの単位は空き（`0xFF`）に戻す**（J-2）。
4. 新しい単位は、空の媒体での割り当て順（l3-disk-format 2.5節）で**最初の空き**を使う（J-3）。
5. 書き込み禁止の媒体では **`ERR 61`**、空きが無ければ **`ERR 68`**。どちらも媒体を変えない（J-4・J-5）。
6. 媒体の無いドライブを指すと、エラーにせず挿入を待つ（J-6）。
