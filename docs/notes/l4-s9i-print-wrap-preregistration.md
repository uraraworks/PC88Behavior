# l4-s9i — 普通の PRINT の行端を測る事前登録

記録日: 2026-10-05  
状態: **測定前**（公式ROMはこの作業では実行しない）

## 根拠と公開ソースを読んだ範囲

CLAUDE.md、[汚染の教訓](contamination-2026-10-05-print-using-empty-format.md)、
[l4-basic.md 第4節](../spec/l4-basic.md)、[l4-program.md 第8節22・25](../spec/l4-program.md)、
[s9h追補1](l4-s9h-addendum1-rejudge.md)、器具 `tools/l4_pusing_measure.py` を読んだ。
公式ROMの内容・保存済み公式画面は読まない。全腕は既知の通常文字の PRINT だけで構成し、
制御文字・誤り処理・PRINT USING を使わない。既知の順序・個数に一致しない画面は内容を返さない。

MIT公開ソース `../refs/GW-BASIC/` を `rg -a -n` で PRINT / STRPRT / WIDTH /
PTRWDC / SCNSOT 等について検索し、次の範囲を読んだ（コードの転載はしない）。

- `GIO86.ASM`: 210–295、420–600、1000–1080、1200–1245。
- `BISTRS.ASM`: 215–300。
- `GIOSCN.ASM`: 60–120、140–210、235–270、280–316。
- `GWSTS.ASM`: 185–240。
- `SCNDRV.ASM`: 195–225、324–350、380–455、475–538、1400–1500。

GW は式を評価してから、文字列・数値を共通の項目として扱う。現在桁が0でなければ、
項目全体が幅を超えると項目の前に改行する。ちょうど収まる場合は改行しない。
行頭では幅より長い文字列でも先に改行せず、文字を順に出し、画面側の折り返しに任せる。
連結式も評価後の一つの文字列なので同じ検査になる。数値は文字列化し、正数の前置空白と
（通常は）後置空白も長さに入れる。コンマ終端にはゾーン境界直前の後置空白を省く特例がある。
コンマ幅は14で、GW の最後の完全な欄の開始桁は幅80では56。現在桁が56以上なら改行する。
WIDTH は画面・装置・ファイルに分かれ、画面幅と高さは機種依存の設定へ渡る。
文字出力の下層には論理行の終端管理もあるため、GW の画面編集全体がN88と同じとは仮定しない。

旧器具の長い定数は35文字ずつ**別の PRINT** に分割されていた。印5文字＋35＋35で75桁に
達した後、次の項目が収まらず改行する手順なら、既報の「70文字後、空白5セル」と整合する。
これは測定前の候補理由で、N88の確定規則ではない。

## 腕と位置の採取

全腕を各2走。`tools/l4_wrap_measure.py` の `arms()` / `controls()` を固定一覧とする。
打鍵は小文字、80文字未満、直接モードは new / cls / run のみ。長い値は string$ で作る。
変数を用意した後、プログラム内の CLS で入力の跡を消す。前印は画面0行の先頭、
測定出力は1行の先頭から始める。先頭の既知文字 p を k 個出した後、次を試す。

- 一つの文字列項目: (k,L)=(0,69/70/71/74/75/76/79/80/81/95/161)、
  (1,78/79/80)、(5,69/70/71/74/75/76/80/81/95)、
  (69,10/11/12)、(70,9/10/11)、(74,5/6/7)、(75,4/5/6)、(79,1/2)。
- 同じ PRINT の二項目: (k,L1,L2)=(0,70,9/10/11)、(5,35,35/36/40)、
  (5,70,1/5/6)、(70,5,4/5/6)。第1項目 a、第2項目 b。
- 数値項目: k=0/68/69/70/71/72/73/74/75/76/77/78/79、
  `print p$;12345;`（数値の既知文字列は前後空白付き7セル）。
- コンマ: k=55/56/57/69/70/71/79 で `print p$,"c";`、
  および k=55/56/69/70/79 で `print p$,` の後に終了印。
- 連結式: (k,L1,L2)=(0,70,11)、(5,35,36)、(70,5,6)、(79,1,1)、
  `print a$+b$;` を一項目として試す。
- 末尾セミコロンあり・なしを対にする: (k,L)=(0,79/80/81)、(5,70/75/76)、(70,9/10/11)。

短い定数対照5腕（空、3文字、二項目、数値、コンマ）は全候補一致を関門とする。
長い定数対照4腕（80/81/95文字、5＋35＋35＋8）は**関門にせず**候補比較に使う。
自作ROM自己検査はこの9定数腕×2走を W_FULL の既知値と照合する。

後印は既知の一文字 z（長い印自身の項目前改行を避ける）。完了印は LOCATE で12行へ固定。
完成後2枚の VRAM 写しが一致することも要求する。各行120バイトの先頭80セルのみ使用。
画面1行を相対行0とし、行・桁は0起点。後印までのセルをコード列で記録し、
コード列の i 番目は (i//80,i%80)、後印位置は end。物理画面の行は相対行＋1。
各完了行の末尾に残った空白数 blank_tails も記録する（数値・コンマの意図的空白を含み、
自動折り返しによる空白との因果はこの数だけから決めない）。非空白のコード列は
腕の既知文字の個数・順序と完全一致を必須とし、未知文字・欠落・重複・順序違いは採取失敗。
不一致の生画面・部分採取・例外のデータは出力も保存もしない。画面写しは採取後削除する。

## 固定候補と数値予測

- **W_FULL**: 幅80。項目長による事前改行なし。80セルを書いた直後に次行0桁。
  コンマは次の14の倍数へ、次境界が80以上なら改行。自作の現状を陽性対照にする。
- **W_ITEM**: 幅80、現在桁が0以外で項目長が残りを超えたら項目前に改行。
  行頭の長い項目は80セルごとに折る。コンマは W_FULL と同じ。
- **W_GW**: 項目検査は W_ITEM。コンマだけ公開GWの完全欄規則（56以上で改行）。
  数値コンマ終端の特殊条件は今回は腕に含めない。下層画面管理の全再現ではなく、
  上記をN88に移した検証候補である。
- **W_75**: 幅80の物理画面で、75セル書いた直後に次行0桁へ。項目検査なし。
  コンマは次の14境界が75未満ならその桁へ、そうでなければ改行。

末尾区切りなしは各候補の現在位置から必ず改行1回。終了印も候補の文字出力に従う。
例えば下表は対象文字の先頭位置／終了印位置／完了行の末尾空白数。

| 腕 | W_FULL | W_ITEM | W_GW | W_75 |
|---|---|---|---|---|
| k=5,L=76 | (0,5)/(1,1)/[0] | (1,0)/(1,76)/[75] | 同左 | (0,5)/(1,6)/[5] |
| k=70,L=11 | (0,70)/(1,1)/[0] | (1,0)/(1,11)/[10] | 同左 | (0,70)/(1,6)/[5] |
| k=0,L=81 | (0,0)/(1,1)/[0] | 同左 | 同左 | (0,0)/(1,6)/[5] |
| k=74,数値12345 | 最初の数字(0,75)/(1,1)/[0] | 最初の数字(1,1)/(1,7)/[6] | 同左 | 最初の数字(1,0)/(1,6)/[6] |
| k=56,コンマ,c | (0,70)/(0,71)/[] | 同左 | (1,0)/(1,1)/[24] | (0,70)/(0,71)/[] |
| k=5,35;35;8 | 最後項目(0,75)/(1,3)/[0] | 最後項目(1,0)/(1,8)/[5] | 同左 | 最後項目(1,0)/(1,8)/[5] |

全腕の全セル位置は上記の固定手順と腕一覧から一意に決まり、`predict --out PATH` で
コード列・end・blank_tails のTSVに展開する。自己検査も自作ROMを動かす前に全腕の
予測TSVを作り、表の固定位置を検査する。既知候補のどれとも一致しない腕は differ、
欠落・2走不一致・打鍵失敗・定数関門不一致は gate_failed。check は全腕の既知値一致だけを
成功とし、SKIP・観測のみを合格にしない。候補の追加や観測後の予測変更は追補の事前登録を要する。
