# m6f-j — SAVE ,A（ASCII 形式の保存）の外から見える挙動 — 事前登録

記録日: 2026-09-28  
状態: **測定前**

## 0. 位置づけ

自作BASICに `SAVE "<ドライブ>:<名前>",A` を入れる前に、l3-disk-format.md 第5版・l4-basic.md に無い「作る側」の挙動を公式ROMで測る。
本体の形（2.6節）とエントリ・割り当て表の読み方（1章・2章）は既知として使う。

担当・禁止は m6f-d 事前登録 §0 と同じ。**割り当て表は位置 0〜159 だけを扱い、160 以降は読まない・比較にも使わない**
（[汚染の記録 2026-09-25](contamination-2026-09-25-fat-buffer-overrun-values.md)）。本体は予測の長さ＋1バイトまでしか読まない（m6f-h §0.1 と同じ）。

構成は m6f-h・m6f-i と同じ（ドライブ1＝参照 diskA 複製で起動、ドライブ2＝自作媒体、打鍵は小文字で届く、画面は行署名のみ、測定後の像は削除）。
媒体の名前はすべて小文字（m6f-i 1回目の教訓）。

## 1. 問い

- **J-I 完了の画面**: `SAVE … ,A` の完了時に、入力待ちの行とは別に `Ok` の行が出るか（LOAD と同じか）。
- **J-II 同名のファイル**: 同じ名前のファイルが既にあるとき、上書きするか・エラーか。上書きなら、エントリは同じ位置か、古い単位は解放されるか。
- **J-III 割り当ての順**: 使用中の単位がある媒体で、新しいファイルにどの単位を割り当てるか。
- **J-IV エラー**: 書き込み禁止の媒体（l3-disk-format 3節の印）・空きの無い媒体・未挿入のドライブへの `SAVE`。

## 2. 媒体（l3-disk-format 第5版だけで作る）

- B0: 空の媒体（m6f-c と同じ）。
- B1: `qsa`（ASCII プログラム `10 PRINT 1`、1単位）が1件ある媒体。単位は自分で選ぶ（空の媒体で最初に割り当てられる単位を避けた位置、例 単位10）。
- B2: B0 の単位 0〜9 を使用中にした媒体（1つのファイルの鎖として。72 以降は空き。`first_free_in_2_5_order` と `lowest_free_number` が別の単位を指すように選んだ）を割り当て済みにした媒体（ファイルのエントリも置く）。
- BP: B0 に書き込み禁止の印（3節）を付けた媒体。
- BF: 予約以外の全単位が使用中の媒体（1つの大きなファイル）。

## 3. 腕（各2走）

| 腕 | 媒体 | 打鍵（`\n` は RETURN） | 観測 |
|---|---|---|---|
| J-1 | B0 | `new\n10 print 1\ncls:save "2:qsb",a\n` | 画面（J-I）、エントリ・単位・割り当て表 0〜159・本体（予測の長さ＋1まで） |
| J-2 | B1 | `new\n10 print 2\ncls:save "2:qsa",a\n` | 画面、ディレクトリの生きたエントリの一覧（名前・位置・9〜15バイト目）、割り当て表 0〜159、本体 |
| J-3 | B2 | `new\n10 print 1\ncls:save "2:qsc",a\n` | 割り当てられた単位 |
| J-4 | BP | `new\n10 print 1\ncls:save "2:qsd",a\n` | 画面（エラー）、媒体が変わらないこと（ディレクトリと割り当て表 0〜159） |
| J-5 | BF | 同上（名前 `qse`） | 画面（エラー）、媒体が変わらないこと |
| J-6 | ドライブ2 空 | 同上（名前 `qsf`）、1200 フレーム後に B0 を挿入 | 待つか・エラーか（m6f-e N-wait と同じ判定の型） |

## 4. 候補と判定

- J-I: `ok_line`（`Ok` の行が1行出る）／`no_line`／`other`（画面の予測は `Ok` の文字列と行の位置だけから作る）。
- J-II: `overwrite_same_slot_frees_old`（同じエントリの位置に書き、古い単位は `0xFF` に戻る）／`overwrite_same_slot_keeps_old`／`overwrite_new_slot`（古いエントリを削除して新しい位置）／
  `error_<N>`（エラーで媒体不変、N は画面の署名から、エラー表の番号と照合）／`other`。
- J-III: 割り当てられた単位の番号の列をそのまま記録し、候補 `first_free_in_2_5_order`（2.5節の空の媒体の割り当て順＝単位72から番号の小さい方へ2つ取っては2つ飛ばす順で、最初の空き）／`lowest_free_number`（番号の最も小さい空き）／`other` と照合。
- J-IV: 腕ごとに `error_<N>`（媒体不変）／`waits_for_media`（J-6）／`other`。
- 本体（J-1・J-2）: m6f-h の `LIST_CRLF_1A` と同じ形であること（`body_matches_2_6`）を確かめる。

2走とも一意に一致した候補名を判定とする。0件・複数は `inconclusive_<腕>`。

## 5. 関門

m6f-h の G1〜G7（凍結照合で起動0、2走一致、参照 diskA 不変、種別バイト `0x00`、本体の読み取り上限）に加え、
- **G8**: 割り当て表の読み取りが位置 0〜159 に限られている（器具が読む位置の最大を記録）。
- **G9**: 媒体の独立検査（B1・B2・BP・BF が第5版どおり）。

## 6. 行き先

`docs/spec/l3-disk-format.md` に「ファイルを作る側」の節、`docs/spec/l4-basic.md` に `SAVE`（ASCII 形式）節を起こす。
その後、自作 main の書き込み（l3-subrom.md 1.35節の送信の形）と `SAVE … ,A` を実装し、(1) 自作 main＋公式 sub で書いた媒体、(2) 自作一式で書いた媒体を、
公式ROM 一式の `FILES`・`LOAD` で読ませて確かめる。

## 7. 決めないこと

- 通常の `SAVE`（`0x80`）・`SAVE ,P`。`OPEN … FOR OUTPUT` による書き込み。
- 割り当て表の位置 160 以降（読まない）。
- 最後のセクタの余りに書かれる値（読まない）。
