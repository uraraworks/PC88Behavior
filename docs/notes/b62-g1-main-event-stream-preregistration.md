# B62: キーを打ったあと、main の RAM 上のコードの読み書きが最初に違う所を値なしで測る — 事前登録

記録日: 2026-11-02
位置づけ: [B61](b61-g1-key-rom-calls-results.md) の次段。B46 の器具の main 版である。**このノートは測定より先にコミットする。**

## 1. 問い

キー `2` と `i` を打った腕で、main の RAM 上のコードのメモリの読み書き・`IN`・`OUT` を起きた順に並べたとき、公式と自作で最初に違うのはどこか。

## 2. 器具

コアに `--main-event-log FILE` と `--main-event-from-frame N` を足す（パッチ 0026）。既定は無効で、無効なら動作を変えない。発行元が main の RAM 上（ROM が切り離されている時も含め、ROM の窓の外）のコードの `R`・`W`・`I`（`IN`）・`O`（`OUT`）を、種類・発行元 `PC`・番地またはポート・値・フレームで作業場の生のファイルへ書く。フレーム N より前は書かない。**生のファイルは開かず、コミットせず、ライブラリへ置かない。**

比較ツールは B46 と同じ形で、次の行だけを出す。**値は出さない。** 番地は RAM 上のコードの `PC` と、読み書きの番地とポート番号だけである。

- `count <左> <右>`
- `first-diff none`、または `first-diff <番号> <違う欄> <左の種類> <右の種類> <左の PC> <右の PC> <左の番地> <右の番地> <左のフレーム> <右のフレーム>`
- `before <番号> <種類> <PC> <番地>`（直前の 16 件）

`I` の値は比べるが、キーのポートの値はハードウェアの事実なので比べて構わない。出力には出さない。

器具は G1 なしで自己検査する（B46 と同じ陽性対照・陰性対照、`I` の追加）。

## 3. 条件

フレーム 3600 でスペース、7200 で腕のキー、9000 フレームまで。記録はフレーム 7000 から。公式 2 走、自作 1 走。腕は `2`、`i`、キーなしの対照。クラウドの実行環境で行う。

関門: 公式どうしが `first-diff none`。キーなしの対照で公式対自作が `first-diff none`（違えば、窓の前から違うので解釈しない）。

## 4. 記録の白リスト

第 2 節の行に腕の名を付けたものだけ。

## 5. 判定（事前に決める）

- `first-diff` の行をそのまま書く。違うのが `I` の値ならキーのポートの状態が違う。`R` なら読む番地の中身が違う。原因は断定しない
