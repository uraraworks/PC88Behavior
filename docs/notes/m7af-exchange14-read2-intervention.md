# m7af: 交換#14第2 READ座標の介入測定

測定日: 2026-08-13

公式環境を1800フレームで新規実走し、値は比較器内部だけで扱った。第2〜第5
READの候補は、要求各位置からの転記、直前READ座標、SENSE INTERRUPT STATUSの
PCN、READ結果各位置、H反転、固定N、RとEOTによる公開FDC進行に限定した。

READ発行境界は、第1 READが要求7件後、第2〜第5 READが要求11件後、バルク開始が
要求12件後だった。第2 READへ、SEEK/Cは同値な要求位置2/6/9/11の代表として位置2、
Hは第1 READから反転、unit/headはHから公開符号化、Rは一意な要求位置3、Nは固定、
EOTはRから14セクタを読む終端、とする候補を介入した。確定済み交互配置も同時に
適用すると、公式期待5635件との先頭一致は2件から1282件、全位置一致は28件から
1300件へ伸びた。第2 READを行わない対照では2件/28件のままだったため採用する。

値一致長779、main構造258、sub構造752、main `IN $FD` 5635件は維持した。
第3 READを同じ候補体系で追加するとバルクへ到達しなかったため、第3 READ以降は
未確定であり、次サイクルで生成元を個別介入する。
