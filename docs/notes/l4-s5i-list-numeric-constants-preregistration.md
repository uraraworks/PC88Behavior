# l4-s5i — LIST での数値定数の書き直し — 事前登録

記録日: 2026-10-02  
状態: **測定前**

## 背景

l4-s5h（l4-basic.md 第14節）で、公式の LIST は数値定数を**値として読み直して書き直す**ことが分かった
（14.3節の24腕: `1e5`→`100000!`、`0.5`→`.5`、`1%`→`1`、`&10`→`&O10` など）。自作は打鍵どおりに出しており、
この24腕と `1rem`・`1 d`・`go sub10` 等を期待値から外している。規則の全体（14.4節: 型の境目・`&` の桁・指数の書式・
数の途中の空白）は測っていない。ここでそれを測る。

## 測り方

l4-s5h と同じ（`tools/l4_listkw_measure.py` の測り方: `new` の後に自作の行を打ち、`cls` → `list`、
数字で始まり表示可能 ASCII だけの行だけを取り出し、腕ごとの署名 sha256 先頭16桁を記録。
他の行は中身を読まず件数だけ）。腕の本文はすべて自分で作った行で、打鍵は小文字で届く。各腕2走。

## 候補 N_A

数値定数（文字列・REM・DATA の中・`'` 以降を除く場所で、名前の連なり〔14.1節〕の途中でない所に現れる、数字か `.` で始まる並び）を次のように書き直す。
それ以外は 14.1節の規則のまま。

1. **読み取り**: 数字の並び、`.` は1個まで、続けて `e`/`d` と任意の符号と数字の指数部、最後に任意の型の印 `%` `!` `#`。
   **数の途中の空白は読み飛ばす**（`1 2` は `12`、`1 e5` は `1e5`、`a=1 data` の `1 d` は指数部の始まり。14.3節の `1 d` の観察）。
   指数部の `e`/`d` の後に数字が無くても指数部として読み、値は変わらない（`1e` は `1`、型は単精度）。
2. **型**: 印 `%` は整数、`!` は単精度、`#` は倍精度。印が無ければ、指数 `d` は倍精度、指数 `e` は単精度、
   `.` も指数も無く値が 32767 以下なら整数、それ以外は数字（先頭の0を除く）が8桁以上なら倍精度、7桁以下なら単精度。
3. **書き出し**: 整数は10進の数字だけ（先頭の0を落とす、印は付けない）。単精度・倍精度は、その値を **PRINT と同じ桁と書式**
   （l4-basic 第5節。先頭の符号用の空白と後ろの空白を除いたもの。倍精度は16桁、指数は `D`）で書き、
   書いた文字列に `.` も指数も無ければ単精度は `!`、倍精度は `#` を付ける。倍精度は `.` があっても `#` を付ける（`1.5#`→`1.5#`）。
4. **`&` の定数**: `&h` の後の16進数字は `&H` と、値を大文字の16進で先頭の0を落として書く。`&o` の後と、`&` の直後に8進数字が続く場合は
   `&O` と値の8進。`&` の後に数字が無ければ値0（`&O0`、14.3節の `&b101`→`&O0B101`）。
5. **数の直後の `rem`**: 数の直後に `rem` が接するときは、間に空白1個を入れて `REM`（14.3節の `1rem`）。

`goto` 等の後の行番号を N_A は普通の数値定数として扱う（`goto 0010` → `GOTO 10`）。行番号が別扱いなら食い違いとして現れる。

## 判定

腕ごとに、2走一致した署名が N_A の予測の署名と一致すれば `agree`、しなければ `differ`。2走不一致は `unstable`。
全体は、`unstable` 0 かつ `differ` 0 なら `N_A_holds`、そうでなければ `N_A_partial`（differ の腕を群ごとに数える）。
`differ` の腕は、自分で打った行と観測行の対を作業中に見て、事後の候補を立てて追補で事前登録してから測り直す（l4-s5h と同じ進め方）。

## 関門

l4-s5h の関門（取り出す行の条件、陰性対照・陽性対照つき自己検査、2走）に加え、
- 予測器の自己検査: 14.3節に書いた観察（`1e5`→`100000!` ほか、本文に例として載っているもの全部）を N_A が再現すること。
- l4-s5h の723腕の期待値の取り扱いは変えない（本段の腕は別の期待値ファイル `tests/conformance/expected_l4_listnum.tsv`）。

## 決めないこと

- `go sub10` が `GOSUB 0` になる件、行番号の途中の空白（`130 1+rem`）。本段では腕を置かない。
- 実行時（RUN）の数値の読み方。本段は LIST の表示だけ。
- 単精度の8桁目以降の丸めの細部（PRINT と同じであることだけを候補にする）。
