# l4-s9p — COLOR の属性域への書き方と、40桁時の CRTC カーソル位置: 結果

事前登録: [l4-s9p-color-attr-preregistration.md](l4-s9p-color-attr-preregistration.md)（29860dd）。器具 ee38065（`tools/l4_colorattr_measure.py`）。
公式ROM 41腕×2走、**全て関門通過**（2走完全一致・アンカー線形・較正〔stmt-rem が S=120・k=1・組なし、参照の誤り署名5種が互いに異なる〕）。
観測は自作の印の位置・自作の行の属性域の生値・CRTC のパラメータ・誤り行の署名で、画面本文は扱っていない（署名は本文を持たない）。

## 予測の的中

予測あり判定項目の的中は、下の項目別表のとおり。**外れた項目は4つ**（fbare の続行・ffive の誤りの種類・m2 の20組目の形、および「既定 (3,0) 候補」は外れた側が候補のほう＝的中扱い）。
規則として確定した部分と、残った曖昧さ（追補1で測る）を分けて書く。

## 1. CRTC カーソル位置（確定）

- `locate c,r` の後の最後のカーソルコマンドは **0x80**（0x81 ではない。0x81 は ROM の別の処理で数回出るだけ）で、パラメータは2つ。
- **80桁: （c, r）**（c=0,1,10,39,79、r=0,3,7,12,15 の5点とも一致）。
- **40桁: （2×c, r）**（c=0,1,10,20,39 → 0,2,20,40,78。r は行そのもの）。桁の値が 2倍になるのは、文字が2バイトおきに置かれる VRAM の並び（5.6.1）と属性域の位置（2×終端桁−1）と同じ単位。
  c=0 の腕は c と 2c が同値なので区別の票に数えない（残り4点で区別）。
- 5腕とも最後の指定のあと同じ値が約3400回繰り返される（ROM がカーソルを書き直し続ける）。

## 2. COLOR の引数

| 項目 | 観測 |
|---|---|
| `color n` n=0 | 先頭組なし（全20組 (0x80,0x00)）。**(3,0) 候補は外れ**＝ l3-main 第12節の「既定と同一」が正しい |
| n=1〜7 | 印の後ろに (3, n) の1組だけ。値バイトは n そのもの（8通り全て区別できる）。残りは (0x80,0x00) |
| 範囲外 `color 8`・`255`・`256`・`-1` | **続行しない（誤り）**。誤り行の署名が参照 `fc`（`a$=chr$(300)`）と一致 |
| `color ,8`（第2引数が範囲外） | 誤り。署名が `fc` と一致 |
| `color "a"` | 誤り。署名が `tm`（型の不一致）と一致 |
| `color 2.5` | 続行。(3,3)（四捨五入、2.5→3）。続く `qz9`（行14）も (3,3)＝色は次の COLOR まで持続 |
| `color ,3`・`color ,,,5`（第1引数なし） | 続行。行13・14とも組なし（テキスト属性は変わらない） |
| `color 2,3`・`color 3,0,0,6`・`color 3:color 5` | 続行。それぞれ (3,2)・(3,3)・(3,5)（最後の指定が効く、後続の行にも持続） |
| **`color`（引数なし）** | **誤り（予測は続行）**。署名は `fc`・`sn`・`ul`・`tm`・`ov` のどれとも一致しない（別の誤り。種類は追補で番号を採る） |
| **`color 5,1,1,2,3`（引数5個）** | 誤り。**署名は `sn` ではなく `fc` と一致**（予測は `sn`） |

行13・14の組は、署名が `rem` 基準との差の行番号だけを採る設計のため、誤りの種類の特定は参照との署名一致の範囲（番号そのものではない）。

## 3. 行内に複数の色が混ざるとき

| 腕 | 80桁 | 40桁 |
|---|---|---|
| m1 `color 2:"zzz";:color 4:"zzz"` | (3,2)(6,4)（的中） | (5,2)(11,4)（的中） |
| m3 3色のあと行の途中（桁3〜4）を `color 5` で上書き | (3,2)(5,5)(6,4)(9,6)（的中。上書きで区間が組み直される） | (5,2)(9,5)(11,4)(17,6)（的中） |
| m4 `color 2`→`color 0`→`color 4` | (3,2)(6,0)(9,4)（的中。値0の区間も組が書かれる） | (5,2)(11,0)(17,4)（的中） |
| m5 色つき行を書いたあと `print` で3行スクロール（印の行が 14→11、アンカー 6→3） | 組は行と一緒に動く: (3,2)(6,4)（的中） | (5,2)(11,4)（的中） |
| **m2 1文字ごとの色替え 24区間** | **1〜19組目は規則どおり (i, v_i)（i=1..19、v は奇数 i で3・偶数 i で2）。20組目は (0x80, 2)（予測は (20, 3)/(20,2)）** | 位置は 2i−1（1,3,…,37）で規則どおり。20組目は (0x80, 2) |

- 組は先頭から詰まって書かれ、使わない組は (0x80,0x00)（`rest_default` 真、全腕）。
- **20組を超えると、20組目は終端位置 0x80（行末）になる**。値の 2 は、設計上 20番目の区間（偶数）と24番目の区間（偶数）がともに 2 なので、
  「20番目の値」か「最後の区間の値」かを区別できていない（器具の設計の隙間。追補で値の異なる列を使う）。

## 4. COLOR 以外の属性変更

読んだマニュアル頁（COLOR 2-29・2-30）に COLOR 以外のテキスト属性変更文は無く、測っていない。第2〜4引数はグラフィック側。
