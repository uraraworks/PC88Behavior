# B28: エミュレータの機種の印を置いた自作 ROM で G1 を走らせる — 結果

記録日: 2026-11-01
規則: [b28-g1-after-rom-version-preregistration.md](b28-g1-after-rom-version-preregistration.md)（f7aab8d）どおり。測定はクラウドの実行環境で b2a0459、OO・SS 各 2 走、すべて rc=0。対照: OO は B1・B6 と一致。SS の 2 走は一致。記録: `measurements/b28-g1-*`。

## 判定

| 項目 | 結果 |
|---|---|
| **テキスト画面の署名（3600 フレーム）** | **一致** |
| 入出力の位置 | 215540 で分かれる（自作だけ先に `OUT $E4`）。要素の総数は SS 938280、OO 941113 |
| 値 | `IN $FC`・`OUT $FD`・`OUT $FF` は**差なし**。差は `IN $FE` だけ（最初は畳んだ番号 10465） |
| FDC | **差なし。** `read_data hi` 15 回、`count` の行はすべて OO と同じ |
| サブ | 要求 9 件、記録 A の `00C1` 17 回（OO と同じ） |
| main の記録 A | **SS は 0 件**（OO は 8 件） |

## 分かったこと

- 打鍵なしの 3600 フレームで、**自作 ROM の上の G1 は公式とテキスト画面まで一致した。** ディスクの読み出し、サブとの通信の値もすべて一致している
- 入出力の並びの差は、割り込みの受け方の順番に見える（**推定**）。`OUT $E4` は割り込みの制御のポートである
- **B1 の 8 番地は、G1 の需要ではなかった。** 自作の main では 0 件のまま同じ画面に達する。公式 ROM 自身の動きだったと読める。実装の対象から外す
- ゴール B で G1 に要ったのは、自作サブの `0x02` 複数セクタ・`0x0C`・`0x0D`・`0x15`・`0x06` の応答・`0x00C1`・作業域の配置・割り込みの扱いと、機種の印だった

## 言えないこと

- **グラフィック画面は比べていない。** 比べたのはテキスト画面の署名だけである
- 3600 フレームより先と、打鍵してからの動き
- 音が同じか
