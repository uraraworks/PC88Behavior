# B60: G1 でどのキーが公式と自作を分けるかを 1 つずつ測る — 事前登録

記録日: 2026-11-02
位置づけ: [B58](b58-g1-more-keys-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

スペースのあとに 1 つのキーを打ったとき、公式と自作で画像か移る回数が違うのはどのキーか。公式は main の ROM へ新しく移るか。

## 2. 条件

フレーム 3600 でスペース、7200 で腕のキーを 1 回打つ。14400 フレームまで。公式 2 走、自作 1 走。クラウドの実行環境で行う。

腕のキー: `0`〜`9`、`a`〜`z`、ファンクション 1〜5、ESC、TAB、BREAK、DELETE、テンキー 2・4・5・6・8。対照はキーなし。

## 3. 器具

`--boundary-log` を足す。`tools/b1_whitelist_boundary.py` の記録 A（main の ROM への飛び先）を腕ごとに比べる。画像とテキストは一致だけを見て、どこへも置かない。

## 4. 記録の白リスト

`key <名> oo=<same|differ> image=<same|differ> text=<same|differ> cross=<左> <右> fc=<左> <右> a-left-new=<対照に無い記録 A の数> a-right-new=<同じ> first-cross-pc=<N|none>`

`A-new <名> <飛び先>`（公式で対照に無い記録 A の飛び先。B1 と同じ記録で、番地だけ）

**値は出さない。**

## 5. 判定（事前に決める）

- 違うキーを表にして書く。効くキーのまとまりが見えれば、そのまま書く
- `A-new` が出れば、公式の main の ROM の需要として書き、方針ノートのとおり働きは自作のプローブで測る
- 原因は断定しない
