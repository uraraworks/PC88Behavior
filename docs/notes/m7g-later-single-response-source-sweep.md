# m7g: 後続単発応答の取得源総当たりと構成不変性

測定日: 2026-08-13

## 1. 目的

m7fでラウンド#0と後続単発1バイト応答の効果を分離した結果を受け、
m7b第4節でラウンド#0へ行った11取得源×21加工の総当たりを、後続単発応答へ
適用した。あわせて公式側の後続応答がフロントエンドで可変な構成軸に連動するか、
同一起動内の複数回が同値かを測った。実装コードは変更していない。

## 2. 情報境界

`private/`配下は名前だけを確認し、参照ROMと参照ディスクは
`PC88_REF_ROM_DIR`と`PC88_REF_DISK_DIR`を介して測定器へ渡した。公式ROM一式、
媒体、ライトプロテクト条件別媒体は、内容を解釈しない不透明コピーとした。
公式ROM・公式ディスクのバイト列を読まず、表示せず、逆アセンブルしていない。

公式側の交換値、一致した値、加工後の値、ビットの極性は、標準出力、本稿、
コメント、コミットメッセージのいずれにも記録していない。値は一時比較器の
メモリ内だけで比較した。外へ出したのは値一致プレフィックス長、位置ごとの
同一／相違、同値グループ数、件数、取得源・加工の名前、構造指標だけである。
生ログ、介入ROM、一時フロントエンド、一時比較器はリポジトリ外で扱い、測定後に
削除した。

## 3. 対象サイトの特定と介入限定の関門

一時ROMではSENDプリミティブの同一命令列を3つへ複製した。

- 初回対照サイト: 単発応答経路の最初の呼出しだけを通し、現行対照のST3取得を行う。
- 後続介入サイト: 2回目以降の単発応答経路だけを通し、取得源・加工を適用する。
- 応答バッファサイト: `RESP_ACTIVE`由来の送信だけを通す。

main側の要求→応答ラウンドを共通クロックで再構成し、応答長1の時間窓内にある
subの`OUT $FD`位置をサイト名へ分類した。対照ではラウンド#0が初回対照、
ラウンド#1・#2・#5が後続介入、ラウンド#3が応答バッファを通った。未知サイトは
0件で、各ラウンド窓の送信は1件だった。この位置列を本走査前の関門とし、
ラウンド#1・#2・#5の後続介入サイトだけを値比較対象にした。

準備中、全`IN $FC`と全`OUT $FD`を添字で対応させる最初の分類器は件数不一致で
関門停止した。根因は35フレーム末端の高速／バッファ受信記録がsub送信と1対1に
ならないのに、全列が1対1と仮定したことだった。次に全sub送信の前後関係だけで
分離しようとすると、応答バッファ区間と後続単発サイトが交錯した。根因は
「応答長1」というmain側のラウンド境界を使わず、送信列全体を分類したことだった。
いずれも採用測定前に停止し、上記のラウンド時間窓＋送信位置の二重分類へ作り直して
から最初から測定した。「たぶん波及していない」という判断は使っていない。

## 4. 検出力、フレーム数、再現性、所要時間

本測定前に次を関門として通過させた。

- `tools/cmp_io_selftest.sh`: 全27項目通過。同一入力は同一、意図的な1バイト差は
  値を表示せず相違と判定した。
- `tools/analyze_boot_exchange_selftest.sh`: 合成3ラウンド、時間窓破壊、送信分類破壊を
  期待どおり検出した。
- 一時比較器・サイト分類器: 同一入力、意図的な1バイト差、サイト名の差をそれぞれ
  期待どおり分類した。

値比較はm7bの実績どおり21フレームで足りるが、対象サイトの限定確認、ラウンド#5、
分岐点の両側を同じログで扱うため、m7fと同じ最小の35フレームを採用した。
1条件1試行は約0.043秒、231条件を各2試行する見積りは約20秒だった。

各試行は15秒の自前タイムアウト、最大8試行とし、生ログ全体が2回連続一致した場合だけ
採用した。231条件の完全走査自体も2回行い、後述の条件集合と最大プレフィックス長が
再現した。

## 5. 11取得源×21加工の結果

取得源はST3、SIS-ST0、PCN、RID-ST0、RID-ST1、RID-ST2、MSR、`$F8 IN`、
PIO-A、PIO-C、INVALID-ST0の11種類とした。加工は生値、ビット反転、上下ニブル交換、
上下ニブルマスク、各ビット保持、各ビット除外の21種類、合計231条件である。

**31条件が後続応答の値一致プレフィックス長を1へ伸ばした。最大は1で、2以上へ
伸ばす条件は無かった。** 該当した取得源・加工名は次のとおりである。

- SIS-ST0: 生値、上位ニブルマスク、ビット7保持、ビット0〜6の各除外。
- MSR: 生値、上位ニブルマスク、ビット7保持、ビット0〜6の各除外。
- `$F8 IN`: ビット7保持。
- INVALID-ST0: 生値、上位ニブルマスク、ビット7保持、ビット0〜6の各除外。

ST3、PCN、RID-ST0、RID-ST1、RID-ST2、PIO-A、PIO-Cは全加工で0だった。
31条件はいずれも公式対照とのmain側構造的一致プレフィックスが258で、259を越えなかった。
したがって「後続側でも231条件全滅」ではないが、直接取得源だけで後続列を説明した、
または分岐点259を突破した、とも言えない。複数取得源・加工が同じ1件目だけに一致し、
2件目で分かれるため、1件一致は取得源の一意な意味付けにならない。

## 6. 公式後続応答の構成連動

一時フロントエンドから公開設定経路を使い、媒体挿入、ライトプロテクト、BASICモード、
CPUクロック、sub CPU実行方式、FDC待ち、音源、PCGの19条件を測った。媒体と
ライトプロテクトは原本でなく使い捨てコピーだけを変更した。各条件は2回連続一致を
採用条件とし、35フレームで3位置へ届かない条件は600フレームまで延長した。

19条件中18条件でラウンド#1・#2・#5の3位置を比較できた。BASIC Nは600フレームでも
交換が発生せず比較不能だった。比較可能18条件の3位置組は**1同値グループ**で、
各位置とも条件間で同一、相違したビット位置は無かった。各構成軸の対比較でも、位置・
ビット位置とも相違なしだった。

よって、今回可変にできた構成軸へ連動する後続応答位置・ビット位置は特定できなかった。
少なくともこのコアが公式ROMへ提示する構成差を直接表すフィールドとは言えない。

## 7. 同一起動内の複数回

ラウンド#1・#2・#5の3回は**2同値グループ**だった。ラウンド#1と#5は同一、
ラウンド#2はそれらと相違した。値と相違ビット位置は記録していない。

したがって、後続単発応答を1つの固定保持値だけで説明することはできない。一方、
3回すべてが別でもないため、都度完全に独立した生成とも限らない。少なくとも交換位置、
直前状態、または内部保持状態に応じた2種類の結果が必要である。

## 8. 異常と根因調査

採用走査中、`q88measure`が一過性に終了コード`-6`で止まる試行があった。該当試行は
破棄し、2回連続一致したログだけを採用した。候補固有の決定論的停止かを調べるため、
一度発生したPIO-C・ビット0除外条件を300回同期再実行したところ、正常298件、同型停止
2件で、stderrは通常の測定器ヘッダだけだった。OSのクラッシュ報告も生成されていなかった。

直接原因はSIGABRT相当の一過性終了であり、候補値・取得源に固定された停止ではないことは
反証できた。しかしabortを発生させたコア／測定器内部の根本原因は、診断情報が無いため
特定できなかった。m7d予備走査から残る同じ測定基盤上の既往と整合する。構成測定でも
発生条件が走査ごとに移動し、同じ一過性終了だけが見られた。

また最初の完全走査後、終了コード表示用にzshの予約済み変数名を使い、測定終了後の
シェルだけがエラーになった。根因は一時ランナーの変数名選択で、別名へ変更した。測定
プロセスと集計は既に完了しており、次の完全走査で同じ結果を再現したため採用結果への
影響は無い。

## 9. 判定と限界

後続単発応答では、SIS-ST0、MSR、`$F8 IN`、INVALID-ST0の一部加工が最初の対象位置だけを
説明できる。しかし最大プレフィックス長1、構造258止まりであり、次の対象位置や分岐点
259を説明しない。構成横断では不変だが、同一起動内では2種類に分かれる。したがって本命は
「単一の固定ハードウェア取得源」ではなく、交換位置または内部状態を加味した生成規則である。

限界は次のとおりである。

- 同一の公式ROM一式、同一コア、同一参照媒体であり、ROM版、別エミュレータ、実機を
  横断していない。
- ラウンド#5は先行応答がmainの分岐を変える条件では35フレーム内に現れない場合があり、
  231条件の値一致プレフィックスは観測できた後続介入列についての判定である。
- 物理ドライブ台数やFDD回路自体は切り替えず、2ドライブ実装上の媒体挿入組合せを測った。
- BASIC Nは交換非発生のため値比較不能で、600フレーム以後の非発生までは証明しない。
- 一過性SIGABRTの根本原因は未特定である。

## 10. ツール状態

一時ROM生成器、一時比較器、構成切替用フロントエンド、生ログ、媒体コピーはすべて
リポジトリ外で扱い、測定後に削除した。恒久ツール、実装コード、判定基準は変更していない。
