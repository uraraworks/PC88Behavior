# m7ds: 複数ファイル読出し削減段階の介入事前登録

実施日: 未実施（本稿は事前登録のみ。測定はまだ行っていない）

本稿は`m7dp`・`m7dr`で未確定となった「同一セッションへ集約したとき、読出し
アクセスがどの段階で減るか」を切り分ける介入を、実測前に固定する。公式ROM・
公式ディスクの内容は読まず、生ログ、画面報告、ROM／ディスク複製はリポジトリ外の
一時領域だけに置く。データポート値列は表示・転記せず、比較は件数、位置、clock、
SHA-256だけで行う。`cmp -l`等でファイル内容を出力しない。`src/`は変更しない。

## 仮説と今回の識別境界

候補を次の4仮説へ分ける。

- **H-F（固定費）**: 別ブート単独2回の合計だけが、起動・初期化・セッション開始の
  固定費を2回払う。同一セッションでは固定費1回分が消える。
- **H-D（ディレクトリ／OPEN段階）**: 1ファイル目のディレクトリ検索またはOPEN時の
  管理情報読出しを、2・3ファイル目で使い回す。
- **H-B（データバッファ段階）**: 直前に読んだデータ、セクタ、またはファイル固有状態が
  残り、後続のデータ読出しを減らす。単に同じメモリ領域を再利用するだけでI/O件数が
  変わらない場合は、本稿の観測量ではH-Bを支持しない。
- **H-S（配置／SEEK段階）**: Q9A/Q9Bの近接配置または読出し順により、後続ファイルの
  SEEKまたはREAD単位が省略される。

「支持」は登録した介入と予測の範囲で整合したという意味に限り、機構の証明とは呼ばない。
複数仮説が同じ予測を持つ条件は、その仮説群までしか絞らない。

## 自作データと準備媒体

公式diskA原本からrun単位の使い捨て複製を作り、書込みは複製だけへ行う。準備runは
測定対象へ含めない。隣接配置用の`adjacent.d88`では、次の自作シーケンシャルファイルを
この順に作る。

- Q9A: A1/A2/A3
- Q9B: B1/B2/B3
- Q9C: C1/C2/C3

各ファイルは`OPEN ... FOR OUTPUT AS #1`、3回の`PRINT #1`、`CLOSE #1`で作る。
作成runはQ9A/B/Cをこの順に閉じた後`P9D`を表示する。別プロセスの検証runで各々を
INPUTで3行読み戻し、連結結果が`A1A2A3B1B2B3C1C2C3`のときだけ`P9A`、全CLOSE後に
`P9C`を表示する。

配置介入用の`separated.d88`では、Q9Aを作った後、Q9FをOUTPUTで開き、
`FOR I=1 TO 64:PRINT #1,STRING$(120,70):NEXT I`で自作フィラー64行を作って閉じ、
その後Q9B、Q9Cを作って`P9D`を表示する。別プロセスの検証runでQ9Fを開いて64行
すべてを`LINE INPUT#`し、各行の`LEN`が120であること、およびQ9A/B/Cの内容一致を
確認した場合だけ`P9F`、全CLOSE後に`P9C`を表示する。フィラーは「離す圧力」であり、
作成成功だけでは物理配置介入成立とみなさない（適用範囲検査を後述する）。

各媒体の準備は公式一式のみの**作成run＋検証run**の2段とする。両方とも9000フレーム、
300F/700Fの二段打鍵、300秒・512打鍵上限を使い、`--save-to-disk-image`は作成runだけへ
付ける。作成runはWRITE DATA 1件以上、取りこぼし0件、`P9D`と直後`Ok`、検証runは
取りこぼし0件、`P9A`または`P9F`→`P9C`→直後`Ok`を必須とする。検証runは媒体へ
保存せず、作成済み複製を変更しない。完成複製から各測定run用の複製を毎回作り直す。

## 測定条件

全条件でINPUTファイル番号は`#1`を再利用し、各ファイルは3行を`LINE INPUT#1`で
読み切ってから閉じる。打鍵上限内で全条件の読出し本体を同一にするため、R3のプログラムを
次に固定する。R1は30・40行、R2は40行を省き、それ以外を同じにする。

```basic
10 S$=""
20 F$="Q9A":GOSUB 200:IF S$<>"A1A2A3" THEN PRINT "S9N":END ELSE PRINT "S1R"
30 F$="Q9B":GOSUB 200:IF S$<>"A1A2A3B1B2B3" THEN PRINT "S9N":END ELSE PRINT "S2R"
40 F$="Q9C":GOSUB 200:IF S$<>"A1A2A3B1B2B3C1C2C3" THEN PRINT "S9N":END ELSE PRINT "S3R"
50 PRINT "S9C":END
200 OPEN F$ FOR INPUT AS #1
210 FOR I=1 TO 3
220 LINE INPUT #1,X$
230 S$=S$+X$
240 NEXT I
250 CLOSE #1
260 RETURN
RUN
```

O1は20行を`OPEN "Q9A" FOR INPUT AS #1:CLOSE #1:PRINT "S1O"`とし、200行以降を
持たない。O2はR1の20行後、30行を
`OPEN "Q9B" FOR INPUT AS #1:CLOSE #1:PRINT "S2O"`へ置換する。O3も同様に
R2の後へQ9Cの無読出しOPEN/CLOSEと`S3O`を置く。
P0は`10 PRINT "S0E"`、`20 PRINT "S9C"`、`RUN`だけとする。全条件は末尾に
`S9C`を表示し、その直後の`Ok`までを到達条件とする。

| ID | 媒体 | 同一run内の操作 | 目的 |
|---|---|---|---|
| P0 | adjacent | ファイル操作なし、`S0E`のみ | 1ブート固定費対照 |
| O1 | adjacent | Q9AをOPEN→無読出しCLOSE | 1ファイル目のOPEN/CLOSE包絡 |
| R1 | adjacent | Q9Aを3行読出し | 1ファイル目全体・単独A |
| O2 | adjacent | R1後、Q9BをOPEN→無読出しCLOSE | 2ファイル目のOPEN/CLOSE包絡 |
| R2 | adjacent | Q9A→Q9Bを各3行読出し | m7dr型基準・2ファイル目全体 |
| O3 | adjacent | R2後、Q9CをOPEN→無読出しCLOSE | 3ファイル目のOPEN/CLOSE包絡 |
| R3 | adjacent | Q9A→Q9B→Q9Cを各3行読出し | 3ファイル介入 |
| SB | adjacent | Q9Bだけを3行読出し | 固定費モデルの単独B |
| SC | adjacent | Q9Cだけを3行読出し | 固定費モデルの単独C |
| AA | adjacent | Q9A→Q9Aを各3行読出し | 同一ファイル再読介入 |
| BA | adjacent | Q9B→Q9Aを各3行読出し | 逆順介入 |
| FP0 | separated | ファイル操作なし | 配置媒体の固定費対照 |
| FA | separated | Q9Aだけを3行読出し | 配置適用範囲のA対照 |
| FB | separated | Q9Bだけを3行読出し | 配置適用範囲のB対照 |
| FAB | separated | Q9A→Q9Bを各3行読出し | フィラー介在配置介入 |

SB/SC/FA/FBはR1と同じ単独読出しテンプレートを使い、20行のファイル名、期待文字列、
固有マーカーだけを置換する。AA/BAはR2の20・30行で指定するファイル名と、各行の
期待文字列だけを置換する。AAの期待連結は`A1A2A3A1A2A3`、BAは
`B1B2B3A1A2A3`、FABはR2と同じ`A1A2A3B1B2B3`とする。従って、同じファイルを
2回OPENしたこと、逆順で両方を読んだこと、3ファイル目を実際に読んだことは、本文を
出力しない画面判定器で区別できる。

各IDを公式一式・混成それぞれ2回実走する。仮説の一次判定には公式2回の一致値を使い、
混成2回は同じ入口が自作subでも成立するかの適合確認に使う。単一走は採用しない。

## 共通の方向判定規則

一次指標はmain `IN $FC`件数とREAD単位数の2つとする。2つの量または差分ベクトル
`X`/`Y`を比べるとき、次の規則を全介入へ共通に適用し、任意の件数幅や割合閾値は置かない。

- 2指標とも`X<Y`なら**Xが小さい**、2指標とも`X>Y`なら**Xが大きい**。
- 一方が等しく他方だけが厳密に小さい／大きい場合は、厳密な側を採る。
- 2指標とも完全一致なら**等値**。
- 一方が小さく他方が大きければ**方向不一致**とし、その比較では支持・反証を採らない。

差分が負になる段階、または追加操作に対応するバルクが0件の段階は、介入適用範囲を
確認できないため方向判定へ入れない。SHA-256は決定論性・適用範囲検査だけに使い、
近さや増減の判定には使わない。

## 段階ラダーと固定費モデルの事前予測

段階差分を、2指標それぞれについて次のとおり定義する。

| 段階 | 差分 |
|---|---|
| 1ファイル目OPEN/CLOSE包絡 `E1` | O1 − P0 |
| 1ファイル目データ読出し追加 `D1` | R1 − O1 |
| 2ファイル目OPEN/CLOSE包絡 `E2` | O2 − R1 |
| 2ファイル目データ読出し追加 `D2` | R2 − O2 |
| 3ファイル目OPEN/CLOSE包絡 `E3` | O3 − R2 |
| 3ファイル目データ読出し追加 `D3` | R3 − O3 |

- **H-Dの予測**: `E2`/`E3`の少なくとも一方が`E1`より小さく、どちらも大きく
  なければ支持。`E2=E1`かつ`E3=E1`なら、後続OPEN段階の使い回しが削減を生む
  H-Dを反証する。大きい段階との混在または方向不一致は未確定とする。
- **H-Bの予測**: `D2`/`D3`の少なくとも一方が`D1`より小さく、どちらも大きく
  なければ、後続データ読出しで内容保持が効くH-Bを支持する。両方が`D1`と等しければ
  反証。大きい段階との混在または方向不一致は未確定とする。
- OPEN/CLOSE包絡には無読出しCLOSEも含むため、`E`の差だけでディレクトリ検索と
  CLOSE処理を分離しない。`D`の差だけでバッファとSEEKを分離しない。後述の配置・
  同一ファイル介入と組み合わせて絞る。

固定費モデルでは、`Z=P0`、単独値を`A=R1`、`B=SB`、`C=SC`とし、同一セッションの
予測値を指標ごとに次の式で固定する。

```text
pred(R2) = A + B - Z
pred(R3) = A + B + C - 2*Z
```

- R2/R3が両指標とも各予測値へ完全一致すれば、**H-Fだけで1→2→3ファイルの削減を
  説明できる**としてH-Fを支持する。
- R2またはR3が予測より小さい方向で一致すれば、固定費だけでは足りず、H-D/H-B/H-Sの
  いずれかによる追加再利用があるとしてH-F単独説明を反証する。
- 予測より大きければ、複数ファイル化に追加費用がありH-F単独説明を反証する。
- R2とR3で方向が逆、または指標の方向が不一致ならH-Fは未確定とする。

3ファイル目の増分`R3-R2`も、単独Cの固定費除外分`C-Z`と比較する。等値なら追加
ファイル当たりの費用が定数である予測を支持し、小さければセッション内再利用の累積、
大きければ配置・キャッシュ容量・ファイル数依存の追加費用を支持する。ただし後二者の
どれか1機構へは帰属しない。

## 個別介入の事前予測

### 同一ファイル再読（AA）

AAをR2（A→B）と比較する。AAが小さければ、ファイル固有のディレクトリ結果、保持
データ、または同一位置に留まることの再利用という**H-D/H-B/H-Sの合成予測**を支持する。
等値なら「同じファイルを読むだけで追加削減が生じる」予測を反証する。AAが大きければ
単純な再利用予測と反対、方向不一致なら未確定とする。AA単独では3仮説を分離しない。
H-FはAA/R2で固定費が同じなので差を予測せず、差が出ればH-F単独説明を反証する。

### 逆順（BA）

BAをR2（A→B）と比較する。等値なら、登録した隣接配置での順序効果を反証する。
大小どちらでも一致して差が出れば、ディレクトリ並びまたは物理位置に対する順序依存を
支持し、H-F単独説明を反証する。ただしH-DとH-Sは分離しない。方向不一致は未確定とする。

### フィラー介在配置（FAB）

媒体ごとの単独費用と固定費を除いた相互作用残差を次で定義する。

```text
Iadj = R2  - R1 - SB + P0
Ifar = FAB - FA - FB + FP0
```

配置適用範囲が成立したうえで、`Ifar`が`Iadj`より大きく、かつFABのSEEK発行件数または
READ単位がR2より増える方向なら、近接配置によるSEEK／READ省略というH-Sを支持する。
`Ifar=Iadj`でSEEK件数も等しければ、登録した配置差が削減を生むH-Sを反証する。
相互作用だけが変わりSEEK件数が変わらなければ「配置依存」は支持してもSEEK省略へは
帰属しない。逆方向または指標の方向不一致は未確定とする。H-Fは媒体内で相殺されるため、
残差差を予測しない。

### 3ファイル目（R3）

固定費モデル式と`R3-R2`対`C-Z`の規則をそのまま使う。等値なら固定費1回＋ファイル数に
比例する増分、後続増分が小さければH-D/H-Bの累積的再利用、後続増分が大きければ
H-Sまたは有限バッファ／ディレクトリ規模による増加を支持する。段階ラダーのE3/D3により、
差がOPEN/CLOSE包絡かデータ読出しかも併記する。3ファイルだけで特定機構へ帰属しない。

## 到達条件・陽性／陰性対照

各測定runの到達条件は次のANDとする。

1. 対象プログラムと`RUN`が画面へ反映される。
2. 指定されたOPEN順、各3行読出し、各CLOSEを通過し、条件固有の内容一致／OPEN完了
   マーカーが順に表示される。無読出し腕はOPEN直後のCLOSEと`SxO`を必須とする。
3. 全ファイルを閉じた後の`S9C`と直後の`Ok`が表示される。
4. 条件が追加するはずの段階で、介入成立節に定めた非0バルク／READを観測する。

陽性対照は各固有マーカー→`S9C`→`Ok`を持つ合成画面と非0バルクを持つ形とする。
陰性対照は、(a)ファイル順を入れ替えた画面、(b)内容一致マーカー欠落、(c)無読出し腕で
読出しマーカーが出る形、(d)`S9C`欠落、(e)直後`Ok`欠落、(f)バルク0件とする。

**不合格条件**は、構文エラー、指定OPEN順不成立、3行未満／内容不一致、CLOSE未通過、
固有マーカー／`S9C`／直後`Ok`欠落、無反応、無限ループのいずれかとする。単なる
構文受理、`Ok`だけ、または片方だけの読出しでは合格させない。

## 介入成立と適用範囲の検証計画

到達と介入成立を分け、次を全て満たした条件だけを支持／反証へ数える。

1. **共通**: 公式・混成の各2runが到達し、全runでmain/sub各ヘッダの取りこぼし0件、
   同一モード2回の全イベント列・画面が決定論的一致する。
2. **段階ラダー**: 比較する長腕が短腕のFDCコマンド種別列・値非表示イベントSHAの
   共通prefixを保ち、追加段階にmain `IN $FC` 1件以上かREAD DATA 1件以上がある。
   差分が負、共通prefix不一致、または追加バルク0件ならその段階は不成立とする。
3. **AA/BA/R3**: 内容一致マーカーで2回目／逆順／3ファイル目の意味上の実行を確認し、
   AAはR1、BAはSB、R3はR2に対して追加バルクまたはREADが1件以上ある。0件なら
   不成立とする。
4. **配置準備**: separated準備のフィラー読戻し64/64行・各長さ120、WRITE DATA 1件以上、
   adjacent準備よりWRITE DATA件数が厳密に多いことを確認する。
5. **配置の局在**: FA/FBのREAD DATAパラメータ組（値は出さない）の順序付きSHA-256を、
   R1/SBの対応署名と比較する。Q9A署名は同一、Q9B署名は不一致であることを必須とする。
   出力するのは件数、SHA-256、一致prefix、最初の差の位置だけとする。Aまで変化した、
   Bが変化しない、またはどちらかがバルク0件なら、物理配置介入は不成立とする。
6. **配置本体**: FABがFAより追加バルク／READを持ち、FAの列を共通prefixとして保つ。
   これを満たさなければ配置介入は支持にも反証にも数えない。

配置の局在条件は「Q9Fを作ったから離れたはず」という意図だけで採用しないための関門である。
値非表示署名では距離そのものを数値化できないため、成立しても「Q9Bの物理アクセス位置が
変わりQ9Aは不変」までを言い、「何トラック離れた」とは記録しない。

## 観測指標と固定手順

全条件で9000フレーム、300F/700Fの二段打鍵、300秒・512打鍵上限、同一ハーネス引数を
使う。測るのは公開FDCコマンド種別列と件数、SEEK・READ DATA・WRITE DATA件数、main
`IN $FD`・`IN $FC`の件数とSHA-256、画面の行数・文字数・SHA-256、値非表示イベント列の
件数・SHA-256・一致prefix・最初の差の位置だけとする。

各IDの公式1回目の到達runでmain `IN $FD`/`IN $FC`、FDCコマンド種別列、画面の期待値を
固定した後、公式2回目・混成2回を判定する。全イベントSHA-256は同一モード2回の決定論性に
だけ使い、公式・混成間の内部FDCパラメータ一致を要求しない。
判定器には件数、SHA-256、期待値0行の故障を注入し、全て不一致になることを確認する。
画面判定器は各固有マーカー欠落・順序入替・`S9C`欠落・直後`Ok`欠落・バルク0件を全て
陰性にできることを必須とする。

## 不採用条件と打ち切り

次のいずれかで該当runを不採用とし、原因を除いた新しい使い捨て複製で再測定する。

- 到達条件または介入成立条件を満たさない。
- 取りこぼしが1件以上ある。
- 固定したディスク原本、作成順、行数、読出し順、フレーム数、打鍵時点、ROM構成、
  ハーネス引数から逸脱する。
- q88measureの既知の起動時クラッシュ以外でrc非0となる。

再測定しても次のいずれかなら測定系列を打ち切る。

- 9000フレーム、300秒、512打鍵の上限内に到達できない。
- 取りこぼしを0件にできない、または同一モード2回が決定論的一致しない。
- 段階ラダーの共通prefix、非0追加バルク、配置局在署名を成立させられない。
- フィラー準備が媒体容量等で正常完了しない。
- 公式ROM・公式ディスク内容またはデータポート値列を表示・転記するおそれが生じる。

打ち切った介入は**不成立**と記録し、H-F/H-D/H-B/H-Sの支持にも反証にも数えない。
別の介入へ後から切り替えず、成立した他介入だけを登録済み規則で判定する。途中で予測や
閾値を変更しない。

## 解釈限界

- 段階ラダーは別run間の差分なので、同一run内部を直接区切ったものではない。共通prefixと
  固定費対照で補強するが、OPENとCLOSE、データ読出しとその後のCLOSEを完全分離しない。
- AAが小さくても、同じディレクトリ結果、データ保持、同じ物理位置の3要因を分離しない。
- BAの差はディレクトリ順と物理順の双方を含む。FABの配置局在が成立した場合だけH-Sを
  追加評価する。
- H-Fの完全一致は固定費モデルで十分という結果であり、内部でキャッシュ等が存在しない
  ことの証明ではない。異なる機構が相殺して同じ件数になる可能性は残る。
- QUASI88上の同じ準備媒体・同じ3行ファイルに対する結論であり、実機一般性、別媒体、
  大きなファイル、ランダムアクセスへ一般化しない。

## 情報境界

記録するのは件数、位置、clock、SHA-256、画面の行数・文字数・SHA-256、自分で打鍵した
文字列・自作データ、および公開されたμPD765コマンド名だけとする。FDCパラメータ組は
解析器内部でSHA-256へ畳み、値を1バイトも出力しない。画面本文全体、ディスクのデータ部、
公式応答値は記録しない。ROM・ディスク複製、生iolog、stdout/stderrは全てリポジトリ外の
一時領域だけで扱う。
