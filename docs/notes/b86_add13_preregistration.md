# B86 追補13 事前登録

G5 の値なし観測 `g5-7071-reads.md` に現れた ROM 実行中の main RAM 読み番地を需要とし、その値・ゲームデータを使わず働きを測る。対象は 7071 と 3E0D。11DF は 7071 から到達し得るが、内部経路・進入回数を計測しないため、得られる規則は 7071 区間全体の規則であり 11DF 単独に帰属できない。F136–137 の帰属も未確定の候補として含める。

公式 ROM と自作起動セクタで起動し、公式 BASIC 起動に伴う初期化後の作業域を初期状態とする。ゲームによる複写を再現しない。各入口について無介入の基準腕、各読み番地を一つだけ 00、01、02、04、08、10、20、40、80、FF に変える腕、読み番地に含まれない E700 を同様に変える陰性対照を設ける。重複番地は一度だけ試す。観測範囲に含まれるスタック・画面も対象にするが、呼出しまでに上書きされる場合や有効でない設定値については介入が入口まで保持されたとは限らない。初期化済みの元の値は出力しない。入力は DI、固定レジスタ、SP D000、戻り先を積んで JP。7071 は自作値 00 を OUT 31 して直後に JP する。各腕は別の ROM 置き場で起動する。

入口から戻りまたは再起動までの OUT 31/30/40/51/50/64/65/68 をポート別の出現順で比較し、件数、介入値との一致、出力ビットと入力ビットの一致・反転の候補、無介入との差を記録する。区間開始前に自作した OUT 31 は除外する。全入力で同じ出力は「定数（値はリポジトリ外）」とし、2種類未満では未判定。異なる分岐で順序がずれた場合、同じ出現番号の比較は仮説にすぎない。固定された他の設定や少数例との偶然の一致も因果を証明しない。公式出力の数値・列は残さない。

F3C8–FFF7 の書込み総件数・異なる番地数・番地範囲と基準との差、復帰と戻りレジスタの入力との関係・基準との差を記録する。画面の値や本文、ROM 内部 PC、ROM による RAM 書込み値は出さない。画面の範囲と総件数が等しくても、番地ごとの回数が等しいとは限らない。書込みは値の変化と区別する。復帰後レジスタの値そのものは出さない。再起動や上限内未復帰は「戻らない」。入口未到達、実行失敗、ログ欠落または取りこぼしは欠測であり、戻らないと混同しない。

各腕は既定 2010 フレーム、タイムアウト 180 秒。記録バッファのあふれは両ログの取りこぼしを検査して欠測にする。上限や欠測を停止条件とせず後続腕を実行する。生ログ・一時値・ROM・媒体はリポジトリ外に置き、集計後に削除する。`PC88_REF_ROM_DIR` を指定して `tools/b86_add13_run.sh` に未使用のリポジトリ外出力先を渡す。`B86_ADD13_FILTER`、`B86_FRAMES`、`B86_TIMEOUT` で腕や上限を変更できる。公式 ROM 未指定時は自作 RET 対照。公式測定後の再集計は一時値削除のためできない。自己検査は器具のみで、ゲーム・公式 ROM・run_all を使わない。
