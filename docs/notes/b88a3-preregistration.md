# B88 追補3 事前登録

測定前の計画。ゲーム実走から採るのは番地・並び・回数・制御ビットだけとし、働きは自作入力と自作媒体で測る。`CLAUDE.md` と goal-b-policy に従い、ROM命令・内部PC・ゲームデータ・画面本文を記録しない。B90集計の1〜3節は測定対象を選ぶ手掛かりであり、レジスタ値やデータ値を本計画の根拠として転記しない。

## 共通

各腕を独立したROM置き場で2走する。原則として両ドライブに自作媒体を入れ、媒体なし腕だけ対象ドライブを空にする。呼出し前・入口・戻り直後のIFF1・IFF2・IM、戻りの有無、入力とのレジスタ一致、FDCコマンド種別を記録する。JP腕は自作の戻り先を積む。フレームまたは時間の上限までに戻らなければ、入口到達を確認できた場合に限って「戻らない」とする。前処理未完、入口未到達、媒体条件不成立、記録不足、搬送不一致は欠測とする。内部PCは採らない。

生の戻り値・一時記録・ROM・媒体は集計後に削除し、公開集計には入力との関係、真偽、回数、番地のみ残す。ただし自作入力と自作媒体に対するFDCのコマンド・引数・結果は値を記録してよい。2走の値を一時的に比較した結果も残す。FDCの相や送受信の完了が確認できないとき、対応する規則は不明とする。

## 00ED

Aに `00,01,02,06,09,0C,0D,0E,12,15,16` を置きJPする。要求番号はmainから重ねて送らない。残る引数は `docs/spec/l3-subrom.md` の該当手順に従いmainから送る。読み後データの送出を要する12は、別の前処理で自作媒体の読みを完了してから呼ぶ。09・15の送出範囲と0C・16の書込み範囲は、自作データを置いたRAMに限定する。0Dの移動先は自作の帰還コードとする。01は仕様にある書込み手順と自作データを用い、引数とデータを揃える。応答値は記録せずmainで受信完了数を数える。応答長の仕様が未確定の要求は一致判定を未確定とする。戻り、応答長、FDC種別、戻りレジスタ・IFFを各要求で比較する。

## 0263

`02A4/0020×7/02A7` からREAD DATAを送り、データ相が存在する場合はデータを読み切る。MSRでRQM=1・DIO=1かつ実行相ではないことを確認した後に0263を呼ぶ。正常読み、存在しないR、存在しないシリンダ、媒体なしドライブの各腕を設ける。データ相を経ず結果相へ移る異常も許す。相の確認ができない場合は0263を呼ばず欠測とする。コマンド、データ受信数、結果7バイト、ST0〜ST2と、戻りA・F各ビット・BC・DE・HLとの関係を求める。`7F0D〜7F13` は各位置と結果バイトの一致だけを判定する。結果7バイトが揃わない場合は完全な結果として扱わない。

## 07D6

両ドライブに媒体を置き、A・B・C・D・Eをそれぞれ独立に振る。基準に対する単独変更に加え、ドライブ選択とシリンダ候補を区別できる境界値・複合変更を含める。入口から戻りまでのOUT F8、FDCコマンドと引数、SEEK後のSENSE INTERRUPT STATUS結果、SENSE DRIVE STATUSの装置番号を記録する。各出力について各入力レジスタの一致・マスク・シフト等の事前指定候補を真偽で比較する。候補が複数残れば一意としない。戻りレジスタ・IFFも記録する。

## 器具の検査

公式参照変数を除いた自作ROMで、通信の途中帰還・未帰還、結果相の正常と異常、相違反、FDC引数の取り違え、各レジスタ依存、結果配置の一致と不一致、IFF変化、時間切れ、記録破損、漏洩と後片付けを陽性・陰性対照で検査する。全腕の実行と再集計も確認する。自己検査が通るまで公式測定に使わない。

## 器具の具体化（公式測定前）

- `tools/b88a3_run.sh OUT` は138腕を各2走する。00EDは11要求×DI/EI、0263は4条件×DI/EI、07D6は基準・各レジスタの単独変更・複合変更53条件×DI/EI、ほかに陽性・陰性対照を置く。07D6の単独変更値は `00,01,02,03,04,07,10,3F,7F,80,FF`（基準と同じ値は省く）。
- 00EDの01には4引数と自作256バイトを送り、本体は2バイト単位。09・15は自作RAMの16バイト、0C・16は同じRAMへの16バイト書込みとする。0Dの自作移動先到達は通常の帰還とは別に数え、搬送用SPだけを戻す。00・01・0Cの応答長は仕様未確定として一致判定を出さない。
- 12の前処理は独立した読み要求・06応答で行う。自作媒体から256バイトを読み、結果7バイトの正常終了とmain側の応答確認を揃えてから測定する。プローブのアップロードを終えた自作ラベルで両ドライブの媒体を交換する。
- 0263のREAD DATAはMFM、N=1、正常腕はC/H/R=0/0/4。256バイトを読んだ時点で `IN F8` によりTCを入れ、EOT到達による異常終了と正常終了を分ける。DIO/RQMに加えEXM=0・CB=1も入口前と入口で確認する。媒体なしなどで結果相へ進まない場合は、0263を呼ばず欠測とする。
- 07D6の候補は各入力レジスタの恒等、マスク `01,03,07,0F,C0`、右シフト1・2、bit0の左シフト2、異なる入力の装置・ヘッド合成、定数0・1・7。全シーク腕で帰還と対象出力が揃った場合だけ候補の共通部分を求め、複数候補を一意としない。SENSE INTERRUPT STATUSの結果は対応するFDC取引に含める。
- 公式参照変数がない場合は `tools/b88a3_fixture.py` の器具専用自作ROMを使う。これは既知の入出力を作る対照であり、製品側subの適合性や公式ROMの動作を主張するものではない。`src/`・`make_subrom`は参照・変更しない。自作対照の割り込み口はDIで復帰し、入口前・区間内のIFF変化を検出する。
- 出力先はリポジトリ外の未使用ディレクトリ。`B88A3_FILTER`、`B88A3_FRAMES`、`B88A3_TIMEOUT`で腕・上限を指定できる。生の戻り値は2走・基準腕との一致へ縮約し、ROM・媒体・生ログ・一時値を削除する。`python3 tools/b88a3_summarize.py OUT`で再集計できる。
- クラウドでは `PC88_REF_ROM_DIR` と必要なら `PC88_CORE_SOURCE` を環境変数で設定して `tools/b88a3_run.sh OUT` を実行する。自作対照の故障注入と公式ROMの併用は拒否する。公式ディスクは使用しない。
