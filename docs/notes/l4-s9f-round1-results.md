有限標本から全式の動作を保証するものではない。

## program-hexspace の観測（関門で止まった）

`20 v=&h 10` は、入力は通り（listed_lines=1）、RUN で ERR 2 の印の**後に ERR 20 の印も出て**
2行になった。器具は「印は1個＋完了印」の形を要求するため関門失敗となる。2走は一致。
直接モードの `&h 10` は ERR 2 と完了印の通常形（agree）で、直接では H_GW どおり
「16進では空白を飛ばさない」が確認できた。

ERR 20 は、誤り捕捉の `resume next` が、誤りの起きた行の続きへ戻り、`10` 以降を再び
誤りとして踏んだ、または誤りでない状態で resume が走った、などの戻り先に由来する可能性があり、
`&h` の後の空白の規則としては**確定していない**。プログラム形でこの1形だけ別の形を取る
事実を記録するにとどめ、器具の想定外の観測として、期待値には含めない。

## 測定で裏付けた規則

- **値の範囲**: 16進は4桁まで。`&h0`=0、`&h10`=16、`&hff`=255、`&h7fff`=32767、
  `&h8000`=-32768、`&hffff`=-1。8進は `&o177777`=-1、`&o17`=15。
  16ビットとして読み、32768以上は負の整数として扱う（符号なしではない）。
- **範囲外**: `&h10000`・`&h1ffff`・`&o200000` は ERR 6（切り詰めない）。
  先頭の0も桁に数える: `&h00010` は ERR 6。
- **省略形**: `&17`（oなし）は8進の15。`& h10`（&の後の空白）は16。`&o1 7`（8進の数字の間の空白）は15。
- **型**: 整数として振る舞う。`&hffff+1`=0、`&h8000+0`=-32768、`a%=&hffff` の a% は -1、
  `&h10/3`=5.33333（単精度）、`abs(&h8000)`=32768（単精度へ昇格）、`-&h1`=-1。
  `&h-1` は -1（`&h` の0から1を引く。数の中の符号は読まない）。
- **桁なし・不正**: `&h`=0。`&hg` は実行時 ERR 2。`&o8` は ERR 2。
  `&h10%`・`&h10!`・`&h10#` は実行時 ERR 2（型指定として吸収されない）。
- **入力時と実行時**: プログラム行では、`&h10000`・`&h1ffff`・`&o200000`・`&h00010`
  （ERR 6）と `&o8`（ERR 2）は**入力時に誤りになり行が入らない**（入力時のERR印あり、
  LISTに行なし。RUNは完了印のみ）。`&hg`・接尾辞・`&h 10` は行が入り、実行時に ERR 2。
  直接モードでは同じ式が実行時に同じ ERR 6/2 になる。
- **大小文字**: 打鍵は小文字のみ。LISTの書き直しは既存の第14.5節に従う。

誤りはERR番号の観測。公式画面のメッセージ文言は測定・転記していない。

## 期待値の固定と照合

根拠の鎖は、自作PRINT数値の測定TSV → 本ノート →
[l4-basic 第22節](../spec/l4-basic.md#22-観測--hex-oct-定数の値l4-s9f)。
[期待値](../../tests/conformance/expected_l4_hexconst.tsv) は関門を通った67腕について、
2走一致を確認し1走目の `observation` を保存した（列は `arm`・`observation`）。
program-hexspace は含めない。

`check` は測定ファイルと期待値の腕集合が一致しないと拒むため、gate_failed 腕を含む
元TSVそのものには通らない（終了値1）。program-hexspace の2行を除いた作業用コピー
`../tmp/l4s9f-work/official_round1_without_hexspace_program.tsv` で、次が終了値0になる。
器具は変えていない。

```
python3 tools/l4_hexconst_measure.py check --expected tests/conformance/expected_l4_hexconst.tsv --measured ../tmp/l4s9f-work/official_round1_without_hexspace_program.tsv
```

公式ROMの再測定、git add、コミットは実行していない。

## 決めなかったこと

- `&h` の後の空白のプログラムモードでの規則（ERR 20 の由来）。ON ERROR を使わない形での再測定が要る。
- 生の大文字での直接打鍵、複合式の網羅、任意番地への利用。
- 自作実装の状況: 自作はLISTで接頭辞を大文字にするが、式の値としては未実装という
  依頼時の観測が出発点。実装は別段で行い、自作での測定は本段に含めない。
