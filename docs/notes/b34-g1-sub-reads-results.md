## 分かったこと

- **G1 の RAM 上のコードは、ROM の領域も、誰も書いていない RAM も読まない。** 読むのは `0x0C` で書かれた範囲（`7815-781A`）と、自分で書いた範囲である
- したがって B30 の違いは、RAM の初期内容や ROM の値を読んでいるためではない

## 読み方（推定）

同じコードが同じ要求を受けて違う値を main へ返すなら、残る入力は **`0x0D` で移るときのレジスタ**か、FDC とポートからの値である。1.36c 節はレジスタを未測定としている。次はこれを自作のコードで測る。
