# B65: 長押しのキーで G1 を先へ進め、公式と自作が同じに進むかを測る — 結果

記録日: 2026-11-02
規則: [b65-g1-held-key-paths-preregistration.md](b65-g1-held-key-paths-preregistration.md) どおり。測定はクラウドの実行環境で rc=0。記録は `measurements/b65-g1-held-key-paths.txt`。

## 結果

| 腕 | 画像 | テキスト | 移る回数 公式 / 自作 | `IN $FC` 公式 / 自作 |
|---|---|---|---|---|
| I1（`i` のあとリターンとスペース） | 違う | 同じ | 93 / 93 | 127799 / 127795 |
| I2（`i` のあと数字） | 同じ | 同じ | 87 / 87 | 124725 / 124721 |
| I3（`i` のあと ESC と F キー） | 同じ | 同じ | 87 / 87 | 124725 / 124721 |
| S1（`s` のあとリターンとスペース） | 同じ | 同じ | 76 / 76 | 113713 / 113709 |
| F1（F1 のあとリターンとスペース） | 違う | 同じ | **74 / 72** | 112817 / 112813 |

## 分かったこと

- I1 は公式も自作も 93 回まで進み、同じに進む。画像だけが違うのは B64 の位相の差の可能性がある
- **F1 の腕だけ、移る回数が違う**（公式 74、自作 72）。`IN $FC` の差は 4 のままで、データのやり取りの量は同じである。移る先が違う番号は無いので、自作は最後の 2 回の手前で止まっている
