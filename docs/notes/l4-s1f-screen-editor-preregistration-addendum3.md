# l4-s1f — 事前登録への追補3（B2'・B3'の位置修正、位置確認の関門化）

記録日: 2026-09-19
状態: 本追補の腕（B2'・B3'取り直し）の**前**にコミット。判定名の体系は
本体・追補1・追補2と同じ。

## 経緯

境界結果ノート（`docs/notes/l4-s1f-screen-editor-results-boundary.md`、
コミット`e08bffb`）のB2'・B3'は、準備手順「HOME/CLR→文字1つ→↓」で
対象キーを押す位置を(行1,列0)と想定していたが、レビューにより
(行1,列1)だったと判明した（文字を打つとカーソルは必ず1つ右へ進む。
続く↓は列不変、本体で確定済みの`row_move`）。この位置ずれにより、
B2'・B3'の結論は取り下げた（訂正節、コミット`fc1df2d`）。

## 見落としの原因と対策

**今回の見落としは「対象キーを押す直前の位置を、対象キー無しで独立に
確認する関門」が無かったために起きた。** 頭の中の計算（打鍵→列+1、
↓→列不変）に頼り、実際に測定していなかった。今後は、境界を扱う腕
すべてで、次の関門を追加する。

- **関門P（位置確認）**: 各腕の準備手順について、対象キーを押さずに
  その位置で直接目印文字を打つ**対照走**を用意し、目印の座標が
  意図した位置と一致することを確認してから、対象キーを含む本走を行う。
  対照走・本走とも各2走（決定論性）。

B1〜B4については、この関門Pを追補2の時点では明示していなかったため、
訂正節で事後的に確認した（結果はB1・B3・B4→(行0,列0)、B2→(行1,列0)、
いずれも2走一致・意図どおり）。本追補以降はP を新規腕の事前登録に
必須項目として明記する。

## B2'・B3'の修正した準備手順

「HOME/CLR→文字1つ→↓→←」（←を追加。文字打鍵後の(行0,列1)→↓で
(行1,列1)→←で(行1,列0)へ、この最後の←は位置決めであり測定対象には
含めない）。関門Pにより、この手順が実際に(行1,列0)へ到達することを
対象キー無しの対照走で確認する。

## 判定

各腕、`unique_survivor`／`no_survivor`／`multiple_survivors`。関門Pが
意図した位置と一致しない場合は、腕を組み直す（今回はP-Cで確認できたため
そのまま進める）。G3（決定論性、各走2走一致）を関門とする。
