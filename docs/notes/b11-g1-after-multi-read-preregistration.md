## 1. 問い

B7 の位置 13510 の途切れは、この実装で解消するか。B9 の座標は公式と同じになるか。その先でどこまで進むか。

## 2. 条件

2a4f910 の配布ビルドを自作とする。腕は B7 と同じ OO・OS・SS・SO の 4 つ、各 2 走。他の条件は B7 第2節と同じで、クラウドの実行環境で行う。
濾過・要約・比較は `tools/b1_whitelist_boundary.py`、`tools/b6_io_sequence.py`、`tools/b8_io_values.py`、`tools/b9_sector_coordinates.py` をそのまま使う。

## 3. 対照

OO の境界記録と入出力の要約が、B1・B6 の記録と一致すること。SO はサブが公式なので B7 の SO の記録と一致すること（自作 main は変わっていないので変わらないはず）。通らなければ根拠にしない。

## 4. 判定（事前に決める）

- **途切れの解消:** OS・SS の OO に対する位置が 13510 を超えれば「解消」。13510 のままなら「残る」
- **座標:** OS・SS の 15 ブロックが OO と同じ `(0,0,2)〜(0,0,16)` か
- **値:** OO 対 OS の `IN $FC` の最初の 3840 件の `differ` が 0 か
- **次の止まる所:** 新しい位置と前後の要素、`IN $FC` の件数を腕ごとに書く。SS と SO の位置を並べる。原因は書かない
