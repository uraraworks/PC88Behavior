# B40: スペース後の G1 で、サブが RAM 上のコードへ移るときの表を値なしで出す — 結果

記録日: 2026-11-01
規則: [b40-g1-sub-cross-table-preregistration.md](b40-g1-sub-cross-table-preregistration.md) どおり。測定はクラウドの実行環境で OO・SS 各 2 走。関門 12 項目はすべて通った。値は記録していない。記録は `measurements/b40-g1-sub-cross-table.txt`。

## 移る先が違う最初の行

番号 29。公式は `7800`、自作は `7803` へ移る。fc は公式 76831、自作 76829 で、**B30 の 76570 より後**である。値の違いのあとで道が分かれている。

## 違うレジスタ

- `F` は番号 0 からずっと違う
- `D`・`E` は番号 5、8、11、14、17、21、24、27 で違う。どれも `7812` へ移る行で、`7812` へ移る番号 28 では同じである
- `L` は番号 29 で違う（移る先が違うので当然）
- `A`・`B`・`C`・`H`・`SP` などは番号 28 まで同じ

## fc

番号 0〜27 で、公式の fc は自作より 4 多い。番号 27（`7812`）は公式 76831、自作 76827 である。257 件の違いの終わり（76570+257=76827）は、自作の番号 27 と重なる。

## 読み方（推定）

- 値の違いの 257 件は、番号 26（`7803`）と番号 27（`7812`）のあいだのデータの最後の部分に当たる
- `DE` が違うのは `7812` へ移るときだけである。B35 の場面では公式の `DE` は 0 だった。`7812` への移り方が B35 の場面と違う可能性がある
- 原因は断定しない
