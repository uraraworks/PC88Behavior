## 観測から読める規則（実装の根拠。G_GW との差を含む）

論理演算:
- 両辺を符号付き16ビット整数へ丸め（半端は絶対値の大きい側: 2.6→3、−2.5→−3、0.5→1）、範囲外（40000・−32769）は ERR 6、文字列は ERR 13。
  XOR は排他的論理和、EQV は XOR の否定、IMP は「左 AND NOT 右」の否定。優先順位は高い順に NOT、AND、OR、XOR、EQV、IMP。
  比較・算術・単項マイナスはそれらより高い。IF の条件にも使える（`5 xor 5` は偽）。

POS・TAB・SPC（幅80。**G_GW と違う点は太字**）:
- **POS(0) は0始まり**。`print "ab";` の後は2（G_GW は1始まりで3と予測）。
- **TAB(n) は0始まりの桁 n（n mod 80）へ**進む（TAB(1) は桁1、TAB(80) は桁0＝次行の頭、TAB(81) は桁1、TAB(256) は桁16）。
  G_GW は「n−1の桁」（POS 1始まりと合わせて見かけ上同じ値になる腕が多く、それで16腕が agree した）。
  現在桁より後ろなら空白で進み、**同じなら何もしない**（k=5 に TAB(5)）、前なら**改行してから**その桁へ（k=5 に TAB(1) は行+1、桁1）。
- TAB の負数（−1）は誤りにならず桁0。32768 は **ERR 6**（符号付き16ビットで受け、G_GW の「32768〜65535 を符号なしで受け0へ寄せる」は成り立たない）。
  65536 も ERR 6、文字列は ERR 13、式中（`a=tab(3)`）は ERR 2。5.5 は6へ丸め。
- 連鎖 `"a";tab(5);"b";tab(10);` は桁10、区切り無し `tab(5)"b"` も通る。末尾に区切りが無くても改行しない（桁10、行増分0）。
  TAB の後のコンマは次の14桁境界（桁14）へ、続く1文字で桁15。
- **SPC(n) は n mod 80 個の空白**（SPC(80) は0個、81 は1個、256 は16個）。負数は0個。32768 は ERR 6、65536 も ERR 6、文字列 13、式中 2。
  実数 2.5 は3個。行端は1文字ずつ折り返す（桁70から20個→桁10・行+1、桁79から2個→桁1・行+1）。
- 80セルちょうどを出した直後の桁は**次行の桁0**（l4-s9i の観測と一致）: 80個の文字の後は TAB(5)→桁5・行+1、TAB(80)→桁0・行+1、
  TAB(1)→桁1・行+1。桁70からの SPC(10) も桁0・行+1。予測なし5腕のうちこの4腕の観測はこの規則どおり。
- CSNG(1d-50)（予測なし）は誤りにならず値は 0。

CSNG: 倍精度→単精度は絶対値の大きい側へ半端を丸める（16777217#→+2、16777221#→+2）。csng(1/3#)>1/3#・csng(2/3#)>2/3#・csng(−2/3#)<−2/3# は真、
csng(.7#)<.7# は真、csng(.5#)=.5# は真、csng(1/3)=1/3 は真。整数は変換するだけ（123456）、6桁表示（csng(123456.789#) は123457）。文字列は ERR 13。

## 予測と観測が食い違った20腕

POS の起点（1始まりで予測）と TAB の桁（n−1で予測）に起因する。値は「桁,行の増分」。

| 腕 | 予測 | 観測 |
|---|---|---|
| tab-k0-n0 / n80 / nneg1 | 1,0 / 80,0 / 1,0 | 0,0 / 0,0 / 0,0 |
| tab-k0-n32768 | 1,0 | ERR 6 |
| tab-k5-n5 | 5,1 | 5,0 |
| tab-k79-n80 | 80,0 | 0,1 |
| tab-comma | 16,0 | 15,0 |
| spc-k0-n0 / n79 / n80 / n81 / n256 / nneg1 | 1 / 80 / 1 / 2 / 17 / 1（行0） | 0 / 79 / 0 / 1 / 16 / 0（行0） |
| spc-k0-n32768 | 1,0 | ERR 6 |
| spc-k5-n3 / k70-n20 / k79-n2 / frac-25 / chain | 9,0 / 11,1 / 2,1 / 4,0 / 6,0 | 8,0 / 10,1 / 1,1 / 3,0 / 5,0 |
| pos-basic | 3,0 | 2,0 |

TAB の負数（−1）は誤り5でなく桁0へ寄る、という G_GW の読みは**当たった**（ERR 5 の見方は外れ）。
SPC・TAB の範囲外 ERR 6・文字列 13・式中 ERR 2・TAB(65536) ERR 6 の予測は全て当たった。
