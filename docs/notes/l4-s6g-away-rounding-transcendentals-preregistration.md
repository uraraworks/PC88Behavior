# l4-s6g: 超越関数内部の単精度演算をaway丸めにする候補M9、事前登録

記録日: 2026-09-20
状態: 事前登録。**本ノートまでは測定未実施。**

## 背景

l4-s7a/s7b(`docs/notes/l4-s7a-single-precision-arithmetic-rounding-
results.md`・`docs/notes/l4-s7b-integer-only-rounding-results.md`)で、
単精度の加減乗除そのものは**正しい丸め・tieはround-half-away(0から
遠い側)**と、整数オペランドの40腕全数一致で確定した。一方、l4-s6f
(`docs/notes/l4-s6f-full-single-precision-rounding-results.md`)の
候補M8はSIN/COS/TAN内の単精度乗算(範囲縮約・多項式評価・自乗)を
round-half-evenで正しい丸めにしており、l4-s7bの確定事実と丸め方向が
食い違いうる。

候補M9(`tools/l4_mbf_oracle_v10_m9.py`、器具コミット`f947e57`)は、
M8の構造をそのまま流用し、超越関数内部の単精度演算(乗算・加算・
減算・除算すべて)をaway丸めに差し替えたもの。SIN/COS/TANに加え、
ATN/EXP/LOGも同じ丸めに広げた版を用意した(SQRはGW-BASICの反復手順が
未特定なため、最終丸め1回だけをawayにした近似版で、演算列そのものを
「すべてaway化した」とは言えない旨を結果ノートに明記する)。

## (i) 事後照合(本測定より前、公式ROM不使用)

l4-s6a〜fで既にコミット済みの公式実測値(A00〜A20・C01〜C21・
D01〜D22・E01〜E21・F01〜F21、計106腕、いずれも「自分で打った式の
直接の結果である数値」としてノートに記録済み)に対し、候補M9の
予測ビット列を単精度でオフラインに再計算し、既存の実測値
(round-half-evenで単精度へ再エンコードした「公式の出力」)と照合した
(公式ROMへは一切アクセスしていない。既にコミット済みの数値を読んだ
だけ)。

結果: **106腕中102腕(96%)が完全一致。** うち8腕
(D06`tan(77)`・D11`cos(999)`・D12`tan(999)`・E05`cos(65)`・
E06`tan(65)`・F08`cos(44)`・F09`tan(44)`・A15`tan(1.2)`)は、M8では
不一致(F08は+2ULP・F09は-1ULPの退行として記録済み)だったのがM9では
完全一致に変わった。**M8で一致していた94腕のうち、M9で不一致に
転じた腕は0腕(退行なし)。** 残る不一致4腕(A16`sin(6.28)`・
A17`sin(6.2831853)`・A18`sin(6.3)`・A20`sin(10000000)`)は、
l4-s6b以来一貫して未解決のSIN固有の外れ(範囲縮約の別要因、l4-s6c
「未解決の外れ値」参照)で、M9の変更対象(演算の丸め方式)とは無関係
なので対象外とする。

この事後照合はオフライン再計算であり、ATN/EXP/LOGとの交差を持たない
(既存実測にATN/EXP/LOG/SQRの16桁全桁値が無いため)。(ii)で新規に
測定する。

## 測定方法(l4-s3a以来と同一)

- 公式ROM一式、ディスク無し、コア既定N88 V2。起動settleは
  `--type-at 300 --type '\n'`、実打鍵の開始は`--type-at 700`。
- 1文字あたりの反映フレームは既定(hold+gap=8フレーム/文字)。
- 各腕は打鍵の前(写し690固定)と、打鍵と実行が終わった後(表の
  写し(後))に`--vram-dump`で写しを取り、`tools/l4_vram_probe.py`の
  差分で出力行を特定する。`tools/l4_s4a_float_classify.py`で
  `numeric_output`判定と出力セル列挙を行う。
- 各腕2走(決定論性G3の確認)、公式ROMは環境変数`PC88_REF_ROM_DIR`
  (測定コマンドごとに指定、値は`private/rom`)経由で与える。

## 訂正(測定前、`a593b15`直後に発見)

Z25・Z30の打鍵文字列を表記する際に手で`.001`と書き写し、実際の
予測値算出・フレーム計算に使った`0.001`(先頭に`0`、1文字多い)と
食い違っていた。フレーム計算・予測値は元から`0.001`で計算済みで
正しかったため、表の打鍵文字列と打鍵文字数・写し(後)だけを訂正した
(値そのものは変更していない)。測定はまだ行っていない。
