# m7dy: ディレクトリ拡張ジャンプ周期性の追加事前登録

実施日: 未実施（本稿は追加事前登録のみ。周期探索はまだ走らせていない）

本稿は`m7dv`の自作ファイル本数ラダーと`m7dx`で観測したN=11の正方向ジャンプ候補を
引き継ぎ、複数ジャンプを「等間隔」と呼ぶ条件を実測前に固定する。公開仕様から管理形式や
境界幅を仮定せず、成立した介入の整数差だけで判定する。`src/`は変更しない。

公式ROM・公式ディスクの内容、画面本文、データポート値列は表示・転記せず、生ログ、
媒体複製、チェックポイントはリポジトリ外で扱う。`private/`を開かず、`cmp -l`等で
ファイル内容を出力しない。

## 周期判定へ採用するジャンプ

周期系列へ採用する点は、`m7dv`の正方向ジャンプ規則を満たすだけでなく、次を全て満たす
**確認済みジャンプ**に限る。

1. 当該Nの作成run、媒体SHA-256差異、ブロック全名OPEN、`FILES`成果物変化が成立する。
2. 不存在OPEN測定が公式2runで到達し、決定論的一致、取りこぼし0件、WRITE 0となる。
3. `Delta_N=(main IN $FC差分, READ差分)`が直前Delta以上で、少なくとも一成分が厳密に
   大きいという`m7dv`の正方向ジャンプ規則を満たす。
4. 直前の8本境界アンカーからN-1/Nを独立再構築し、同じ符号、差分ベクトル、FDC構造分類を
   各2runで完全再現する。

介入不成立、到達失敗、取りこぼし、非決定、独立再構築不一致の点は、ジャンプ0件へ
読み替えず欠測とする。`m7dx`のN=11は現時点では候補1点であり、独立再構築確認を通るまで
周期判定の`J_1`へ採用しない。

## 周期性の固定判定規則

確認済みジャンプの位置を昇順に`J_1,J_2,...,J_k`、各ジャンプの2指標差分を
`V_i=Delta_(J_i)`とする。任意の件数幅、割合、誤差許容、近さは導入しない。

1. **k=1:** 単発ジャンプ。周期を算出しない。
2. **k=2:** 唯一の間隔`P_1=J_2-J_1`は**周期候補**として記録できるが、反復が無いため
   等間隔周期とは確定しない。
3. **k>=3:** 観測済みの全隣接間隔`P_i=J_(i+1)-J_i`が同じ正整数`P`へ完全一致し、かつ
   全ジャンプベクトル`V_i`が完全一致し、ジャンプ間の成立済みNに別の正方向ジャンプ、
   負方向変化、方向不一致が無い場合だけ、**「観測範囲でP本間隔・同一増分の周期」**とする。
4. 間隔が1回でも異なる、または間隔が同じでも`V_i`が1回でも異なる場合は、外れ値を除外せず
   **非等間隔／増分不一致**とする。都合のよい3点だけを部分列として選び直さない。
5. FDCコマンド種別列の追加suffix、未見コマンド、値非表示イベント構造は各点で併記するが、
   数値周期の成立条件へ後付けで出し入れしない。同じP・同じVでも構造が混在すれば、
   **数値周期は成立、経路の同一性は未確定**と分けて書く。

周期成立後に次の予測位置`J_k+P`まで全介入が成立しても同じVの確認済みジャンプが無ければ、
その位置を通過した時点で**周期破れ**とする。さらに後の点まで待って都合のよい間隔へ
付け替えない。予測位置より前に容量上限や介入不成立で打ち切られた場合は周期破れではなく、
後続周期を検査不能とする。

従って、N=11の候補と同じ`(+258件,+1単位)`が今後も出ることを予想値として固定はするが、
完全一致しなければ同一増分周期へ丸めない。三つ目の確認済みジャンプで初めて2区間を比較し、
上記条件を満たせば周期成立とする。さらに測定範囲を延長して後続ジャンプが条件から外れた
場合は、既存3点を残したまま「後続で周期破れ」と訂正し、外れを削除しない。

## 周期成立時に言えること／言えないこと

周期が成立した場合に言えるのは、固定した公式diskA基準へ同じ規則の自作空ファイルを
追加し、固定不存在OPENで観測した範囲において、**追加ファイルP本ごとにアクセス件数が
同じベクトルVだけ階段状に増えた**という操作上の事実である。Pは追加本数軸上の実測周期で
あり、同じ条件に対する「アクセス1段階当たりP本」という実装試験上の目安にはできる。

一方、今回の測定だけでは、その観測管理単位がディレクトリエントリ、セクタ、クラスタ、
割付表、検索ブロック等のどれかは決まらない。エントリ長、セクタ長、媒体上のバイト数・
アドレスをPから逆算せず、元媒体の既存項目数を含む絶対境界とも呼ばない。追加READを特定の
管理形式やROM内機構へ帰属するには、公開仕様との別照合または別介入が必要である。

## 二つ目以降が出ない場合

- N=64まで全介入が成立し、N=11以外に確認済みジャンプが無ければ、**「追加0〜64本の
  観測範囲ではN=11の単発だけで、反復周期を観測しなかった」**と記録する。周期が存在しない
  という一般反証や、N=11が媒体形式の唯一の境界だとは書かない。
- 二つ目だけを得て三つ目をN=64までに得なければ、唯一の間隔を周期候補として残すが、
  周期確定とはしない。
- 方向不一致や負方向変化だけが後続すれば未確定の変化点として記録し、二つ目の正方向
  ジャンプへ読み替えない。

## 到達・不合格・打ち切り

個々のrun、媒体、介入、独立再構築の到達・不合格条件は`m7dv`と`m7dx`をそのまま引き継ぐ。
上限はN=64で、実測後に延長しない。正方向ジャンプ候補を得たら通常系列を止め、独立再構築
確認を先に行い、その後の再開は受理済みアンカーから行う。

N<64で容量／作成上限、WRITE 0、`FILES`不変、全名OPEN失敗へ達した場合は、そのNで
打ち切る。これは**容量で観測範囲が打ち切られた結果**であり、「次の境界が無かった」や
「周期なし」とは数えない。介入不成立、取りこぼし0件を得られない、2run非決定、危険な
値出力の可能性が生じた場合も、その先を欠測として打ち切り、成立済み範囲だけを報告する。

## 情報境界

記録するのはN、件数、差分、位置、frame、clock、SHA-256、画面の行数・文字数・SHA-256、
自分で打鍵した文字列・自作名、公開FDCコマンド名だけとする。値列や画面本文は記録しない。
