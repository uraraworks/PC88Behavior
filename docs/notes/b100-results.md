# B100 結果：媒体が抜けて読みが失敗し続けると、公式は約900フレームで再試行を打ち切って静かに止まる

実施: 2026-11-17、クラウド（公式 ROM と自作 ROM 2d122aa、G5 を2枚入れて F3600 でリセット）。手順は [事前登録](b100_preregistration.md) のとおり。値・画面本文は出さない。

## 公式

抜いた後に読みが失敗し始めてから、SENSE DRIVE STATUS を連続で出し続け、約900フレーム（約114万〜120万回）で打ち切る。打ち切った後は BASIC へ行かず、FDC も main/sub の PIO も0件になって止まる（R+3600 まで入力待ちに着かない）。

| 腕 | 連続区間 | 長さ | 回数 |
|---|---|---|---|
| E-5 | R+35〜960 | 925F | 約120万 |
| E-60 | R+143〜1057 | 914F | 約118万 |
| E-200 | R+200〜1099 | 899F | 約116万 |
| E-600 | R+824〜1702（ドライブ2） | 878F | 約114万 |
| E-5-D2 | R+227〜1120（ドライブ2） | 893F | 約116万 |

E-5-D1 は E-5 と同じ。E-NONE は普通に読み続ける。E-EMPTY（最初から空）は FDC 0件で R+300 に入力待ちへ着く。

規則は「リセットから一定」でも「抜いてから一定」でもなく、「失敗の連続が始まってから一定」がいちばん揃う（878〜925F、114万〜120万回）。1フレームあたり約1295回で一定なので、時間で数えているか回数で数えているかは区別できない。

## 自作（2d122aa）

E-5・E-60・E-5-D1 は R+92 から最後まで出し続け、打ち切らない（WebQ88 でランプが点滅し続けた原因）。E-200・E-600・E-5-D2 は抜いた直後に SENSE と READ を1回ずつ出して止まり、連続区間が無い。E-NONE・E-EMPTY は公式と同じ。

## 判定

自作の sub の読みに、公式と同じ「失敗の連続が始まってから一定で打ち切り、その後は何もしない」を入れる（[l3-boot-sector](../spec/l3-boot-sector.md) 第4版 第4b節）。区間の長さは回数で数える（sub に時計が無いため）。どの時刻で抜いても連続区間が現れるように、抜いた直後に止まってしまう自作の道も同じ再試行に乗せる。
