# 汚染の記録 2026-11-12 — 入口の戻り時レジスタ実装の担当が測定ノートを見た

## 何が起きたか
自作 main の固定入口（369A・37C9・37D2・3847・3391）の戻り時レジスタを仕様 main-rom-entry 第4版に合わせる実装担当（作業用クローン tmp/entry-impl、ブランチ impl/main-rom-entry）が、
原因調査の検索結果に `docs/notes/b86-rom-entry-results.md` の 11〜15 行（B86 初回〜追補2 の値なし集計の表）を表示した。担当は CLAUDE.md の「実装者は docs/spec から右側だけ」に反すると自分で判断し、作業を中断した。

## 見た範囲
- 上記ノートの 5 行。中身は測定の値なし集計（送受信の件数、戻ったか、座標の変化）で、公式 ROM のバイト列・逆アセンブル・画面本文は含まない。
- 同じ内容は仕様 main-rom-entry に規則として反映済みのものが大半。

## 対応（CLAUDE.md「汚染したとき」）
1. 範囲は上の通り。
2. その担当（セッション）を当該実装から外した。
3. その担当の未コミットの編集（src/l3_main/rom_entries.asm、tools/main_rom_entry_selftest.py）を破棄した。コミット済みの入口実装（c7bd10f・fa5a8dc）は別の担当で、この担当の作業を含まない。
4. 戻り時レジスタの実装は、新しい担当が仕様だけを見てやり直す。再発防止として、実装担当への指示に「検索は docs/spec・src・tools に限る（リポジトリ全体を grep しない）」を明記する。
