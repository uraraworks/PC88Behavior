# m7jl: 外側の「4」は規則か、窓の打ち切りか — 事前登録

## 位置づけ

[m7jk](m7jk-run-internal-request-identity-results.md)は、土俵側の構造が二段で
あることを示した——**内側が9（同じ対象への要求の繰り返し）、外側が4
（SEEKを挟んだrunの繰り返し）**で、記号列は`A A A A B B B B C C C C`だった。

**本稿はその最大の留保を潰す。**

> **外側の「4」は規則なのか、それとも窓（`--frames 3000`）がそこで
> 切れているだけなのか。**

`m7jk`の3つ目のグループ（`C C C C`）はログ末尾にあり、**続きがあったのか
無かったのかを見ていない。** `m7hb`もログ末尾が窓の打ち切りであることを
記録している。

## 介入は「窓を延ばす」こと（届いたかを合格条件に入れる）

`m7jc`・`m7je`で2周続いた失敗は「介入が対象に届いていなかった」ことだった。
本稿の介入は`--frames`を増やすことなので、**届いたことは
「FDC総数・READ総数が水準間で増えること」で確認できる。**
**これを合格条件に入れる。** 増えなければ主判定はO。

## 測定条件（`m7jj`と同一。`--frames`だけを振る）

- 条件Oのみ。A: は`disk#8`（`650cfac8`。`stage_disk_by_digest.sh`経由）に固定。
- B: は自作D88（**両面・`--cylinders 40`・`--sector-base 200`・
  `--sectors-per-track 8`**）。**ディスクは1本に固定し、振らない。**
- 打鍵は水準E。摂動は当てない。窓は`frame >= 700`。
- **水準: `--frames` ∈ {3000, 6000, 12000}**（3水準）。3000は`m7jk`の再現。
- タイムアウトは`m7jk`と同じ枠組み。**足りなければ器材のタイムアウト値だけを
  上げてよい**（測定条件ではないため）。上げた場合は開示に書く。

## 記録するもの（すべて値を出さない。件数・基数・真偽・記号列のみ）

1. **グループの多重度の並び**（例`4,4,4`）。グループ＝要求の組が同じrunの
   まとまり。**どの要求かは示さない。**
2. **記号列**（出現順にA,B,C…を振る。値とは無関係）
3. run長の並びと多重集合
4. FDCコマンド総数、`READ DATA`総数（**介入が届いたかの確認に使う**）
5. **到達指標R'**（3座標。件数と不一致内訳の件数）
6. エラー真の件数と公開ビット復号名の内訳
7. SEEK件数、相異なるSEEK目的シリンダの個数（基数のみ）
8. **run間の要求組の基数**（窓を延ばすといくつになるか）

## 最後のグループを判定から除く（測定前に固定）

**どの水準でも、記号列の最後のグループは窓で切れている可能性がある。**
よって**判定には「完了したグループ」だけを使う。**

> **完了したグループ**: そのグループの後ろに**別の記号のグループが1つ以上
> 続いている**もの。最後のグループは常に判定から除く。

**完了したグループが2つ未満の水準は、その水準を判定から外す**（記録は残す）。
全水準が該当すれば主判定は**O''（判定が到達不能）**。

## 事前登録する判定（測定前に固定。後から動かさない）

- **BB1（4は規則）**: すべての水準の**完了したグループ**の多重度が**すべて4**。
- **BB2（4は窓の都合）**: 完了したグループに**多重度が4を超えるもの**がある。
- **BB3（別の値で揃う）**: 完了したグループの多重度がすべて等しく、**4以外**。
- **BB4（不揃い）**: 完了したグループの多重度が揃わない（4を超えるものは無い）。
- **O''（判定が到達不能）**: 上記の中止規則に該当。
- **O（測定不能）**: `--frames`を増やしてもFDC総数・READ総数が増えない
  （介入が届いていない）、いずれかの水準で`R' = 0`、決定論性が確認できない、
  **3000の水準が`m7jk`を再現しない**（`{9:12}`・エラー真108・要求組の基数3・
  多重度`4,4,4`）、のいずれか。

**どの判定になるかは予測しない。**

## 内側の「9」も同時に見る（判定には使わない）

窓を延ばしてもrun長が9のままかを記録する。**`m7ji`・`m7jk`の再現確認であり、
主判定には使わない。** 9以外が出た場合は、**判定を動かさずに事実として
記録し、器材を疑う。**

## 事前登録する合格条件（測定前に固定）

1. `tools/recv_run_field_leak_selftest.sh`が全項目OK・rc=0。
2. `tools/analyze_error_exchange_shape_selftest.sh`がrc=0。
3. **介入が届いたこと**: `--frames`が大きい水準ほどFDC総数・READ総数が
   **単調に増える**こと。
4. 全水準で`R' > 0`（3座標）。
5. **決定論性**: 各水準で生ログが独立2回で**素の`cmp`によりバイト一致**。
   媒体パス・出力パス・引数を固定して測る。
6. **元ディスクを壊さない**: `disk#8`の原本ダイジェストが不変。
7. **`m7jk`の再現**: `--frames 3000`の水準が`m7jk`と全指標一致。
8. **実行した水準数を出力に載せ、期待値（3）と一致すること。**
9. `tools/check_cleanroom.sh`が全項目OK。

## 言えないこととして先に書いておくこと

- **BB1が出ても「4が上限値としてコードに書かれている」とは言えない。**
  言えるのは「完了したグループはどれも4だった」までである。
- **BB2が出ても、真の多重度がいくつかは言えない**（また窓で切れている
  可能性が残るため）。**その場合は「4は窓の都合だった」までで止める。**
- **窓内で扱われた対象の個数から、対象の総数や順序の規則を導かない。**
- **セクタ番号・シリンダ値は出さない。基数・記号列・件数だけ。**
- 自作ディスクは公式と形が違う。形の違いが効く可能性を排除していない。
- 条件O・水準E・A:=`disk#8`固定という1つの使い方しか見ていない。

- 値・バイト列を報告に書かない。**件数・基数・真偽・記号列だけ。**
- **公式ROM/ディスクの実ファイル名・実パスを書かない。**
- 画面本文を出力・転記しない。
- **決定論性は最初から固定パスで測る。**
- **判定（BB1〜BB4）を書かせない。**

  バイト値を出力しない。**基数・記号列は値ではない。**
