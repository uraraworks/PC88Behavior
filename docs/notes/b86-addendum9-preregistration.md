# B86 追補9 事前登録：main ROM 入口の戻り時規約

追補5と8bの自作プローブを土台とし、公式 ROM の内部経路や生値を記録せず、入口と出口の対応を測る。これは測定前の計画であり、観測結果や仕様ではない。公式 ROM・媒体の値はリポジトリ外の非公開一時領域でのみ扱う。集計ファイルは関係の真偽と取得状況だけとする。

- 対象は 369A、37C9、37D2、3847、3391。各条件で異なる4組の自作 A、BC、DE、HL、IX、IY、F を与え、DI/EI も振る。SP は D000、IM2 ベクタと RETI 受け口は自作。入口直前の CALL による2バイト消費を含めて扱う。入力 SP は CALL 前、通常の出力 SP は RET 後。3391 は飛び先到達時の SP とする。
- 369A は B=0、1、3、80h、C=0、1、5 の直積とし、各々 C フラグを0/1に振る。C=0 と B≧80h を含む。HL は自作 RAM、DE は別の自作値。同一入力で自作媒体の起動セクタ以外の内容を反転した腕も追加し、出力変化を比較する。起動セクタは器具自身なので固定する。媒体と入力条件のためにレジスタが制約される腕は、その制約の範囲に限って結論する。
- 37D2 は 37C9 に 0Ch を与えた後に測る。3847 は 37C9(0Ch) と 37D2 で自作サブ RAM に256バイトの同一模様を書き、37C9(09h)→37D2×4 の後で呼ぶ。模様は 00、01、80、FF の4種。A と模様の一致、Z と受信 A のゼロ判定の一致、各出力の模様による変化を真偽で集計する。
- 3391 は入力 HL の自作コードに到達した時点を捕捉し、そこに到達しない場合は戻らないと数える。他の入口は RET 後に捕捉する。取得途中の再起動と時間上限も戻らないと数え、前置き未完了やログ欠落は欠測と区別する。
- 各組について出力と各入力の不変、入力との差が一定、出力一定、入力が変化したかを集計する。F は Z、C、S、P/V を個別にも判定する。IFF は LD A,I の P/V で捕捉する。値や差の定数は出力しない。入力変化のない条件や同時に変えた入力の間には交絡があり、有限の4組で成立した関係は普遍則の証明ではない。模様による変化も観測条件内の依存を示すにとどまる。
- ログに欠落がある場合は欠測。実行中のログ、ROM 複製、ディスク、レジスタ一時値は終了時に削除する。出力先はリポジトリ外で新規作成。PC88_REF_* を除外した自作 ROM の対照で、入口の保持、飛び先、再起動、欠測、関係判定を自己検査する。実測は事前登録後に別途実施し、結果を自動で仕様や実装に反映しない。
