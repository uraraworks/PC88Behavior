# B90 entry5 の比べ直し

2026-11-13。対象は entry5 `b558ca1`。値のない集計と自作入力との関係のみを記録する。仕様は [sub-rom-entry.md](../spec/sub-rom-entry.md)。

- 画面ハッシュ60点中の一致数は、G2・G5 の N/SP/RT が各 0/0/0、G3 が 54/0/52、G1 は I1・I2・I3 が60、S1・F1 が59。entry4 と同じ。
- G2 の 00ED は1バイト返して輪へ戻るようになった。続く 048F は、06A6 で受けた B・C・D・E を引数に公式ではセクタを1つ読み RET する。自作側は SENSE DRIVE STATUS のみで読み込まず、後続の要求の並びが異なる。048F のプローブ確認は未。
- G5 の 07D6 の FDC 操作の並びは公式と自作で一致したが、戻り時に自作側は E を変える。公式実走では BC・DE・HL 保存、A=00・Z=1・P/V=1。その後の READ DATA のセクタ番号が異なり、読み込んだデータにも差が生じる。
- B88 追補3 の 0263・07D6・00ED と器具の制約は [B88 結果](b88-sub-rom-entry-results.md)に記録した。
