# B60: G1 でどのキーが公式と自作を分けるかを 1 つずつ測る — 結果

記録日: 2026-11-02
規則: [b60-g1-single-keys-preregistration.md](b60-g1-single-keys-preregistration.md) どおり。測定はクラウドの実行環境で rc=0。対照（キーなし）は公式どうし・公式対自作とも同じ。画像と画面本文は開いていない。記録は `measurements/b60-g1-single-keys.txt`（左が公式、右が自作）。

## 結果

公式と自作で同じだったキー: `0` `1` `3` `5` `7` `9`、`i` と `s` を除く英字、F2、F3、TAB、BREAK、DELETE、テンキー 5。

違ったキー（テキストはすべて同じ、画像が違う）:

| キー | 移る回数 公式 / 自作 | `IN $FC` 公式 / 自作 |
|---|---|---|
| `2` `4` `6` `8`、テンキー 2・4・6・8、ESC | 71 / 71 | 112687 / 112683 |
| F1、F4、F5 | **72** / 71 | 112689 / 112683 |
| `s` | **76** / 71 | 113713 / 112683 |
| `i` | **87** / 71 | 124725 / 112683 |

`A-new`（公式で対照に無い main の ROM への飛び先）はどのキーでも 0 だった。移る先が違う番号も無い。

## 読み方（推定）

- **自作は、公式が反応するキーに反応していない。** 方向に当たるキー、ESC、F1・F4・F5、`s`、`i` である
- 自作の上の G1 は、どのキーでも対照と同じに動いている。キーが G1 に届いていない
- 公式は起動時から main の ROM の 8 か所へ飛んでいる（B1）。自作はそこへ飛ばない（B29 で「打鍵なしでは需要でない」とした）。キーで分かれた今、この 8 か所のどれかがキーを読む働きを持つ可能性がある
- B58 の L の腕は左右が逆に見えるので、ここでは B60 の 1 キーずつの記録を正とする
