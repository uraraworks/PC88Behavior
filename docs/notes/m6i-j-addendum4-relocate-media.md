# m6i-j 追補4 — T-D2-S の媒体で使用中にする単位を変える

記録日: 2026-09-29  
状態: **測定前**（追補3の判定はまだ無い）

## 1. 追補3の1回目（器具 `17d810c`）

公式ROM起動17回。m6i-j の8腕（16走）は関門を通った。T-D2-S の1走目で、器具の「本体がトラック18ヘッド0の外に出る」関門
（器具内の名前は `reserved_units_used`）により `gate_failed`。この腕の媒体は単位 72・71・68・67 を使用中にしていたが、
**公式ROM は新しいファイルの本体を単位73（トラック18ヘッド0の後半）に置いた**。

## 2. 観察（判定には使わない）

l3-disk-format.md 2.5節の「空の媒体では単位72から番号の小さい方へ、2つ取っては2つ飛ばす」は空の媒体での観察であり、
72・71 を使用中にした媒体では 73 が選ばれた。**割り当て順の規則としては 2.5節の記述は不完全**である（1.5節の「2.5節の順で最初の空き」も、
使用中の単位が 72・71 より前に並ぶ場面は確かめていない）。割り当て順そのものは本稿では決めない（別稿）。

## 3. 変更

T-D2-S の媒体で使用中にする単位を **72→73 と 71→70 の2本の鎖**にする（トラック18ヘッド0の2単位とその次の2単位）。追補3のねらい
（本体をトラック18ヘッド0の外に置き、T・R を区切りや順番から離す）は変えない。ほかの腕・仮説・判定は変えない。追補3の凍結値は作り直す。
