# m7li: 再試行の条件の作り直しは不採用——容量が足りず、送信単位の数も公式と合わない

実施日: 2026-09-11（16:25〜16:40）
事前登録: [m7li-...-preregistration](m7li-retry-on-result-error-preregistration.md)
（**測定前に単独コミット済み**。合格条件と数え方は本稿で動かしていない）

## 主判定

> **合格条件のうち2つが偽。規則どおり採用しない。**
>
> - **条件2（自己検査の門）が偽**——置き場由来の1件のほかに3本がNG。**3本とも、故障注入などの
>   変種ビルドが窓からはみ出し、直した関門（m7lc）に止められた。** 余白2バイトでは、既定より
>   最大8バイト大きい変種が入らない。**ふるまいの問題ではなく容量の問題である。**
> - **条件8（G-CRCで公式と一致）が偽**——混成は**1単位あたり9件読み直すようになった**（最長9）が、
>   **送信単位の数が5対12で足りない**（54件・40対に対し公式117件・96対）。**これはm7lhで
>   セクタ不在の媒体に出ていた食い違いと同じ数である。**
>
> **作り直しそのもの（ICが00でなければ読み直す）は、狙いどおりに効いている。**
> **採用を止めているのは、この作り直しとは切り離せる2つの問題である。**

## 条件2——余白は既定ではなく「一番大きい変種」で見積もる必要があった

NGになった3本（`analyze_no_disk_signals_selftest.sh`・`response_ready_rom_selftest.sh`・`verify_l3.sh`）は、
**どれも既定の版に加えて故障注入などの変種をビルドする。** その変種が窓の外へ2〜5バイトはみ出し、
**m7lcで直した関門が拒否した。** BASE（今の採用版）では通っていたので、**この書き換えで余白が2バイトに
減ったことが原因**である。

`build()`の変種フラグを1つずつ立てて測ると:

| | 既定 | 変種で増える最大 | 窓の外へはみ出す変種 |
|---|---|---|---|
| HEAD（今の採用版） | 2033（余白15） | **+8**（`emit_fdc_abort_mark`・`restore_request_kind_length6`） | 0個 |
| 候補（本稿） | 2046（余白2） | — | **21個中10個** |

**候補（+13）を入れて一番大きい変種（+8）も窓に収めるには、既定で21バイト以上の余白が要る。
今は15バイトなので、あと6バイト空ける必要がある**（整列パディングで前後しうるので、実物で確かめる）。

**事前登録の段階では、余白を既定の版だけで見ていた。** 見積もりの誤りである。

## 条件8——作り直しは効いたが、送信単位の数が合わない

| 媒体 | 側 | BASE（今の採用版） | 候補（2回とも） |
|---|---|---|---|
| G-OK | 公式 | 14・連続0・最長1 | 同じ |
| | 混成 | 14・連続0・最長1 | 同じ |
| **G-CRC** | 公式 | 117・連続96・最長9 | 同じ |
| | **混成** | **14・連続0・最長1** | **54・連続40・最長9** |
| P（セクタ不在） | 公式 | 117・連続96・最長9 | 同じ |
| | 混成 | 54・連続40・最長9 | 同じ |

- **G-CRCで、混成は読み直すようになった**（連続0→40、最長1→9）。**作り直しは狙いどおりに効いている。**
  最初のエラー結果の復号名も公式と同じ（ST1・ST2ともDATA ERROR）。
- **それでも送信単位の数は5対12で、公式に届かない。** **G-CRCの混成の数（54・40・9）は、セクタ不在の
  媒体Pで前から出ていた数と完全に同じ**である。
- **つまり残っている差は、m7lhで「登録していない観察」として残した問題そのもの**——9件をやり尽くした
  あとに自作が返す応答が公式とずれ、mainの要求の回数が減っている可能性——である。
  **読み直す条件をいくら直しても、この問題を直さない限り条件8は満たせない。**

## 次にやること（本稿ではやらない）

1. **余白をあと6バイト以上作る。** 既存の候補（受信の振り分けまわりで同じ命令列が3回出る箇所。
   節約の見積もり10バイト）が使える見込み。**m7ldと同じく純粋なコード移動として、事前登録してから。**
2. **送信単位の数の食い違いを測る**（読めない媒体で、9件のあとに自作と公式が返す応答の違い）。
3. **1と2のあとで、本稿の作り直しを同じ合格条件で再挑戦する。**
