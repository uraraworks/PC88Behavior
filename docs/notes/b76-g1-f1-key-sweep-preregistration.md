# B76: F1 の道で、後半のキーを大きくずらすか長く押すと自作も先へ進むかを測る — 事前登録

記録日: 2026-11-04
位置づけ: [B75](b75-g1-f1-handshake-before-0e-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

B65 の F1 の腕で、自作の G1 が `0x0E` を送る前の場面から抜けないのは、キーを読む位相の差か。後半のキーの時刻を大きくずらすか、押す時間を長くすると、自作も公式と同じ 74 回へ進むか。

## 2. 条件

B65 の F1 の腕の打ち方を基にする。フレーム 3600 でスペース、7200 で F1 を 60 フレーム押す。そのあとの後半のキー（リターンとスペースの交互）を次のように変える。全部 43200 フレーム。公式・自作とも各 1 走。クラウドの実行環境で行う。

| 腕 | 後半のキーの始まり | 押す時間 |
|---|---|---|
| D0〜D9 | 12000 + 6×k フレーム（k=0〜9） | 60 フレーム |
| H120 | 12000 | 120 フレーム |
| H300 | 12000 | 300 フレーム |
| L1 | 後半のキーを打たない | — |

## 3. 記録の白リスト

`arm <腕> cross=<公式> <自作> fc=<公式> <自作> image=<same|differ> text=<same|differ>`。**値は出さない。**

## 4. 判定（事前に決める）

- 自作が 74 になる腕があれば、位相か押す時間の問題として書き、その条件を書く
- どの腕でも自作が 72 のままなら、位相では説明できないと書き、音源のポートまわりを次に測る
- 公式が 74 にならない腕があれば、公式も時刻に敏感だと書く
