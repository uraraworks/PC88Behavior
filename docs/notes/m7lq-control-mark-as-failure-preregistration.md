# m7lq: 失敗の判定にST2のCONTROL MARKを加える——削除マークでも読み直し、ほかの失敗と同じ応答を返す — 事前登録

## 位置づけ

- [m7lm](m7lm-retry-and-response-rework-results.md): 再試行の条件と9件のあとの応答を「ST0のICが00でないか」で決める形に作り直し、
  トラック不在・セクタ不在・データのCRCエラーで公式と同じ1単位9件・単位12になった。
- [m7lo](m7lo-more-failure-shapes-results.md): 失敗の形を5つ足した。4つ（ID部のCRCエラー・データの目印なし・IDが無効・単密度）は
  自作も公式と一致した。**削除マーク（DEL）では、最初のエラー結果の復号名が公式・自作とも`ST2=CONTROL MARK`だけで、
  ICは異常終了になっていない。公式は9件読み直し（117件・連続96対・最長9、単位12）、自作は1回も読み直さない（14件・連続0）。**
- [m7lp](m7lp-margin-factor-two-more-results.md): 余白を27バイトにした（本稿の容量の前提）。

**m7krの更新の条件「公式と食い違う条件が見つかったとき」に当たる。**

## 何を変えるか（`src/l3_service/make_subrom.py`の`FDC_IN_7`だけ）

`FDC_IN_7`で結果3件目（ST2）を読んだ直後に、**CONTROL MARK（bit6）が立っていれば`LAST_ST0`へ0x40を入れる**。
残り4件は従来どおり読み捨てる。

```
call FDC_IN ; ld (LAST_ST0),a      ; ST0（m7lmのまま）
call FDC_IN                         ; ST1（読み捨て）
call FDC_IN ; and 0x40 ; jr z,no_cm ; ld (LAST_ST0),a   ; ST2のCM → LAST_ST0=0x40
no_cm: ld b,4 ; 残り4件を読み捨て
```

**再試行の条件と9件のあとの応答は、どちらも`LAST_ST0`のbit7-6（IC）だけを見る**（m7lm）。0x40はICの位置で
「異常終了」と同じビットになるので、**判定側を1バイトも変えずに、この1箇所で両方に効く。**
CMが立っていないときは`LAST_ST0`はST0のまま（m7lmと同じ）。`FDC_ABORT`が立っているときは`FDC_IN`が読まずに戻り、
判定側は`FDC_ABORT`を先に見るので、ここで残る値に意味は無い（m7lmと同じ）。

**根拠は1.58節（m7lo）と公開μPD765データシート（ST2 bit6の意味）だけである**（m7krの約束1）。
**「ICが00でない、またはCMが立っている」は、測った7種類の失敗と削除マークと成功に同時に合う最小の形**であって、
公式の規則を測って書いたものではない（m7krの約束2。コメントに明記した）。

**試し版で測った（測定前。自作コードの大きさだけ）**: 全長2021→2034（+13）、窓までの余白14、変種の最大増分+8、
**変種フラグを1つずつ立てた全ビルドが関門を通る（拒否0個）。** コメントを足した候補は、試し版とビルド結果がバイト一致。

## 合格条件（**測定前に固定する。1つでも偽なら採用しない**）

**m7lmの11項目（数え方もm7lmのまま）**:
1. ビルドが通る（2034バイトで関門通過・変種の拒否0個を確認済み）。
2. `tools/run_all_selftests.sh`がrc=0（worktreeの切り離したHEADへ使い捨てでコミットして回す。置き場由来の`check_cleanroom.sh`の1件を除く）。
3. 既存の適合テストが悪化しない（同じ実行群のBASEとm7lfの同一性で(a)〜(d)。数字を伏せて救われた行は全部列挙し、理由を説明できなければ不採用）。
4. 読めない媒体（適合テスト`unreadable_disk`の混成側）でREAD DATAが連続96対・最長9。
5. 読める媒体（drive1・drive2・書き込み・LOAD混成・LOAD既存の混成側）で連続0対のまま。
6. `src/`以外を変えない。
7. `tools/check_cleanroom.sh`が全項目OK（本体の作業ツリーで）。
8. G-CRCで、混成のREAD DATAの件数・連続・最長が公式と一致する。
9. G-OKで、混成は連続0対のまま。
10. **MA・ND・G-CRCに加えてDEL**の4媒体で、混成の単位の数が公式と同じ12になり、長さ1の応答runの数と一致する。
11. 混成の応答が、**4媒体どうし**でk番目がすべて同じ値になり、各媒体の中で単位間でもすべて同じ値になる
    （値そのものが公式と同じであることは求めない）。

**本稿で足す2項目**:
12. **DELで、混成のREAD DATAの件数・連続・最長が公式と一致し、(117, 96, 9)である。**
13. **m7loで一致した4つの形（IDCRC・MAMD・IDBAD・SD）で、混成が公式と件数・連続・最長・単位の数とも一致したまま。**

**加えて**: 決定論性——候補を独立2回、判定行の集合・9媒体の数・応答の並びがすべて一致すること。

## 記述として載せるもの（合否に使わない）

- 混成と公式の応答の値が一致するか。
- 判定行の差分の全部。

## 言えないこととして先に書いておくこと

- **エミュレータの上での振る舞いである。**
- **「9」を決める規則は依然として書けていない。**
- **公式がCMを見て判断しているとは言わない。** 言えるのは「削除マークでも公式は失敗として扱う」ことまで。
- 削除マークを読み飛ばす指定（SK）や、READ DELETED DATAの振る舞いは測っていない。

## 採用したら
