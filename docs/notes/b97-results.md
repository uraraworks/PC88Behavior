# B97 結果：自作 ROM では 3DED・11DF・39CE・3E0D・30CF へ飛び込まれない

実施: 2026-11-17、クラウド（自作 ROM main dbe1b37 のみ、36000 フレーム）。手順は [事前登録](b97_preregistration.md) のとおり。G2・G3・G5 の N・SP・RT 9腕はすべて正常に最終フレームまで走った。G4・G6 は媒体が測定環境に無く未実施。

- 注目の5番地（3DED・11DF・39CE・3E0D・30CF）への RAM からの横断は、9腕すべてで0件。
- G2（N・SP・RT）の横断先は 369A×1・37C9×1・37D2×2 だけで、すべて固定入口。
- G3 は main ROM への横断が0件。
- G5 N の横断先は 3080・369A・37C9・37D2・3847・6F6B・7071 で、すべて固定入口。SP・RT はこれに 35CE×24 が加わる。
- 固定入口以外への横断は 77B7（7071 が呼んだ RAM のフックから自作 7071 の続きへの戻り、G5 全腕で1回ずつ）と 765F（3080 が呼んだ ECDF フックから自作 3080 の続きへの戻り、SP・RT で8回ずつ）だけで、どちらも自作入口の内部への戻りである。
- 割り込み受け口・RST 番地への横断は0件。
- 陽性対照：G5 N で 7071・3080 への横断を記録した。N で 35CE が0件なのはキー入力が無いため。
- main の I/O は全腕で最終フレームまで続いた。sub は末尾に無通信の区間がある（G5 N 266 フレーム、SP・RT 約3300 フレーム）。

## 判定

事前登録の判定どおり、5番地は公式 ROM 内の流れの一部として現れたもので、G2・G3・G5 からの需要ではない。**固定入口は足さない。** [main ROM 入口仕様](../spec/main-rom-entry.md) の 1.5節の観測はそのまま残し、需要が無いことを追記する。

参考: B97 と同時に、自作 KANJI1/2.ROM が libretro 経路で読み込まれること（B96 の前提）も確認した。OUT/IN で読んだ値は生成物と一致し、ROM を外すと FF を返した。
