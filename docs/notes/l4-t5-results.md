# l4-t5 TRON/TROFF・DELETE — 公式測定の結果

2026-11-07。事前登録 `l4-t5-tron-delete-preregistration.md`（追補2まで）の器具を、クラウドの測定環境で
公式ROMに対して走らせた（89621d1＋bb9be4c・3933b77・dc92327 を当てた木、3回目の走）。
24腕すべて独立2走一致・関門通過。記録は `measurements/l4-t5/official.json`（行ごとの署名・数値・同定ラベルのみ、
画面本文なし）。1回目・2回目の走は器具の誤りで全腕が関門落ち（追補1・2に経緯）。

## DELETE（プログラムは行10〜90の9行）

| 腕 | 操作 | 残った行 | 誤り |
|---|---|---|---|
| single | `delete 20` | 20 だけ消える | なし |
| range | `delete 20-40` | 20・30・40 が消える | なし |
| open-left | `delete -30` | 10・20・30 が消える | なし |
| open-right | `delete 30-` | 全部残る | ERR5 |
| comma | `delete 20,40` | 全部残る | ERR2 |
| missing-ends | `delete 15-45`（両端とも無い行） | 全部残る | ERR5 |
| missing-single | `delete 25`（無い行） | 全部残る | ERR5 |
| reverse | `delete 40-20` | 全部残る | ERR5 |
| empty | `delete` | 全部残る | ERR5 |
| program | 行95 `delete 30:end` を直接 goto で実行 | 30 だけ消える | なし |

- 消えた行へ直接 goto すると ERR8（Undefined line number）。
- 誤りのときは1行も消えない（部分的に消してから誤りになることは無い）。
- 直接モードで誤りになったあと、直接 `poke …,err` は 5 を返した（ERR は直接モードでも残る）。ただし誤り2の参照腕では 0 だった。直接モードの ERR の規則は本測定の対象外で、仕様には書かない。
- 片端だけが無い範囲（例 `delete 15-40`）は測っていない。両端が無い範囲が ERR5 なので「指定した行番号が存在しないと ERR5」と仮に置く（未確定）。

## TRON/TROFF

TRON 中に RUN した腕では、RUN の打鍵行の次の行に、実行した行の番号が順に出た。
表示の形は、作者が事前に用意した候補文字列（行番号を `[` `]` で囲み、間を空けずに並べたもの）の
行署名（`check_l3_screen_output.signature`、行番号つき SHA-256）が公式の行署名と一致したことで確かめた
（3行版 16文字・5行版 28文字・プログラム中 TRON 20文字の3腕すべてで一致。本文は採っていない）。

- 同じ行を2回通ると2回出る（3行版で行20を2回、5行版で行20・30を2回）。
- 出力はプログラム終了後に改行され、次の行にプロンプトが出る（行数の比較から）。
- プログラム中の `tron` は、その行自身は出さず次の行から出す。`troff` の行自身は出る。
- TROFF で止まる。TRON→RUN→TROFF→RUN の2回目は何も出ない。
- 直接モードの文（`rem`）は TRON 中でも何も出さない。
- NEW で TRON は解ける（TRON→NEW→プログラム入力→RUN で何も出ない）。
- `tron 1` は ERR2。
