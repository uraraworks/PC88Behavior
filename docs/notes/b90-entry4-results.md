# B90 entry4 — 比べ直し結果

記録日: 2026-11-12  
対象: 自作 423178e と公式 ROM の G5・G2・G1・G3 実走。各腕 36000 フレーム、600 フレームごとに画面署名を比較。G2・G5 の公式側は漢字 ROM なし。値列や画面本文は記録しない。

署名60点の一致数は G2 の N/SP/RT が 0/0/0（前回 29/54/54）、G5 が 0/0/0、G3 が 54/0/52（前回同じ）、G1 の I1/I2/I3 が 60/60/60、S1/F1 が 59/59（前回 60/59）。G2 は退行し、G5 は停止位置が変わった。

## 1. G2 と 00ED

G2 はサブの 00ED を要求番号を A に入れて呼び、通常の要求を1回処理してゲームの待ち受けへ戻る。A=06 では main へ1バイト、A=12 では70バイト送って戻った。A=00 は初期化に相当する。自作は A に関係なく初期化を行い戻らない。前回は 06A6 が戻らずこの経路に達しなかったが、entry4 で戻るようになり 00ED の不一致が現れたため G2 が退行した。

## 2. G5 と 0263

G5 は結果相（MSR=D0）で 0263 を呼ぶ。正常終了時は A=00、Z=1・H=1・P/V=1・Cy=0、BC・DE・HL 保存を観測した。自作の戻りでは別経路へ進み停止する。前回のプローブは誤って実行相で呼んでおり、「Cy=1、A は1バイト目で決まる」は結果相の規則ではない。A=ST0 AND C0 とその AND のフラグを返す試しでは G5 が通過したが、一般則と異常時は未確認。

## 3. G5 と 07D6

公式は読込み前に OUT $F8、SEEK、SENSE INTERRUPT STATUS、SENSE DRIVE STATUS を行う。自作はシークせず、転送データの後半が一致しない。その後ゲームは停止する。シーク先が D>>1 であることは推定で、装置番号の出所も未確定。

## 4. 3847 と割り込み

公式 G5 ではサブの1バイトを待つ 3847 の 7680 回の呼出し中に割り込みを68回受け付けた。待機中 EI・戻る前 DI は、戻り時 DI のプローブ観測と両立する推定である。待機中の割り込み許可だけを試しても、3節の不一致により停止した。

## 5. 入口の判定

6F96・42F6・43E1・43E9・4353 はゲームの割り込み受け口からの戻り先で、ROM 入口ではなかった。7071・11DF・3E0D・3080 には自作はまだ到達していない。

## 出所と今後

根拠は値を含まないクラウドの B90 entry4 summary に記録された G5/G2 などの実走比較。専用プローブによる確認は B88 追補3・B86 追補11 で行う。本人の2026-11-12の判断「実装は Codex に投げてOK」により、プローブ確認より先に実装に入る。これは実走から働きを採らないとした [goal-b-policy](goal-b-policy-2026-10-24.md) の基本手順より先に進める今回の判断であり、観測と推定を区別して記録する。
