## 暫定R_Cの自足した定義

R_Aとの差は、周期境界で積の仮数の低バイトが零なら補正量を
0x00FEFFから0x00FF1Fへ変えることだけ。**低バイト零による一般化は1事例からの
未確認仮説**で、0x20の差が積の丸めか補正かは未分離。
以下では再現模型として補正側にまとめる。RANDOMIZEとcはR_Aのまま。

Q(v)は厳密値vを24ビット仮数のMBF単精度に最近接丸めする。
ちょうど半分は絶対値の大きい側。非零を `(σ,E,M)` とし、
値は `(-1)^σ*M*2^(E-152)`、`0x800000<=M<=0xffffff`。
負はσ=1、正は0。零はσ=E=M=0。
`P=(M & 0x7fffff)|(σ<<23)`、rev24は3バイトの順序を逆にする操作。

```
N = (rev24(P XOR 0x00004f) << 8) | E
T(σ,E,M) = Q(N / 2^32)
```

状態は単精度x、次の乗数位置i、周期位相c（0〜170）。
起動、RUN、NEW後のRUNは `x=0xcfc752/2^24; i=1; c=0`。
初回RND(0)は(0,3324,1874)。

| i | A_i | σ | E | M |
|---:|---:|---:|---:|---|
| 0 | -26514538 | 1 | 153 | `0xca4a35` |
| 1 | 16129081 | 0 | 152 | `0xf61c39` |
| 2 | -11769122 | 1 | 152 | `0xb39522` |
| 3 | 13098250 | 0 | 152 | `0xc7dd0a` |
| 4 | -20161190 | 1 | 153 | `0x99d153` |
| 5 | -10426890 | 1 | 152 | `0x9f1a0a` |
| 6 | -13483109 | 1 | 152 | `0xcdbc65` |
| 7 | 12482518 | 0 | 152 | `0xbe77d6` |

通常更新は次の順で行う。

```
y = Q(A_i * x)                    # σ,E,Mはこの丸めた積のもの
c = (c + 1) mod 171
if c == 0:
    d = 0x00ff1f if (M & 255) == 0 else 0x00feff
    y = Q((-1)^σ * (M + d) * 2^(E-152))
x = T(y)
i = (i + 1) mod 8
```

加算後の仮数が24ビットを越してもQで再正規化する。この分岐は独立未検証。
正引数または引数なしRNDは通常更新1回でxを返す。正引数の大きさは不使用。
RND(0)はxを返し、x・i・cを変えない。
RND(-y)は単精度正入力yのE,Mを使い、`x=T(1,E,M); i=0; c=0`としxを返す。
負RND自身は乗算もcの加算もしない。前歴を消す。

RANDOMIZE nはnを符号付き16ビット整数に最近接丸め、半分は絶対値の大きい側。
現在のEと仮数の最下位バイトbを保ち、
`P'=((n & 65535)<<8)|b; σ'=P'>>23; M'=(P' & 0x7fffff)|0x800000`。
xを `(σ',E,M')` へ置換し、**現在のi,cから通常更新を1回**行う。
cはリセットせず、内部更新も1回数え、境界なら補正する。値は出力しない。
連続RANDOMIZEも各々1回数える。

比較R_Aはdを常に0x00FEFF、R_BはR_Aと同じだがRANDOMIZE直前にc=0。
追補4ではR_Dを加えた4候補を比較する。以前の事前登録候補・TSVは変更しない。

```

c = (c + 1) mod 171             # 通常更新内で1回だけ進める
```

### R_CとR_Dの差の条件

R_CはMの加算・再正規化後にTを適用し、R_Dは元のPのrev24後に加算する。
バイト反転とXORは整数加算と一般には交換できない。
仮数再正規化もRの溢れもなく、Pの上位バイトの+1が繰り上がらず、
Mの中位バイトが非零の通常範囲では、下位バイトbが非零の16の倍数
`10,20,…,f0`（16進）で差が出る。b=0のR_C特例はこの範囲でR_Dと同じ。
他のbでは両者が同じになる。代表M=0xda7800+b, σ=0,E=151で
全256値を列挙し、差が出る15値を確認した。
M中位バイト零による借り、P上位バイトの繰上げ、M補正後の再正規化は
別の差の条件なので、低バイトだけで全領域を分類したとは主張しない。
一般の判定は上の2つの固定式をそれぞれ計算する。
特にRANDOMIZE 46は低バイト0xcfでもM+0xfeffが0x100b6ceとなり、
R_C側だけ積の再正規化・指数変更が起こる分離例となる。
