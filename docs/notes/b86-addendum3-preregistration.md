# B86 追補3 事前登録（未測定）

追補2から C はセクタ番号、D/E/A/IX/IY の介入ではトラック・面・ドライブが変わらなかった。3847 は自作媒体の読み込みを含むが試した前置きでは時間内に戻らず、ゲームでの呼び出しはほぼ戻る。ゲームの入力や ROM の中身・内部経路は扱わない。

369A は C=1 のまま B=0,1,2,3,4,8,16,32,64,128,255 とする。基準の独立走行で main が読んだ共有 RAM 番地を記録から自動選択し、各番地を1つずつ元値と異なる値に変えた独立腕を、座標による条件を付けず実行する。読み取りを捕捉できない範囲、器具・スタックによる影響、介入により呼び出しが成立しない場合を区別し、因果関係を過大に解釈しない。

3847 は SP=E000/F000、スタック上の自作値 00/01/FF、DI/EI を組み合わせる。加えて 3847→3847、369A→37C9→3847、37C9→37D2→369A→3847 とする。後続呼び出しは前の戻り状態を引き継ぐ。各入口の開始・終了印を記録する。3847 区間で sub が何を待っているかと、時間上限での最後の main PC は、既存ログでは区間・時点を確実に対応付けられないため、境界の時系列器具ができた後の次の追補へ送る。観測不能やログの欠落は欠測とする。

自作媒体は追補2と同じ。座標は自作媒体256バイト全体との一致でのみ採用する。各腕は独立起動し、ROM 置き場を分離する。生ログや媒体はリポジトリ外の非公開 raw のみ、公開集計は値なしとし、自作入力との一致・自作媒体座標は許す。自己検査には PC88_REF_* を使わず、陽性・陰性・欠測・漏出を検査する。自己検査が PASS するまで公式 ROM では測定しない。
