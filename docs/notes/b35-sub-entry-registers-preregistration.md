# B35: `0x0D` で移るときのレジスタを、自作のコードで測る — 事前登録

記録日: 2026-11-01
位置づけ: [B34](b34-g1-sub-reads-results.md) の次段。[追補1](goal-b-policy-addendum1-boot-sector-2026-10-24.md) で起動用セクタに認めた「入口のレジスタの記録」と同じ型である。**このノートは測定より先にコミットする。**

G1 は使わない。公式は `DISK.ROM` だけで、コードは自作。

## 1. 問い

`0x0D` で番地 A へ移った直後の AF・BC・DE・HL・IX・IY・SP・I は何か。場面で変わるか。公式と自作でどう違うか。

## 2. 器具

自作のコードが入った直後にレジスタを自分の領域へ書き、`0x00C1` へ戻る。main は `0x15` でその領域を受け取り、値を記録する。**レジスタの値が指す先は読まない。スタックの中身も読まない。** 値はレジスタそのものだけで、ROM のバイト列ではない。

## 3. 行

| # | 場面 |
|---:|---|
| 1 | 起動後すぐ `0C`・`0D` |
| 2 | 行1 のあと 2 回目の `0C`・`0D` |
| 3 | 読み要求（P1=1）と `0x15` のあと |
| 4 | 読み要求（P1=15、R=2）と `0x15` のあと |
| 5 | 番地を変えて（`0x6000`）`0C`・`0D` |
| 6 | 入った直後に、`0x00C1` へ戻る前に各レジスタを別の値に変えたコードのあと、2 回目の `0C`・`0D` |

各行 2 走。公式と自作（`--dry-run-sub-rom`）の両方で測る。

## 4. 判定（事前に決める）

対照: 2 走が全行で一致する。行5 で A が変わっても動く。
レジスタごとに、値を行ごとに書く。公式で場面によらず同じレジスタ、番地 A と一致するレジスタ、行6 で前の値を引き継ぐレジスタを書く。自作との違いを書く。

実装に渡す仕様は、この判定で確定した範囲だけを `docs/spec/l3-subrom.md` に書く。
