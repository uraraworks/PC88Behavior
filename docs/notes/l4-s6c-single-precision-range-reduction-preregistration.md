# l4-s6c — 候補M5(SIN/COS/TANの範囲縮約を単精度で行う旧形)の事前登録

記録日: 2026-09-19
状態: 事前登録(測定前)。本ノート内の(i)は既に記録済みの単精度腕の
事後照合(参考)、(ii)が測定前に固定する本命の判定。

## 位置づけ

親が、l4-s6b結果(`docs/notes/l4-s6b-transcendental-precision-results.md`
「訂正」節)の公式値から、A05(`SIN(6.283185)`)の実測`-3.745070387140004
D-07`が`-2π×2^-24`(単精度1ULP相当)に極めて近いことに気づき、候補M5
(範囲縮約を単精度で行う旧形)を提案した。GW-BASICソース(MATH1.ASM)の
コメント"Changed COS to double precision range reduction 24-JUN-82/NGT"
が示すとおり、1982年6月**以前**は範囲縮約が(少なくともCOSは)倍精度
ではなかった。M5はこの「以前」の形を、**倍精度化された箇所だけを
単精度に戻す最小差分**として再現する候補である。

また、A17(`SIN(6.2831853)`)・A20(`SIN(10000000)`)は、打鍵した定数が
いずれも8桁(有効数字ではなく文字としての桁数)であり、N88-BASICの
数値リテラル既定精度規則(7桁を超える定数は倍精度既定になる、l4-s4a/
l4-s5e系列の既定精度の知見と整合)により、**単精度の腕のつもりだったが
実際には倍精度の引数を渡す腕になっていた**と判断する。事前登録の腕
設計の誤りとして本ノートで訂正する(`docs/notes/l4-s6b-transcendental-
precision-preregistration.md`・`l4-s6b-transcendental-precision-
addendum-cdbl.md`の該当腕の設計ミスとして記録し、それらのノート本文は
書き換えない)。よって単精度の分析対象はl4-s6bの21腕からA17・A20を
除いた**19腕**になる。

## 候補M5の実装

`tools/l4_mbf_oracle_v5_m5.py`(新規、v3は無改変)。範囲縮約
(RR/RR1/RR2/RR3、GWソースの`$CDS`→`$FMULD`→`$DINT`→`$FSUBD`)を、
`$CDS`を経由せず単精度のまま`$FMULS`→単精度INT→`$FSUBS`で行う。
使う定数(IN2PI)はv3の倍精度定数を単精度へ丸めたものをそのまま使う
(独自の単精度定数は作らない)。多項式係数(SINCN等)・TANのSIN/COS除算・
ATN等はv3から変更していない。根拠・読んだ行番号はファイル冒頭の
docstring参照。

説明できておらず、COSだけ別の(M5とも異なる)扱いが要る可能性が残る。

## 測定方法(l4-s6b追補と同一)

`print cdbl(<式>)\n`形式、各腕2走、フレーム計算・関門・記録方法は
l4-s6b追補1・2と同一(G1〜G6、`tools/l4_s4a_float_classify.py`)。
公式の出力の数値文字列を結果ノートに記録する(禁止事項7の許容範囲)。

## 判定

- (ii)の21腕について、公式出力がM0・M5のどちらの予測文字列と(符号・
  桁数含めて完全)一致するかを腕ごとに記録する。
- 両方不一致の腕は、単精度ビット照合でULP差をM0・M5それぞれについて
  出す。
- `sin`群・`cos`群・`tan`群で、M5一致率がM0一致率よりはっきり高ければ
  「SINの範囲縮約は単精度(M5)」という主張を補強する。`cos`群でどちらも
  一致しなければ、COSには別の扱いが要ることを示す傍証とする。

## 禁止事項7の遵守について

再掲したものであり、新たな観測ではない。(ii)の予測値は自作予測器の
出力。測定はまだ実施していない。
