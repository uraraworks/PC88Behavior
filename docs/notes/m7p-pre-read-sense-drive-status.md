# m7p: sub側221件目とREAD DATA前のSENSE DRIVE STATUS

測定日: 2026-08-13

## 1. 情報境界

第33版自作sub ROMの混成ログと公式基準ログを、CPU・方向・ポートだけで比較した。
データポートの値は伏せたまま使用せず、FDCアクセスの方向と連続件数だけを用いた。
比較器の自己検査は全件合格した。

## 2. 221件目の構造差

sub側の畳み込み後構造列は220件まで一致した。単発TC後、公式・自作ともSEEKと
SENSE INTERRUPT STATUSに相当するコマンド出力・結果入力を同じ長さで完遂した。
続いて公式subは2件をFDCへ出力し、1件をFDCから入力するが、自作subはREAD DATAの
長いコマンド出力へ直接進んだ。このため221件目で公式の入力と自作の出力に分かれた。

公開μPD765/8272仕様と既存仕様書第22版の分類では、2バイトコマンド・1バイト結果の
組はSENSE DRIVE STATUSに一意である。公式4条件の同じ遷移でも、SEEK系の出力4件・
入力2件に続いてこの出力2件・入力1件が現れる構造が一致した。ポート値は使用していない。

## 3. 測定時点の到達点

- sub側構造的一致プレフィックス: 220件
- main側構造的一致プレフィックス: 258件
- main側単発送受信列の値一致プレフィックス: 4件
- 混成照合のmain `IN $FD`: 0件

生ログと一時解析物はリポジトリ外に置き、コミットしない。
