# B86 追補8b 事前登録

追補8の70腕は戻りを確認できなかった。値なし追跡で EFFF・EFF9・F001、E6C3、E6D0〜E6E7 への書込みと、出口後の割り込みによる再入が判明した。本計画は器具の修正であり、公式の再測定結果ではない。

[追補8](b86_add8_preregistration.md) の70腕、入力、ポート31、I/O・RAM書込み・キー対応・戻りレジスタ・EI状態の集計、欠測と生ログの扱いを維持する。独立した器具を使用し、追補8のファイルは変更しない。

SP を D000 に変更する。測定区間の CF80〜CFFF の書込みを別掲し、既知の作業番地や自作陽性対照の D000 と重ならないことを自己検査する。この範囲の書込みには正当なスタック操作も含まれ、別掲だけでは衝突の有無を断定しない。範囲外へのスタック伸長は保証できないため全 RAM 書込み一覧も確認する。

プローブは DI のまま IM2 と I=C4 を設定し、C400〜C500 を C2 で埋め、全ベクタを C2C2 の自作受け口に向ける。受け口は OUT 7A の印と RETI のみ。戻り先の先頭に OUT 7D の印を追加し、受け口の回数と各印が戻り印の前か後かを記録する。戻り印前には処理中と RET 直後の双方が含まれ、I/O 印だけでは区別できない。印は I/O 形の比較から除外する。受け口が実際に呼ばれ RETI から復帰することを割り込みを発生させる自作 ROM の陽性対照で検査する。EI状態は従来どおり戻り後の LD A,I で測り、受理が先行した場合はその影響を含む。

自己検査は PC88_REF_* を解除し、追補8の検査に加えて全70腕の生成、受け口陽性対照、スタック範囲と既知の書込み範囲の非重複を検査する。公式測定は別途クラウドで行う。停止条件は設けない。
