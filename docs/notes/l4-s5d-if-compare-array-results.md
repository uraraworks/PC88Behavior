## 進め方

事前登録どおり、15腕（D1〜D15）を各2走、陽性対照（直接モード
`print 7717\n`）を1走、計31走を実施した。打鍵は
`tools/harness/frontend/q88measure`を直接呼び、
`--type-at 300 --type '\n'`（起動settle）→
`--type-at 700 --type "<腕の打鍵文字列>"`（実打鍵）の順で与えた。
写しは打鍵前（frame 690）と、事前登録のフレーム式
（`line_end=700+8*文字数`、`dump=line_end+300`、`run=dump+200`。
陽性対照も同式）で計算した「後」の1枚を取得した（D12を除く）。

D12は事前登録「D12の扱い」節どおり、`run`の出力完了（`dump1=1304`）
を写しで確認した後、同じフレームから`cont\n`を打鍵し、`cont`の出力
完了（`dump2=1644`）まで走らせた。写しは3枚（打鍵前690・`run`後1304・
`cont`後1644）取得した。

記録には`tools/l4_s4a_float_classify.py`（`5735eb3`）の`NUMERIC_CODES`
集合を、`l4-s5b`・`l4-s5c`で確立・正式化した行の構造的特定手法（打った
行数から`run`（またはD12の`cont`）の入力エコー行を特定し、その後・
最終`Ok`行の前の範囲を出力とみなす）と組み合わせ、出力行ごとに適用
した。

`\`（D14の`7\2`）は事前登録の器具確認どおり¥キー経由で`0x5C`として
問題なく打鍵注入できることを確認済みで、実測でも打てない文字の警告は
出なかった。

## 判定

- **Q1**（D1・D2・D6・D13・D15）: 全腕**`branch_ok`**。
  - D1（`1<2`、真）: `THEN`側（`print 1`）が実行され、出力は`1`。
  - D2（`2<1`、偽）: `ELSE`側（`print 2`）が実行され、出力は`2`。
  - D6（`a>2`、真、`THEN`の後が行番号`40`）: `30 print 1`を飛ばし
    `40 print 2`が実行され、出力は`2`（行番号を指定した`THEN`が
    正しく機能した）。
  - D13（`if 1`、`0`以外を条件に）: `THEN`側が実行され、出力は`5`
    （`0`以外の値は真として扱われた）。
  - D15（`1<2 and 3<4`、複合条件）: `THEN`側が実行され、出力は`8`
    （複合条件が正しく評価された）。
- **Q2**（D3〜D5、比較演算の値）: **`true_is_minus1`**。
  - D3（`1<2`、真）: 出力は`-1`。
  - D4（`2<1`、偽）: 出力は`0`。
  - D5（`1=1`、真）: 出力は`-1`（D3と同じ）。
  - 真は`-1`、偽は`0`として出力された。
- **Q3**（D7・D8、論理演算の値）: **`bitwise`**。
  - D7: `3 and 5`の出力は`1`（`011 AND 101 = 001`とビットANDが一致）、
    `3 or 5`の出力は`7`（`011 OR 101 = 111`とビットORが一致）。
  - D8: `not 0`の出力は`-1`（16ビットのビット反転が`-1`〔全ビット1〕
    になる、`AND`/`OR`がビット単位である結果と整合する）。
  - D7の結果がビットAND・ビットORの値と完全に一致したため`bitwise`
    と判定した。
- **Q4**（D9・D10）: 両腕とも**`array_ok`**。
  - D9（`dim a(3)`で宣言後、`a(2)=7`、`print a(2)`）: 出力は`7`。
  - D10（宣言なしで`a(5)=1`、`print a(5)`）: 出力は`1`（宣言なしでも
    代入・参照が機能した）。
  - D11（宣言なしで`a(11)=1`）: 判定名は付けない（事前登録どおり）。
    出力行は1行（相対行5、`other`、件数24・桁0-28）で、`Ok`は相対行6
    に現れた。数字0-9のコードを持つセルを含む行だったことのみ真偽値
    で確認した。
- **Q5**（D12）: **`cont_resumes`**。`run`の実行は`10 print 1`の
  出力`1`の後、`20 stop`により停止し（`other`分類の応答行が1行、
  `Ok`相当の行が相対行8に現れた）、そこへ`cont`を打鍵したところ、
  `30 print 2`に相当する出力`2`が現れた（`cont`部分の相対行1）。
  `STOP`で止めたプログラムが`CONT`で正しく再開された。
- **Q6**（D14、記述のみ）: `2^3`（べき乗）の出力は`8`、`7\2`（整数
  除算）の出力は`3`、`7 mod 2`（剰余）の出力は`1`。いずれも算術的に
  期待される値と一致した。
- `gate_failed`: 該当する腕は無い（G1〜G5・G8すべて真）。

## 禁止事項7の遵守について

本測定でツール出力・本ノートに載せたのは、(1)自分で打ったプログラム
が`RUN`（またはD12の`CONT`）によって`PRINT`した数値（`NUMERIC_CODES`
集合内のみで構成される行に限る。事前登録が明示的に許可する範囲）、
(2)`other`分類の行（D11・D12の`run`部分の相対行7）の件数・桁範囲、
および「数字0-9のコードを持つセルが含まれるか」という真偽値のみ
（D11について。事前登録が明示的に許可する範囲）、(3)ハードウェア
設定に相当するアドレス式・行/列番号のみ。誤り・`Break`相当の応答の
文言・具体的な行番号の値は、分類の過程でも一度もデコード・出力して
いない。
