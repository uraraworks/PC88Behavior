## 規則の要約（5行）

1. GWも資料も `#` は右詰め数値欄、`.` は小数点、桁以下は0埋め、丸めは絶対値を上へ半端処理し、欄あふれは `%` を前置する。
2. `+` は前置または後置の符号、後置 `-` は負数の符号（正数は空白）、`**` は余白の星埋め。GWは `$$`・`**$`、N88資料は円記号2個・星2個＋円記号で浮動通貨位置を指定する。
3. 数値欄内の `,` は整数部の3桁区切り、`^^^^` は指数形式。GWは型により E/D。N88資料は小数点より右の `,` を末尾リテラルとして説明する。
4. GWの `!` は1文字、`&` は全文字列、バックスラッシュ2個の間の空白は幅n+2。N88資料は `!`、アンパサンド2個の間の空白で幅n+2、`@` で全文字列を指定する。
5. 欄以外の文字はそのまま、`_` は次の文字をリテラルにする。値が余れば書式を再利用する。GWの値間 `;`/`,` は隣接出力、末尾では改行を抑止し、空書式・欄無し再走査・25セル以上の数値欄はERR 5、型違いはERR 13。

N88資料の第5行のエラー番号・値間のゾーン送りの有無は今回の頁では明示されて
いないため、U_N88ではGWと共通と仮定した小候補であり資料の確定事項ではない。
N88資料の正数に後置 `-` が付く画面例は説明文と整合しないように見える。
予測は説明文の「負のとき」に従い、測定で確認する。資料の画面例は転記しない。

## 腕と値の事前固定

**本測定133腕＋定数対照7腕＝140腕、各2走**。各走で完了後のVRAMを2枚写し、
同一であることを要求する。候補の全値・ERR・打鍵列は
[固定予測表](l4-s9h-print-using-predictions.tsv) に記録した（140腕×2候補）。
これは器具の予測であり、公式の観測結果ではない。

U_GWを第一候補とする。U_N88は文字列書式と通貨記号だけを資料に合わせて
分岐した小候補で、両者の共通部分は同値。例えば1.125を `##.##` に入れると
コード列[32,49,46,49,51]、ERR 0。`###` の-2.5は[32,45,51]。
`&  &` に1文字ならGWは[97,32,32]、N88は[97,32,32,32]。
25セルの数値欄はコード列[]・ERR 5、`##` へ文字列は[]・ERR 13。
固定表はセル位置も含み、候補が不一致なら測定後の追補で扱う。先に書き換えない。

数値は整数または二進で正確に表せる分数を選び、表示丸めの境界には1.125
（小数2桁）、±1.25（小数1桁）、±2.5（整数）を置く。
予測器はDecimalで表示をモデル化し、MBFの演算器そのものは再現しない。
巨大数の自由書式フォールバック、漢字・制御文字・文字数上限255はこの段の対象外。

## 取り出し方式Aと関門

前印は自作PRINTの `s9hb|`（5セル、行頭、改行抑止）、後印は `|s9hz`。
PRINT USINGの出力を両印の間だけ取り出す。記録は `codes`（整数のコード列）、
`end`（前印行からの後印行差と0起点列）、`err`（自作PRINTのERR番号）であり、
観測文字を文字列に戻してTSV・標準出力・例外へ出す経路はない。
印そのものは観測コード列に混ぜず、他の画面行は非空行数だけ記録する。

通常はPRINT USING末尾に`;`を置き、後印を同じ出力位置に続けるので、
末尾空白をrtrimせず採取できる。末尾区切り無しの腕では、改行時の未使用セルも
コード32として残す。したがってその腕のcodesは論理的な文字列長ではなく
**印間の画面セル列**である。改行前に出力した末尾空白と未使用空白を区別する
能力はないが、末尾`;`の同型腕で確認できる。endで改行位置を識別する。
80列の折り返しは同じセル列方式で扱い、定数wrap/longで境界と後印の位置を検証する。

画面は25行×120バイト（各行先頭80セルのみ）。印の欠落・重複・逆転、前印が
行頭でない、完了印の欠落、ERR印の異常、範囲超過、制御文字は採取失敗。
ON ERRORで `e=err:resume 40` として後印に戻るので、エラー前の部分出力も残る。
後印の次行にERR印、その次行に完了印を要求する。
2走と各走2写しの一致、定数7腕すべてと既知値の一致が必須。空集合・欠落・
打鍵失敗・SKIPを合格にしない。既知候補と食い違う値は `differ` として記録し、
measure/checkはrc=1。checkは腕集合・走番号1/2・同一値・期待値を全て照合する。

打鍵は小文字、各行80文字未満。`@` は `chr$(64)` で作る。
定数symbolsの最初の実走で、直接打鍵した下線だけが欠落した（rc=1）。
期待値を欠落へ合わせず、`u$=chr$(95)` を自作プログラム内で作り、書式内の
下線も `u$` の連結に変更した。以後はコード95との一致を必須とする。
`&` はfrontendのSHIFT+6対応を読み、定数symbolsの実走でもコード38との一致を検証する。
複数写しのファイル名は `screen.f<6桁フレーム>.bin`。採取後に削除し、
画面写し・エミュレータのstdout/stderrは成果物へ保存しない。

## 使用方法と自己検査

器具は `tools/l4_pusing_measure.py`（predict / measure / check / selftest）、
入口は `tools/l4_pusing_selftest.sh`。作業置き場の既定は `../tmp/l4s9h-work`。
predictは `--out`、checkは `--expected`/`--measured` を受け取る。
自作のmeasureは `--rom-dir`、公式は `--official` と環境変数
`PC88_REF_ROM_DIR` だけから場所を受け取り、私物の絶対パスは焼き込まない。
今回公式measureは実行しない。

selftestは合成画面の陽性・陰性、固定された予測値、2走差・ERR差・印欠落・
定数欠落・採取失敗の伝播、checkの期待値改変を検証する。
自作ROMを一時ディレクトリへビルドし、PRINT USING未実装のため普通PRINTによる
定数7腕×2走だけを実走する。ビルド/実行の失敗は失敗とし、SKIP経路はない。
本セッションでは既定置き場が書き込み許可外のため
`bash tools/l4_pusing_selftest.sh --work-dir /private/tmp/l4s9h-work < /dev/null`
で検証する。既定置き場での最初の試行はPermissionError、rc=1。

2026-10-05 最終自己検査: **rc=0**。合成採取と固定値・陰性対照、および
自作ROM一時ビルドの普通PRINT定数7腕×2走すべてが既知値と一致した。
途中の陰性対照で片走改変がemitに伝わらない欠陥を検出し、emitでも2走の
一致を再確認するよう修正した。小数点後の`,`をリテラルとする固定値も追加した。
これは器具の自己検査であり、133腕の公式PRINT USING測定は未実施のままである。
