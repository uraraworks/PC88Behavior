# B88 追補1: サブ ROM 入口の残りと細部（事前登録・未測定）

初回の 0F 除外後の公式走（130腕×2走）を受けた計画である。番地の由来と境界、値なし集計、欠測・再起動・時間上限、2走、各走の独立 ROM 置き場、後片付けは B88 初回事前登録を継承する。この文書は測定結果ではない。利用者の指示によりコミットしない。

入力は `tools/b88a1_arms.py` の列挙を固定する。0010・06A6 は自作値 00、35、A6、FF を main から送る。0018 は A・HL・BC・DE・HL 指示先をそれぞれ変える。0020・02A4・02A7 は A、B、C、D、E、H、L を互いに異なる自作値にし、回転した組も使う。7F0C は自作初期値を2通り与え、前後が同じか、入力レジスタに一致するか等の真偽を集計する。02B4 は A 全256値と F=00/01 の直積、035B は A=00/01/35/80/FF と F=00/01/40/FF の直積。00ED は A=0/1 とドライブ2の有無を組み合わせる。048F・07D6 は A、ドライブ1・2の有無、00ED 先行の有無を直積にする。0263 は準備なしと自作の SENSE INTERRUPT STATUS コマンドを 0020 で送る条件を置く。対照2腕を設ける。

媒体ありは自作ディスクを使用し、起動後に対象ドライブを入れ替える条件を含む。先行処理が戻らなければ対象入口未到達として欠測にし、その事実を別途示す。0010・06A6 の送信は入口到達後に行い、0018 は受信側が応答する。受信数と入力レジスタおよび自作初期化した HL 指示先との一致だけを公開する。FDC 先頭バイトおよび OUT F7 の実値は保存せず、入力との一致・関係のみを集計する。02B4 は全域の恒等・定数・ビット単位の写像等の候補について全入力で成立するかを報告し、該当しない場合は表引き的と留保する。戻りの A/F の列はリポジトリ外の一時領域に限定し、集計後に削除する。00ED の戻り値が全対象腕で一定と確認された場合、その規則の定数は記録してよい。

実測前に、PC88_REF_* を外し、自作側による通信・データ比較・FDC・ポート・前処理・媒体交換・戻らない場合・欠測・再起動・出力の値漏れ・一時ファイル削除を陽性と陰性の両対照で検査する。各走を逐次処理し、生ログと ROM コピーを消去して数 GB 以内とする。器具は下記の自己検査まで完成した。公式走はこの作業では行っていない。

## 器具と実行方法

`bash tools/b88a1_selftest.sh` は `PC88_REF_*` と測定条件の環境変数を外し、自作 ROM で628腕を各2走する。全腕の入口・媒体条件、陰性／陽性対照、通信協力、受信数0・1・2、八つの自作入力との比較、FDC受理、7F0C、F7、計算の戻り、結果搬送の破壊、未帰還、先行処理未帰還、再起動、ログ欠落、値漏れ拒否、後片付けを検査する。計算の全入力が揃わなければ全域則を出さず、00EDの全4条件×2走が揃わなければ一定値を出さないことも検査する。自作サブの任意入口が戻ることは合格条件にしない。2026-11-12にPASSを確認し、共通部を使う既存の `bash tools/b88_selftest.sh` もPASSした。

本実行は `bash tools/b88a1_run.sh "$OUT"`。OUTにはリポジトリ外の未使用ディレクトリを指定する。`PC88_REF_ROM_DIR` を指定した場合だけ公式ROM一式を各腕・各走の独立した `rom/` にコピーし、指定しなければ既存の自作サブと自作IPLを生成する。参照ディスクは使用しない。自作IPLが置くのは初段256バイトで、後続512バイトは自作媒体からFDC経由で読む。

入力レジスタは `b88a1_arms.inputs()`、自作RAMの初期値は同ファイルの `memory_inputs()` に固定する。FDC腕は七つの8ビットレジスタを区別する。main側の送信は対象へのCALL/RST/JPを実行した次の命令境界で許可し、受信側は既存のPIO手順で応答する。CFFE/CFFFは自作器具だけの同期用RAMで、到達／帰還フックが印を立てる。受信せず即座に戻る入口ではmainの待ちを解除し、送信未完了を明示する。返り値が偶然送信予定値と一致しても、未送信なら受信成功とは扱わない。

媒体はローダ完了後、サブの自作プローブ先頭で交換する。ドライブ1の起動媒体を取り出す条件と、ドライブ2に自作媒体を挿入する条件を実際のドライブ状態で照合する。交換後に先行00EDまたは0020を呼び、その前後と対象入口を別の印で区別する。先行処理が戻らなければ「先行処理未帰還」の欠測とし、対象区間のI/Oには先行処理を混ぜない。

`b88a1_capture.c` は既存B88フックを継承し、OUT内のコアコピーにだけ組み込む。FDCが受理可能な状態で書かれた先頭バイト、mainが実際に受信したバイト、F7出力、7F0Cは、ホストメモリ内で自作入力との関係へ縮約し、実値を追加ログに出さない。ROM領域の読出しや内部PCの保存は行わない。戻りのレジスタは既存B88と同じく一時記録だけに置き、mainへ搬送された結果と独立に照合する。

既定の上限は自作120・公式2010フレーム、実時間120秒。`B88A1_FRAMES`（1–10000）、`B88A1_TIMEOUT`（1–600秒）で変更できる。部分確認用の `B88A1_FILTER` は腕名の正規表現で、未指定なら全628腕となる。`PC88_CORE_SOURCE`、ビルド環境、各子プロセスの32 MiB出力上限は既存B88と共通である。

出力は `summary.json`、各走の `row.json`、集約した関係の `relations.json`。`python3 tools/b88a1_summarize.py "$OUT"` で生値削除後も再集計できる。2走の値なし記録の一致と、戻りレジスタそのものの一致を別々の真偽で残す。計算は恒等・定数・ビット写像を全512入力で照合し、候補で表せなければ「表引き的」と留保する。00EDのA/Fは全対象条件で一定の場合に限って規則の定数を出す。

生ログ・媒体・ROMコピーは各走の集計後に、腕間比較用の `values.tmp` は最終集計後に削除する。自己検査は終了時に作業ディレクトリ全体も削除する。`src/`・`docs/spec/`・vendor原本は編集せず、コミットしない。
