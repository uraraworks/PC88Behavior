## 候補判定と読み出し

**K_BUFが残り、K_LAST・K_NONEを棄却する。** 取り直しのbuffer-ab・buffer-aab・early-abは
打った順に全文字を1回1文字で取り出した。先頭の読みは空、読み尽くすと空に戻った。
K_LAST・K_NONEはこの3腕で不一致。early-abには待ちの時間関門を課していないが、
buffer-ab・buffer-aabは前後の写しによる時間関門も通過している。
追補1のbuffer-abcde-long・buffer-10・buffer-20も全打鍵後まで待ち中である関門を通り、
それぞれ5・10・20文字を全部、順に1回1文字で取得した。
待ち後の30回中、残り25・20・10回は空。K_LAST・K_NONEは追補3腕すべてで不一致。
取り直しと追補の定数重複を除くと、通過25腕50走＝予測一致21腕42走＋予測なし4腕8走。
K_BUFの無限容量を確定したわけではない。**20文字までは上限に当たらない**ことが確定し、
容量上限と満杯時の動作は未確定である。

idle-onceは空、idle-100は100回とも空。run-returnは最初と待ち後の計9回とも空で、
RUNを開始したRETURNはINKEY$へ届かなかった。
通常単発キーのASCは a=97、z=122、上段0=48、9=57、空白=32、!=33、?=63、+=43、[=91。

## 予測なし4腕の観測

以下は取り直しの各2走一致の観測であり、事前予測の的中には加算しない。

| 腕 | 観測 |
|---|---|
| key-return | 初回は空、追加RETURNはLEN=1・ASC=13 |
| echo-idle | 10000回中非空0、最大LEN=0、他行件数4 |
| echo-a | 10000回中非空1、最大LEN=1、取得文字ASC=97、他行件数4 |
| hold-a | 160フレーム長押し、10000回中非空34、最大LEN=1、保存した先頭8文字はすべてASC=97、他行件数4 |

INKEY$で読んだ文字による画面への追加は、echo-idleとecho-aの他行件数4対4、
増加フラグ0として観測された。実装はこの観測に合わせて読んだ文字を画面へ表示しない。
ただし件数比較は既存行内の変化を検出できず、あらゆる状況での非エコーを証明しない。
hold-aは複数のリピートが文字として届くことを示す。34という回数や間隔を一般仕様にはしない。

## 期待値と照合

[expected_l4_inkey.tsv](../../tests/conformance/expected_l4_inkey.tsv) は取り直しの通過22腕と
追補1の6腕のprint_valuesを固定した25行（定数3腕の重複を除く）。
予測なし4腕も観測済み整数列を固定し、予測nullを合格扱いする変更はしていない。
器具checkは元登録・追補の腕を同時に認識する。期待値1行／腕、測定2行／腕と腕集合の完全一致を要求するため、
測定側もbuffer-abcdeの失敗2行を除き、追補側の重複定数6行を除いて一時ファイルに統合した。
元TSVは変更していない。

```sh
python3 tools/l4_inkey_measure.py check --expected tests/conformance/expected_l4_inkey.tsv --measured /tmp/l4s9c-measured-combined.tsv
```

照合一致（終了値0）、25腕50走。git diff --checkも通過。
