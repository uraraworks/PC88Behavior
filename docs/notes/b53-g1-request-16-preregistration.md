# B53: `0x16` を実装した自作 ROM で G1 のスペース後を確かめる — 事前登録

記録日: 2026-11-01
位置づけ: [B52c](b52c-sub-request-16-ram-diff-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

第231版の `0x16` を入れると、G1 のスペース後の `IN $FC` の違いと移る回数は変わるか。

## 2. 条件

腕 F の 4800 フレーム。OO 2 走、SS 2 走。クラウドの実行環境で行う。自作 ROM は実装コミットの配布ビルド。

関門: OO どうし、SS どうしの記録が一致する。OO の `IN $FC` の回数が B42 と同じ 112426 である。

## 3. 記録の白リスト

`row self fc-diff=<N> first=<N|none> run=<N> left=<N> right=<N> cross=<N> screen=<same|differ>`（B42 と同じ形）。**値は出さない。**

## 4. 判定（事前に決める）

- `fc-diff=0` で `cross=71`、`screen=same` なら、この腕の 4800 フレームは公式と一致したと書き、14400 フレームまで別に確かめる
- 変わったが一致しないなら、新しい行をそのまま書き、次を別のノートで決める
- B44 の行と同じなら、`0x16` だけではこの違いは直らないと書く
