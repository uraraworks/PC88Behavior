## 動機（1回目の再判定で外れた2腕）

U_N88 は 137 腕中 136 で一致した。外れたのは次の2腕。

- scientific-07（999.5 を `##.##^^^^`）: 公式の文字コード列は「10.00E+02」相当。
  U_N88 の予測は「 1.00E+03」。丸めで仮数の桁が増えたとき、仮数を正規化し直していない可能性。
- format-empty（`print using "";1`）: 2走とも採取失敗（観測 null）。
  行が入らなかったのか、実行時の誤りで印が出なかったのかが分かっていない。

## A. 繰り上がり（候補を値まで固定）

- S_NORM: 丸めで仮数が桁あふれしたら仮数を 1/10 にして指数を+1（現行の予測器）。
- S_KEEP: 仮数が桁あふれした形のまま指数を変えない。欄幅を超えれば `%` を前置。

値は二進で正確な数か、タイでなく確実に繰り上がる数だけにした（9.995・99.95・9.9995 は
単精度で正確に表せず、丸め方向が値でなく表現に左右されるので、9.999・99.99・9.9999・999.9 に替えた）。
`#.##^^^^` 系は先頭 `#` を符号セルとして数える予測器の仮定により S_NORM が「0.10E+02」型になる。
この仮定が外れる可能性があるので、一致しなくても結論は出さず観測として残す。

| 腕 | 書式 | 値 | S_NORM | S_KEEP |
|---|---|---|---|---|
| carry-01 | `#.##^^^^` | 9.999 | 0.10E+02 | 1.00E+01 |
| carry-02 | `##.#^^^^` | 99.99 | ␣1.0E+02 | 10.0E+01 |
| carry-03 | `##.##^^^^` | 999.5（再現） | ␣1.00E+03 | 10.00E+02 |
| carry-04 | `#.###^^^^` | 9.9999 | 0.100E+02 | 1.000E+01 |
| carry-05 | `##.##^^^^` | -999.5 | -1.00E+03 | %-10.00E+02 |
| carry-06 | `##.##^^^^` | 998.5（繰り上がらない対照） | ␣9.99E+02 | ␣9.99E+02 |
| carry-07 | `###^^^^` | 995 | ␣10E+02 | 100E+01 |
| carry-08 | `##.##^^^^` | 999.9 | ␣1.00E+03 | 10.00E+02 |
| carry-09 | `##.##` | 99.999（`^`なし、桁あふれ対照） | %100.00 | %100.00 |
| carry-10 | `##` | 99.5（同上） | %100 | %100 |

（␣ は空白1セル。ERR は全腕0。）carry-03 の S_KEEP は1回目の観測と一致する予測。

## B. 空の書式

予測は「GW の手順」（空書式・欄なし書式は ERR 5、出力は欄なし書式の走査前に出た
リテラルまで）と「予測なし」。GW 手順と一致すれば pass、外れれば observed（失敗にしない）。

| 腕 | 内容 | GW 手順の予測 |
|---|---|---|
| empty-lit | `print using "";1`（1回目 format-empty の打鍵と同じ形） | コード列なし、ERR 5 |
| empty-var | `a$="":print using a$;1`（変数で渡す） | 同上 |
| xonly-lit | `print using "x";1`（書式文字なし） | 「x」、ERR 5 |
| *-probe | 上の3腕の末尾に `list 30-30` を足した版 | 同じ |
| probe-present | `print using "!";"a"` の probe 版（行が入る基準） | 「a」、ERR 0 |
| probe-absent | 30番を持たない probe 版（行が入らない基準） | コード列なし、ERR 0 |

行が入ったかは LIST 本文を読まず、**非空行数だけ**で判定する。probe 腕では 30 番の
LIST が1行を足す（`list 30-30` は行が無ければ出力なし）。他行は同じなので、
other_line_counts を probe-present（入った）・probe-absent（入らない）と比べ、
`line_entered` 列に entered / absent / ambiguous と記録する。LIST の行本文は
採取も転記もしない（extract は印の外の非空行を数えるだけで本文を保持しない）。

## C. 関門

- 1回目で2走一致・予測一致だった腕を打鍵まで同じにして再測: gate-hash-02（`###` に12）、
  gate-scientific-02（`##.##^^^^` に12）。
- 折り返さない定数対照: gate-control-empty、gate-control-spaces。
- 各2走（各走2写し一致）。4腕すべてが2走一致・形式有効・予測一致でなければ全体失敗。
  腕の欠落・採取失敗・2走不一致も失敗。
- 打鍵は小文字、`@` と `_` は chr$ で組む（1回目の作法）、直接モードの行は数字で始めない
  （`list 30-30` は英字始まり）。既存 133 腕・7 対照の打鍵は変えていない
  （selftest が関門腕の打鍵を1回目と静的に突き合わせる。保存済み1回目TSVがあればそれとも）。

## D. 判定規則（測定前に固定）

- carry 腕: S_NORM か S_KEEP のどちらかに一致すれば pass、どちらにも一致しなければ differ。
- 空の書式腕と probe 基準腕: GW 手順に一致で pass、外れれば observed（総合の合否に影響しない）。
- 総合の合否は、関門の全通過と carry 腕の全 pass（＝全腕が既知候補のどちらかに一致）。
  合格条件は既知値との一致だけで、観測が外れた場合は理由の説明を追補3以降に回す。
