# B82: G1 を長く走らせ、公式と分かれる最初の時点を探す — 事前登録

記録日: 2026-11-05
位置づけ: [B81](b81-g1-0e-new-request-results.md) の次段。**このノートは測定より先にコミットする。**

## 1. 問い

B81 で 5 腕とも 43200 フレーム（約 12 分）の終わりで公式と同じ画面になった。
その先、どこまで同じに進むか。分かれるなら、最初に分かれるのはいつか。
終わりの 1 枚だけを比べると、途中で分かれて戻った場合や、終わりの直前に分かれた場合の区別がつかない。

## 2. 器具の追加

測定器のフロントエンドに、N フレームごとの画面の SHA-256 だけを記録する選択肢を足す
（`--frame-hash-every N --frame-hash-log PATH`）。記録は「フレーム番号と SHA-256」の行だけで、
画素も画面本文も書かない。陰性対照つきの自己検査を足し、本文や画素が出ていないことと、
画面が変われば値が変わることを確かめる。

## 3. 条件

- 腕は B81 と同じ 5 腕（I1、I2、I3、S1、F1）。打鍵の並びも B81 と同じで、43200 フレームより先も同じ間隔（2400 フレーム）で同じ並びを繰り返す
- 長さは 108000 フレーム（約 30 分）。画面の SHA-256 は 600 フレームごと（180 点）
- 公式 2 走、自作 1 走。クラウドの実行環境で行う。G1 の媒体はクラウドだけで扱う

## 4. 判定（事前に決める）

- まず公式 2 走どうしが 180 点すべて一致することを確かめる。一致しなければ、その腕は比べない（走ごとの揺れがあるため）
- 公式と自作で、最初に一致しない点のフレーム番号と、一致しない点の数を腕ごとに書く
- 180 点すべて一致した腕は「108000 フレームまで同じ」と書く
- 一致しない腕は、その時点の前後を次の段で詳しく見る。この段では原因を書かない
- B81 の 43200 フレームの終わりの結果（I1 の画像だけ違う）と、この段の 43200 フレーム付近の点が食い違えば、器具を疑って先へ進まない
