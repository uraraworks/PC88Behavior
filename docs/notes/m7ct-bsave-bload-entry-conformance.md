# m7ct: BSAVE / BLOAD 需要入口の事前登録

実施日: 2026-08-25

本稿の到達条件は実測前に固定した。公式ROM・公式ディスクの内容は読まず、
生ログ、画面報告、ROM／ディスク複製はリポジトリ外の一時領域だけに置く。

## 自作データと使用領域

`CLEAR ,&HBFFF` でBASICが管理するメモリの上限を明示し、その直上の
`&HC000`〜`&HC003`だけを自作データ用に確保する。この範囲は公開ハードウェア
仕様上のRAM側でもある。これは公式ROM内部の番地やワークエリア番地を参照した
選択ではなく、公開メモリマップとBASICの公開されたメモリ確保機能に基づいて
自分が確保した領域である。保存内容は自分で `POKE` する4値
（71, 149, 203, 37）だけとし、公式ディスクの既存内容を使わない。

## BSAVE

公式一式／混成の各測定runで、同じ入力から作った使い捨てdiskA複製を読書き
可能にして、上記の `CLEAR`、自作4値の `POKE`、4値一致時だけ `B7S` を出す
自己検査、`BSAVE"Q7B",&HC000,4` を順に打鍵する。

到達は (1) POKE後の自己検査が `B7S` と直後の `Ok` を出すこと、
(2) BSAVE打鍵の画面反映と直後の `Ok`、(3) FDCの `WRITE DATA` が
1件以上発行されたことの両方とする。陽性対照は全打鍵と各 `Ok` を持つ合成画面、
陰性対照は `BSAVE` の直後だけ `Ok` を欠く合成画面とする。従って、構文エラー、
書込み禁止、コマンド未実行、画面上だけの受理は合格しない。

## BLOAD

公式一式の準備runで上記BSAVE到達条件を満たした完成複製を作る。同じ複製を
別プロセスの公式一式／混成へ渡し、`CLEAR ,&HBFFF` 後に `&HC000`〜`&HC003`
をすべて0へ上書きしてから `BLOAD"Q7B"` を打鍵する。続けて4番地が自作した
4値と全一致する場合だけ `B7X`、それ以外は `B7N` を表示する。

到達は (1) 先行するBSAVE準備の到達条件、(2) `BLOAD"Q7B"` の画面反映と
直後の `Ok`、(3) その後の条件式の画面反映、(4) 読込み成功固有マーカー
`B7X`、(5) さらに後の `Ok` の全条件と
する。陽性対照はこの完全形、陰性対照はBLOAD直後の `Ok` はあるが `B7X` を
欠いて `B7N` となる合成画面とする。事前のゼロ化により、BLOADが失敗または
無処理でも保存前の値が偶然残って合格することはない。単なる正常終了、ファイル
不在、構文エラー、読込み内容がメモリへ反映されない状態は合格しない。

## 固定手順

既存の測定ラッパ、FDC分類、main受信列、画面署名を再利用する。初回公式実走では
件数・SHA-256と画面の行数・文字数・SHA-256を出し、期待値へ固定した後に
公式／混成を同条件で再検証する。各条件は2回の決定論性と取りこぼし0件を確認し、
件数およびSHA-256を壊した期待値コピーも不一致検出させる。

ここまでを実測前の事前登録とする。

## 初回校正

最初の60000台は `CLEAR` の上限として不適切、30000台は下位32KiBのROMマップ内、
40000台はPOKE直後の一致までは得たがBSAVE後の正常復帰を確認できず不採用と
した。標準的な機械語領域確保形である `CLEAR ,&HBFFF` と直上 `&HC000`〜
`&HC003`へ改め、単発実走でPOKE直後の4値一致、BSAVE直後Ok、WRITE DATA 8件、
取りこぼし0件を確認した。完成複製を別プロセスへ渡したBLOADでは、事前ゼロ化後に
`B7X`と直後Okまで到達した。不採用試行の署名は期待値へ採用しない。

## 情報境界

記録するのは件数、SHA-256、画面の行数・文字数・SHA-256、および公開された
μPD765のコマンド名だけとする。画面本文、ディスクのデータ部、公式の応答値は
記録しない。
