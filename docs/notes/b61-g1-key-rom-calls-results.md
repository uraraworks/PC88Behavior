# B61: キーを打った前後に、公式の G1 が main の ROM のどこを使うかを測る — 結果

記録日: 2026-11-02
規則: [b61-g1-key-rom-calls-preregistration.md](b61-g1-key-rom-calls-preregistration.md) どおり。公式のみ 2 走、一致した。記録は `measurements/b61-g1-key-rom-calls.txt`。

## 結果

5 腕とも同じで、main の ROM への飛び先は **0〜3599 フレームの 20 回だけ**（B1 の 8 か所）。3600 以降はどの腕でも 0 回だった。

## 分かったこと

公式の G1 はキーを読むときに main の ROM を呼ばない。事前登録の判定どおり、ROM 以外の経路を次に測る。

起動時の 20 回は自作では起きない（B29）。その間に ROM が作った状態（ポートの設定や RAM の内容）を、G1 があとでキーを読むときに使っている可能性がある（**推定**）。B62 で main 側の RAM 上のコードの読み書きを公式と比べ、最初に違う所を探す。
