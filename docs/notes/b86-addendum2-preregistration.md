# B86 追補2 事前登録（測定前）

追補1の値なし集計を受け、369A の読み出し座標の出所と 3847 の前提を調べ、3391 中の要求の見出しを観測する。需要の出所は B86 と同じ。ゲームの入力・ROM の内容・内部経路は読まない。各腕は独立起動、SP=F000、割り込み禁止。公式 ROM の置き場は腕ごとに分離する。

369A の基準は A=0、BC=1、DE=D400、HL=D000、IX=IY=0、キャリー0。D、E、C、A、IX、IY を各々一つだけ D= D5、E=01、C=02、A=02、IX=0001、IY=0001 に変える。ドライブ1の自作媒体は40シリンダ両面各16セクタ、識別子 A1。起動セクタ (0,0,1) は自作器具、それ以外は coord-header。受信列または RAM 写しにセクタ256バイト全体が一致したときのみその座標を採る。起動セクタも自作器具との全体一致で識別する。取得できない腕は欠測。

全レジスタ腕で座標が取得でき同じとき、基準腕の呼び出し前後における C100-EFFF の RAM 差分番地を自動で展開し、各番地に0または1を書いてから同じ呼び出しをする独立腕を実行する。差分には出力バッファやスタックも含み、書き込み履歴ではなく同値書き込みや隠れたバンクは見えない。介入値が既存値と同じ場合や、介入がスタック等を壊した場合は、その腕から因果関係を結論しない。介入の有効性は前後比較だけでは保証できない。自作媒体座標と自作入力との一致だけを公開する。

3847 は 37C9→37D2、369A、37C9 の各前置き直後に呼ぶ。37C9 単独前置きは A=0,1,2,FF、他は A=1。BC=1、DE=D400、HL=D000、キャリー0 から開始し、各呼び出しの戻り状態を次に渡す。各 CALL の直前・直後の印のほか、最後の前置き終了後、3847 開始前にも独立した OUT 7E の印を置く。前置き戻り印、前置き終了印、3847 開始印の有無を別々に記録する。未確認は欠測で、停止原因の断定はしない。

3391 は 37C9 または 369A を前置きする2腕。3391 の開始印から終了印、次の同じ開始印（再起動）、時間上限のうち最初までを観測する。戻らないことの判定はしない。main の OUT FD を IN FC で区切ったサブ要求と、sub の FB 入出力方向で区切った FDC 送信 run を見出しとして記録する。FDC run は必ずしも一つのコマンドではなく、区間端で切れたものも含む。両 CPU の I/O 時計を使って区間を切り出す。見出しの先頭バイトは生ログ内のみ、公開集計は長さと自作 A との一致真偽のみとし、公式 ROM 由来値は出さない。

前後写しは C100-EFFF、印の重複・欠落や取りこぼしを考慮し、取得できないものは欠測。生ログ、媒体、標準出力等はリポジトリ外の非公開 raw に置き、値なし summary だけを共有する。自作 ROM の RET および自作 RAM の陽性対照、欠測と漏出の自己検査を通してから測定する。サイクルは測定しない。
