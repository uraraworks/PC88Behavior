# B86 追補11: 3847 の待ちと割り込みの事前登録

2026-11-12。測定前の計画。G5 では 3847 がサブの1バイトを待つ間に割り込み受理が 7680 回中 68 回あった（ゲームの値は使わない）。追補9では 3847 の戻り時 IFF は 0。どちらもこの自作器具の結果ではない。

自作サブコードを 0C で RAM に送り、0D で起動する。コードは 09 と4引数を受けた後、異なる2長のループで送信を遅らせ、自作の1バイトを PIO で送る。main は 37C9(09)→37D2×4 の後、DI または EI で 3847 を呼ぶ。2種類の自作模様を交えた計8腕。09 を処理するのは自作サブコードであり、公式サブの 09 の実装を測るものではない。

IM2 の全ベクタを自作受け口に揃え、VSYNC を有効化。受け口はレジスタを保存し、スタック上の割り込み復帰 PC が ROM 領域かだけを印に変換し、割り込み源を再許可して EI; RETI する。3847 呼出開始印から最初のデータ受信までの受け口回数と ROM 内かの真偽、戻り直後の IFF、受信値と模様の一致、09 前置き送信の一致、受信前の状態ポート読取回数を記録する。状態読取は待ちの補助指標で、回数だけでサブの送信前だったことを確定しない。開始印と CALL の間の受理もこの区間に含まれるため、ROM 外の受理と区別する。データ受信が無い場合は時間上限までを数え、その旨を併記する。戻らない場合の IFF と一致は欠測とする。

公開集計には受信値、PC 番地、ROM 内容、ゲームの値を出さない。生 I/O と一時 ROM はリポジトリ外で処理し終了時に削除する。実行失敗、ログ取りこぼし、前置き不成立、再起動、時間上限は分けて扱い、欠測をゼロ件と解釈しない。自己検査では PC88_REF_* を外した自作 ROM と合成ログで受け口、ROM 内外、受信前後、模様不一致、欠測を検査する。計測はこの器具の自己検査後に行う。
