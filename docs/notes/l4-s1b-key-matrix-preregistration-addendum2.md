# l4-s1b — 事前登録の追補2（SHIFT の取り直し、測定前）

記録日: 2026-09-15
状態: 事前登録の追補、測定前

本体（`a8f7b05`）と追補（`d484cdb`）は書き換えず、Q2 のうち SHIFT を重ねた腕の解析の規則だけを改める。問いと判定の名前は変えない。この追補2 が本体と追補に優先する。

## 経緯

Q2 の測定（結果 `d8eb0a1`）で、SHIFT を重ねた64腕はすべて未判定になった。SHIFT を単独で押しただけで22セルが変わり、SHIFT＋キーでは23セルが変わったため、差分に「前が空白だったセルの単一の文字コード」として現れなかった。22セルは最下行のファンクションキー表示の切り替えによるものと推定される。

## 改める規則

- 最下行（表示行数が20のとき row0=19。表示行数は l4-s1a の結果ノート
  （`l4-s1a-text-vram-results.md` Q3、コミット未変更）の観測から20行と
  確かめた: WIDTH80,20条件でスクロール1回あたりの連続書き込みが18行分
  （表示行数20−2）であり、対象範囲19行＋最下行1行＝20行という数え方と
  整合する。l4-s1e の事前登録はまだ無い。本追補2の測定も
  WIDTH80,20（既定）のまま行うため、row0=19 を最下行として使う）を
  **件数だけの行**とし、解析道具 `tools/l4_vram_probe.py` の差分モードに
  `--count-only-rows 19`（コミット `530588c`）を付けて解析する。この行で
  変わったセルは、文字コードも位置も出さない（ファンクションキーの既定の
  割り当ては ROM のデータであり、この測定では扱わない）
- SHIFT を重ねた腕の判定は、**最下行を除いたセル**に対して、本体の Q2 の判定の規則をそのまま当てはめる
- 対照: SHIFT 単独を押す腕（2走）で、最下行を除いたセルの変化が0件であることを確かめる（関門 G8）。0件でなければ、SHIFT 単独の働きが最下行の外にも及ぶので、SHIFT を重ねた腕は判定せず未判定のまま記録する

## 関門への追加

- G8 SHIFT 単独の対照: 最下行を除いたセルの変化が0件、最下行の変化件数が0より大きい
