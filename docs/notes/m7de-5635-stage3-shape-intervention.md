# m7de: 使い捨てdiskA複製のD88形状介入ではH1/H5は観測等価のまま

実施日: 2026-08-28

`docs/notes/m7da-5635-origin-preregistration.md`第3段を、公式diskAの使い捨て複製へ
内容介入する許容条件で再開した。m7ddで「公式ディスクを複製しない」を前提に停止したのは、
今回の指示で撤回された過剰制約である。公式diskAの内容は読まず、公開D88配置から算出した
セクタ記述部へ書き込むだけとし、`src/`には触れていない。

## 情報境界

- 公式ROM・diskAは測定器へ渡しただけで、バイト列を表示、解釈、転記していない。
- diskAは条件ごとにリポジトリ外へ不透明コピーした。変更対象は公開D88規則上の
  セクタ記述部にある「トラック内セクタ数」2バイトだけで、元の値を読まずに上書きした。
- 対象物理トラックは、第2段の生ログから値非表示解析器内で得たREAD#4またはREAD#5の
  Cとunit/headを、公開式`physical_track = C * 2 + head`へ入れて選んだ。
- 生iolog、stdout、stderr、解析出力、介入D88はリポジトリ外の一時領域だけに置いた。
  データポート値は比較器メモリ内だけで扱い、本ノートには件数、構造、rc、SHA-256だけを書く。

## m7abの14条件が変えた軸

m7abの記録は、14条件すべてでFDCデータ部の16位置が変化し、定常列にも7〜8位置の
連動差が出た一方、位置1・位置2は不変だった、とする。観測した差は媒体**内容の値差**であり、
READ長、EOT、トラック当たりセクタ数が変化したという記録はない。

当時追加された`tools/analyze_exchange14_read_rules.py`の媒体比較入口も、比較ログから
交換#14、5回のREAD、main `IN $FD` 5635件を抽出できなければ比較不能にする。
m7abは14条件を比較成立として報告しているため、少なくとも5 READと5635件の外形を保つ
内容介入だった。14条件の個々の一時生成手順は恒久ツールとして残っていないため、各条件の
書込み位置までは再現不能だが、READ長/EOTを操作した形状介入として採る根拠はない。

従ってm7abの14条件は、内容差への追随を示す対照ではあっても、44セクタ形状に追随するH1と
固定`0x1600`カウンタのH5を識別しない。内容だけが変わり44セクタ形状が同じなら、両仮説とも
各ポート5632件を予測する。

## 形状介入の設計

D88のセクタ記述部はトラック内セクタ数を持つ一方、EOTはD88属性ではなくFDC READ DATAの
命令パラメータである。よってdiskA複製だけで命令上のEOTを直接変えることはできない。
今回は、16セクタ標準配置の対象物理トラックについて、16個のセクタ記述部すべての
トラック内セクタ数を15または1へ上書きし、実際に完了するREAD長が変化するかを測った。
トラックオフセット表やセクタデータは読まず、公開標準配置
`688 + physical_track * (16 * 272) + sector_index * 272 + 4`から書込み位置を算出した。

介入候補は次の3条件である。

1. READ#5対象トラックを15セクタ化する。通常5 READを保った局所的な形状対照を狙う。
2. READ#5対象トラックを1セクタ化する。2セクタREADの途中欠落を狙う。
3. READ#4対象トラックを15セクタ化する。16セクタREADを15セクタへ短縮する主候補。

## 結果1: READ#5対象トラック15セクタ化

1800フレーム、測定rc=0、既存解析器rc=0。介入D88のSHA-256は
`2a35608f71fb5a4324d88e03d9d69fcf4d86431ff841fbd502a53e89a39b8d64`、
生iologは`ee74cc70ce98d4ab21fb6455f9890aa15932a73643539103cdb45e255e839f5e`だった。

| 観測量 | 結果 |
|---|---|
| 5回のREAD長 | `1/14/16/16/2`セクタ（対照から不変） |
| 選択された一意セクタ数 | 44セクタ |
| 両ポート定常件数 | FC 5632件、FD 5632件 |
| 末尾パディング件数 | FC 74件、FD 73件（対照と同じ） |

定常2ポート列は既知先頭からREAD残部へ11263/11264位置が連続一致し、最後の1位置も
直前座標の重複で説明できた。セクタ数記述の変更はREAD#5の2セクタ完了長を変えず、
対照構造をそのまま再現した。後から座標関係を確認するとREAD#5の開始RはEOT直前ではなく、
2セクタ終了は媒体末端でなくTC側に支配される形と整合した。この条件はバルク到達対照として
成立するが、選択形状が44セクタのままなのでH1/H5を識別しない。

## 結果2: READ#5対象トラック1セクタ化

300フレーム、測定rc=0。介入D88のSHA-256は
`deadc6fceddf835f46b5cd70b2205b7d170a7edcebda873e0f9acb0340f87b05`、
生iologは`d5820d95d5714be64de7e48ba3bfdab3d66e1e591324de262bebd2da6cc6bb15`だった。
交換#14とバルク区間を特定できず既存解析器rc=2、main `IN $FD`とsub `OUT $FC`は
ともに0件だった。事前登録どおり**介入不成立**であり、H1支持にもH5反証にも数えない。

## 結果3: READ#4対象トラック15セクタ化

1800フレーム、測定rc=0。介入D88のSHA-256は
`93854f0ce7d9943473c5031ad556580d790722be7d2b944736837a642aa87407`、
生iologは`0bbb0e039034644f9914016b3a7f27a58b4269c1431c5714a0c4b079cdf01d40`だった。

バルク入口には到達したが、通常の5 READではなく、第1回バルク直前だけで
`1/14/16/15/15/15/15/15/15/15/15/15/2`セクタの13 READになった。
15セクタREADは9回あり、エラー再試行を含む。5632件の定常バルクは24回反復し、
各回のプリアンブルも3件だった。従って、単一の5 READから選択窓だけを変えるという
事前登録の介入ではない。

第1回バルクについて、READ#2第5セクタ第2位置からREAD#3、15セクタREAD候補1回、
READ#5へつなぐ43セクタ候補を9候補すべて照合したが、全候補で全長連続一致しなかった。
最長一致は10495位置で、43セクタ候補末尾までは届かない。両ポート定常件数は各5632件を
保ったが、末尾パディングはFC 74件、FD 73件で対照から補償的に増えなかった。

| 観測量 | 結果 |
|---|---|
| 5回のREAD長 | 不成立。13 READ（上記内訳） |
| 選択された一意セクタ数 | 判定不能。単一43セクタ窓の全長対応は0/9候補 |
| 両ポート定常件数 | 各5632件。ただし同形バルクを24回反復 |
| 末尾パディング件数 | FC 74件、FD 73件。補償変化なし |

READ長が変わっても定常件数が固定だった事実はH5と方向上は整合する。しかしH5の事前登録
合格条件は、**成立した媒体形状介入**で選択一意セクタ数が変わり、不足分のパディングが
補償的に変わることである。本条件はREAD再試行、バルク反復、選択窓不明、パディング不変を
伴うため、その合格条件を満たさない。固定件数だけを抜き出してH5支持にはしない。

## H1/H5判定

- H1: 維持。通常到達した15セクタ対照は44セクタ窓への既知対応を再現した。
  READ長が変わった条件では単一選択窓を確定できず、媒体形状追随を検査できなかった。
- H5: 未確定。READ#4介入の固定5632件は整合的だが、事前登録した補償パディングを伴わず、
  介入自体も5 READ経路を保っていないため合格に数えない。

従ってH1とH5は**観測等価のまま**である。

## 識別に次に必要なもの

識別には、交換#14の5 READという制御流を保ったまま、少なくとも1件のREADのEOTまたは
TC終端だけを1セクタ変え、変更後もFDC結果を正常完了させる測定介入が要る。D88の
セクタ数記述だけでは、緩い変更はTC支配のためREAD長が変わらず、強い変更はエラー再試行か
バルク未到達になる。公式diskA内容を読むのではなく、測定ハーネス側で対象READのEOT/TCと
対応する媒体形状を同時に整合させる値非表示介入、または同じ5 READを正常完了する公開規則の
媒体構成が必要である。本セッションは測定だけを担当し、その実装には参加しない。
