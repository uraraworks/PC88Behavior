# m7ab: 高速バルク先頭3位置の生成源分類

測定日: 2026-08-13

公式環境を1800フレームで新規実走し、生ログと媒体の使い捨て複製はリポジトリ外だけで扱った。データポート値は比較器内部だけで使用し、出力したのは位置別の同一／相違、一致件数、同値グループ数と構造上の位置名だけである。

## 分類

- 位置1は**説R**。交換#14要求12位置、5回のREADパラメータ、FDC結果各7位置との一致は0。転送長・個数・境界・残数、要求／FDCの加算和・XOR、READ別および256件境界別の加算和・XORにも一致候補0だった。媒体の14差し替え条件では全条件でFDCデータ16位置が変化したが位置1は不変だった。ライトプロテクト変更でも不変。別BASICモードは高速バルク自体が発生せず比較不能だった。したがって観測できたD/N/P/F/Cのいずれにも対応しないROM内部由来と分類する。
- 位置2は**説N**。転送組数、定常転送件数の上位境界量など同値な4候補が1同値群を作り、すべて「5632件を256件単位に分けた組数」という同じ量へ帰着した。媒体14条件とライトプロテクト変更でも不変だった。
- 位置3は**説D（直接源はFDCデータ部）**。媒体14条件すべてでFDCデータ16位置の変更が届き、うち1条件で位置3も連動した。基準・連動条件・非連動対照の3条件を交差すると、5回のREADデータ中で全条件追随する直接位置は1件だけで、第2 READの第5セクタ先頭位置だった。要求・READパラメータ・結果との一致は0である。

## ヘッダ後の配置

先頭3件を除く5632件を256件境界に分け、5回のREADデータ49セクタと全組比較したが、完全一致する出力セクタは0/22、位置一致は0/5632だった。一方、媒体差し替えでは定常列にも7〜8位置の連動差が出た。したがって媒体由来ではあるが、READセクタの無加工・同位置配置ではなく変換規則は未確定である。

位置1が説Rになったため、指示された停止条件に従いブラックボックス値探索と実装は行わない。位置2・3の規則は仕様へ記録するが、位置1を含む3件ヘッダの実装介入は行わない。

## 停止時の再測定

現行実装を公式環境で1800フレーム再実走した。公式期待5635件との先頭一致は0件のまま、値一致長779、main側構造258、sub側構造752、混成main `IN $FD` 1031件だった。実装変更を行っていないため、主指標は0件から伸びていない。
