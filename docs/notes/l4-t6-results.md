# l4-t6 INPUT$ — 公式測定の結果

2026-11-07。事前登録 `l4-t6-input-dollar-preregistration.md`（追補2まで）の器具を、クラウドの測定環境で
公式ROMに対して走らせた。18腕すべて独立2走一致・関門通過。記録は `measurements/l4-t6/official.json`
（印の値・行署名・数値のみ）。t5 と同時に走らせた初回は全腕が「実行/打鍵」で落ち、単独で走らせ直した
（器具どうしの並列は避ける）。

打鍵した文字は作者が決めた `k7q9m2v4b6` の先頭 n 文字（＋余分な `xz`）。

| 腕 | 結果 |
|---|---|
| n1/n3/n10 ちょうど | LEN = n、各文字の ASC は打鍵どおり |
| n1/n3/n10 超過 | LEN = n。直後の INKEY$ が次の打鍵文字（`x`）を返す（余りはキーバッファに残る） |
| return（`k` RETURN `q`、n=3） | LEN=3、2文字目が 13。RETURN は入力を終わらせず1文字として入る |
| early（INPUT$ の前に打鍵） | 先に打った3文字がそのまま入る（先行入力が使われる） |
| n255（255文字） | LEN=255、全部入る |
| n0 / n256 / -1 | ERR5 |
| 文字列引数 `input$("k")` | ERR13 |
| エコー | INPUT$ の前後で CSRLIN・POS が変わらない（5,0 → 5,0）。画面に何も出さない |
| 直接 `print input$(1)` | 受理される。打鍵した1文字を表示して次の行へ（応答1行・1文字） |

ファイル版 `input$(n,#f)` は測っていない。
