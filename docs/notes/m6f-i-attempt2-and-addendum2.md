# m6f-i 2回目の結果と追補2（LOAD 完了時の画面と、行番号の無い行のエラー）

記録日: 2026-09-28

## 1. 2回目（器具 `4c80d09`、追補1 適用）

公式ROM起動12回（6腕×2走）。関門 G0〜G15 はすべて真、参照 diskA 複製は不変、2走はすべて一致した。

| 腕 | 判定 |
|---|---|
| I-1 | **`loads_lines`** |
| I-2 | **`replaces`** |
| I-3 | **`sorted`** |
| I-4 | `other` |
| E-1 | **`err_53`**（1回目と一致） |
| E-2 | `not_trapped` |

### 1.1 採るもの

- 自作の生成器で l3-disk-format 第5版どおりに作った ASCII 形式のプログラムを、公式ROM は `LOAD` できた。
- `LOAD` は既にあるプログラムを**置き換え**（元の行は残らない）、行は**行番号順**に並ぶ。
- 存在しない名前の `LOAD` は **`ERR 53`**。

### 1.2 事後の観察（判定には使わない）

- **I-4**: `cls:load "2:qia"` の後、物理行0に2文字の行があった。自作の仕様（l4-basic.md 第1節）の入力待ちの行と同じ文字列 `Ok` の署名と一致した。
  予測器は `LOAD` の出力を「何も出さない」（`ok_only` は入力待ちの行だけを数えず、エントリ行は0）としていた。
  `LOAD` の完了後に、入力待ちの行とは別に `Ok` の行が出ていると読める。
- **E-2**: 誤り捕捉のプログラムが `LOAD` で置き換えられて捕捉できず、直接モードの画面になった。最後の出力行（物理行7、24文字）は、
  自作のエラー表（`src/l4_basic/errors.asm`、マニュアル由来）の **57番のメッセージ**の署名と一致した。

## 2. 追補2（状態: 測定前、公式ROM起動0のまま置く）

媒体は追補1のまま（`qia`・`qib`・`qid`）に、次の1ファイルを足す（l3-disk-format 第5版どおり、小文字の名前）。

| ファイル | 種別 | 中身（各行 CR LF、最後に `0x1A`） |
|---|---|---|
| `qie` | `0x00` | `10 PRINT 1` / `ABC` / `30 PRINT 3` |

### 2.1 腕（各2走）

| 腕 | 打鍵 | 観測 | 候補 |
|---|---|---|---|
| I-4' | `cls:load "2:qia"`（I-4 と同じ） | `LOAD` 完了時の画面 | `ok_line`（物理行0に `Ok` の1行、その後に入力待ち）／`no_line`（エントリ行0）／`other` |
| E-2' | `new` → `cls:load "2:qid"`（直接モード、捕捉なし） | 画面 | `direct_msg_<N>`（エラー表の N 番のメッセージの行が出る。N は表にあるすべての番号）／`other` |
| E-3 | `new` → `cls:load "2:qie"` → 完了後 `cls:list` | `LIST` 後の画面 | `none_loaded`（行なし）／`upto_error`（`10 PRINT 1` だけ）／`all_numbered`（`10 PRINT 1` と `30 PRINT 3`）／`other` |
| E-3m | `new` → `cls:load "2:qie"` | `LOAD` 直後の画面 | `direct_msg_<N>`／`ok_line`／`other` |

- 画面の予測に使う文字列は、`Ok`（l4-basic.md 第1節）、エラー表のメッセージ（`src/l4_basic/errors.asm`、マニュアル由来）、`LIST` の出力（l4-program.md 第2節）だけ。
  打鍵の文字列は使わない。
- 予測の行の位置は、`CLS` の後の物理行0から、出力の順に並ぶものとする（m6f-e と同じ）。

### 2.2 判定・行き先

判定は事前登録 §4 と同じ（2走とも一意に一致した候補名、それ以外は `inconclusive_<腕>`）。
I-1〜I-3・E-1（2回目）と本追補の判定を合わせて、`docs/spec/l4-basic.md` に `LOAD` 節（ASCII 形式）を起こす。
