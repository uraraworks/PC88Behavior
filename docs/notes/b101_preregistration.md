# B101 事前登録：INKEY$ が返す ESC・カーソル・ファンクションキー等の文字コード

記録日: 2026-11-17。B95 と実走確認で、公式の 3080 は ESC・カーソル上・f1 で文字を積むが、自作の INKEY$ 表ではこれらが0（未測定）だった。文字コードは G5 の測定から写さず、BASIC の INKEY$ で測る（既存の表を作ったのと同じ方法）。

## 方法

公式 ROM で BASIC を起動し、自作のプログラム `10 P=&HD000:20 A$=INKEY$:IF A$="" THEN 20:30 POKE P,ASC(A$):P=P+1:POKE &HD3FF,P-&HD000:GOTO 20` を打鍵して RUN し、各キーを1回押して離す。押す前後で D000〜D3FF の RAM を読み、増えたバイト列をそのキーの INKEY$ の値とする（自作プログラムが書いた値で、画面は読まない。CLAUDE.md 禁止事項7）。キーごとに走を分けるか、キーの間に十分な間を空ける。複数の値が出るキー（ファンクションキーの文字列など）は列のまま記録する。

## キー

ESC、カーソル上下左右、HOME/CLR、SHIFT+HOME/CLR、INS/DEL、SHIFT+INS/DEL、TAB、f1〜f5、SHIFT+f1〜f5、ROLL UP・ROLL DOWN、テンキーの各キー（, . = + - * / RETURN）、STOP、COPY、HELP（あるキーだけ）、CTRL+各英字（A〜Z、既存の表と照合）、GRPH+英字の数個（既存の表と照合）、カナ+SHIFT+英字の数個（既存の表と照合）。

## 公開するもの

各キーの INKEY$ の値（BASIC の振る舞いの測定値。既存の表と同じ扱い）。既存の自作表と一致したか。ファンクションキーの文字列は、既定のファンクションキー定義の文字列が出るなら「既定の定義の文字列が出た」とだけ記し、その文字列は自作の KEY 文の既定値（l4 仕様）と一致するかで判断する。
