# B94 — G5 のスペース押下後のずれ

記録日: 2026-11-13。クラウド測定の値なし報告に基づく。

公式の 3080 は押し始めとリピート時に文字コードを RAM の輪バッファに積み、G5 は索引と先読み枠を確認して 35CE から1文字取り出す。自作の 3080 は積まないため、G5 からはスペースが押されていないように見える。リピート間隔の差は主因ではない。

36000 フレームを600フレームごとに比較した60点の画面ハッシュ一致数は、公式・自作の無入力同士が38、スペース入力同士が4、公式のスペース入力と無入力が12。公式で積む処理を止めたスペース入力と自作のスペース入力は34、同じ公式の腕と公式の無入力は31だった。R 由来の散発差があるため、ハッシュ一致数は傾向の裏付けとして扱う。

G5 は 3080 の直後に EFCD・EFCE・EFCF を読み、EFCD≠EFCE または EFCF≠0 なら 35CE に飛ぶ。観測範囲 F7215〜7330 でゲームが読むキー関係の番地はこの3つだった。

測定は公式 ROM（漢字なし）と自作 ROM（main ce3ccbd、46533ae と同じ ROM）を使い、無入力と、F3600・F7200 以降にスペースを300フレーム押す腕を比較した。G5 の3枚連結 D88 を分割し、1枚目・2枚目をドライブ1・2に置いた。RAM 書き込み、ゲーム側の読み、ROM 境界と RAM 読みのログを取得し、3080 初回前の単一番地への介入も行った。測定用に改変した手元 core で 3080・35CE・F0D3・ECDF のレジスタを観測した。画面本文や ROM・ゲームの値は転記しない。

未確定は、輪が満杯の場合、複数キー同時押し・SHIFT・カナ・ファンクションキー、ECDF 呼び出し時の BC・DE、35CE の E6CB・E6CC の扱いと空のときの動作。EFF9 の押し始めの一定値と EFC6・EFC7 に書く値も未確定。自作の既存の値で代用してよい。詳細な規則は [main ROM 入口仕様](../spec/main-rom-entry.md#151-3080g5-実走での観測) に記す。
