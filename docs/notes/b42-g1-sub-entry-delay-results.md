# B42: 0x0D で移るまでの時間を変えると、G1 の値の違いが変わるかを介入で確かめる — 結果

記録日: 2026-11-01
規則: [b42-g1-sub-entry-delay-preregistration.md](b42-g1-sub-entry-delay-preregistration.md) どおり。測定はクラウドの実行環境で行い、関門 8 項目はすべて通った。値は記録していない。記録は `measurements/b42-g1-sub-entry-delay.txt`。

## 結果

待ちなしと n=1、8、16、24、32、48、64、128、255 の全行が同じだった。`fc-diff=257`、`first=76570`、`run=132`、`left=112426`、`right=76828`、`cross=30`、`screen=differ`。

## 読み方

この待ち（最大で約 3300 T ステート）は効かない。B41 の推定した位相は、値の違いの原因としては裏付けられなかった。ほかの場所のタイミングまで否定するものではない。

残る候補は移る時点の `F` である（**推定**）。番号 0 からずっと違い、B35 は `F` を記録していない。
