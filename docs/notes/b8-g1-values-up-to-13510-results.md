# B8: 位置 13510 までの通信の値が公式と同じかを、値を出さずに比べる — 結果

記録日: 2026-10-31

測定はクラウドの実行環境。リポジトリは 3fa35a2（`src/` はこの事前登録と同じ）、器具は 3727191 の `tools/b8_io_values.py`。

## 対照

- OO・OS・SS とも rc=0。入出力の要約は B7 と（走の名前の行を除いて）一致
- 空振りの対照: OO 対 OS の `compared` は `IN $FC` 3840、`OUT $FD` 10 で、事前に決めた件数どおり

## 結果

| ポート | 比べ方 | OO 対 OS: 比べた / 違う / 最初 | OO 対 SS: 比べた / 違う / 最初 |
|---|---|---|---|
| `IN $FC` | そのまま | 3840 / **3783** / 0 | 3840 / **3531** / 256 |
| `OUT $FD` | そのまま | 10 / 0 / なし | 10 / 0 / なし |
| `IN $FE` | 畳む | 7724 / 7681 / 43 | 7724 / 7681 / 43 |
| `OUT $FF` | 畳む | 7714 / 0 / なし | 7714 / 0 / なし |

第4節の判定（OO 対 OS）: 最初に違うのは `IN $FE` の 43 番目なので、「**`IN $FE` か `OUT $FF` が先に違う**」に当たる。

## 読み方

- **`OUT $FD`（main からサブへ送る10バイト）と `OUT $FF` は同じ。** main が送るものと段取りの出力は変わっていない
- **`IN $FC`（サブから main へ渡す 3840 バイト）は大半が違う。** 自作サブが渡しているデータは、公式と別物である
- SS は最初の 256 バイトだけ OO と同じで、OS は先頭から違う。main が公式か自作かで、自作サブの返す内容が変わっている
- `IN $FE` は 43 番目以降ほとんどが違う。ただし比べたのは値全体なので、段取りに使うビットが違うのか、別のビットだけが違うのかは分からない。したがって「段取りが違う」とはまだ言えない

なぜ違うデータになるかは、この測定からは言わない。
