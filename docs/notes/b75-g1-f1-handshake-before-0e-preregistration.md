# B75: G1 の F1 の道で、`0x0E` の直前の受け渡しの制御を公式と自作で比べる — 事前登録

記録日: 2026-11-02
位置づけ: [B74](b74-sub-0e-after-00c1-preregistration.md) の追補の次段。**このノートは測定より先にコミットする。**

## 1. 問い

公式が `0x0E` を送る直前、main とサブの受け渡しの制御（`$FE`・`$FF` の下位 4 ビット）はどう並ぶか。自作で止まる所では、main とサブはそれぞれ何を待っているか。

## 2. 器具

B49 の `tools/b49_handshake_order.py` と同じ出力の形（データのポートは値を出さない）。窓は main の `IN $FC` の番号で、公式は 112684〜112690、自作は 112680〜112685 と、その後に止まって繰り返す並びの最初の 200 件。io ログは `--io-log-from-frame` で `0x0E` の少し前から取る（取りこぼしを避けるため、窓の長さを短くする）。

## 3. 条件

B65 の F1 の腕と同じ。公式 1 走、自作 1 走（B73 で走どうしは一致済み）。クラウドの実行環境で行う。

## 4. 記録の白リスト

B49 と同じ `E` の行。

## 5. 判定（事前に決める）

公式が `0x0E` の最初の `OUT $FD` を出す直前の並びと、自作が止まる直前の並びを比べ、最初に違う出来事を書く。原因は断定しない。
