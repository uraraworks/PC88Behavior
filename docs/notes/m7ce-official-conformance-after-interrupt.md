# m7ce: 割り込み駆動化後の公式環境適合実走

実施日: 2026-08-23

## 1. 情報境界と測定条件

直前コミット`deefaf4`の自作subを対象に、開発者本人の公式環境
（`PC88_REF_*`設定下）でオーケストレータが`tools/conform_l3.sh`本体を
実走した。本noteの作業者は伝達された件数・合否・ハッシュ一致結果だけを
記録し、公式ROMのバイト列、逆アセンブル、公式ディスクのデータ値を読んで
いない。市販媒体はdiskBという記号だけで記す。

構成はスクリプト既定どおり、基準となる公式ROM一式と、公式main＋自作subの
混成を比較する。diskA起動は1800フレーム、条件3も同じ混成の起動実走である。
条件2はdiskB起動とdiskA（混成）の陽性対照、条件4はディスク無しと陽性対照、
条件5は公式main＋自作subでSAVEを実行する条件で判定した。条件文、期待値、
判定ロジックは変更していない。実走全体の終了コードは0だった。

## 2. 5条件の結果

| 条件 | 結果 |
|---|---|
| 1 | 本番・混成ともmain受信5635件、SHA-256一致。合格 |
| 2 | diskB起動の混成`sub OUT $FC`は0件。陽性対照diskA（混成）は5635件。合格 |
| 3 | 自作subの割り込み受理13362件、判定対象13362件、直前main 0件。初めて判定が成立して合格 |
| 4 | ディスク無しのsub I/Oは0件。陽性対照は2565件。合格 |
| 5 | WRITE 8件、2112バイト、SHA-256一致。合格 |

これにより`docs/spec/l3-subrom.md` 5.2節の適合条件1〜5はすべて判定・
合格した。SKIPを合格と読み替えた結果ではなく、公式環境で本体を実走した
結果である。

## 3. 公式との差と結論の限界

同条件の公式subは割り込み受理13593件であり、自作subの13362件とは一致しない。
また公式は受理点の直前に`IN $FA`が現れない一方、自作では現れる。この直前外形は
解消しておらず、公式と一致したとは扱わない。条件3が問うのは「直前1件がmain側で
ないこと」であり、受理件数一致や直前のsub側I/O種別一致ではないため、現行条件3の
合格と、この構造差の残存は両立する。

## 4. この記録で走らせていない検証

本note作成セッションでは公式環境実走を再実行していない。また、実機、別の
エミュレータ、別媒体、長時間走行、割り込み受理件数や直前`IN $FA`を公式へ
一致させる追加実装・再検証は行っていない。ローカルでは文書更新後に
`bash -n tools/conform_l3.sh`と、公式環境なしの
`LC_ALL=C tools/run_all_selftests.sh`だけを別途実行した。
