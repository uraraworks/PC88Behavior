## 3. 候補 N_B（N_A への事後の変更）

1. **型の印 `%` の付いた小数**は、整数に丸めて書く。丸めは0.5を切り上げる（`1.5%` → `2`）。
2. **整数に収まらない値に `%`** が付いた行は、**入力の時点でエラーになり、行は入らない**（`32768%`）。
   どのエラーかは §4 の入力時エラーの探りで決める（候補: `Overflow`〔エラー表6番〕）。
3. **指数部がある数には型の印を読まない。** 指数部の後の `%` `!` `#` は数の外の文字としてそのまま残る
   （`1e5#` → `100000!#`、`1d5!` → `100000#!`）。
4. **`&h` `&o` の後の空白は読み飛ばさない。** 空白で数字が終わる（`&h 10` → `&H0 10`）。
   `&` の直後に空白があって数字が続く場合は従来どおり読み飛ばす（1回目 n7-08 `& 10` → `&O10` は一致）。
5. **`e` の後に `lse` が続くときは指数部にしない**（`1else` → `1ELSE`）。`d` には同じ扱いを予測しない（`1data` → `1#ATA` は一致）。
