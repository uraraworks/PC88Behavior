# m7ad: 高速バルク位置1の観測応答

測定日: 2026-08-13

`docs/PLAN.md`第5節のユーザー承認済み方針を位置1へ適用した。公式ROMは読まず、
全256候補を非表示のランダム順で一時生成ROMの位置1へ介入し、各候補を公式mainとの
混成環境で1800フレーム実走した。判定は公式期待列との先頭一致件数が伸びるかだけで
行い、最初の一致で停止した。候補値とデータポート値は標準出力へ表示していない。

観測応答は確定した。値は規律どおり仕様書と実装だけに記録する。意味は未特定であり、
公式ROMを読んで得た値ではなく、ブラックボックス挙動から再構成した応答である。
要求・FDC結果・計算量・媒体14条件・ライトプロテクトの各経路はm7abの測定で否定済み。
意味が判明した場合は観測応答を廃止し、意味に基づくルール生成へ差し替える。
