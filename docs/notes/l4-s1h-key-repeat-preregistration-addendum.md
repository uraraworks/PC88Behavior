## 予備走から決めたこと

1. **遅延のおおまかな範囲**: 件数が「1」(offset=30)から「2以上」
   (offset=60で9)へ変わっているので、遅延はoffset 30〜60の間にある
   （この区間の解像度は今のところ30フレーム、以下で密に取り直す）。
2. **間隔のおおまかな見積もり**: offset=60〜450の区間（390フレーム、
   件数9→107、98回分）で線形回帰すると、間隔 ≈ 390/98 ≈ **3.98
   フレーム/回**。同区間の33個の隣接差分（例: 60→90で+7、90→120で+8…）
   がほぼ7〜8で安定しており、加速・減速は見られない（定速のリピートと
   整合）。この間隔で offset=60・450それぞれから逆算した遅延は
   28.16フレーム・28.12フレームとほぼ一致（**遅延 ≈ 28フレーム**の
   見積もりに収束）。
3. **本走のHOLDとサンプリング間隔（下記で確定）**。
4. 450フレームで件数は伸び続けており（倍のHOLDへの取り直しは不要）。

## 本走（Q1-main）のサンプリング設計（確定、以後変更しない）

- **HOLD = 400フレーム**（遅延≈28の後、約93回分のリピートを含み、
  かつHOLD終了後の「離した後」を確認できるだけの余裕を残す長さ）。
- 写し16枚（D0＋15枚）:
  - **遅延ブラケット（間隔5フレーム、7枚）**: offset 30, 35, 40, 45,
    50, 55, 60。予備走で「1→2以上」の境目が入っていたoffset 30〜60を
    密に取り直し、±15フレーム以内に絞る。
  - **間隔確認（間隔60フレーム、6枚）**: offset 90, 150, 210, 270,
    330, 390。予備走と同じ範囲を粗く再確認し、間隔の見積もり
    （≈3.98フレーム/回）を本走データでも裏づける。
  - **離した後の確認（2枚）**: offset 420, 450（HOLD=400なので、
    どちらもキーを離した後）。この2枚どうしの件数が同じなら
    `stops_on_release`、増えていれば`continues_after_release`。
- 2走（G3、決定論性）を取り、写しの時系列（各offsetの件数）が完全一致
  することを確認してから判定に使う。
