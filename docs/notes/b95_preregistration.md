# B95 事前登録：3080 の SHIFT・カナ・ファンクションキー・同時押し

記録日: 2026-11-17。[main ROM 入口仕様 1.5.1節](../spec/main-rom-entry.md#151-3080g5-実走での観測) で未確定のまま残した「空白と RETURN 以外のキー」「SHIFT・カナ」「ファンクションキー（EFC4〜EFC7 の働き）」「複数キーの同時押し」「輪が満杯のとき」を、G5 の実走で測る。公式 ROM・ゲーム由来の値、画面本文、媒体データは公開記録に含めない。

## 腕

G5 を B94 と同じ配置（3枚連結 D88 を分割し、1枚目・2枚目をドライブ1・2）で起動し、F3600 以降に次の打鍵を入れる。公式 ROM と自作 ROM（main dbe1b37）で同じ腕を走らせる。基準は無入力。

| 腕 | 打鍵 |
|---|---|
| K-A | `A` を単独で押す（300F） |
| K-1 | `1` を単独で押す |
| K-SA | SHIFT を押したまま `A` |
| K-S1 | SHIFT を押したまま `1` |
| K-KANA | カナ（ロック）を入れてから `A`、その後カナを戻す |
| K-F1 | f1 を単独で押す |
| K-SF1 | SHIFT を押したまま f1 |
| K-UP | カーソル上 |
| K-TEN8 | テンキー 8 |
| K-ESC | ESC |
| K-AB | `A` と `B` を同時に押す（押し始めは同じフレーム） |
| K-FULL | ゲームが 35CE で取り出さない間に `A`〜`Z` を連打し、輪を満杯にする（取り出しが続くなら「満杯に到達せず」と記録） |

## 記録すること（値は出さない）

3080 の各呼び出しについて、輪バッファへの積み（P+0 の更新と積んだ1バイト）、EFF9・EFFA〜EFFE・EFC4〜EFC7・E6CF への書き込み、ECDF 呼び出し時の A・BC・DE・HL を測定用コアで採る。35CE が返した A も採る。生記録はリポジトリ外にだけ置く。

公開するのは、各腕について公式と自作の次の比較だけ。

- 積んだ文字の列（積んだ回数と順）が一致するか。最初に違う1始まりの番号
- 積んだ各文字が、自作の INKEY$ 対応表（src から引く、自作の値）と一致するか。一致しない場合は「自作表に無い／自作表と違う」の区分と件数
- EFF9・EFFA〜EFFE・EFC4〜EFC7・E6CF の書き込み列が一致するか。最初に違う番号と、どの番地か
- ECDF 呼び出し時の BC・DE が、呼び出し前の値のまま（不変）か、毎回同じか、押したキーで変わるか（真偽だけ）
- K-FULL で満杯に達したか、達した後の押し始めで書いた番地の集合が満杯でない回とどう違うか（番地名だけ）

## 判定

- 一致した腕は、1.5.1節の規則がそのキーにも及ぶと記す。
- 違った腕は、測定で値の規則を特定できるかを次に決める。値そのものを写すことはしない。文字コードは自作の INKEY$ 対応表（BASIC の INKEY$ で測った既存の表）に合わせる形でしか直さない。
- G5 が使わないキー（ファンクションキー等）は、G5 での一致を「影響が出ない」ことの確認とし、働きの規則は確定扱いにしない。
