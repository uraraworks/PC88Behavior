# B93 結果：G5 の 7071 帰還直後の R は 36000 フレームまで道を変えない

実施: 2026-11-17、クラウド（公式 ROM、G5 は3枚連結 D88 を分割し1・2枚目をドライブ1・2）。手順は [事前登録](b93_preregistration.md) のとおり。公開するのは集計だけで、値・画面本文・媒体名は出さない。

- 介入なしの基準2回は、境界・main I/O・sub I/O の見出し列が一致した。
- R に 00・01・02・03・10・40・7F・80・FF を入れた9腕は、すべて帰還し、介入はちょうど1回成立し、「介入効果の比較可能」が真だった。
- 9腕とも、境界・main I/O・sub I/O の最初に分かれる件目は無し（基準と完全一致）。境界件数は全腕 71025 件で、記録はバイト単位で一致した。
- main の末尾無通信は 0 フレーム、sub は末尾 209 フレーム無通信で、全腕同じだった。

## 解釈

[方針追補8](goal-b-policy-addendum8-r-register-2026-11-13.md) は、7071 から戻った後 62 件目で公式と自作が分かれる原因を、その区間で唯一違い得る R と推定した。公式の実走で戻った直後の R を9通りに振っても道は36000フレームまで1件も変わらなかったので、**7071 帰還直後の R は分かれ目の原因ではない**。追補8の推定は否定された。

R が後の別の地点で読まれる可能性、割り込みの受理位置（ROM の処理時間の違いによる時刻ずれ）など、他の原因は未確定。打鍵なしの散発的な画面ハッシュの不一致は、この測定では説明されないまま残る。
