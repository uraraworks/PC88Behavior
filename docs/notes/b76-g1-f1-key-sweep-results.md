# B76: F1 の道で、後半のキーを大きくずらすか長く押すと自作も先へ進むかを測る — 結果

記録日: 2026-11-04
規則: [b76-g1-f1-key-sweep-preregistration.md](b76-g1-f1-key-sweep-preregistration.md) どおり。測定はクラウドの実行環境で rc=0。記録は `measurements/b76-g1-f1-key-sweep.txt`。

## 結果

| 腕 | 移る回数 公式 / 自作 | 画像 |
|---|---|---|
| D0〜D9（0〜54 フレームずらす） | 74 / 72（全部） | 違う |
| H120、H300（長押し） | 74 / 72 | 違う |
| L1（後半のキーなし） | **72 / 72** | **同じ** |

## 分かったこと

- **位相でも押す時間でもない。** ずらしても長く押しても、自作は 72 のまま
- 後半のキーを打たなければ、公式も 72 で、画像も同じになる。公式は F1 のあとのリターンかスペースに反応して `0x0E` を送り、自作の上の G1 はそのキーに反応しない

## 読み方（推定）

F1 のあとの場面で、自作の上の G1 はキーを読んでいるのに（B75 で `IN $00`〜`$09` を回している）、先へ進まない。B75 では同じ場面で `$44`・`$45`（音源）も回している。音源の割り込みか状態の読みで待ちが決まる可能性がある。B77 で、この場面の main の割り込みの受け付けを公式と自作で比べる。
