## 原因の診断（事前登録外、公式・引数なしを同条件で2回、行単位比較。値は出さず件数・行番号だけ）

- `io_log_full_sha256()`はI/Oログのファイル全体をハッシュしていたが、フロントエンド
  （`tools/harness/frontend/main.c`の見出し出力）は`rom-dir`行・`disk`行に**走ごとの
  作業ディレクトリ名（タグ入り）**を書く。そのため同一条件の2回でも指紋が必ず異なっていた。
- 診断: ログ1,426,187行のうち異なるのは2行だけ（0始まりで16・17行目＝上記パス行）。
  I/Oのデータ行は全一致——**走行自体は決定的**だった。
- **G2の「m0と指紋が異なる」判定も同じ欠陥の下では常に真になる**（どんな2走でも
  パス行が違えば指紋は割れるため）。したがって1回目のG2「到達=真」は、有効性を
  実際に確認したものではなく、**器具の欠陥がそう見せていただけ**である。
