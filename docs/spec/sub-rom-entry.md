## 0. 位置づけ

ゲームがサブ側のコードから直接使うサブ ROM 番地を示す。需要の測定と自作プローブの測定を分け、測定範囲外は確定しない。測定 ID の定義と条件は結果ノートを参照。自作サブ ROM は2KBで空きが少ないが、需要のある入口番地は固定する必要がある。配置や共通化は実装者が検討する。

## 1. 入口一覧

| 番地 | 需要の測定 ID | 働きの測定 ID | 働き・状態 |
|---|---|---|---|
| 02DB–02DC | B90（G5、サブ側 4000 のゲームコード） | — | 2バイトの番地（下位バイト先）。ゲームが間接 CALL の呼び先として使用する。値は 07D6（入口 07D6 を指す）。根拠は CALL 後に最初に入った PC の観測であり、ROM の内容を読み取っていない。 |
| 0010 | B87（G2・G5） | B88・B88-add1 | CALL/RST。main から1バイト受け A に返す。A・F以外不変。 |
| 0018 | B87（G5） | B88・B88-add1 | CALL/RST。A を main に1バイト送る。OUT $FD 1回。A・F以外不変。 |
| 0020 | B87（G5） | B88・B88-add1 | CALL/RST。FDC へ A を1バイト書く。1.1節。 |
| 00ED | B87（G2 JP） | B88・B88-add1 | FDC 初期化・シーク。1.2節。 |
| 048F | B87（G2 JP） | B88・B88-add1 | SENSE DRIVE STATUS で準備を待つ。1.3節。 |
| 06A6 | B87（G2 CALL） | B88・B88-add1 | 需要あり・働き未確定。プローブは時間上限まで戻らない。 |
| 0263 | B87（G5 CALL） | B88・B88-add1 | 需要あり・働き未確定。プローブは時間上限まで戻らない。 |
| 02A4 | B87（G5 CALL） | B88・B88-add1 | FDC へ A を1バイト書き、7F0C にも A を書く。1.1節。 |
| 02A7 | B87（G5 JP） | B88・B88-add1 | 02A4 の途中の入口。FDC へ A を1バイト書く。1.1節。 |
| 02B4 | B87（G5 CALL） | B88・B88-add1 | I/O なしの計算。1.4節。 |
| 035B | B87（G5 CALL） | B88・B88-add1 | OUT $F7 1回、その値を A で返し 7F0B に書く。1.5節。 |
| 07D6 | B87（G5 CALL・JP） | B88・B88-add1 | SENSE DRIVE STATUS で準備を待つ。1.3節。 |

0010・0018 は main が通信に応じる条件で戻る。A・F の詳細な戻り規約や通信相手が応じない場合の終了条件は未確定。

### 1.1 FDC への1バイト書込み

0020・02A4・02A7 は MSR（IN $FA）を見てから A を OUT $FB で FDC へ書き、全レジスタを保って戻る。02A4 はさらに 7F0C に入力 A を書く。測定条件では 0020・02A7 は 7F0C を変えない。02A7 は 02A4 の途中の入口である。待機条件の詳細は未確定。

### 1.2 初期化とシーク

00ED は SPECIFY・RECALIBRATE・SENSE INTERRUPT STATUS・SEEK を行う。測定条件では入力 A=0 で戻り、A=1 は時間上限まで戻らない。戻った腕のレジスタは入力によらず一定だったが、その具体値は集計にないため未確定。SP は入力と一致した。他の入力や媒体条件は未確定。

### 1.3 準備待ち

048F・07D6 は SENSE DRIVE STATUS で準備を待つ。測定で対象入口に到達した腕では、ドライブ2に媒体があるときだけ戻り、ないときは時間上限まで戻らなかった。A の意味、戻り時のレジスタ、未測定条件は未確定。前処理が戻らず入口未到達の腕は判定に含めない。

### 1.4 計算

02B4 は I/O を行わず戻る。入力 A の全256値と入力 F=00 または 01 の測定範囲では、戻り A=00、F=44。他のレジスタは入力のまま。入力 F のその他の値や他の状態での規則は未確定。

### 1.5 F7 出力

035B は OUT $F7 を1回行い、その出力値を A に返す。7F0B にも書くが、書込値の関係は未確定。BC・DE・HL は不変。測定した A=00/01/35/80/FF と F=00/01/40/FF の組合せでは戻りレジスタは基準腕と一致した。出力値の具体値と、その他の入力との関係、F の一般的な戻り規約は未確定。
