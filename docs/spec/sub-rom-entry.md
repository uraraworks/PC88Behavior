## 0. 位置づけ

ゲームがサブ側のコードから直接使うサブ ROM 番地を示す。需要の測定と自作プローブの測定を分け、測定範囲外は確定しない。第5版は G5/G2 実走と B88 追補3 の観測を区別して記す。測定 ID の定義と条件は結果ノートを参照。自作サブ ROM は2KBで空きが少ないが、需要のある入口番地は固定する必要がある。配置や共通化は実装者が検討する。

## 1. 入口一覧

| 番地 | 需要の測定 ID | 働きの測定 ID | 働き・状態 |
|---|---|---|---|
| 02DB–02DC | B90（G5、サブ側 4000 のゲームコード） | — | 2バイトの番地（下位バイト先）。ゲームが間接 CALL の呼び先として使用する。値は 07D6（入口 07D6 を指す）。根拠は CALL 後に最初に入った PC の観測であり、ROM の内容を読み取っていない。 |
| 0010 | B87（G2・G5） | B88・B88-add1 | CALL/RST。main から1バイト受け A に返す。A・F以外不変。 |
| 0018 | B87（G5） | B88・B88-add1 | CALL/RST。A を main に1バイト送る。OUT $FD 1回。A・F以外不変。 |
| 0020 | B87（G5） | B88・B88-add1 | CALL/RST。FDC へ A を1バイト書く。1.1節。 |
| 00ED | B87（G2 JP） | B88・B88-add1 | A の要求を1回処理して戻る。1.2節。 |
| 048F | B87（G2 JP） | B90 entry5・entry6（G2 実走） | 引数を受けてセクタを1つ読み、サブのバッファに置く。送信はしない。1.3節。 |
| 06A6 | B87（G2 CALL） | B88・B88-add1・B88-add2・B88-add2b | main から4バイト受信して戻る。1.6節。初回・追補1では未帰還。 |
| 0263 | B87（G5 CALL） | B88-add2b・B88-add3 | FDC の結果相を7バイト読み、7F0D〜7F13 に置く。1.7節。 |
| 02A4 | B87（G5 CALL） | B88・B88-add1 | FDC へ A を1バイト書き、7F0C にも A を書く。1.1節。 |
| 02A7 | B87（G5 JP） | B88・B88-add1 | 02A4 の途中の入口。FDC へ A を1バイト書く。1.1節。 |
| 02B4 | B87（G5 CALL） | B88・B88-add1 | I/O なしの計算。1.4節。 |
| 035B | B87（G5 CALL） | B88・B88-add1 | OUT $F7 1回、その値を A で返し 7F0B に書く。1.5節。 |
| 07D6 | B87（G5 CALL・JP） | B88-add3・B90 entry5（G5 実走） | シーク等を行う。1.3節。 |

0010・0018 は main が通信に応じる条件で戻る。A・F の詳細な戻り規約や通信相手が応じない場合の終了条件は未確定。

戻る入口は、割り込み許可（IFF1・IM）を呼出し前の状態のまま保って戻る。確認対象は0010・0018・0020・02A4・02A7・02B4・035B・0263・06A6。00ED・048F・07D6 の IFF は未確定。

### 1.1 FDC への1バイト書込み

0020・02A4・02A7 は MSR（IN $FA）を見てから A を OUT $FB で FDC へ書き、全レジスタを保って戻る。02A4 はさらに 7F0C に入力 A を書く。測定条件では 0020・02A7 は 7F0C を変えない。02A7 は 02A4 の途中の入口である。待機条件の詳細は未確定。

### 1.2 要求処理（00ED）

A に命令（要求）番号を入れて入ると、その要求を [l3-subrom](l3-subrom.md) の通常の要求処理として1回実行して RET する。G2 実走では A=06 は状態1バイトだけを main へ返し、A=12 でデータを送り戻す。G2 実走で A=06 は OUT $FD 1回の後、0x09→0x08→0x0B の順となり、[l3-subrom](l3-subrom.md) の 06 と同じ。A=00 は初期化で、B88 の測定では SPECIFY・RECALIBRATE・SENSE INTERRUPT STATUS・SEEK を行い戻った。第1版の「FDC 初期化とシーク」は A=00 の場合として訂正する。A=1 は測定時間内に戻らなかった。B88 追補3 は main 側の手順が成り立たず全腕時間切れで、器具の不足により要求内容を確認できなかった。第4版の観測はそのまま。他の条件や戻りレジスタは未確定。

### 1.3 読込みとシーク

048F は G2 実走の観測では、06A6 で受けた4バイト（B・C・D・E）を要求 02（[l3-subrom](l3-subrom.md) 1.36b節の読み）の引数としてセクタを1つ読む。順序は OUT $F8 → SEEK → SENSE INTERRUPT STATUS → SENSE DRIVE STATUS → OUT $F7 → READ DATA（256バイト）→ IN $F8 → 結果7バイトで、その後 RET する。読んだデータはサブのバッファに置くだけで、048F から送信しない。送信は要求 12 で行う。第1版の「SENSE DRIVE STATUS で準備を待つ」はこの処理の一部だったとして訂正する。

07D6 の SEEK の装置バイトは C、シリンダは D>>1（B88 追補3）。C≥04 では OUT $F8・SEEK をせず、装置バイト C の SENSE DRIVE STATUS だけを行う。一部の C では同コマンドを繰り返し時間上限に達した。D≥7F では SEEK せず、OUT $F8 は bit3 を立てた値となる。D=3F でも bit3 は立つが、境目は未確定。SEEK したプローブ腕は完了待ちで時間切れとなり、器具の条件に不足がある可能性がある。

G5 実走では OUT $F8 → SEEK → SENSE INTERRUPT STATUS → SENSE DRIVE STATUS を行い、戻り時 BC・DE・HL を保存し、A=00、Z=1、P/V=1 だった。他の条件での戻りは未確定。

### 1.4 計算

02B4 は I/O を行わず戻る。入力 A の全256値と入力 F=00 または 01 の測定範囲では、戻り A=00、F=44。他のレジスタは入力のまま。入力 F のその他の値や他の状態での規則は未確定。

### 1.5 F7 出力

035B は OUT $F7 を1回行い、その出力値を A に返す。7F0B にも書くが、書込値の関係は未確定。BC・DE・HL は不変。測定した A=00/01/35/80/FF と F=00/01/40/FF の組合せでは戻りレジスタは基準腕と一致した。出力値の具体値と、その他の入力との関係、F の一般的な戻り規約は未確定。

### 1.6 main から4バイト受信

06A6 は main から4バイトを受信すると戻る。1バイトごとの手順は、[l3-subrom.md](l3-subrom.md) 1.15節の sub 側 RECV と同じ: OUT $FF 0x0B → FE bit0=1 待ち → OUT $FF 0x0A → IN $FC → OUT $FF 0x0D → FE bit0=0 待ち → OUT $FF 0x0C。4バイト目まで受け取ると戻る。

戻り時は B=1バイト目、C=2バイト目、D=3バイト目、E=4バイト目、A=4バイト目、F=0x10。HL・SP は保存される。サブRAMへの書込みはスタックのみ。受信バイト数が4未満の場合は待ち続ける。未測定の通信条件は未確定。

### 1.7 FDC 結果相の読出し

0263 は FDC の結果相を読み、7バイトを 7F0D〜7F13 に順番に置く。B88 追補2b では各バイトについて IN $FA（MSR）を1回、続けて IN $FB を1回行った。MSR の RQM 待ちで読み直す回数は未確定。

entry6 の再照合では、戻り A = (ST0 AND 0xC0) OR ST1 OR ST2、Cy は A≠0 で1。ヘッド1の正常読みでも ST0 の HD bit が立つため、ST0 全体を OR する規則は成立しない。観測と矛盾しない ST0 マスクは 0xC0〜0xF8 の範囲に複数あり、どのビットまで含めるか未確定。P/V は A のパリティ（偶数で1）に一致する。BC・DE・HL・SP は保存された。G5 実走の正常時には Z=1・H=1 も観測した。第4版の推定「ST0 AND C0」は異常の2通りに合わないため訂正する。未測定条件のフラグは未確定。

第3版の「Cy=1、A は1バイト目で決まる」は、前回のプローブが実行相で呼んだ誤りであり、結果相の規則としては取り消す。
