## 0. 位置づけ

ゴール B の入口番地を、ゲーム実走による需要と自作プローブによる働きに分ける。測定 ID は結果ノートの定義に従う。観測の範囲外と推定は実装の確定要件にしない。自作 main ROM では需要のある番地に入口を置く必要がある。既に浮動小数点処理などがその番地を占める場合は、その処理を退かす。

## 1. 入口一覧（観測）

| 番地 | 需要の測定 ID | 働きの測定 ID | 働き・状態 |
|---|---|---|---|
| 369A | B84（G2・G5 CALL）、B86-timeline | B86、B86-add1・add2・add3 | セクタ読み書き。引数は1.1節 |
| 37C9 | B84（G2・G5 CALL）、B86-timeline | B86、B86-add1・add4・add5 | A を要求の先頭バイトとしてサブへ送る |
| 37D2 | B84（G2・G5 CALL）、B86-timeline | B86-add1・add2・add4・add5 | A を引数1バイトとしてサブへ送る |
| 3847 | B84（G5 CALL）、B86-timeline | B86・B86-add1〜add5 | サブから1バイト受け取り A に返す |
| 3391 | B84（G2・G5 CALL）、B86-timeline | B86-add1・add2（働き未確定） | 需要あり・働き未確定 |
| 3080 | B86-timeline（G5 JP） | 未測定 | 需要あり・働き未確定 |

### 1.1 369A

- B はシリンダ×2＋面、C は1始まりのセクタ番号、HL は256バイトの読み書き先。キャリー0は読み、1は書き。測定した読みの座標と HL への転送は B86-add1・add2・add3、書きの方向は B86・B86-add1 の送受信量に基づく。書き込み先媒体への格納は未確認。
- ドライブは測定した条件では常にドライブ1。自作の両面40シリンダ媒体で B を振り、他のレジスタも一部振った。RAM 介入は途中までであり、任意の状態でドライブが変わらないことまでは測っていない。
- B=80・FF および C=0 の測定腕では送信6・受信1の別経路となった。エラー応答に見えるが意味と戻り値は未確定。B≥80 全域や他の不正値は未測定。
- 戻り時のフラグ・レジスタ、エラー時の契約、未測定の入力条件は未確定。

### 1.2 37C9・37D2・3847

37C9 は A を要求の先頭バイトとして送り、37D2 は A を引数1バイトとして送る。3847 はサブから1バイト受け取り A に返す。追補5では、自作の `0C` 要求で書いた模様を `09` と4引数の後に3847を256回呼んで読み戻すと、A に引数を入れた腕で256/256一致した。C・E・L に引数を入れた腕では全体一致しなかった。戻り時の他のレジスタ・フラグは未確定。

第1版の37D2「2バイト送る」は訂正する。観測した OUT FD 2件をデータ2バイトと読み違えたもので、ハンドシェイクを含む I/O 件数と送信データ数は同一ではない。37C9 の A=01 でも OUT FD は2回観測された。

追補4では 37C9 の A=00・FF の後、37D2 の1回目が戻らなかった。A=02 では4回戻り、5回目が戻らなかった。要求の引数が揃わないうちに3847を呼んだ測定腕では戻らず、公式環境では約340〜377フレーム後に起動からやり直した。無限に戻らないとまでは断定しない。02→15 の腕で3847が128回戻った後に停止した理由は未確定。

### 1.3 ハンドシェイクとの対応

[l3-subrom 1.10節・1.15節](l3-subrom.md)の手順に照らすと、37C9 の要求先頭と37D2 の各引数は main側 SEND 1バイト、sub側 RECV（1.15節手順1〜7）の実データに対応し、3847 の受信は main側 RECV 1バイト、sub側 SEND（同節手順1〜5）の実データに対応すると推定される。入口ごとにこれらの手順との対応を直接検証したわけではなく、連続転送時の手順や切り替え条件も確定していない。詳細な待ちとフェーズは同節および1.19節を参照する。

## 2. サブ要求との対応（推定）

369A の読みは送信9・受信258、書きは送信267・受信1であり、[l3-subrom.md](l3-subrom.md) の読み出し準備と256バイト転送、または制御6バイトと256バイトの書き込み・1バイト応答に似る。しかし総件数だけでは要求の分割、見出し、座標の符号化や既存要求との同一性は決まらない。既存要求で表せると確定せず、追加測定を要する。
