## 1. グラフィック VRAM（観測）

- **3プレーン**（0＝青 B・1＝赤 R・2＝緑 G）。メイン CPU の C000〜FFFF に重なる。
  **1ライン80バイト、200ライン＝1プレーン 16000 バイト**。
- 点 (x,y) は**オフセット y×80＋x÷8、x%8==0 が bit7（左端）、MSB が左**。
  17点（(0,0)(1,0)(7,0)(8,0)(15,0)(16,0)(0,1)(0,2)(9,1)(100,100)(319,51)(320,50)
  (638,198)(639,199)(0,199)(639,0)(400,150)）が全て仮説どおりに立った。
- **色**: パレット番号 c の点は、プレーン0に c の bit0、プレーン1に bit1、プレーン2に bit2
  （**B=1・R=2・G=4**）。c=1〜7 全て一致。c=0 は何も立たない（背景色 0 に対する黒）。
- **オフセット 16000〜16383 は触らない**（一度も光らず、`cls 2`／`cls 3` の塗りも
  16000 バイトちょうどで止まる。残り 384 バイトは書き換えない）。
- **上書き**: 同じ点へ別色を `pset` すると3プレーンとも新しい色に置き換わる
  （7→2 は赤だけ残る、7→0 は消える、1→6、5→5 は変化なし）。
- **起動直後**: VRAM は全バイト 0、`OUT 0x31` の値は 0x19 のまま。

## 2. 書き込み手順（ポート。観測）

実装は「同じ画素が立つ」ことが本質。ROM を同じ I/O 列にする必要はない。
適合試験でポート値を比べる場合に限り、以下の値を合わせる。

### 2.1 カラーモード（`screen 0` 既定、0x31 bit4=1）

- `pset`／`preset` は **OUT 0x34 ← 色（0〜7。preset の既定は背景色）** と、
  **OUT 0x35 ← 0x80、0x00 の組**で VRAM に書く。0x35 の組は描画1回ごとに +1 組、
  `cls 3` の塗りでは 200 組（1ラインに1組）。
  **0x35 の組が 0x34 の前か後かは未切り分け。0x34・0x35 のビットの意味は未測定**
  （ハードウェア資料は開いていない）。
- **0x5C〜0x5E は使わない。** 事前登録の予測「カラーでも 0x5C〜0x5E のいずれかを
  書く」は外れた（予測の外れ。この件のため追補1で `pset` 1回分のポート列を採り直した）。
- 読み（`point(x,y)` 関数）は **OUT 0x5C←0, 0x5F←0x40, 0x5D←1, 0x5F←0x40,
  0x5E←3, 0x5F←0x40**（3プレーンを順に選んで読み、毎回 0x5F に戻す。値は観測のまま、
  意味づけはしない）。

### 2.2 白黒モード（`screen 1`、0x31 bit4=0）

- アクティブページ p（0〜2）が**プレーン p**（青・赤・緑）。`pset` は
  **OUT 0x34 ← 0xEF（ページ0）／0xDF（1）／0xBF（2）**（色 0 は 0xEE／0xDD／0xBB 側）。
- 色が 0 以外なら**色によらずそのページのプレーンに1ビット**（7・6・5・3・1 とも）。
  色 0 で消える。
- 読みは 0x5C／5D／5E のうちアクティブページの1つ＋0x5F。`point` は 1／0。
- `screen 1` のあと `screen 0,0` に戻すとカラーの書き方に戻る（直前に白黒で立てた
  色 5 と 3 の点は VRAM にそのまま残る）。

## 3. 表示 ON/OFF（観測）

- **グラフィック表示は `OUT 0x31` の bit3**（l1-ipl.md のポート表の GRPH）。
  `screen 0,2`・`screen 0,3`（画面スイッチ bit1＝グラフィックマスク）で
  **OUT 0x31 ← 0x11**（0x19 から bit3 を落とす）。画素は**見えなくなるが VRAM の点は残る**。
  `screen 0,0`・`0,1` はポートを動かさない（`0,1`＝高速書き込みは V1S 専用）。
  `screen 0,0` のあと 0x31 は bit0・3・4 が立つ（0x19）。
- **白黒（`screen 1`）**: OUT 0x31 ← 0x09（bit4＝0 白黒、bit3＝1 表示、bit0＝1 640×200）を2回。
  **第4引数（ディスプレイページ d）は OUT 0x53 ← 0xF0 | ((7−d)<<1)**
  （d=7→0xF0、0→0xFE、1→0xFC、2→0xFA、3→0xF8、4→0xF6、5→0xF4。bit0 は 0 のまま）。
  0x53 の画素への効果は未測定。
- 画面スイッチ 0・1 で画素は見え、2・3 で見えない（的中）。

## 4. 座標系・LP・STEP（観測）

- **画面は 640×200**。範囲内の整数座標は誤りなしで立つ（四隅 (0,0)(639,0)(0,199)(639,199) 確認）。
- **範囲外（640以上・200以上・負）は誤りなし、何も描かず、LP は指定座標へ移る**
  （巻き戻り・切り詰めなし）。
- **座標の有効範囲は −32768〜32767**。32768・−32769・65535・65536・70000・`1e10`・−1e5 は
  **ERR 6（Overflow）**で LP は直前のまま。**−32768 は受理**（予測は ERR 6 で外れ）。
- **小数は四捨五入（0.5 は切り上げ）**: (10.4,20.6)→(10,21)、(10.5,20.5)→(11,21)、
  (12.49,22.51)→(12,23)、(−0.4,24)→(0,24) は立つ、(−0.6,25)→(−1,25) は範囲外、
  (639.6,27)→(640,27) は範囲外、(28,199.4) は立つ、(29,199.6)→(29,200) は範囲外。
  LP も丸めた値。
- **STEP**: LP からの相対。`screen 0,0`＋`cls 3` 直後の LP は (0,0)。LP は範囲外へも
  進み続ける（(640,199) から `step(−1000,−1000)` で (−360,−801)）。
  `point(300,100)`（文）は LP だけ動かす、`point step(50,0)` は相対。
- **`POINT(0)`・`POINT(1)` は LP の X・Y。`POINT(2)`・`POINT(3)` も同じ値**
  （ワールド＝スクリーン）。n が 4・−1・5 は **ERR 5**、0.5 は 1 に丸まる。
- **LP の更新は座標の組を読み終えた時点**（GW-BASIC の SCAND と同じ）:
  色引数の誤り（ERR 5・13・22）や、座標の組のあとの構文誤り
  （`pset(14,40),1,2`・`pset(16,40) 3`・`pset(18,40),,`・`pset(19,40);3`）でも
  LP は新しい座標に移る。座標の組を読み終える前の構文誤り
  （`pset 12,40`・`pset(13)`・`pset(,41)`・`pset(21,)`・`pset()`・`pset`）は LP が動かない。
  オーバーフロー（ERR 6）で LP が動かないのは座標の読み取りが失敗するため。

## 5. PSET・PRESET・POINT（観測）

- **色**: 0〜7 を受理（0 は点を消す）。**−1・8・9・15・16・255・256・1000 は ERR 5**
  （点は立たず LP は新しい座標へ）。文字列は ERR 13、`1e10` は ERR 6。
  小数は四捨五入（0.4→0 で消す、0.5→1、1.5→2、2.5→3、−0.5→−1 で ERR 5）。
- **`pset` の省略色は COLOR 第4引数（前景。初期値 7）**: `color ,,,f` で f（0〜7 全て確認）、
  `color ,,,0` のあとは黒（立たない）。`color 5`（第1引数）も `color ,2`（第2引数）も
  `pset` の色を変えない。
- **`preset` の省略色は背景色（`color ,b` の b）**: 背景0なら消える、背景3なら色3で
  描く（`preset(40,10),0` は黒で穴が開く）。`preset(..),c` は PSET と同じ。
  `preset(700,10)` は誤りなし。
- **構文**: 受理は `pset(10,40)`・`pset (15,40),3`（空白可）・`pset step(17,40),4`・
  `pset(20.5,40)`。**ERR 2**: `pset 12,40`・`pset(13)`・`pset(14,40),1,2`・
  `pset(16,40) 3`・`pset(18,40),,`・`pset(19,40);3`・`pset(,41)`・`pset(21,)`・
  `pset()`・`pset`。**`pset(11,40),`（色が空）だけ ERR 22（Missing operand）**（予測は ERR 2）。
- **`point(x,y)`（関数）**: 描いた点はその色 c（1〜7 全て）、描いていない範囲内は背景色
  （背景0なら0、`color ,5: cls 3` のあとは5）、**範囲外は −1**
  （(−1,10)・(640,10)・(10,200)・(10,−1)・(1000,1000)・(−1,−1)）。小数は丸める。
  背景5の上へ `pset(..),0` したあとは 0（背景色ではなく黒）。白黒モードは 1／0。
  `point(x,y)` の文形は LP を動かすだけ。

## 6. 色と背景（観測）

- **描画色は COLOR 第4引数（前景）**。第1引数はテキストの色／ファンクションコード
  （[l4-program.md](l4-program.md) 第5.4節）でグラフィックに効かない。
- **背景は第2引数**: `color ,b` のあとの `cls 3`／`cls 2` が、b の bit0・1・2 に当たる
  プレーンを 16000 バイトだけ 0xFF にし、他のプレーンは全 0 にする（b=0〜7 全て一致）。
  `cls 1` と `color ,b` だけでは塗られない。`color ,,,3`＋`cls 3` は全 0。
- アナログパレット（`color=`）は未測定。

## 7. CLS の引数（観測）

| 文 | グラフィックの点 | テキスト | LP | 誤り |
|---|---|---|---|---|
| `cls`・`cls 1` | 残る | 消える | 変わらない | なし |
| `cls 2` | 消える（背景色で塗る） | 残る | (0,0) | なし |
| `cls 3` | 消える | 消える | (0,0) | なし |
| `cls 0` | 残る | 残る | 変わらない | **なし（受理、何もしない）**（予測は ERR 5） |
| `cls 4`・`cls -1` | 残る | 残る | 変わらない | ERR 5 |
| `cls "a"` | 残る | 残る | 変わらない | ERR 13 |
| `cls 1.5` | 消える | 残る | (0,0) | なし（2 に丸まる。予測外れ） |

## 8. SCREEN 文（測った範囲。観測）

- 形: `screen 画面モード, 画面スイッチ, アクティブページ, ディスプレイページ`。
- **画面モード**: 0（640×200 カラー）・1（白黒）・2（640×400）を受理、**3・4 は ERR 5**
  （日本語モードはこの ROM に無い）。第2引数 0〜3、第3引数 0〜2、第4引数 0〜7。
- **誤り**: `5`・`-1`・`0,4`・`0,-1`・`0,0,3`・`0,0,-1`・`0,0,0,8`・`0,0,0,-1` は
  ERR 5（LP 不変）。`1,0,2,5` は受理。`"a"` は ERR 13、`0,0,0,0,0` は ERR 2。
  小数（0.5・1.5）は受理（丸め）。**`screen`（引数なし）は ERR 22**（予測は誤りなし）。
- **LP**: モードを書いた `screen 0,0`・`1,0`・`0,1` は LP を (0,0) へ戻す。
  **`screen ,1`・`screen ,,1`（モード省略）は受理するが LP を戻さない**（予測は戻す）。
- **`screen 2`（400ライン）**: 受理、LP→(0,0)。OUT 0x31 ← 0x08（bit0＝0 で 640×400、
  bit4＝0）を2回、0x53 ← 0xF8、0x34 ← 0xEE×3, 0xDD, 0xEE×2（プレーンの初期化らしいが
  意味づけしない）。VRAM の点はそのまま。

## 9. 未測定

  効果、白黒3ページの合成表示。
- LINE・CIRCLE・PAINT・VIEW・WINDOW、`color=`（アナログパレット）、GET@／PUT@。

## 10. 自作ROMの現状（記述。s9t 時点）

引数なしの `cls` のみ受理。VRAM は起動直後から全 0、`cls 2`／`cls 3` の塗りは未実装。
