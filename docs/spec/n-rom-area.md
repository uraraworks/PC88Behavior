## 0. 根拠

[事前登録](../notes/n1-nrom-area-preregistration.md)、[結果](../notes/n1-nrom-area-results.md)、`measurements/n1/results.json`。
自作の試験ROMで7条件×2走一致。公式ROMは使っていない。

## 1. 観測 — エミュレータの事実

- N 側 ROM のファイル名は `N88N.ROM`、無ければ `N80.ROM`（大小文字の別名も読む）。libretro 版・WebQ88 も同じ名前で読む。
- 無いとき 0000〜7FFF は全部 FF。16KB のファイルなら後半 4000〜7FFF が FF。32KB を超える分は読まれない。
- N88 モードで動いている状態から、ポート 31 の bit2 を 1 にして出力すると、**次の命令から** 0000〜7FFF の読み出しが N 側に替わる。0 に戻すと元に戻る。
- N 側を選んでいる間は、拡張ROM窓（6000〜7FFF、ポート 71/32）より N 側が優先する。拡張バンクの選択状態は残っていて、N 側を外すと元の窓に戻る。
- ポート 31 は書き込み専用。`IN 31h` は DIP スイッチを返す（書いた値は読めない）。
- N 側を選んでいる間に来た IM1 割り込みは、N 側の 0038h へ入る。
- 起動時の機種設定（N88 V2・V1H・V1S・N）に関係なく、上の切り替えは同じに働いた。

## 2. 観測から導いた実装上の要件

1. **切り替えて呼び、戻す中継は RAM に置く。** 0000〜7FFF に置くと、切り替えた瞬間にその中継自身が消える（拡張窓の要件1と同じ理由）。
2. **ポート 31 に書く値の写しを RAM に1か所だけ持ち、31h へ書く経路はすべてその写しを通す**（`SCREEN`・`WIDTH` など既存の 31h 書き込みも含む）。N 側への切り替えは「写し | 04h」を、戻すときは「写し」を出す。
3. **N 側の 0038h には割り込みの入口を置く。** 入口は RAM の中継へ飛び、中継が N88 側へ戻して main の割り込み処理を呼び、終わったら N 側へ戻して `RETI`/`EI:RET` する。N 側のコードは割り込みを禁止して走る設計にはしない（キー入力・VSYNC の取りこぼしを避ける）。NMI（0066h）も同様に入口を置く。
4. **N 側のコードから main のルーチンを呼ぶときは、RAM の中継を通す**（中継が N88 側へ戻し、main のルーチンを呼び、N 側へ戻す）。N 側から 0000〜7FFF の番地を直接 `CALL` しない（N 側の内容が実行される）。
5. N 側を選んでいる間は拡張ROMバンクを呼ばない（N 側が窓を覆うので、バンクの内容は見えない）。main の中継を通して N88 側に戻った後なら拡張バンクを呼んでよい。
6. RAM の中継とスタックは 8000h 以上に置く（N 側への切り替えで消えない場所）。
7. N 側の ROM が無いとき（FF）を起動時に検出し、N 側に置いた命令は 5（Illegal function call）にする。N 側に依存する機能が無いだけで、BASIC の他の部分は動く。

8. **中継の RAM は他のどの作業域とも重ねない**（`memmap.py` の OVERLAPS に入れない）。N 側のコードや、そこから呼ぶ main のルーチンは数値演算・文字列などの一時域を使うので、重ねると実行中の中継が書き換わる。空きが少ないので、中継は必要最小限（main→N の呼び出し口と、その戻り）にする。
9. 割り込みの入口（要件3）は、RAM 中継を経ずに、**main の割り込み処理と同じコードを N 側の 0038h・0066h へ複製**してもよい。複製する処理と、そこから呼ぶルーチンは RAM とポートだけを触り、拡張バンクを呼ばないこと。状態は RAM にあるので両側で共有される。
10. N 側から main のルーチンを使う（要件4）代わりに、**そのルーチンを N 側にも複製して直接呼んでもよい**（N 側は 32KB あり容量に余裕がある）。複製したルーチンは拡張バンクを呼ばないこと。

## 3. 未確定

- DIP の bit2 を変えた起動での挙動（bit0 は両値で確認、bit2 は未測定）。
- N 側を選んでいる間の DMA・テキストVRAM（F000〜）への影響（8000h 以上は切り替わらないと置く。観測は 0000〜7FFF の範囲だけ）。
